# 破除线性成长幻觉

## 一句话定义

把人生想象成永远向上的直线是工业文明与资本算法强加的幻觉，天地万物皆循周期起伏，人不必要求自己永远高效笃定。

## 详细说明

工业文明把人异化成机器，资本算法把人驯化成指标。现代社会叙事里，人生似乎必须是一条永远向上的直线：二十岁必须锋芒毕露，三十岁必须成家立业，三十五岁必须财富自由；状态必须永远饱满，工资必须季度环比增长。

但抬头看天地，没有任何东西沿直线永远生长：

| 现象 | 规律 |
| --- | --- |
| 太阳升到最高点 | 必定开始西斜 |
| 月亮圆到最满时 | 必定开始亏缺 |
| 草木盛夏狂放绽放 | 深秋枯黄，严冬把水分养分抽回根部 |

道德经讲「飘风不终朝，骤雨不终日。孰为此者？天地。天地尚不能久，而况于人乎？」连天地都无法维持永恒的狂风暴雨，人却要求自己一年三百六十五天处于亢奋、笃定、高效的状态，这是把幻觉当标准，再用它来审判自己。破除这一幻觉，是接受「冬天也是一种生长」的前提。
