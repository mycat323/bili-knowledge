# 停止审判过去的自己

## 一句话定义

永远不要用后来的认知去审判当年的选择，因为在那个具体节点上，你的决定几乎就是当时能力边界内的必然结果。

## 详细说明

很多人每天拿着现在的认知，像无形的皮鞭一样抽打过去那个弱小无知的自己。要终止这种内耗，第一步是彻底停止倒果为因，赦免过去的自己。

核心逻辑：你现在回头看觉得蠢，是因为你站在结果明朗的今天；而在五年前、十年前那个具体节点上，以你当时掌握的信息、身处的环境和有限的阅历，你所做出的决定几乎就是你当时能力边界内的必然结果。

毛主席在《反对本本主义》中反复强调，脱离具体历史条件的评判没有任何意义。既然当年的选择受限于客观条件，那么无休止的悔恨就是最无意义的情绪宣泄。

可操作的做法：

1. 承认当年的局限，原谅当年的笨拙；
2. 把被过去死死套牢的注意力赎买回来，专注解决当下的生存与发展；
3. 把「我当初怎么那么傻」换成「以当时的条件，我还能怎样」。

逼过去的自己未卜先知，是对唯物主义最大的背叛。
