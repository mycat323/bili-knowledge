# 群众路线：把焦点从自己转到别人

## 一句话定义

社交紧绷源于注意力全部聚焦在自我监控上，用调查研究把焦点转向他人，紧张感会瞬间消失。

## 详细说明

毛选智慧中最具生命力的法宝是群众路线：从群众中来，到群众中去。

为什么你一社交就浑身紧绷？因为注意力一直死死聚焦在自己身上：我手放这里自不自然？我这句话是不是说得太蠢？我脸上的表情是不是很僵硬？主意识全部被自我监控占满，根本没有多余注意力处理外界信息。

下次进入任何社交场合，强迫自己执行毛主席在《反对本本主义》里的绝招——调查研究：

- 走进房间不要管自己是什么状态，把眼睛看向别人
- 看张三今天穿的衬衫是什么颜色，他的神态是疲惫还是兴奋
- 看李四进门时是不是叹了口气，他遇到了什么麻烦
- 听别人说话时，全身心去听他字面背后的诉求，而不是在脑子里演练自己下一句该怎么接

当你把注意力从「我表现得好不好」切换成「对方现在需要什么、对方处于什么状态」时，紧张感会瞬间消失。因为人的大脑无法同时处于深度观察和极度自我焦虑之中。你走进了群众，就忘记了那个虚妄的自我。
