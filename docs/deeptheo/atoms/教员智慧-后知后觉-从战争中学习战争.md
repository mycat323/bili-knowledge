# 从战争中学习战争

## 一句话定义

读书是学习，使用也是学习，而且是更重要的学习，人不可能在岸上看会游泳，也不能靠彻底避开风险获得真正的智慧。

## 详细说明

很多人在经历几次后知后觉的打击后走向另一个极端：因为害怕犯错，干脆不敢做任何决定，试图躲在房间里把一切想透了、看穿了再迈步。

毛主席在《中国革命战争的战略问题》中早已给出答案：读书是学习，使用也是学习，而且是更重要的学习。从战争中学习战争，这是我们的主要方法。

推论很直接：

- 你永远不可能在岸上看会游泳；
- 你也不可能在彻底避开风险的真空里获得真正的智慧；
- 不要怕摔跤，要怕的是因为害怕摔跤而原地踏步。

可操作的做法：用极小的成本去尝试，主动接收现实世界的一手反馈，在动态推进中修正方向。只有在不断实践中，感知事物本质的速度才会越来越快，被现实打耳光的频率才会越来越低。

人生的核心命题从来不是追求虚妄的永不犯错，而是缩短从实践到认识的时间差。
