# 复盘三问

## 一句话定义

摔跟头后拿出一张纸逼自己回答三个只谈事实不谈情绪的问题，把一次痛苦经历转化为两三条扎扎实实的行事准则。

## 详细说明

摔了跟头之后，有人只留下痛感，有人却留下经验。分水岭在于有没有完成一次严苛冷静的复盘。

具体方法：一旦在工作或生活中搞砸一件事，不要急着自责，拿出一张纸，逼自己回答三个极其现实的问题：

1. 在这个事件中，哪些客观规律是我之前完全忽视或者误判的？不要谈情绪，只谈事实。
2. 我的主观决策是在哪一个具体环节脱离了客观实际？是高估了自己的能力，还是低估了事情的难度？
3. 如果下一次面对同样的局面，我的第一道防线应该设在哪里？

当你能把一次痛苦的经历转化为两三条扎扎实实的行事准则时，这次失败的价值就已经超越了它带来的损失，你的后知后觉才没有白白发生。

这套机制的本质，是缩短从实践到认识的时间差，把每一次迟来的明白尽快淬炼成下一次行动的底牌。
