# 局部主动战三标准

## 一句话定义

在全局劣势下集中力量于极小局部夺取主动，用三个标准筛选出一场百分之百能赢的主动进攻战。

## 详细说明

毛主席在《中国革命战争的战略问题》中给出弱者破局的法则：在全局处于劣势的条件下，集中兵力在局部夺取优势和主动。对应到普通人，就是「伤其十指不如断其一指」——不需要全面反抗生活，只需在每天二十四小时的夹缝里划出一个极小的局部战场。

一场合格的局部主动战必须同时满足三个标准：

| 标准 | 含义 | 例子 |
| --- | --- | --- |
| 主动发起 | 不是老板交代、不是家人催促，是自己决定 | 自己定下睡前读书 |
| 规模极小 | 确保百分之百能赢 | 只读二十分钟、只快走两公里 |
| 结果可见 | 产生清晰可感知的微小成果 | 干净的桌面、写了字的纸、走完的步数 |

微小胜利的真正意义不在于成果大小，而在于对神经系统做了一次「去奴化训练」：完成瞬间，你用铁一样的事实告诉潜意识——在这漫长被动的一天里，至少有三十分钟，我不是在应付外部环境，在这块小阵地上我才是最高指挥官。口子一旦撕开，生活不可抗拒的虚幻压迫感就会出现裂缝。

常见误区是把改变想得太宏大，觉得必须辞职换赛道、明天脱胎换骨，结果还没开始就被无力感劝退。
