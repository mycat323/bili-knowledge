# 后知后觉是认识常态

## 一句话定义

人对客观现实的真正理解总是滞后于亲身实践，先知先觉只是站在结果明朗的终点回望过去时产生的唯心妄想。

## 详细说明

很多人痛苦，是因为默认了一个「天才假设」：高手走第一步时就看清了第一百步。事实并非如此。

《毛选》的唯物主义认识论指出，认识来源于实践，并且往往滞后于实践。事物内部错综复杂的利益关系与运行法则，在刚开始时大多是隐蔽的、伪装的，只有在运转过程中充分暴露出来、撞痛了你，认知才能完成从感性到理性的关键一跃。

党史就是最好的例证：1921年建党时没人知道中国革命的具体道路，全党照搬苏联经验集中攻打大城市，直到1927年大革命失败、南昌起义与秋收起义接连碰壁，队伍只剩几百几千人，才在残酷失败中接受了「农村包围城市，武装夺取政权」。1962年七千人大会上，毛主席自己说，经过两次胜利、两次失败、两次比较，党才真正认识了中国革命的客观规律，他自己也是碰了很多钉子、打了败仗之后才知道怎么打仗的。

一个政党探索正确道路尚且需要十几年摸索，普通人凭什么要求自己二十出头就洞察人性？把后知后觉当成罪过，是对客观规律的无知。
