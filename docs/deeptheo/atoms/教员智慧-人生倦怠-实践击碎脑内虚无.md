# 实践击碎脑内虚无

## 一句话定义

一切真知和力量来源于主体与客观物质世界的直接相互作用，脱离具体实践的思想会滑向空转与虚无。

## 详细说明

《实践论》揭示：一切真知和力量都来源于主体与客观物质世界的直接相互作用。主观认识一旦脱离具体实践，思想就会滑向唯心主义的空转与虚无。

很多年轻人的倦怠根源在于大脑严重悬空：天天坐在办公室吹空调、盯屏幕、敲键盘、处理报表消息，脑子里全是互联网信息，但手和脚一整天没碰过真实的物理世界。人长期脱离真实的物质阻力，神经系统必然钝化麻木。毛主席当年在延安亲自开荒种菜、在苏区亲自下田调研，正是清楚精神力量必须从现实和具体的劳作中汲取。

三条可动手的实践路径：

1. 做具体的劳动：脑子乱时去菜市场买菜、切肉下锅做一顿热饭，或打盆水把落灰的角落擦干净。
2. 做具体的输出：停止在脑子里推演宏大人生构想，拿笔在纸上拆解一个具体问题，或用学到的知识做出一个简陋但能实际运行的工具。
3. 做具体的接触：停止在社交媒体参与宏大叙事争吵，去倾听同事的真实疑惑、帮朋友搬一次家、观察楼下早餐摊老板的营生。

真实的物理世界有阻力，但唯有这种实在的阻力，才能把悬空在大脑里的迷茫和虚无砸得粉碎。用双手克服具体阻力并创造出可感知的变化时，神经系统会从麻木中复苏。
