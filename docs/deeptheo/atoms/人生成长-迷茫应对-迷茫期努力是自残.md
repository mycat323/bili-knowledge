# 迷茫期乱抓是自残

## 一句话定义

方向失真、内心浑浊时的拼命努力不是自救而是自残，如同在悬崖边加速冲刺，无序碰撞只产生热耗做不出有用的功。

## 详细说明

人在迷茫时最本能的反应是恐慌性乱抓：到处看别人的经验、找人倾诉、跟风考证创业。折腾一圈后精力耗尽、时间花掉，迷茫不但没散反而更看不清未来，还陷入深深自责。

易经说：「无妄之往，何之矣？天命不佑，行亦哉。」当方向已经失真、内心已经浑浊，所有狂奔不过是在悬崖边加速冲刺。在物理学上这叫布朗运动——无序碰撞只产生热耗，做不出任何有用的功；在天地规律里，这叫违逆天时、强行造作。

这背后是被效率绑架的社会叙事：所有人都在告诉你，只要你在跑就是进步，只要停下来就会被时代淘汰。但古人早已看穿这层妄念。迷茫时最该学习的对象不是某个世俗成功的商业大佬，也不是朋友圈里光鲜的同龄人，而是育养你却从不喧嚣的天与地。
