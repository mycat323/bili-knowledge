# 根据地是固定时间结构

## 一句话定义

日常生活中不受任何人干扰、属于自己的固定时间结构，是抵御外界消耗的战略纵深，让主动权有扎根的土壤。

## 详细说明

打完一场局部主动战后，多数人会掉进第二个陷阱：今天心情好学半小时，明天加班累瘫又连刷几天手机，接着陷入自责。这种靠一时热血、今天冲锋明天溃退的状态，毛主席在《井冈山的斗争》里称之为流寇主义——没有阵地，到处游荡，打到哪算哪，士气全凭情绪支撑，遇到风浪就树倒人散。

秋收起义后，毛主席坚决不去打大城市，转兵井冈山，核心逻辑是：在敌强我弱的长期对峙中，弱者必须先有一块属于自己的立足之地。

你的根据地就是日程里一段不受干扰的固定时间：可以是早上起床后的半小时，也可以是睡前的一小时。在这个时间段立一条铁律——手机扔到一边，切断无聊信息，只做有积累的事：读一本难啃的书、打磨一项职业技能、复盘一天的得失。

根据地不需要大，关键在于确定性。外面世界高度混乱、充满意外，但只要每天有这四十分钟可以退守，生活秩序就稳固：白天工作再厌烦、老板的话再难听，那不过是在外线跟敌人周旋；到了晚上，我依然有一块没人能染指的根据地。有了它，心气才有扎根的土壤，才算拥有抵御漫长消耗的战略纵深。
