# 乾卦潜龙勿用：蓄力

## 一句话定义

潜龙勿用不是消极认命，而是承认自己是龙、只是时机未到，核心修行是隐忍与蓄力，不向外界证明自己。

## 详细说明

易经乾卦初九「潜龙勿用」，常被误读为消极避世、叫自己认命别折腾。关键在词的前半部分：你是龙，不是泥鳅，也不是草履虫。潜是潜伏在深渊之底；勿用是因为时机未到、羽翼未丰、天时不合，此时强行出头只会被风浪打得粉身碎骨。

迷茫的本质，就是你正处于潜龙阶段。这个阶段的核心修行只有两个字：隐忍与蓄力。

- 别去向任何人证明自己，别在乎外界的眼光和评判。
- 甘于寂寞，甘于坐在冷板凳上，默默吞咽所有委屈与迷茫，把它们全部化为腹中的龙珠。

那些在深渊里没有把你吞噬的黑暗，终将成为你未来腾空而起时最好的背景布。乾卦的后续阶段是九二「现龙在田」与九五「飞龙在天」：露出地面后要莫贪大、莫求速，像呵护初生婴儿一样呵护每一次极小的正向反馈；而飞龙在天的腾飞从来不是在迷茫期咬牙切齿挣扎出来的，是潜龙阶段耐住严寒、守住本心之后天地自然回馈的水到渠成。
