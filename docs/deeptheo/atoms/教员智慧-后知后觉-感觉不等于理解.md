# 感觉不等于理解

## 一句话定义

感觉到了的东西不能立刻理解它，只有理解了的东西才能更深刻地感觉它，道理必须与切身利害剧烈碰撞才会真正被读懂。

## 详细说明

为什么父母讲过的道理、书本上写过的道理，甚至背得滚瓜烂熟，却一定要被现实摔得鼻青脸肿之后才真正醒悟？

《实践论》给出的答案是：感觉到了的东西我们不能立刻理解它，只有理解了的东西才更深刻地感觉它。

十八岁时听长辈说「人际关系本质是价值交换」「选择比努力重要」「身体是一切的本钱」，你确实感觉到了这些话的存在，但它们只是挂在嘴边的词句、飘在半空的概念，没有进入你的现实世界，没有跟你的安全与利益产生剧烈碰撞，因此不可能真正理解。

必须亲自在职场上因轻信别人而替人背一次黑锅，必须亲自在深夜看着空空如也的银行账户体会为尊严低头的窘迫，必须亲自在某个项目上拼尽全力却因大势已去而血本无归——在那些具体的窒息感和无力感落到身上的瞬间，轻飘飘的大道理才突然有了千钧重量。

这就是「感觉」与「理解」的区别：前者是词句的存储，后者是利害的刻痕。
