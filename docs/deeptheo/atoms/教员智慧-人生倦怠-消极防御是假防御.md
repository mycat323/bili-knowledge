# 消极防御是假防御

## 一句话定义

长期被动应付外界刺激、只招架不还手的生活状态，看似在防御实则持续消耗，是倦怠与消沉的真正根源。

## 详细说明

毛主席在《中国革命战争的战略问题》中指出：消极防御实际上是假防御，只有积极防御才是真防御，才是为了反攻和进攻的防御。

把这条军事原理对照日常生活，会发现结构完全一致：

| 战争中的消极防御 | 生活中的消极防御 |
| --- | --- |
| 敌人打哪我防哪 | 闹钟响才起、消息来才回 |
| 没有自己的战略意图 | 没有自己主动发起的事 |
| 只有招架之功 | 一整天都在回应外界刺激 |

关键判断标准：你做的事里，有没有一件是出于自己意志主动发起、独立推进、并拿到真实结果的。如果一件都没有，你就是在打一场漫长而绝望的消极防御。

很多人误以为倦怠是体力透支，于是选择躺平休息。但躺平仍在消极防御框架内——肉体不动，心智仍在焦虑周一的例会和下个月的业绩，只是抱着头缩在战壕里等下一轮炮弹。结果是越休息越虚弱，越虚弱越想逃避，形成恶性循环，把仅存的心气抽干。
