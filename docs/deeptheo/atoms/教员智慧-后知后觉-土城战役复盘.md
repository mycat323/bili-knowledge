# 土城战役复盘

## 一句话定义

土城战役因情报误判陷入苦战，毛主席当即撤出战斗并当晚总结三条教训，正是这次急速复盘才有了后来的四渡赤水。

## 详细说明

遵义会议之后，毛主席重新指挥红军，在贵州土城试图围歼尾随而来的川军。由于情报侦查出现严重偏差，把对方四个团的人数错估成两个团，且低估了川军的战斗力与装备。战斗一打响，红军不但没能吃掉敌人，反而陷入极其被动的苦战，伤亡惨重。

如果换做一个被虚荣心和悔恨绑架的人，刚重新掌握指挥权就遭遇大挫折，很容易陷入「我到底行不行」的恐慌，或为了面子硬拼自尊。

毛主席的做法是：战斗不利，没有半点犹豫，立刻决定撤出战斗。撤到赤水河边后，当天晚上就召集干部，极其冷静地总结了三条教训：

1. 对敌情判断不准；
2. 对地形利用不够；
3. 没有集中绝对优势兵力。

既然正面强攻不行，就绝不意气用事，果断决定全军脱离接触，西渡赤水河。正是有了对土城失利的急速复盘与战术修正，才有了后来彻底甩开国民党几十万大军的四渡赤水。

在真正的高手眼里，挫折从来不是终点，每一次撞墙都是现实在校准你脑海里的方向。
