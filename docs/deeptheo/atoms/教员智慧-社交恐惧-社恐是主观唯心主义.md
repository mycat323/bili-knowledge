# 社恐的哲学根源是主观唯心主义

## 一句话定义

社交恐惧的哲学根源是主观唯心主义：脱离客观现实，把自己的主观意识当成宇宙核心，误以为全场目光都在审判自己。

## 详细说明

很多人以为社恐是性格内向、情商低、天生懦弱，于是拼命学高情商沟通技巧，结果一到现实场景脑子还是一片空白。问题出在病根没挖出来。

毛主席在《实践论》《矛盾论》里反复批判一种人叫主观唯心主义者：脱离客观现实，把自己的主观意识当成宇宙的核心，认为世界围绕自己的意志运转。

套到社交场景：你怕别人觉得你穿得土，怕别人看出你声音紧张，怕领导觉得你汇报逻辑有错。在你的认知模型里，你一走进房间，所有人的目光就都落在你身上，每个人都在观察你的一举一动，等着发现你哪里不够好。

用唯物主义的事实说话：坐在你对面的领导正为下个月部门业绩和自己的房贷焦头烂额；旁边看似光鲜的同事正忍着胃痛想今晚要不要去医院；聚会上高谈阔论的人心里也在打鼓，生怕别人看穿他吹的牛皮。大家都在自己的泥潭里挣扎，没有一个人有闲心审判你。

所以你的窒息和恐惧不是外在环境给的，是脑子里那个唯心主义小剧场凭空捏造出来的。你不是怕别人，是被自己膨胀的自我意识吓瘫了。
