# 自力更生：把表演型社交换成价值型交换

## 一句话定义

把社交当乞讨必然产生恐惧，因为主动权在对方手里；深耕核心价值、从求认可切换为做交换，社交姿态才能堂堂正正。

## 详细说明

毛主席在延安大生产运动中提出四个字：自力更生。

社恐的人之所以在人际关系里觉得弱小无助，是因为潜意识里把社交当成了乞讨：我希望能得到你的认可，我希望你能觉得我幽默，我希望你能接纳我进入你的圈子。只要你把自己放在索取者的位置上，就必然产生恐惧——给不给的主动权在对方手里，你永远处于被动挨打的状态。

毛选智慧告诉你，真正的关系从来不是求来的，是靠自身硬实力吸引来的。你在社交场合不需要八面玲珑，不需要会讲段子，不需要假装外向，只需要做一件事：深耕你的核心价值。

- 如果你是技术专家，你能解决别人解决不了的专业问题
- 如果你是靠谱的执行者，任何事情交到你手里都能事事有回音
- 如果你是情绪稳定的人，别人跟你待在一起就觉得如沐春风

当你有了这种根据地式的核心价值，根本不需要在酒桌上强颜欢笑、敬酒陪笑脸。从求认可切换为做交换，从表演者切换为生产者：你不是去讨好谁的，你是带着独特价值去跟客观世界做平等的资源互换。这时候你的社交姿态就是堂堂正正、不卑不亢。
