# 心气是主动发起的能力

## 一句话定义

心气不是高昂情绪或一时亢奋，而是一个人主动发起生活、独立推进并做成事情的能力，靠主动做工获得的正向反馈滋养。

## 详细说明

多数人把心气理解成一种情绪：看完励志电影后的冲动、亢奋、热血。这种理解下的心气最多维持三天，现实冷水一泼就跌回更深的虚无。

心气的真正定义是主动发起的能力。判断一件事是否属于「主动发起」，看四点：

1. 不是环境逼我做的，不是别人要求我做的，外界甚至可能根本不在乎；
2. 基于自己的理性判断和对客观规律的认识，自己决定做；
3. 自己制定步骤、调动资源去克服阻力；
4. 最终把它做成。

哪怕事情极小——把凌乱的书桌彻底收拾干净、关掉手机写完一页读书笔记、换上鞋跑完既定的三公里——只要由你主动发起，你就在那一瞬间从被动挨打的受害者切换成调兵遣将的指挥员。大脑接收到的信号随之反转：这个世界不是铁板一块，我对生活拥有局部的掌控权。

《论持久战》中说，做或行动是主观见之于客观的东西，是人类特殊的能动性，名之曰自觉的能动性，是人之所以区别于物的特点。这就是心气的源泉：人不能活得像一件家具、像一个齿轮，必须通过自觉的主观能动性去撞击外部世界。
