# 改变社恐要经历持久战三阶段

## 一句话定义

性格重塑不可能一蹴而就，必然经历战略防御、战略相持、战略反攻三个阶段，每个阶段有各自的核心任务。

## 详细说明

毛主席在《论持久战》中提出的框架，用来解决人性的弊端同样精准。任何一场深刻的变革都绝不可能一蹴而就，必然要经历三个阶段。

**战略防御阶段：保存自己，允许笨拙。** 刚开始尝试改变时，过去几十年的恐惧惯性依然是绝对优势力量，你一定会被打得节节败退：跟同事打招呼声音小得像蚊子，开会发言手抖得连稿子都拿不稳，回去后忍不住自责。这个阶段的核心目标不是全歼敌人，而是保存自己——不因为一次结巴就全盘否定自己的人格，不因为一次冷场就判定自己是废物。允许自己笨拙、脸红、手抖。每一次在恐惧面前没有转身逃跑，而是在原地多站了十秒钟，都是在消耗恐惧的有生力量。只要不自暴自弃，你就是胜利者。

**战略相持阶段：建立阵地，塑造脱敏。** 遇到打招呼的场景依然会紧张，但那种紧张不再让你难堪；说错一句话，自我审判还是会出现，但五分钟后就想通了，不再因此失眠三天。你在两三个知心朋友或熟悉的工作领域里，已经能建立起舒适自洽的小型根据地。这个阶段最忌讳心浮气躁，不要强迫自己立刻变成社交高手，老老实实守好阵地：今天多跟保洁阿姨说一声谢谢，明天多跟电梯里的邻居点一次头。微小的胜利积累起来，就是量变到质变。

**战略反攻阶段：从对抗到本能。** 标志不是你变得多么能说会道，而是你彻底不在乎了。走进任何豪华会场、面对任何位高权重的人物，内心波澜不惊；聚会上不想说话时可以安静坐在一旁吃水果，没有任何尴尬和自责。别人夸你，坦然接受；别人冷落你，淡淡一笑。
