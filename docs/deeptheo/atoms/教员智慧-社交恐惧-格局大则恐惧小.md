# 格局有多大，恐惧的空间就有多小

## 一句话定义

克服社恐的终极解药不是变得外向，而是用彻底的唯物主义砸碎虚妄枷锁，让心里装着真实的客观世界和广阔的奋斗目标。

## 详细说明

很多人以为克服社恐的解药是变得外向，拼命逼自己去迎合别人、强颜欢笑，结果把自己搞得心力交瘁，这叫南辕北辙。

毛选智慧给出的答案完全不同：克服社恐的终极解药从来不是变成另一个人，而是用最彻底的唯物主义把套在自己脖子上的虚妄枷锁狠狠砸碎。

内向从来不是缺陷。毛主席年轻时在湖南求学，为了锻炼专注力和心力，常常一个人跑到最繁华喧嚣的长沙城南门闹市读书。他同样不热衷于无意义的客套应酬，但他心中装着救国救民的伟大实践，眼里看着劳苦大众的真实生活。当一个人的心里装着真实的客观世界、装着广阔的奋斗目标时，他根本没有空去在乎身边某个路人看他的眼神是赞许还是嘲弄。

你的格局有多大，你的世界里属于琐碎恐惧的空间就有小。

毛主席在《湘江评论》创刊宣言里写过：天下者我们的天下，国家者我们的国家，社会者我们的社会，我们不说谁说？我们不干谁干？这个世界不是某几个领导的，不是某几个外向者的，更不是那些高高在上之人的，它属于每一个真实活着的普通人。

下一次再感到心跳加速、手心冒汗时，在心里默念：他是肉体凡胎，我也是肉体凡胎；他不是神，我也不是犯人。彻底的唯物主义者是无所畏惧的。
