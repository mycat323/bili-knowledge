# 社恐本质是一场隐秘的精神自恋

## 一句话定义

社恐看似自卑，实则是一种极度向内膨胀的精神自恋：把自己看得太重，才会觉得全世界都在审判自己。

## 详细说明

很多人一听「社恐是自恋」第一反应是不服气：我明明觉得自己不如别人，长相普通、嘴笨不会说话，自卑得要死，怎么能叫自恋？

关键在于区分两种自我关注。自卑和自恋在这里是同一枚硬币的两面：都建立在「我很重要」这个前提上。你之所以怕别人评价你，是因为你默认自己值得被全场评价。

用唯物主义的事实检验一下：别人下班回到家，洗着澡吃着饭，脑子里还在回味你今天下午那句磕磕绊绊的发言吗？不会。每个人都被自己的现实问题占满了。

所以「当你把自己看得太重的时候，全世界都在审判你；当你真正承认自己不过是沧海一粟，承认自己只是个普通人的时候，枷锁瞬间就碎了」。

这不是让你自我贬低，而是把自我放回客观尺度：你既不值得被全场审判，也不值得被全场崇拜，你只是人群中的一个普通人。这个认知一旦落地，社交中的窒息感就失去了燃料。
