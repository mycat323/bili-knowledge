# 绝境中收缩战线

## 一句话定义

当宏观主动权被外部彻底剥夺时，把战线收缩到唯一还能控制的狭小范围，在其中重建绝对主动权。

## 详细说明

1932年10月宁都会议后，毛主席红一方面军总政委职务被撤销，军事指挥权被剥夺，被批评为「山沟里的狭隘经验论」，同时身患恶性疟疾持续高烧，躺在长汀医院的担架上，身边冷冷清清。

换成普通人，大概率是万念俱灰、长吁短叹、埋怨不公，在憋屈中把精神耗光。但他的做法是：绝不打消极防御，立刻把战线收缩回来，在自己唯一还能控制的狭小范围里重新建立绝对的主动权。

- 既然不能指挥打仗，中央安排他抓政府和查田工作，他就把全部精力扑在上面；
- 1933年秋天身体稍恢复，就带着两三个人挽起裤腿走进江西长冈乡和福建才溪乡；
- 坐在农民门槛上挨家挨户调查：一口井怎么挖、一亩地收多少谷子、生了几个孩子、办了几个合作社，甚至记录一个贫农家庭一年吃多少盐、买几尺布；
- 在看似毫无光彩的农村基层，写出《长冈乡调查》和《才溪乡调查》。

这套打法的硬核之处在于：大局由不得我，这是客观现实；但我今天迈出哪只脚、调查清楚哪一个具体问题，由我说了算。他没有等环境变好，也没有跟人打嘴仗，而是通过扎进最真实的泥土、对具体问题的绝对掌控，让心智始终处于主动进攻状态。后来他写下「踏遍青山人未老，风景这边独好」，不是盲目乐观，而是把主动权重新攥在手里之后对规律的笃定。
