# 零元AI视频课报名体验

## 一句话定义

零元AI视频课程以免费报名、免费提供AI工具和内部接单渠道为卖点，通过手机号加微信、填写入学登记、定制一对一学习计划的方式完成入学。

## 详细说明

这类课程的报名流程通常是：先在平台看到宣传（如宣称新手学十五天就能接单、做得好可能月入五万），然后零元报名，输入手机号并添加微信，接着填写入学登记表，机构再给出所谓「一对一定制学习计划」，并约定固定上课时间（案例中是周五和周末晚上七点到九点半）。

课程方强调的三大卖点是：

| 卖点 | 具体内容 |
| --- | --- |
| 零元学费 | 不用花钱就能直接学 |
| 工具免费 | 所有AI工具由课程方免费提供 |
| 接单渠道 | 提供内部接单渠道，号称外部找不到 |

需要注意的是，宣传中的「月入五万」「十五天接单」属于招生话术，实际收益需要自己验证。案例作者正是抱着「试一个月，没赚到钱就避雷」的心态报名的。
