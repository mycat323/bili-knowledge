# 零元AI影视课报名流程

## 一句话定义

零元AI影视课通过B站引流，用户输入手机号添加微信、填写入学登记，再由老师一对一制定学习计划并安排固定上课时间。

## 详细说明

作者亲测的报名路径分四步：

1. **引流入口**：课程在B站爆火，宣传语包括「新手学十五天就能接单」「做得好可能月入过万」。
2. **零元报名**：确认报名页面确实不收费，只需输入手机号。
3. **添加微信**：加微信后填写入学登记表。
4. **一对一制定计划**：老师根据个人情况安排上课时间，作者被安排的是周五和周末晚上七点到九点半。

课程方承诺的配套资源有三项：所有AI工具免费提供、提供内部接单渠道、课上可连线老师一对一解决问题。作者强调自己报名的动机正是「零元课+免费工具+内部接单渠道」这套组合，并给自己设定了一个月的验证期——如果一个月没接到单赚到钱，就当避雷。
