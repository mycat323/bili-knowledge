# AI视频接单渠道与甲方选择

## 一句话定义

AI视频接单的甲方按体验排序为外企最好、国企次之、大型私企和个人尚可、市级企业小老板最差，熟练后每天两三个小时即可完成商单。

## 详细说明

作者根据实战经验，把AI视频接单的甲方分成几档：

| 甲方类型 | 特点 |
| --- | --- |
| 外企 | 最好接，事少，给钱爽快 |
| 国企 | 钱多，但规矩和忌讳多 |
| 大型私企、个人 | 也不错 |
| 市级企业小老板 | 一般只赚一两千，事情多还喜欢挑刺，能不接就不接 |

接单渠道方面，作者提到完成AI商业应用课程后可以直接在内部接单渠道接到各种单子，也可以通过平台接触甲方赚钱，而不是去公司应聘。他学完一周多才开始接单，初期一个视频要做好几天，靠下班后每天投入几个小时、不挑活地接单积累经验。熟练之后，每天两三个小时就能搞定这些商单。
