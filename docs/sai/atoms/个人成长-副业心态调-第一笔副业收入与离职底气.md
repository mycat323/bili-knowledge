# 第一笔副业收入与离职底气

## 一句话定义

作者靠AI赚到第一笔4863元后，第二天就向领导提出离职，副业收入带来的底气让他不再忍受主业里的委屈。

## 详细说明

作者在月底靠AI赚到第一笔不菲的收入，金额是4863元。他记得很清楚，拿到钱的第二天就立马找领导提出了离职，理由是「老子能自己赚钱，还受你们这鸟气」。

这个节点说明副业收入的意义不只是钱本身：

- 4863元接近他原本六千的月薪，意味着副业已能覆盖主业收入的大部分。
- 收入来源从单一工资变成可自主接单，议价权和心理位置随之改变。
- 他离职后没有去找工作，而是通过平台接触甲方赚钱。

需要补充的是，这笔钱不是轻松得来的：他学了一周多才开始接单，初期一个视频要做好几天，每天下班回家啥也不干，花好几个小时做商单，不挑活、什么都接。
