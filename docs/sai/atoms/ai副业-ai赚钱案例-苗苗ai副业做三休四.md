# 苗苗AI副业做三休四

## 一句话定义

29岁杭州女孩苗苗靠AI副业实现做三休四、月入过万，上个月只工作半个月收入仍有22500元。

## 详细说明

苗苗原本从事主播行业，因嗓子受损、业绩压力大而转向AI副业。她现在的状态是「做三休四」，即工作三天休息四天，收入完全取决于自己接多少单子。

关键数据：

| 项目 | 数据 |
| --- | --- |
| 年龄 | 29岁 |
| 上个月工作天数 | 半个月 |
| 上个月收入 | 22500元 |
| 单笔最高案例 | 浙江某乡镇政府宣传片，预算2万 |

她的收入不是靠熬时间涨薪，而是靠接单量自主调节。她自述「单子多的都接不过来」，说明需求端并不缺。
