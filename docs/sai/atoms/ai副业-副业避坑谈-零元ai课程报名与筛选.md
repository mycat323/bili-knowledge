# 零元AI课程报名与筛选

## 一句话定义

作者通过前同事推荐报名了一个零元AI绘画课程，课程提供一对一制定计划，讲师来自阿里国际旗下AIGC专业领域，作者事后查证课程来自深圳电好科技旗下的AI全媒体项目实训营。

## 详细说明

作者在找副业时，前公司的兄弟推荐了一个AI绘画课程，说是零元免费，讲师都是阿里国际旗下AIGC专业领域的。这个兄弟中专毕业，上个月靠这个挣了三万多，作者因此报名。

报名后课程提供一对一制定计划，给作者制定的计划是明天上午十点开始。课程方表示即使上班想做副业也完全不冲突。

作者在赚钱后专门查了一下课程来源，确认是深圳行业天花板电好科技旗下的AI全媒体项目实训营，在业内算得上最靠谱的。

需要注意的是，作者在视频最后把课程报名链接放在了评论区，并推荐大家自取。这说明视频本身带有推广性质，读者在参考时需要自行判断课程是否适合自己，不要仅因为零元就盲目报名。作者也提到自己报名前是眼红同事收入才行动的。
