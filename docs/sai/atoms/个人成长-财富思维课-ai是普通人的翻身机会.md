# AI是普通人的翻身机会

## 一句话定义

作者把AI视为类似二十年前互联网、十年前直播的新媒介和业态，认为它会辐射各行各业，普通人应主动赶上风口。

## 详细说明

作者的核心判断是：AI不一定会代替人类，但一定会代替部分还在传统行业一成不变的人。

他把AI放进媒介演进的序列里——二十年前的互联网、十年前的直播，都是先被少数人抓住、再辐射到各行各业的新业态。基于这个类比，他主张与其等待被淘汰，不如主动出击，先赚一点钱、积累转行找工作的筹码。

作者还提到自己的处境：三十多岁，上有养老下有房贷，失败不起。这个现实压力是他强调「主动出击」的直接原因。
