# AI分镜视频接单

## 一句话定义

把规定画布的提示词复制进来，加上甲方内容生成视频再微调，一条耗时一个多小时，报价200到300元。

## 详细说明

分镜视频是作者单价最高的接单类型，客户是AI视频公司。

具体流程：复制规定画布的提示词 → 加入甲方的个人内容 → 直接生成视频 → 微调。一条视频耗时一个多小时，收入两三百元。作者提到提示词都是课上老师给好的，直接用即可，所以整个流程做下来并不复杂。

这条路径的核心是把「提示词」当成可复用的生产工具，而不是每次从零设计。作者一天能做两条，构成月入一万三中的主要部分。
