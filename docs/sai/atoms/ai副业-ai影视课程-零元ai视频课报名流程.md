# 零元AI视频课报名流程

## 一句话定义

零元AI视频课通过B站引流，用户输入手机号添加微信、填写入学登记后，由课程方提供一对一学习计划并安排固定晚间上课时间。

## 详细说明

这类课程的报名路径通常分四步：

1. **引流入口**：在B站等平台看到「零元AI视频课程」的宣传，主打新手十五天接单、月入五万等话术。
2. **留资加微**：点击报名后输入手机号，添加课程方微信。
3. **入学登记**：填写一份入学登记表，用于收集学员基础信息。
4. **定制计划**：课程方根据登记信息给出一对一的学习计划，并约定上课时间（案例中是周五和周末晚上七点到九点半）。

报名本身确实不收费，课程方宣称所有AI工具免费提供、还有内部接单渠道。需要留意的是：免费报名不等于全程免费，后续往往有「进阶课程」环节，真正的接单资源和深度教学可能集中在这一步。判断是否值得投入，可以先只上免费部分，观察工具是否真能用、是否有真实学员接单案例，再决定要不要继续。
