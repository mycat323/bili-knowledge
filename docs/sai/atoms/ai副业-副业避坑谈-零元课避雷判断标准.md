# 零元课避雷判断标准

## 一句话定义

判断零元AI课是否靠谱，可看三点：是否真零元报名、是否提供免费AI工具与内部接单渠道、是否有可查证的主讲人和公司主体。

## 详细说明

作者在视频中给出的自检思路，可以整理成一张判断清单：

| 检查项 | 靠谱信号 | 风险信号 |
| --- | --- | --- |
| 报名费用 | 确认页面零元，只需手机号 | 报名即收费或层层加价 |
| 工具提供 | 所有AI工具免费提供 | 工具需另行付费购买 |
| 接单渠道 | 有内部接单渠道且能实际接到单 | 只讲理论、无渠道 |
| 主讲人 | 有具体姓名和可查作品 | 只有昵称、无作品 |
| 公司主体 | 有具体公司，如深圳变好科技 | 查不到主体 |
| 收益宣传 | 承认个案差异 | 承诺月入五万、财富自由 |

作者自己的做法是设定验证期：试一个月，如果这个月没有接单赚到钱就当作避雷。这个「先设止损线再投入」的思路，比事后判断更可操作。需要提醒的是，作者的结论来自个人一个月的体验，样本量为1，不能直接外推到所有人。
