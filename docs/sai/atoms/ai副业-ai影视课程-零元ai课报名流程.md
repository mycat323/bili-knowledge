# 零元AI课报名流程

## 一句话定义

B站爆火的零元AI课程报名需经过零元报名、填写手机号加微信、提交入学登记、由机构制定一对一学习计划四步，上课时间安排在周五到周末晚七点到九点半。

## 详细说明

作者亲测的报名路径如下：

1. **零元报名**：课程页面显示零元，无需付费即可进入。
2. **加微信**：报名后需要输入手机号并添加课程方微信。
3. **填入学登记**：添加微信后要填写一份入学登记表。
4. **制定学习计划**：机构根据登记信息给学员制定一对一的学习计划，作者被安排的上课时间是周五到周末的晚上七点到九点半。

课程方宣称的卖点包括：所有 AI 工具全部免费提供、提供内部接单渠道、新手学十五天就能接单赚钱。作者正是被「零元课 + 免费工具 + 内部接单渠道」这套组合打动才决定报名实测。

需要注意，报名免费不等于后续环节免费，作者在实测中进入了「训练营」和「进阶课」阶段，说明课程体系存在分层。
