# 三天入门半个月接单

## 一句话定义

苗苗的AI学习节奏：入门三天，真正上手接单约半个月，熟练掌握约两个月。

## 详细说明

苗苗给出的学习时间线非常具体：

| 阶段 | 时间 |
| --- | --- |
| 入门 | 3天 |
| 真正上手接单 | 约半个月 |
| 熟练掌握 | 约2个月 |

她强调自己是「系统性学习过的」，所以觉得做单子很简单，而新手零基础可能会觉得有点难。

她推荐的学习方式是参加三天免费试学课程，课程特点：
- 晚上上课，不耽误白天正常工作
- 提供很多新手的接单渠道
- 可以先试学，看看自己是不是有天赋，再考虑后续报不报课

她认为这个赛道目前「没几个人知道」，先入场有信息差优势。
