# 副业收入与离职底气

## 一句话定义

在就业环境严峻的背景下，一份稳定的副业收入能让人拥有离职的底气，其价值不只是钱本身，而是选择权。

## 详细说明

案例作者在总结一个月赚八千元的经历时，把意义落在了「底气」上：在现在就业环境这么严峻的情况下，有个副业收入，至少还有离职的底气。

这句话包含两层判断：

1. **副业的心理价值大于账面价值**：八千元本身不算巨款，但它意味着不依赖单一雇主也能获得现金流，从而降低对主业的恐惧感。
2. **底气来自可持续性而非单月收入**：案例中的收入由接单、账号分成、数字人分成等多条线构成，只要其中一条能持续，底气就成立；如果只是单月爆发，则不具备支撑离职决策的意义。

需要提醒的是，副业收入达到「能覆盖基本生活开支」之前，离职仍然是高风险决策。更合理的用法是把副业收入当作缓冲垫和试错资金，而不是立刻辞职的信号。
