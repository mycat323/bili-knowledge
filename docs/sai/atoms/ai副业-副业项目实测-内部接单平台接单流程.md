# 内部接单平台接单流程

## 一句话定义

学员在AI课程训练营沉淀一段时间后，可将作品挂在课程内部接单平台，接单后获得转账收入，作者第一单分镜视频收入两百元。

## 详细说明

作者在学完进阶课程两个多星期后，收到了一笔两百块钱的转账，对应的是挂在内部接单平台上的一条分镜视频。作者表示不敢相信这是自己做的。

接单流程大致为：
1. 在训练营学习并沉淀一段时间
2. 用AI工具制作出可商业化的视频
3. 将作品挂在内部接单平台
4. 接到订单后完成交付并获得转账

作者提到同期的学员朋友做了一个商业化视频，一条赚了一千块。这说明内部接单平台上的单价因视频类型和商业化程度而异，从两百到一千不等。

除了内部接单平台，作者还通过自己的抖音账号开橱窗带货、在红果账号接商单，每天收入大概五百元。内部接单平台是起步阶段的主要渠道，因为门槛较低，适合刚学完课程的学员。
