# 零基础学AI的可行性

## 一句话定义

作者认为AI接单不需要技术背景，提示词由课程提供，中专学历的宝妈也能学会并签约成为长期AI生成师。

## 详细说明

支撑「零基础可行」的证据有两条：一是作者自己的接单流程只有复制粘贴和微调；二是同期一位中专学历宝妈成功签约某团长期AI生成师。

作者把AI类比为二十年前的互联网、十年前的直播，认为它是一种新的媒介和业态，迟早辐射到各行各业。因此与其等待被淘汰，不如主动出击，先赚一点钱、积累转行找工作的筹码。

需要区分的是：作者说的是「入门接单」不需要基础，而不是说AI本身没有门槛。课程提供现成提示词，是这个可行性成立的前提条件。
