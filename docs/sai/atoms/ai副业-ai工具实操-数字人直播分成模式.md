# 数字人直播分成模式

## 一句话定义

把AI生成的数字人卖给实体商家用于直播，创作者按周获得分成，案例中一周分成约五百元。

## 详细说明

数字人是AI视频工具链中的一个产出物，除了用于自己账号的内容制作，还可以作为产品卖给有直播需求的实体商家。

案例中的具体做法是：把数字人卖给一家理发店用于直播，一周大概有五百元的分成。这种模式的逻辑是实体商家有直播需求但缺少出镜人力，数字人可以替代真人出镜，创作者提供数字人资产并持续获得分成，而不是一次性买断。

与分镜接单相比，数字人分成的特点是：

- 交付一次，收益按周期持续
- 客户是本地实体商家，不依赖线上接单平台
- 单价不高但可以复制到多个商家

案例中作者同时还在运营自己的自媒体账号，观众需要解锁或看广告才能观看，后台的解锁收入和广告收益分成会持续到账，这与数字人分成同属「一次制作、持续收益」的类型。
