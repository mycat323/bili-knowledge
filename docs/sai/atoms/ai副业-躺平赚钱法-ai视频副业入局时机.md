# AI视频副业入局时机

## 一句话定义

AI视频行业处于类似早期抖音短视频的窗口期，入局早的人更容易赚到钱，普通人可以从中获得每月万把来块的副业收入。

## 详细说明

案例作者把当前的AI行业类比为很多年前的抖音短视频刚兴起的时候，核心判断是「谁入局早谁就能够赚到钱」。

这个判断包含两层含义：

1. **不指望暴富**：作者明确说自己不敢想像大主播那样赚几千万、赚得盆满钵满，普通人吃到的是「苍蝇肉」级别的小钱，一个月赚个万把来块钱。
2. **窗口期有限**：类比短视频的逻辑意味着，随着入局者增多，接单单价和流量红利都可能下降，早入局的优势会减弱。

从案例的实际数据看，这个「万把来块」的量级是可信的：分镜接单一条三百元、自媒体商单一条一千元、数字人分成一周五百元，组合起来一个月八千元左右。作者也强调，在当下就业环境严峻的情况下，有副业收入至少让人有离职的底气。
