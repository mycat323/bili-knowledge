# 突然变有钱而非熬时间涨薪

## 一句话定义

靠熬时间一点一点涨薪不可能变有钱，有钱人往往是突然变得有钱的，作者用自己半年内从月薪六千到月入三万多印证了这一点。

## 详细说明

作者第一次月入三万时得出的结论是：人不可能靠熬时间一点一点涨薪变得有钱，有钱人就是突然变得有钱的。

他自己的对照数据：

| 时间 | 状态 |
| --- | --- |
| 半年前 | 月薪六千的小运营，快三十岁，住一千三的小单间，下班打游戏，吃十五块的猪脚饭 |
| 半年后 | 平均月收入两万三四，最高一个月三万多 |

这个跃迁的触发点不是资历积累，而是踩中了AI视频这波机会：上个月AI换脸视频大火，他接到两个文旅官方的AI视频需求，每个七千元，加上自制小猫视频爆火和平台商单，才凑出三万多。他也设想过，如果没有接触AI，自己可能还拿着六千块死工资，或者已经被裁员窝在出租房里。
