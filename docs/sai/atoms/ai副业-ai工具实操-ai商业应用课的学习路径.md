# AI商业应用课的学习路径

## 一句话定义

作者通过一个免费三天的AI全能实战班入门，课程由阿里国际设计认证的AI高级专家主讲，教AI推文、绘图、视频及变现，学完可在内部接单渠道接单。

## 详细说明

作者的入门路径是：朋友在抖音发了一条AI美女跳舞视频成为爆款，点赞一万多，而这位朋友高中没毕业、自认不聪明，是在一个AI全能实战班免费学了三天做出来的。作者由此进入同一个课程学习。

课程的关键特征：

- 线上主讲老师是阿里国际设计认证的AI高级专家，给很多大型企业做过AI商业落地。
- 不教用AI写小说、编剧情，而是教怎么用AI赚到钱，覆盖AI推文、绘图、视频以及变现方式。
- 完成所有课程后，可以直接在内部接单渠道接到各种单子。

作者本人学了一周多之后才开始接单赚钱，初期并不熟练，一个视频要好几天才能做出来。他强调这个视频是纯个人分享、不卖课，并提醒不要指望看完视频马上就能月入一两万。
