# 影视外包接单收入

## 一句话定义

影视外包是小微企业宣传片、电商产品介绍等项目的接单收入，来源为接单平台或熟人介绍，单月可达六千多元。

## 详细说明

作者上个月的影视外包收入为 6680 元，项目类型包括小微企业的宣传片、电商产品的介绍等。接单渠道有两类：一是直接在接单平台上接到的项目，二是熟人介绍的项目。

这类收入的特点是：

- 项目制结算，不是平台自动分账，需要自己对接客户或通过平台撮合；
- 客户以小微企业和电商卖家为主，需求偏宣传片、产品介绍等标准化内容；
- 与短剧分账相比，外包收入更依赖接单渠道的稳定性。

作者在讲课程价值时也提到，学完之后可以在内部接单渠道直接变现，不用自己去找客户，反过来说明「找客户」是这类外包收入的主要门槛之一。
