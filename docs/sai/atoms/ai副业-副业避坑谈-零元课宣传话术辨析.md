# 零元课宣传话术辨析

## 一句话定义

零元AI课宣传中的「月入五万」「十五天接单」属于招生话术，实际收益需要自己实测验证，案例作者一个月实际收入约八千元。

## 详细说明

面对「不上班一个月赚五万」「靠兼职AI视频实现财富自由、跨越阶级」这类宣传，合理的做法是区分话术和可验证的事实。

案例作者的验证方式是：给自己设定一个月的观察期，明确「如果这个月没有接到单赚到钱就避雷」，然后记录每一笔实际到账。结果是一个月小赚八千元，与宣传的月入五万差距明显，但也不是完全没收益。

判断这类课程时可以关注几个点：

- 宣传中的收入数字是否有具体来源，还是只作为招生钩子
- 课程方是否真的免费提供AI工具和接单渠道（案例中确认了这两点）
- 师资背景是否可查（案例中课程方称是阿里国际设计认证的AIGC专家代教，并与多个影视资方合作）
- 自己实际投入的时间成本（案例中作者下班后每天做三小时）

作者最终的结论是：AI行业像多年前抖音短视频刚兴起时，入局早能赚到钱，普通人一个月赚个万把来块是可能的，但不要相信几千万、财富自由这类说法。
