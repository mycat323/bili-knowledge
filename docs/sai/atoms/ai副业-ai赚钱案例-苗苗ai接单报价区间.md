# 苗苗AI接单报价区间

## 一句话定义

苗苗的AI接单报价从新手期十几元的海报到企业宣传片2000元、政府宣传片2万元不等，质量决定甲方层级。

## 详细说明

苗苗的接单报价随作品质量提升而分层：

- 新手期：十几块钱的预算，做AI海报之类的简单单子
- 图片类作品：一晚上能生成几十张，报价几十到一百多不等
- 企业科技宣传AI宣传片：单笔2000元，半天可做出一版
- 浙江某乡镇政府宣传片：预算2万元，制作周期两三天

她强调「一开始肯定是遇不到这种甲方这种预算的」，质量上来之后自然会有优秀甲方找上门。也就是说，报价不是靠谈判技巧，而是靠作品集质量自然筛选客户层级。
