# 分镜视频接单收入结构

## 一句话定义

AI视频副业的收入由分镜接单、自媒体账号商单、数字人分成和解锁广告收益四部分构成，案例中一个月累计约八千元。

## 详细说明

根据案例作者的实测记录，收入来源可以拆成四块：

| 收入来源 | 单价/金额 | 说明 |
| --- | --- | --- |
| 分镜视频接单 | 一条三百元 | 外包接单平台价格，下班后做三小时可完成三条，约八百元 |
| 自媒体账号商单 | 一条一千元 | 同期的学员朋友做仙侠剧、霸总剧账号，粉丝五十万后的商单价格 |
| 数字人直播分成 | 一周约五百元 | 把数字人卖给理发店做直播 |
| 账号解锁与广告分成 | 每天五十到五百元不等 | 观众解锁或看广告，后台持续到账 |

作者的节奏是：学进阶课程两个多星期后接到第一笔三百元转账；半个月左右累计约五千元，每天保底收入约八百元；干满一个月小赚八千元。作者也明确表示「没有一个月五万那么夸张」，但认为作为兼职已经很多。

另有一个参照数据：同期学员的朋友做了一集商业化的AI剧情视频，一条两千元。
