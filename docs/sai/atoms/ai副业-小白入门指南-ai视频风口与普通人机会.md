# AI视频风口与普通人机会

## 一句话定义

AI基础模型爆发后商业应用开始落地，进入红利增长期，字节跳动估算今年AI实际应用产值将超过千亿，普通人也能从中赚到三五百。

## 详细说明

作者判断，随着去年AI基础模型爆发式增长，今年的商业应用将彻底落地，进入黄金红利增长期。他引用字节跳动的估算：今年AI实际应用产值将会超过千亿。

在这个判断下，他认为即使没能成为行业大佬，普通人也能通过这个机会赚个三五百。他把当下类比为父辈那个只要做生意就能赚钱的千禧年，认为这是普通人可以低成本试错的时代风口，下一个类似机会不知道要等到什么时候。

需要区分的是，作者同时强调这并不意味着看完视频就能立刻月入一两万。他自己的路径是：先免费学三天入门课，再学一周多开始接单，初期一个视频要做好几天，靠下班后每天投入几个小时、不挑活地接单，才在月底拿到第一笔4863元。
