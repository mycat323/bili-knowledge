# 政府AI补贴与全民AI趋势

## 一句话定义

作者观察到各地政府推出AI相关补贴公告，包括OPC艺人公司现金补贴最高五十万和算力补贴，认为全民AI时代很快到来，掌握AI技能后整理作品集不愁找工作。

## 详细说明

作者在视频中提到，政府发的各种公告里有针对OPC艺人公司的现金补贴，最高有五十万，还有算力补贴。作者表示这样的公告网上有很多，各地政府都有推出。

基于这些观察，作者判断全民AI的时代很快了。作者的计划是把自己用AI做的海报、视频、短剧、小说等整理成一个作品集，认为这样肯定不愁找不到工作，最好是找一个双休的。

这里反映了一种财富思维：把AI技能视为未来职场的通用能力，而不仅仅是副业工具。作者从辞职躺平到靠AI赚钱，再到计划用AI作品集重返职场，形成了一个闭环。

需要注意的是，作者提到的补贴金额和公告来源来自其个人观察，具体政策需以官方发布为准。
