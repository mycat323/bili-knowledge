# AI剧本与分镜生成流程

## 一句话定义

用AI工具生成视频的流程是：先输入一句剧情设定让AI自动生成剧本小说，再把剧本复制给AI视频生成工具，自动产出一个个分镜视频。

## 详细说明

案例中作者展示的AI视频制作流程分两步：

1. **生成剧本**：不需要自己写，直接给AI工具一句剧情设定（案例中输入的是「霸道总裁爱上杀猪的我」），AI就能自动生成一部剧本小说。作者学一个小时就完成了这一步。
2. **生成分镜视频**：把AI生成的剧本直接复制给AI视频生成工具，工具会自动生成一个个分镜视频。此外还需要给提示词，让AI生成海报和数字人。

这条流程的价值在于把传统影视制作中「编剧—分镜—拍摄」的环节压缩成提示词输入，普通人不需要专业设备就能产出可交付的视频素材。案例中一条分镜视频在外包接单平台的价格是三百元。

需要区分的是：剧本生成、分镜视频生成、海报与数字人生成是三个不同的AI工具环节，课程方提供的是这些工具的免费使用权。
