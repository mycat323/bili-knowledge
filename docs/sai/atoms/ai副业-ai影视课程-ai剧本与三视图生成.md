# AI剧本与三视图生成

## 一句话定义

把老师给的关键词输入AI工具即可自动生成剧本和分镜头，再用提示词生成人物形象与三视图，三视图能避免AI视频中人物变脸换脸。

## 详细说明

作者上课一小时后产出的第一份成果，流程如下：

- **生成剧本与分镜**：不需要自己写，把老师提供的关键词交给AI工具，它会自动生成剧本和对应的分镜头。
- **生成人物形象与三视图**：按老师教的提示词，让AI生成剧本中的人物形象和人物三视图。
- **三视图的作用**：有了三视图，后面生成的AI视频就不会出现人物变脸换脸。作者此前自己生成视频总是前后人物不一致，原因就是没有生成人物三视图。
- **生成视频**：把前一天用AI生成的分镜和三视图直接交给AI视频生成工具，工具按这些图片自动生成十五秒的影视大片。
- **动态海报与数字人**：课上还会直接给提示词，让AI生成动态海报和数字人。

关键点在于三视图是人物一致性的前置条件，跳过这一步，后续所有镜头的人物都会漂移。
