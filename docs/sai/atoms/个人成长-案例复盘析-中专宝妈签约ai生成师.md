# 中专宝妈签约AI生成师

## 一句话定义

作者同期的一位中专学历宝妈为争取孩子抚养权学AI，如今签约某团长期AI生成师，月收入超过作者本人。

## 详细说明

这是作者用来回应「普通人能不能学会」质疑的核心案例。

人物背景：中专学历、宝妈，学AI的动机是离婚时争取孩子抚养权，希望获得找工作的机会。结果是签约某团成为长期AI生成师，每月赚得比作者还多。

这个案例的作用不是证明AI门槛低，而是说明学历和起点不是决定因素，动机强度（为了孩子）反而可能是关键变量。作者由此得出「这是普通人翻身的好机会」的判断。
