# 课程方背景与接单渠道

## 一句话定义

该课程由大元老师主讲，隶属深圳变好科技，老师作品包括爆火的昭君出塞与白蛇传番外，公司已与多个影视资方合作并招募AI视频创作者。

## 详细说明

作者在赚到钱后回头查证的课程方信息：

- **主讲人**：大元老师，作品包括之前爆火的AI影视作品《昭君出塞》《白蛇传番外》。
- **公司**：深圳变好科技旗下，作者评价「在业内也算得上是靠谱了」。
- **合作资源**：已和多个影视资方合作，招募了大量AI视频创作人员。
- **渠道价值**：内部接单渠道和外部公司就业都相对容易。作者特别强调，课程教学、AI工具免费提供、内部接单渠道这些资源，自己在网上费劲找也找不到。

这段信息的用途是判断课程是否靠谱——有具体主讲人、具体作品、具体公司主体和具体合作方，比只有宣传口号的课程可信度更高。
