# 运营转AI视频接单月入三万

## 一句话定义

一名月薪六千的运营，用半年时间通过AI视频接单把平均月收入做到两万三四，最高一个月超过三万，收入来源包括文旅官方需求、自制爆款视频和平台商单。

## 详细说明

作者原为月薪六千的运营，近三十岁仍租住一千三的单间。接触AI视频后，半年内平均月收入达到两万三四，最高一个月三万多。

最高收入那个月的构成：

| 收入来源 | 金额/说明 |
| --- | --- |
| 文旅官方AI视频需求 | 两个，每个七千元 |
| 自制小猫视频 | 爆火一条 |
| 平台派发商单 | 与上述合并计算 |

他学了一周多才开始接单，初期不熟练，一个视频要做好几天，下班后每天花好几个小时做商单，不挑活、什么都接。第一笔AI收入是4863元，拿到钱的第二天就向领导提出离职。经过一个多月实战接单，水平已可应聘AI专员岗位。熟练后每天两三个小时就能完成商单，加上自己做AI自媒体，收入达到之前的四五倍。
