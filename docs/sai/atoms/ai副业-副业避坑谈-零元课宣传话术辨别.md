# 零元课宣传话术辨别

## 一句话定义

零元AI课常用「新手十五天接单」「月入五万」「财富自由」等夸张话术引流，实际收益远低于宣传，需用实测数据校准预期。

## 详细说明

案例作者报名前的宣传口径是：新手学十五天就能接单赚米，做得好的月入五万，靠兼职AI视频实现财富自由。作者本人的态度是「虽然我也觉得有点离谱，但他们是零元课」，于是决定先试一个月，接不到钱就当避雷。

一个月后的实际结果是八千元，作者自己承认「没有月入五万那么夸张」。

辨别这类宣传可以看三点：

1. **极端数字是否可复现**：月入五万属于头部个案，普通学员的实测值往往在几千元量级。
2. **免费的是哪一段**：零元通常只覆盖入门课，接单渠道和商业化教学往往在进阶课程里。
3. **收益是否依赖持续投入**：案例中的日保底800元建立在每天下班后再做三小时的基础上。

作者最终的态度是收回偏见，因为确实赚到了钱，但这不等于宣传话术成立——把宣传上限当成自己的预期下限，是这类课程最容易踩的坑。
