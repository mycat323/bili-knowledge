# 不吹不黑，亲测AI的我竟然...

<BiliPlayer :bvid="'BV1cVao6CEu8'" />


**摘要**：作者亲测B站爆火的零元AI影视课程，记录从报名、学习到接单赚钱的全过程，一个月后小赚八千元，认为课程靠谱且AI行业入局早能赚钱。

## 一、零元AI影视课程报名与初体验

不上班，一个月赚五万块钱，靠兼职AI视频就能实现财富自由，跨越阶级了？这是国内吗？最近B站上爆火的零元AI影视课程，我报名了。听说新手学十五天就能接单赚米，做的好还有可能月入过万。虽然我也觉得有点离谱，但他们是零元课，所有AI工具免费提供，还能提供内部接单渠道，我也就没忍住报名了。我就试一个月，如果这个月没有接单赚到钱，你们就避雷吧。

你看他这个确实是零元报名的，输入手机号添加微信。加了，他要填入学登记，然后再一对一给你制定学习计划。好了，给我制定的上课时间是周五和周末的晚上七点到九点半，到时候给你们看看。

## 二、学习AI工具生成剧本、分镜与三视图

给你们看个很牛的东西，这是我刚学了一个小时写出来的剧本。其实都不是我自己写的，他们有这个AI工具，就是我直接把老师给我的关键词给他，他就会自动生成剧本和对应的分镜头。最牛的是按照老师教我们的提示词，就能生成剧本中的人物形象和人物三视图。就是有了这个三视图，我们后面生成的AI视频就不会出现人物的变脸换脸。我说我之前自己生成的视频怎么老是前后不一样，原来是没有生成人物的三视图。我靠，原来是这样。

刚上完课，今天把昨天用AI生成的分镜和三视图直接给AI视频生成工具，你看它直接就按照这些图片自己生出了十五秒的影视大片。而且课上还是可以连线的，就是在实操中遇到的问题就可以和老师连线，一对一的解决问题，就不会像之前一样，遇见问题就只能自己瞎琢磨。而且还要直接给提示词，让AI生成这种动态海报和数字人。然后你看这个外包接单平台，一条分解视频就三百块。等我在训练营沉淀一段时间，到时候做出商业化的视频，岂不是酷酷赚钱了？

## 三、接单赚钱与学员案例

真的假的？刚收到了三百块钱转账，学进阶课程已经两个多星期了。家人们，我赚到钱了。今天晚上要学怎么做完整的一条AI视频。和我同期的一个学员说，他朋友做了数字人文旅宣传片，一条就两千块。还有做了自己的自媒体账号，就是那种AI科普养生，还有带货。现在粉丝五十万，一条视频的商单价格就是一千块。

学了一段时间了，和大家汇报一下，我现在每天的收入大概是八百块钱。下班后拼命做三小时，三条视频八百块。有时候顺带更新下我的红果账号，每天收入在五十到五百不等。上个星期还把数字人卖给一个服装店做直播，这周大概有五百块的分成。就是观众想看我账号，他们只能解锁或者看广告。所以我后台不管是解锁的钱还是广告收益分成都会持续到账的。你看我这半个月差不多是赚了五千，没有一个月五万那么夸张了，但是我觉得作为兼职来说已经很多了。

## 四、一个月总结与课程背景

我现在差不多是干了一个月了，先收回之前对他的偏见，因为确实这个月小赚了八千块。查了一下，这个课程是大元老师主讲，像之前爆火的AI影视作品昭君出塞、白蛇传番外都是老师的作品，而且是深圳变好科技旗下的，在业内也算得上是靠谱了。已经和多个影视资方合作，招募了大量的AI视频创作，所以不管是内部接单渠道还是外部公司就业都很容易。像这些课程教学和AI工具的免费提供，甚至是内部的接单渠道，这些资源都是我自己在网上费劲找也找不到的。

其实现在AI行业就像很多年前的抖音短视频，刚刚兴起的时候，谁入局早啊，谁就能赚到钱。我不敢说像大主播那样赚几千万，赚得盆满钵满，但像我们这种普通人也是能吃到一点苍蝇肉，一个月赚个万把来块。在当下就业环境那么严峻的情况下，有副业收入至少我们还有离职的底气。那我报名的这个课程链接就放在评论区了，大家可以自取，就不要私信我了。
