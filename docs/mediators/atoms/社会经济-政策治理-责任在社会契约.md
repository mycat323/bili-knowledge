# 责任在社会契约里，不在脑子里

## 一句话定义

加扎尼加主张责任是存在于人与人之间的社交概念，而非大脑内部的神经属性；只要一个人能理解并享用社会规则，他就是有责任能力的社会人。

## 详细说明

面对「全是我的大脑干的，所以我是无辜的」这类辩护，加扎尼加给出三点提醒：

1. **平均值不等于个体**。所有脑扫描图都是几十上百人数据的统计平均图，没法指着一张脑图百分之百确定某个人在作案那一刻的真实心智状态。
2. **脑异常不等于行为必然异常**。成千上万前额叶受损甚至患精神分裂症的人，照样每天遵守交通规则、按时付账、不伤害别人。脑损伤只是增加了某种冲动的概率，绝不等于行为的必然。
3. **责任不在脑子里，而在社会契约里**。责任是一个存在于人与人之间的社交概念，而不是大脑内部的神经属性。解剖一个人的大脑找不到「责任」两个字，就像拆开一辆汽车找不到交通堵塞。

直观例子是限速牌和警车效应：一个平时飙车、自控力极差的司机，从后视镜里看见警车跟着，往往会立刻踩刹车乖乖减速。这说明他的大脑完全有能力接受外部社会规则，并用宏观规则压住底层冲动。既然在警车面前能刹车，作案时没刹车，就必须为自己的行为承担法律和道德责任。法律和惩罚的存在，本质上是社会系统在大脑外部为所有人的安全形成的外部约束机制；没有惩罚和追责，人类的合作秩序会受到严重冲击，退化成丛林法则。
