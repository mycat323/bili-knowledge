# 欧米伽数

## 一句话定义

欧米伽数是随机生成的程序最终能够停机的概率，其二进制展开具有算法随机性，无法被任何更短的有效算法系统性压缩或逐位算出。

## 详细说明

设想用公平硬币生成零和一，把随机二进制序列作为程序送入计算机运行：有些程序马上报错，有些运行一会儿停下，还有些永远运行。随机程序最终停机的概率就是欧米伽数。

技术细节上，程序必须采用能自我界定长度的编码方式，否则无法知道程序在哪里结束，算法信息论通常用前缀无歧义的编码解决。长度为 n 比特的程序对应概率一除以二的 n 次方，所有停机程序相加得到介于零和一之间的欧米伽。

它的诡异之处在于：每一位都对应某些程序最终是否停机，而停机问题不可计算，因此不存在通用算法把欧米伽的所有二进制位逐位算出。这与圆周率完全不同——圆周率虽有无限多位，但背后有简洁的数学结构，只要有足够计算资源就能继续算下去。欧米伽把大量不可计算的信息编码进一个看似普通的实数。

需要谨慎的是，说它像掷硬币一样随机，并不是说数学里真有一枚物理硬币，而是指它的二进制位具有算法随机性，无法被更短的算法压缩。这让我们直观看到：随机性不只存在于物理世界，纯数学深处同样存在无法压缩、无法完全预测的信息。
