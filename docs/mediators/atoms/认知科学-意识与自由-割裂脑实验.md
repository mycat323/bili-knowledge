# 割裂脑实验：解释器如何编故事

## 一句话定义

加扎尼加对胼胝体被切断的患者分别向左右脑呈现不同图像，发现左脑在信息不足时仍会为右脑驱动的行为编造连贯理由。

## 详细说明

实验背景：切断胼胝体后左右脑无法直接交流；左视野信息进右脑，右视野信息进左脑；语言中枢绝大多数只在左脑。

操作：向患者左脑（右眼）展示鸡爪图片，向右脑（左眼）展示雪景图片，然后让左右手各挑一张最相关的卡片。右手（左脑控制）挑母鸡，左手（右脑控制）挑扫雪铲。

关键追问：为什么右手指母鸡、左手却指铲子？负责说话的左脑并不知道右脑看见了雪景。按最诚实的逻辑，患者该说「我不知道左手为什么拿铲子」。但左脑解释器看了看铲子又看了看母鸡，很快给出回答：鸡爪当然配母鸡，至于铲子，清理鸡舍里的鸡粪刚好需要。

结论：左脑在信息不足时不会直接承认不知道，而是凭眼前蛛丝马迹硬编出一个听起来连贯的因果解释，甚至说服自己相信这就是真实原因。这是心理学研究中颇具启发性的发现。
