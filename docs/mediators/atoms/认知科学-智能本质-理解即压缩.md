# 理解即压缩

## 一句话定义

理解的本质不是知道更多事实，而是用越来越少的信息解释越来越多的现象，规律就是从大量数据中提取出的重复结构，即一种更短的描述方式。

## 详细说明

十七世纪以前，人类积累了数千年的天体观测资料，行星有时前行、有时看起来倒退，数据庞大而混乱。牛顿没有逐条背诵这些数据，而是找到万有引力定律，把需要无数张表格描述的运动压缩成几行公式，既能解释过去又能预测未来。

从这个角度看，科学的力量来自用极少信息解释极多现象。大语言模型也遵循同样的逻辑：它并不原封不动保存人类所有文字，而是从海量文本中提取语法、词语关系、概念关联等统计结构，压缩进模型参数，再据此生成新回答。

一个系统如果能用非常少的信息重建或预测大量现象，我们就会觉得它「理解」了。这个定义把理解从「知识存量」转向「描述长度」，也自然引出一个问题：是否存在无论如何都无法压缩的东西？
