# 私有信贷串联赌注

## 一句话定义

规模超2.5万亿美元的私有信贷市场，建立在软件公司年化可重复收入永远可重复且高增长的假设上，AI摧毁该假设后引发连锁违约。

## 详细说明

低利率时代，华尔街私有信贷规模狂飙到2.5万亿美元以上，很大一部分被私募股权基金用于软件公司杠杆收购，定价核心假设是：软件公司年化可重复收入永远可重复，且保持15%以上高增长。

AI击碎该假设的案例：某著名机构花上百亿美元将一家客服软件巨头私有化，打包几十亿美元直接贷款，由顶级信贷巨头领投。逻辑是它是客服软件霸主，企业每年续费，现金流稳如泰山。但2027年年中，AI已接管绝大多数企业客服，智能系统在后台直接解决诉求，不生成工单、不需人工接入，工单系统和坐席费彻底失去价值。全美历史最大软件抵押贷款变成私有信贷史上最大违约案。

更深层的资金链：资管公司收购人寿保险公司，用养老年金投自己发起的私有信贷，两头吃管理费和利差，并通过离岸再保险层层打包风险。2027年11月，保险监管机构突然大幅提高对人寿保险公司持有私有信贷资产的资本金要求，国际评级机构迅速下调相关金融机构信用评级，头部资管公司股价两个交易日暴跌超20%，私有信贷板块全线雪崩。美联储官员形容其为：一串建立在白领生产力持续增长假设之上的高度相关的串联赌注。
