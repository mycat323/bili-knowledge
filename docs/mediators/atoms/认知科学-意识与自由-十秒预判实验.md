# 十秒预判：选择可被提前读出

## 一句话定义

海恩斯二零零八年用高精度核磁共振发现，在受试者意识到自己要按左手还是右手之前整整十秒，科学家已能通过前额叶和顶叶活动预测其选择。

## 详细说明

二零零八年，神经科学家约翰·迪伦·海恩斯把里贝特的实验升级：受试者可在左手、右手按钮之间自由选择，同时盯着屏幕上滚动的字母。

科学家通过分析前额叶和顶叶的活动，能在受试者自己意识到要按左手还是右手之前**整整十秒**，就在一定程度上预测出他的选择。画面是：科学家在监控室说「十秒后他会按右手」，十秒后受试者果然按下右手，还心满意足地以为这是自己那一瞬间的自由选择。

与里贝特实验相比，时间尺度从几百毫秒拉长到十秒，说明无意识决策的提前量可能远超直觉。

需要注意的边界：这是**统计意义上的预测**，不是百分之百的宿命读取。它挑战的是「意识到决定的那一刻就是决定开始的那一刻」这一直觉，而不是证明人生剧本早已写死。
