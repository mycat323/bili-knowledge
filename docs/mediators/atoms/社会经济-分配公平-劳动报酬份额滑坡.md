# 劳动报酬份额滑坡

## 一句话定义

劳动报酬占经济总量份额从五十年前的64%降至56%，AI爆发后四年内陡降到46%，切断企业利润经家庭回流消费的经济循环。

## 详细说明

现代政府税收根基本质上是对人类工作时间征税，个人所得税和工资税占财政收入绝对大头。2028年第一季度，美国联邦政府税收收入比官方基线预测低12%。

原因是：生产力虽飙升，但利润全部分流给资本和算力拥有者，不再经过人类家庭这一站。劳动报酬占经济总量份额从五十年前的64%阴跌到56%，AI爆发后短短四年出现史上最陡滑坡，直接砸到46%。

经济循环链条因此断裂：企业生产海量商品和服务，却不再通过薪水把钱发给家庭；家庭没钱，就无法缴税，也无法向企业购买商品；政府却要在税收暴跌的同时，向成千上万被置换的白领发放救济金。政府急需向家庭转移支付，却恰恰收不到税。
