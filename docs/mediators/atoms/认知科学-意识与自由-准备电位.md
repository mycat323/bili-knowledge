# 准备电位：决定早于意识

## 一句话定义

里贝特实验发现，受试者意识到「我想按按钮」之前约三百到五百毫秒，大脑皮层已出现准备电位，无意识电信号先于主观决定。

## 详细说明

上世纪八十年代，生理学家本杰明·里贝特让受试者戴上脑电波头套，在任意时刻自由决定按按钮，并记下自己意识到「想按」的精确时间。

结果：在受试者产生「我想按按钮」这个念头之前的三百到五百毫秒，大脑皮层里的准备电位就已经出现。也就是说，大脑的无意识电信号早已启动，几百毫秒后意识才「醒过来」，并误以为是自己刚刚做出的决定。

常见误解是把这理解为「人没有自由」。实验真正说明的是：**意识到决定的时刻，未必是决策过程的起点**。它把「决定」拆成了至少两段——无意识的神经准备，与随后到达意识层面的「我想」。

可动手验证的思路：任何一次「我突然想动一下」的体验，都可以反问自己——这个念头是决策的起点，还是决策已经发生之后才被意识读到的结果？
