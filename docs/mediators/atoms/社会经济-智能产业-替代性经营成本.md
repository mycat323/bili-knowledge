# 替代性经营成本

## 一句话定义

企业对AI的投入不是新增预算而是替代人力成本，因此宏观失血时基础设施巨头仍狂欢，形成极端结构性分化。

## 详细说明

很多人以为全社会消费下降，科技巨头的数据中心资本开支就该停下。根本不会，因为企业对AI的投入是替代性经营成本，不是新增预算。

算例：一家公司过去每年花1亿雇人、500万买软件。现在把员工薪水砍到7000万，算力预算提到2000万。AI投资翻了四倍，但总支出缩减了1000万。

于是出现诡异奇观：整个宏观经济在失血，基础设施巨头却依然狂欢——芯片巨头营收不断创历史新高，代工厂产能利用率超过95%，各大云服务商单季度仍砸数百亿上千亿美元买芯片。

这种结构性分化还反映到国家层面：处于硬件和半导体供应链核心的经济体获得前所未有的红利；而极度依赖信息技术服务外包的经济体遭毁灭性打击——当写代码的边际成本降到只需几度电的电费时，外包性价比荡然无存，外包巨头海外订单2027年大量被取消，当地货币四个月内暴跌18%，2028年第一季度IMF不得不紧急进驻救助谈判。
