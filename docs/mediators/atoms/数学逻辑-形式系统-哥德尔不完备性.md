# 哥德尔不完备性

## 一句话定义

在任何足够强大的形式系统中，都存在无法在系统内部被证明的命题，因此数学真理并不等于形式证明，有些东西为真却无法仅靠当前规则证明。

## 详细说明

二十世纪初，希尔伯特提出纲领，梦想建立一套足够强大的形式公理系统：确定基本公理与严格逻辑规则后，所有数学真理都能像机器生产产品一样被逐步推导出来；真命题可被证明，假命题可被证伪，且系统自身不产生矛盾。他留下名言「我们必须知道，我们必将知道」。

一九三一年，哥德尔划出无法跨越的边界。其核心是自指，例如「我正在说的这句话是假话」：若它为真则内容为假，若它为假则内容为真，逻辑陷入循环。哥德尔发明哥德尔编码，把数学符号、公式乃至证明过程转化为数字，使系统能在内部谈论自己，进而构造出「这个命题在当前系统中无法被证明」的命题。

若系统能证明它，就证明了一个假命题，破坏一致性；若系统一致，就不能证明它。但站在系统外看，这个命题恰恰为真，因为它确实无法在系统内被证明。结论是：数学真理不等于形式证明，理性第一次清楚看见了自己的边界。
