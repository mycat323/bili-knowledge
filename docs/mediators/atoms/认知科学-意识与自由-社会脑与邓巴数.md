# 社会脑与邓巴数

## 一句话定义

罗宾·邓巴提出灵长类新皮层比例越大社会群体越大，据此推算人类舒适社交圈上限约一百五十人，即著名的邓巴数。

## 详细说明

加扎尼加认为，能约束大脑的宏观心智与责任不在单个人脑袋里，而在多脑互动的社会网络里。

牛津大学演化人类学家罗宾·邓巴提出社会脑假说：灵长类的新皮层比例越大，对应的社会群体就越大。根据人脑新皮层的大小，邓巴算出人类舒适社交圈的上限是**一百五十人**，即著名的邓巴数。

我们演化出这样一个耗能较高的大脑，最核心的驱动力不是在野外打制石器，而是为了在复杂群体里生存、合作、识别骗子、建立联盟。

从出生起大脑就预装了强大的社交装置：几个月大的婴儿看动画片里帮小球爬坡的圆圈和挡小球的方块时，更倾向于选择利他者；镜像神经元让你看见别人伸手抓苹果、或看见别人脚趾被砸时，相同脑区也会亮起，在自己脑子里实时仿真别人的感受，这是同理心和共情的来源。
