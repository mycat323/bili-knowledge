# 生命作为开放程序

## 一句话定义

生命不是一段写好的程序，而是一套不断修改自己的程序，它在运行的同时创造新的运行方式，没有最终版本，永远不会真正停机。

## 详细说明

悉尼布伦纳曾把 DNA 比作生命的软件。DNA 中四种碱基——腺嘌呤、胸腺嘧啶、鸟嘌呤和胞嘧啶——组成高度复杂的信息编码系统：三个碱基组成一个密码子，对应特定氨基酸，一连串编码经转录、翻译参与构建蛋白质及更复杂的细胞结构。于是生命不是一堆静态物质，更像一套不断运行的程序：细胞是硬件，DNA 是信息，蛋白质和代谢网络构成运行中的程序过程。

生命真正神奇之处在于这套代码能修改自己、复制自己、产生变异、与环境互动，并在漫长演化中产生此前从未存在过的结构。自然选择像巨大的测试环境：能适应环境的结构被保留，不能适应的逐渐消失。在细菌世界里，生命还能通过水平基因转移在不同个体间交换遗传信息，已非常像一个开放的网络系统。

从算法角度看，突变相当于代码变化，基因重组相当于模块重新组合，自然选择相当于真实环境对程序进行测试，而环境本身也在不断改变。普通程序通常在预先确定的规则中运行，生命却不断改变自己的规则、结构和信息——它在探索算法空间，是一套没有最终版本的软件，永远在修改自己，永远不会真正停机。
