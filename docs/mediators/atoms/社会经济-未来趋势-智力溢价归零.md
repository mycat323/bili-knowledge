# 智力溢价归零

## 一句话定义

人类智力从数百年最稀缺输入要素变为极度过剩，所有建立在智力稀缺性与溢价之上的社会制度假设同时失效。

## 详细说明

在人类现代经济史上，人类智力在漫长几百年里一直是最稀缺的输入要素：资本可以充裕，自然资源可以替代，技术迭代足够慢，以至于人类有充分时间学习适应。

我们所有的社会制度——劳动市场、房贷体系、税收法律、消费习惯——全都建立在人类智力具有稀缺性与溢价这个底层假设之上。而现在经历的恰恰是智力溢价的全面归零。

这是人类历史上第一次，生产力最高的资产创造的不是更多工作，而是更少工作。没有人的教科书里写过应对方案，因为过去没有任何一个经济学框架是为一个稀缺要素突然变得极度过剩的世界所设计的。

报告最后提醒：读者并非坐在2028年雪崩后的废墟里，股市大盘可能还在历史高位附近徘徊，负反馈螺旋还没全面铺开，预警危机的矿井金丝雀依然在歌唱。投资者仍有时间重新审查资产组合中建立在无法跨越这个十年的过时假设之上的部分；社会成员仍有时间在风暴到来前推动制度与安全网的重构。
