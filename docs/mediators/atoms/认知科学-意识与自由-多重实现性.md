# 多重实现性：条条大路通罗马

## 一句话定义

伊芙·马德的龙虾胃神经网模拟显示，超过两千万种突触参数组合中有十万到二十万种不同网络配置能产生完全相同的胃蠕动模式。

## 详细说明

龙虾胃的神经节特别简单，只有几十个神经元，负责胃的节律蠕动。按理说这么简单的系统，连线方式应该很固定。

马德的团队用计算机模拟测试了超过两千万种不同的突触强度和参数组合，结果发现竟然有**十万到二十万种**完全不同的网络配置，能产生一模一样的胃蠕动模式。这在哲学和神经科学上叫多重实现性——条条大路通罗马。

含义：大脑不需要一套死板的指令代码，底层微观网络具有较强的稳定性和灵活性，可以通过成千上万种不同的神经状态达成同一个宏观目标。

这解释了为什么全是密密麻麻的局部模块却不会乱套：不同的神经状态能产生同一种稳定行为。
