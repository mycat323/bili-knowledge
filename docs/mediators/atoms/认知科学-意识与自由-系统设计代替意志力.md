# 用系统设计代替意志力

## 一句话定义

意志力是稀缺又缓慢的低频模块，与其靠它硬刚几百万年演化出的自动驾驶系统，不如通过改变外部环境输入来重塑底层模块的竞价规则。

## 详细说明

加扎尼加一再强调：别让虚幻的意志力去硬刚几百万年演化出来的自动驾驶系统。

错误做法：想专注工作学习，却把手机放在手边，靠强大意志硬忍——底层模块每秒都在竞价，耗的全是你的能量。

正确做法：直接把手机锁进另一个房间的抽屉，从物理上切断竞价源头。与其苦练意志力，不如设计环境，用物理环境的硬约束去重塑大脑模块的自动驾驶路径。

配套的四步实践：

1. **停止自我内耗**：把无意识冲动与左脑公关分开。忍不住拖延、暴饮暴食或莫名烦躁时，以旁观者视角对自己说「看，我底层的多巴胺模块和警报模块又在竞价了，这只是电信号的正常波动」。把无意识冲动与对自己的整体评价区分开，不给左脑解释器提供自我贬低的素材。
2. **系统设计代替意志力**：给大脑造一个环境重力场。
3. **喂养优质输入**：做自己左脑解释器的首席总编。解释器是你喂它什么垃圾它就吐什么故事的系统；切断垃圾信息流，多读经典、多接触积极的人，它才还你有力量、自洽、坚韧的人生叙事。
4. **搭高质量社会约束网**：想坚持健身就加打卡小组、找严格教练；想持续输出就公开承诺更新计划；想提升认知就把自己放进优秀自律的圈子，利用镜像神经元和模仿机制被动完成行为升级。
