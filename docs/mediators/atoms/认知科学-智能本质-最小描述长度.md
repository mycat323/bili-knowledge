# 最小描述长度

## 一句话定义

真正有力量的科学规律应当比它所解释的现象更加简洁，用极其复杂的曲线强行拟合数据并不构成真正的解释。

## 详细说明

早在十七世纪，莱布尼茨就已隐约触及后来成为算法信息论核心的问题：什么才算真正的规律？如果一堆数据可以用一条极其复杂的曲线强行拟合，这种描述并没有真正解释什么。真正有力量的科学规律应该比它所解释的现象更加简洁。这与今天所谓的最小描述长度思想有很深的亲缘关系。

莱布尼茨还是二进制体系的重要奠基者，他意识到只需零和一两个符号，通过不同位置组合就能表示极其复杂的数字和结构。这对他不只是数学技巧，还带有哲学意味：在他的思想里，零和一与虚无和存在这样的概念发生联系，数学、逻辑、信息和宇宙起源产生奇妙交汇。

几个世纪后，计算机、互联网、人工智能全部建立在离散信息结构之上，一个曾经属于哲学家的问题重新出现：宇宙到底是不是某种意义上的计算？
