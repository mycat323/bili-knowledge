# 循环反噬

## 一句话定义

软件公司按人头卖许可证，客户用其软件裁掉员工后注销对应账号，导致软件公司自身收入基石被摧毁的自我吞噬机制。

## 详细说明

2026年10月，一家头部企业软件巨头发布第三季度财报：年化合同增速腰斩，同时宣布裁员15%，股价当天暴跌18%。华尔街由此看懂了一个恐怖循环：

1. 该公司按人头账号卖软件许可证；
2. 客户为降本增效，用AI替代15%白领员工；
3. 客户顺手注销这15%的软件账号；
4. 软件公司收入基石被机械性摧毁。

与柯达、黑莓式的傲慢抵制不同，这一轮老巨头不敢抵制，反而比谁都疯狂拥抱AI：股价几天暴跌40%~50%，董事会施压，管理层唯一选择是疯狂裁员，把省下的薪水全部投进算力。

每一家公司的个体选择都是理性的，但加总结果是毁灭性的：企业省下的每一块钱薪资都变成投入AI的炮弹，精准打向下一批白领的饭碗。
