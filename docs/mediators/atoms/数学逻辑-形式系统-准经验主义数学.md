# 准经验主义数学

## 一句话定义

计算机不应只是证明已知结论的工具，也可以成为数学家的实验室，但计算实验不能自动替代严格证明。

## 详细说明

传统数学重视从公理出发、经逻辑一步步推出结论的严格证明，这种方法的力量毋庸置疑。但算法信息论提醒我们，数学宇宙中可能存在大量不可压缩的信息，有些事实我们能计算、能观察，却很难从更短的规则中推出。

于是出现准经验主义的数学观念：计算机可以成为数学家的实验室，数学家像物理学家做实验一样大规模计算、观察、寻找模式。当然，计算机实验不能自动替代严格证明——一个模式计算了一万亿次都成立，也不意味着它在逻辑上永远成立。但实验可以帮助发现问题、找到新结构，甚至判断哪些地方值得证明、哪些地方可能存在完全不同的理论。

这其实是科学一直以来的方式：实验与理论不是敌人，而像两只眼睛，一只负责观察，一只负责解释。真正危险的不是严格证明，而是把某一种方法当成唯一合法的思维方式。科学一旦只奖励可量化成果、只追逐论文数量与短期指标，就容易失去提出真正奇怪问题的能力，而许多重大突破最初都显得不合规。
