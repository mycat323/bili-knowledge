# 电车难题：直觉在先理性在后

## 一句话定义

乔舒亚·格林的核磁共振研究显示，非个人化道德抉择激活前额叶逻辑区，亲手推人的抉择激活腹内侧前额叶情绪社交区，道德判断是直觉情绪在先、理性逻辑在后。

## 详细说明

情境一：失控电车冲向轨道上的五个人，拉一下扳手让它变道只会压死一个人。超过百分之八十九的人选择拉，用一条命换五条命，是功利主义的选择。

情境二：同样五个人在轨道上，你站在天桥上，旁边有个素不相识的胖子，唯一办法是亲手把他推下去挡住电车。超过百分之八十九的人选择绝对不推。

纯从数学看两个情境都是一换五，为什么选择一百八十度大转弯？神经科学家乔舒亚·格林用核磁共振扫描受试者大脑：面对情境一这种非个人化的道德抉择，负责冷酷逻辑计算的前额叶被激活；面对情境二这种亲手推人的直接暴力，演化极古老的情绪和社交脑区——腹内侧前额叶明显增强，强烈的生理厌恶感像踩死刹车一样拉住手上的动作。

心理学家乔纳森·海特概括：人类的道德判断本质上是直觉和情绪在先，理性和逻辑在后。我们天生预装了关于伤害、公平、忠诚、权威、纯洁的底层道德模块；等这些模块产生情绪直觉，左脑解释器才粉墨登场，为这份直觉编出一套看似高大上的道德理论。
