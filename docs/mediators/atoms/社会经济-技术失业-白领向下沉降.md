# 白领向下沉降

## 一句话定义

被AI替代的高薪白领向下涌入低薪服务业与零工经济，挤爆原有低收入生态并拉低全社会工资水平的连锁过程。

## 详细说明

报告中的典型案例：一位资深产品经理，有完备医疗保险和养老金，年薪18万美元，在公司第三轮裁员中失业。苦找六个月无果后开网约车，年收入从18万美元断崖式跌到4.5万美元。

罕见的是二阶数学效应：把该案例乘以各大都市圈数十万高薪白领，这些高学历过剩劳动力涌入零工市场，瞬间挤爆原本属于低收入群体的生态，导致服务业与零工市场整体工资被进一步拉低。局部行业的技术置换，演变为全社会范围的薪资压缩。

更糟的是兜底网也是暂时的：无人驾驶出租车和无人配送车在2027年加速普及，准备切断被置换白领的最后退路。2027年第三季度，每周初请失业金人数飙升到接近50万人，创近年最高，其中绝大多数是白领专业人士，美股大盘接下来一周重挫6%。
