# 优质房贷违约潮

## 一句话定义

2028年信用评分极高、首付充足的优质借款人因高薪机会被AI抹平而无力偿还房贷，与2008年次贷危机性质相反的结构性违约。

## 详细说明

2028年6月，权威房屋价值指数显示旧金山湾区房价同比跌11%，西雅图跌9%，奥斯汀跌8%。房贷机构警示：科技与金融从业人员占比超四成的区域，优质巨额贷款早期违约率异常飙升。

这不是2008年次贷危机的翻版。2008年是金融机构把钱借给根本没有还款能力的人，贷款第一天就是坏账，是坏人借了坏钱。2028年这批借款人信用评分极高、付了足够首付、信用记录干净、工作履历稳定，在所有风险模型里都是最坚不可摧的优质资产，是好人在第一天借了合理的钱。

但几年后，整个世界把他们赚高薪的机会抹平了。他们借钱买房时锚定的是一个再也无法拥有的未来。失去几十万年薪、只能靠零工收入维持的断崖式降薪群体，就算耗尽储蓄、取消一切可选消费，也终会在某天支撑不起高额月供。当13万亿美元规模的市场出现结构性裂痕，美股大盘最终跌幅被推演为追平2008年金融危机，退回2022年底AI刚问世时的起点。
