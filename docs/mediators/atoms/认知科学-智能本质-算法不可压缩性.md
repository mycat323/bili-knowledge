# 算法不可压缩性

## 一句话定义

真正随机的数据不存在比它本身更短的规律，要准确记录它最可靠的方法就是原样记录，这类对象被称为算法不可压缩的。

## 详细说明

设想不断抛硬币，正面记作一，反面记作零，得到一串二进制序列。如果这串数据真的完全随机，你无法说「前面出现了零一，所以后面大概率还是零一」，因为真正的随机数据不承诺下一位是什么。

这意味着不存在一个更短的程序能生成同样的序列，最可靠的记录方式就是把它原样抄下来。这就是算法不可压缩性。

它令人不安的地方在于：科学最擅长寻找规律，但如果数学世界里真的存在大量这样的不可压缩对象，那么依赖寻找规律的理性方法还能走多远？这个问题把讨论从「理解是什么」推向「理解的极限在哪里」，并引出二十世纪数学的思想危机。
