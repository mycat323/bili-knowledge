# 左脑解释器：事后找补的发言人

## 一句话定义

左脑中的解释器模块在底层模块做出无意识反应后，于毫秒间编造出连贯合理的理由，让人误以为决定是深思熟虑的结果。

## 详细说明

加扎尼加用割裂脑实验展示了这个模块。为治疗严重癫痫，医生会切断连接左右脑的胼胝体；视神经构造使左视野信息进右脑、右视野信息进左脑，而语言中枢绝大多数只在左脑。

实验：向患者左脑（右眼）展示鸡爪图片，向右脑（左眼）展示雪景图片，再让左右手各挑一张相关卡片。右手（左脑控制）挑母鸡，左手（右脑控制）挑扫雪铲。当被问「为什么左手拿铲子」时，负责说话的左脑根本不知道右脑看见了雪景，却回答：鸡爪配母鸡，铲子嘛，清理鸡舍里的鸡粪刚好需要。

左脑解释器像公司的公关部发言人：对底层各部门的冲动一无所知，被追问时立刻面不改色地编出一整套战略规划。

日常版本：吃完巧克力蛋糕后解释「今天太累，补补脑，明天多跑两公里」；直播间冲动下单后解释「性价比高，迟早用得上」；莫名烦躁时找个倒霉蛋怪上去。道理是解释器事后编的，行动是底层模块当场冲动出来的。
