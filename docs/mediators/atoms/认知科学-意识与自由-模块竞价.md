# 模块竞价：大脑没有总司令

## 一句话定义

大脑由约八百六十亿神经元组成的成千上万个专业模块并行运行，各模块无高低贵贱地争夺意识控制权，类似谷歌广告的实时竞价系统。

## 详细说明

加扎尼加的核心模型：大脑等于千万个去中心化的微型模块在并行自动驾驶，再加一个负责组织解释的左脑解释器。

我们常以为脑袋里坐着一个小人（自我或灵魂）在拉操纵杆，但四十年研究指向：脑子里根本没有总司令。大脑是高度去中心化、超大规模并行分布的复杂网络，由约八百六十亿个神经元组成，被切成成千上万个极度专业的功能模块——有的识别线段倾斜度，有的看见蛇就拉响恐惧，有的对高糖高脂食物产生冲动。

加扎尼加的比方是谷歌广告竞价系统：没有人工审核员挑广告，而是成千上万广告主按出价、匹配度和质量分在一毫秒内无声竞价，出价最高者更容易显现。你想去健身房又想躺床上刷手机，背后是两组神经模块在后台疯狂举牌，哪组电信号更强、多巴胺更浓，哪组就抢占意识的中央舞台。

由此可解释自律为何难：意志力是跑得最慢、最耗能的低频模块。深夜加班、低血糖、压力大时，前额叶理性模块失去竞价优势，杏仁核、基底核、边缘系统等演化了几百万年的原始模块更容易胜出。
