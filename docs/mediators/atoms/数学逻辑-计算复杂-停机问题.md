# 停机问题

## 一句话定义

不存在一个通用算法能正确判断任意程序最终是否会停机，这不是计算能力或技术成熟度的问题，而是逻辑上根本不存在这样的通用计算方法。

## 详细说明

一九三六年，图灵从「什么叫计算」出发，设计出足以表达一般计算过程的抽象机器，即图灵机。在研究过程中他遇到一个朴素却无法解决的问题：能否写出一个程序，专门判断其他程序最终会不会停下来？

假设存在一台万能预言机。构造一个专门捣乱的程序：它先调用预言机预测自己。若预言机说「你会停」，它就故意进入无限循环；若预言机说「你不会停」，它就立刻停止。于是无论预言机怎么回答，都会被这个程序反过来推翻。因此不存在能正确判断所有程序是否停机的万能算法。

这一步把边界从「证明」推进到「计算」：哥德尔告诉我们有些真理无法证明，图灵进一步告诉我们有些问题甚至无法计算。二者联系起来看，不完备性似乎来自更深的地方——计算本身的边界。
