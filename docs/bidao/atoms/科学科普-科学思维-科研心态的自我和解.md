# 科研心态的自我和解

## 一句话定义

科研心态的自我和解是接受自己可以不擅长科研、接受普通毕业，只要达到毕业要求且内心自洽即可。

## 详细说明

毕导把「与自己和解」视为自己科研走上正轨的关键因素，而不是科研水平的进步。

他复学初期每天在迷茫中睡去、在困惑中醒来，陷入不能毕业的恐慌，甚至深夜搜索读研抑郁怎么办。转折点来自一位学术大神师兄的话：你可以志存高远地科研，也可以心平气和地科研；你擅长科研就追求优秀的毕业，不擅长科研就接受普通的毕业。只要你能堂堂正正达到毕业要求，那两种选择都成立，关键是内心要自洽，别拧巴。选前一条路别看不起选后一条路的，选后一条路别看不起自己。

毕导当时以为听到了读博的真谛，后来明白在科研大佬心中这就叫躺平。但心态转变确实让他轻松了一些。他用笔记软件记录代码和数据，并用一个表情描述每天的成果，回头看每一天的情绪像过山车一样跳跃，但也不时会做出一点小成果。

他强调不同的人有不同走出科研困境的方式，这种和解不是放弃，而是让信心先立起来，再靠信心撑过读博这场苦行。
