# 知网采购费统计方法

## 一句话定义

在政府采购网搜索「学校名+知网/数据库/期刊」，即可查到高校知网数据库采购的预算价与合同价，部分结果也可通过百度直接搜到。

## 详细说明

高校采购知网数据库属于政府采购行为，因此采购公告会公开在政府采购网上。检索时把学校名称与「知网」「数据库」「期刊」等关键词组合输入搜索栏，就能找到该校某年度的采购项目。

公告中通常包含两个关键数字：

| 名称 | 含义 |
| --- | --- |
| 预算价 | 学校计划花多少钱 |
| 合同价 | 学校实际花多少钱 |

两者的差值可以粗略理解为砍价金额，但这只是朴素理解，不同学校采购的数据库内容和范围不同，不能直接横向比较谁被坑得更惨。

以清华大学为例，2021 年知网采购金额为 188 万元，在校生约五万人，相当于每人要看 37 块钱的文献才能回本。
