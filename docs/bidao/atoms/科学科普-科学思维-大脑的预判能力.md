# 大脑的预判能力

## 一句话定义

大脑并不只是被动接收外界信息，而是不停寻找外界环境的最佳模拟，从而能提前半秒预判运动物体的位置。

## 详细说明

接住一个飞来的球时，大脑显然没有在瞬间完成微积分、平抛运动和马格努斯效应的计算——连不懂微积分的人也能轻松接住球。心理学认为，大脑并不只是简单从外界获取信息，它更是不停寻找外界环境的最佳模拟。

因为我们曾经看见过千百个飞行的球，所以能够脑补出半秒后的球在哪；因为我们见过阴影带来的黑暗，所以一堆视错觉图片才能够成立；因为我们平时都能看见自己的手，所以才会把被插的橡胶手错当成自己的手。

这种预判能力和数觉遵循同一条规律：练习越多，能力越强。数数多了，数觉就会越来越强；接球多了，预判就越来越准。我们多练习一次，大脑就会进步一点点；多探索一些未知，人类常识的边界就会向外拓展一点点。
