# 高斯绝妙定理

## 一句话定义

曲面在等距变换下各点的高斯曲率保持不变，因此只有高斯曲率相同的曲面之间才能相互弯折或展平，曲率不同则永远无法互相转化。

## 详细说明

高斯绝妙定理的核心是：只要曲面不发生拉伸或压缩（即等距变换），曲面上每一点的高斯曲率就恒定不变。

所谓等距变换，是指弯折前后曲面上相邻两点之间的距离保持不变。一张纸可以卷成筒、卷成锥，怎么卷都行，因为纸面内任意两点的距离没变；而一块布被拉长时点点距离改变，就不是等距变换。

由此可以判断曲面能否展平：

| 曲面 | 高斯曲率 | 能否展平 |
| --- | --- | --- |
| 平面、圆柱面、圆锥面 | 0 | 能 |
| 球面、橘子皮、蛋壳 | 正数 | 不能 |
| 薯片、马鞍面 | 负数 | 不能 |

橘子皮本来近似球面，高斯曲率为正，无论怎么剥碎，每块小碎片仍是翘的，永远无法贴合平铺在桌面上；蛋壳同理。而圆柱形的纸卷、圆锥形的可爱多包装纸都能完全展平，因为它们的高斯曲率处处为零。

该定理的深刻之处在于：等距变换只约束曲面内部的距离关系，而高斯曲率描述的是曲面在外空间中如何弯曲，内在的距离竟然决定了外在的弯曲性质。它是现代微分几何的开端，高斯的学生黎曼在此基础上发展出黎曼几何，又成为广义相对论的基础。
