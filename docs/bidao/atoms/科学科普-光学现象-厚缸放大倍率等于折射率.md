# 厚缸放大倍率等于折射率

## 一句话定义

亚克力大厚缸从侧面看会把内部液体放大变粗，放大倍率等于该液体的折射率，而厚缸自身内径的放大倍率等于亚克力的折射率1.49。

## 详细说明

往厚缸里分别倒入蜂蜜、水、油，从侧面看它们都会被放大变粗，但放大倍率各不相同，非常反直觉。实测结果是：水被放大到1.33倍，油被放大到1.47倍，都等于各自的折射率；而厚缸自身内径被放大到1.49倍，等于亚克力的折射率。

也就是说，同一个缸里同时存在两套放大标准：液体的粗细按液体的折射率放大，缸的边界按亚克力的折射率放大。

因为常见液体的折射率都小于亚克力，液体放大后的直径都还落在缸的内径之内，所以从侧面看总能同时看到液体轮廓和缸壁轮廓。这一规律是后面几个现象的基础：折射率越大的液体看起来越粗，折射率接近1的气体几乎不变粗。

可动手验证：拿一个厚壁透明亚克力容器，分别倒入已知折射率的液体（水1.33、食用油约1.47），从侧面拍摄比较液柱宽度与真实内径的比例。
