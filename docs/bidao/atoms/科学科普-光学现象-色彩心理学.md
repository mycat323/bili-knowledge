# 色彩心理学

## 一句话定义

颜色不仅是一种主观感受，还会受认知、心理、环境因素影响，冷色给人沉静安定感，暖色给人活力欢乐感，并会改变人对时间长短的感受。

## 详细说明

视频中给出的现象是：冷色往往让人感到沉静安定，暖色则让人感到活力欢乐。颜色还会影响时间感知——在蓝色海水里潜水，明明报了一小时的项目，感觉才过了二十分钟；相反在暖色调环境下，等待会显得格外漫长。

一个常见场景是约在快餐店见面：暖色环境会影响对时间的感受，让人觉得等待格外漫长，还会越等越饿。

利用色彩心理学可以调节状态：把书桌的光选成冷色荧光灯、电脑桌面改成 Windows 蓝，营造层次丰富的冷色氛围，有助于专注；床边刷上暖色调，则更适合刷剧打游戏。
