# 狼人杀是社会的缩影

## 一句话定义

狼人杀看似是逻辑的大比拼，实则是性格的试金石，数学模型能算出最优策略却算不透人性。

## 详细说明

狼人杀著名玩家裘大说过，狼人杀是社会的缩影。程序的世界里没有悍跳、没有归票、没有盲毒、没有自刀，被人查杀不会生气，被骗解药不会懊恼；而真实对局中，这些情绪和反应恰恰构成了游戏的主要乐趣与变数。

随着玩法成熟，狼人杀渐渐形成公认的潜规则：女巫第一晚必救人，预言家要熟练留警徽。不懂套路，高玩就觉得你是小白不会玩；小白输了就会背锅、被喷。于是游戏逐渐两极分化，玩时笑嘻嘻，复盘 MMPP。

但归根到底，游戏最重要的不是输赢，而是开心。有些人虽然打得好，却对输赢太计较；有些人虽然玩得差，但说话全场都笑炸——后者才是狼人杀的最高境界。

这个观察也适用于更广的场景：任何用规则和策略描述人类行为的模型，都会在情绪、幽默和关系面前失效。数学模型可以给出最优解，但人际互动的价值往往不在最优解上。
