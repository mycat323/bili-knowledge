# 贝里悖论

## 一句话定义

贝里悖论指出：若假设存在不能用二十个以内汉字表达的自然数，则必存在一个最小的这类数，而这个数恰好被「最小的不能用二十个以内汉字表达的自然数」这句话用二十个字以内表达出来了，矛盾。

## 详细说明

贝里悖论的一个通俗版本是：所有的自然数都能用二十个以内的汉字表达出来吗？

直觉上不可能，因为汉字数量有限，二十个字的组合也是有限多，而自然数有无穷多个。但反证法会给出矛盾：

1. 假设存在一些不能用二十个以内汉字表达的自然数；
2. 则必存在一个最小的不能被二十个以内汉字表达的自然数；
3. 但这个数刚刚已经用「最小的不能被二十个以内汉字表达的自然数」这句话，在二十个字以内表达出来了；
4. 矛盾。

于是结论变成：所有的自然数都能用二十个字以内表达。视频中邀请观众讨论问题究竟出在哪一环。

与之类似的还有「有趣数字论」：假设存在无趣的自然数，则必存在最小的无趣自然数，而「最小的无趣自然数」这个身份本身就很有趣，故原假设不成立，所有自然数都有趣。这类悖论与罗素悖论同属二十世纪初打破数学对错分明信念的数学矛盾。
