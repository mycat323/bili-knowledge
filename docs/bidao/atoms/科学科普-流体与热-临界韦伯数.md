# 临界韦伯数

## 一句话定义

描述液体射流飞溅难易程度的无量纲数，液体温度越高，临界韦伯数越小，越容易产生强力飞溅。

## 详细说明

韦伯数用于衡量惯性力与表面张力之比。在射流冲入液面的问题中，存在一个临界韦伯数：当射流条件超过该值时，液面会产生飞溅。

视频引用二零零三年 Manzano 等人的研究：往水池中滋水时，液体越烫，临界韦伯数越小，会产生越强力的飞溅。这与毕导自己的实验结果相符——开水冲入开水时飞溅显著强于温水冲入冷水。

物理直觉是：温度升高使液体的粘度和表面张力下降，液滴更容易被惯性力撕裂成小水滴，因此飞溅所需的临界条件更低。这一结论解释了为什么往开水里尿尿比往冷水里尿尿更危险。
