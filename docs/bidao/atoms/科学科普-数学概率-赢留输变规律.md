# 赢留输变规律

## 一句话定义

石头剪刀布中上一局的赢家倾向于保持同一手势，输家倾向于改成能克制上把手势的出法，简称赢留输变。

## 详细说明

浙大等机构的实验发现：上一局的赢家这一局倾向于不变，输家倾向于出上把手势的被克手势，即「赢留输变」。平局时的规律不明显，对方可能不变，也可能出克制上把的手势。

据此可以设计反制策略：

- 如果这局你赢了或输了，下局就出被这局克制的手势，也就是按石头→剪刀→布的顺序往下出。
- 如果平局，就反过来出克制这局的手势，也就是按石头→布→剪刀的顺序出。
- 想不清楚时，就按石头剪刀布的顺序一直出下去。

这套策略对无脑玩家非常有效，可以用左手和右手对练验证。它成立的前提是对手具有「只根据当前这轮结果决定下一轮」的马尔可夫性。
