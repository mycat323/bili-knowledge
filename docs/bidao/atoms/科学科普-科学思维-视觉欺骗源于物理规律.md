# 视觉欺骗源于物理规律

## 一句话定义

化妆品看着比实际粗并非厂商刻意设计，而是圆柱瓶壁贴壁放大这一光学规律造成的，欺骗来自物理本身。

## 详细说明

美妆博主质疑化妆品包装视觉欺骗，实验最终证明：直接看确实比真实粗，泡水后变细更接近真实，博主的结论是对的。但原因不是厂商在瓶身做了夹层或特殊设计，而是圆柱形容器贴壁放大的光学规律。

判断这类问题要区分两种解释路径：一是归因于人为设计（商家算计），二是归因于自然规律（折射）。视频中先怀疑厂商做了粉色夹层，但瓶身外侧缺口与料体缺口一一对应，排除了人为夹层的可能，最终落到折射率之比这一物理量上。

这个现象在任何一杯水里都能看到，用手指戳戳杯壁就能发现，却鲜有人研究。它说明：看似被欺骗的日常体验，背后往往是一条简单但未被注意的物理规律；把现象归因于物理规律，比归因于阴谋更经得起实验检验。
