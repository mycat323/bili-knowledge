# 科研中迷茫的心累最累

## 一句话定义

科研中真正消耗人的是方向不明的迷茫与心累，而写综述这类体力上的累相对容易承受。

## 详细说明

毕导复学后换到化工故障检测与诊断方向，虽然大方向定了，却定不下来具体研究什么创新点、今天该做什么。他形容读博就像在没有攻略的情况下五天通关艾尔登法环，最多延你两天：先刷级、先找装备，还是无用之人出门硬刚大树守卫？复学前两个月，他每天在迷茫中睡去、在困惑中醒来，并陷入不能毕业的恐慌。

他明确区分了两种累：科研中迷茫的心累是最累的，而写综述这种肉体的累对他就还好。因此当导师建议他写综述时，他白天科研、晚上码字，反而推进顺利，最终大修后 accept。

这一区分对科研新人有实际意义：当感到疲惫时，先判断是方向不清带来的心累，还是任务量带来的体力累，前者需要的是缩小问题、先做出保底成果，后者只需要按节奏推进。
