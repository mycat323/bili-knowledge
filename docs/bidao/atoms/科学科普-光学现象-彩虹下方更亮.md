# 彩虹下方更亮

## 一句话定义

彩虹下方的水滴发出的光锥中部白光进入眼睛，光量更多所以显得更亮；彩虹上方的水滴光锥不经过眼睛，所以更暗。

## 详细说明

平行光入射水滴后会变成夹角为八十四度的光锥，光锥边缘是七色，内部七色光混在一起是白光。

考察彩虹及其上下方的水滴：在彩虹位置的水滴，发出的光锥边缘刚好到达眼睛，看到的就是彩虹的形状；在彩虹下方的水滴，光锥的中间部位到达眼睛，等于这个区域有更多白光入射眼睛，看着就更亮；在彩虹上方的水滴，光锥压根不会经过眼睛，光少了看着就暗。

彩虹下面的天空比上面更亮，就是这么简单的道理。
