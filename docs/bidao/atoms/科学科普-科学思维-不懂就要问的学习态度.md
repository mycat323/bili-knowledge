# 不懂就要问

## 一句话定义

遇到不懂的问题主动提问、主动搜索答案，而不是搁置或回避，是把未知转化为已知的第一步。

## 详细说明

视频反复唱到「千万别再等，不懂就要问」，把提问当作学习的起点而非丢脸的事。

背后的逻辑是：问题不会因为被搁置而消失，只会持续消耗注意力。歌词里「每天太多的问题始终缠绕在你胡思小脑袋」，描述的正是问题积压带来的内耗。主动发问或主动去查，才能把缠绕的疑问变成可解决的具体问题。

可操作的做法：

| 步骤 | 动作 |
| --- | --- |
| 1 | 把模糊的困惑写成一句具体的话 |
| 2 | 判断这是「没学过」还是「没想通」 |
| 3 | 前者去查资料，后者去问人 |
| 4 | 得到答案后复述一遍，检验是否真懂 |

歌词把提问和「求知欲」并列，强调「保持你的求知欲别被过程定义」——提问的动力来自好奇，而不是分数压力。
