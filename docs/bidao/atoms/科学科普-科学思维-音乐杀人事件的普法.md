# 音乐杀人事件的普法

## 一句话定义

罗翔用一个思想实验普法：仇人组织人在心脏病患者病房门口唱一晚上歌，导致患者心脏病发作死亡，这构不构成犯罪。

## 详细说明

罗翔老师在录音前讲了一个案例：

有一个人得心脏病，医生要求绝对静养。他的仇人组织了一波人在他病房门口唱了一晚上歌，结果他真的心脏病发作死了。

罗翔提出的问题是：这构不构成犯罪？

这个案例的核心在于因果关系的认定：行为人的行为（唱歌）与死亡结果之间是否存在刑法上的因果关系。罗翔在视频中没有给出最终结论，但这个案例本身展示了普法的一种方式——用极端但可理解的情境，把抽象的法律问题具体化。

毕导描述这个过程时说「普法的罗老师浑身散发着智慧的光芒，和刚才听rap时判若两罗」，说明罗翔在进入普法状态时和放松状态下的表现差异很大。
