# 自由意志与原子决定

## 一句话定义

若人的每个原子都遵循物理规律，则人的行为也被过去决定，自由意志在决定论观点中并不存在，你并不比硬币高级。

## 详细说明

如果我能知道一个人所有原子这一刻的性质，那理论上每个原子未来的运动都是被决定了的，你整个人接下来的行为其实也是被决定了的。你表白被拒并不是女神的选择，而是那些女神原子在按客观规律行动。

在决定论的观点里面，自由意志并不存在。你以为是自己自由地决定做某件事，但其实你自以为自由的决定是已被客观规律所决定了的。只要我算力够强，我能根据硬币的原子坐标预测硬币未来的运动，我也能根据你的原子坐标预测你的未来运动。你并不比硬币高级，你们都是原子。

《信条》中男主第一次在女材料学家实验室里看到逆转子弹时就问了这个问题：我能看到未来的弹孔，说明开枪在未来是注定发生了的；我的车后视镜碎了，说明撞车在未来是注定发生了的。如果我自以为自由的选择只是将我导向未来确定的事件，那我还有自由意志吗？

爱因斯坦在写给泰戈尔的信里说：如果月亮在其环绕地球的永恒运动中被赋予自我意识，它就会完全确信它是按照自己的决定在其轨道上一直运行下去。这样会有一个具有更高洞察力和更完备智力的存在物注视着人和人的所作所为，嘲笑人以为他按照自己的自由意识而行动的错觉。爱因斯坦的下一句话是：这就是我的信条。
