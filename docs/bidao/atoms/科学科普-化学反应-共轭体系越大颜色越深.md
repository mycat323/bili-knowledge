# 共轭体系越大颜色越深

## 一句话定义

分子中单双键交替的共轭体系越大，电子跃迁所需能量越低，吸收波长越长，物质颜色越向深色和长波方向移动，深色物质往往具有更复杂的分子结构。

## 详细说明

共轭体系的大小直接决定吸收光的波长。共轭越大，π→π* 跃迁能级差越小，吸收的光波长越长。因此深色物质通常具有更大的共轭体系，例如紫色石蕊、甲基橙、花青素，分子中往往含有多个苯环。

除共轭结构外，含有 O、R、S、N、P 等原子的基团也会促进吸收光谱红移，具体移动多少可用一些经验公式估算。

视频中列举的天然色素也印证了这一点：番茄红素分子有长有短，粪胆素又大又圆，叶绿素由四个吡咯构成卟啉环并嵌有一个镁原子，黑色素则是超级共轭大分子，不饱和度难以数清。这些分子人工合成难度极高，但每一片叶子都能合成叶绿素。
