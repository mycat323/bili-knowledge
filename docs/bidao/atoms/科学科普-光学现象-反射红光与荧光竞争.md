# 反射红光与荧光竞争

## 一句话定义

青红酒本色红光反射与蓝光激发的绿色荧光一直同时存在，哪束光更强，人眼就主要看到哪种颜色；酒坛、银碗、黑碗的差别在于反射红光的强弱。

## 详细说明

青红酒本身是红褐色，光照时酒中荧光物质吸收白光中的蓝光、发出绿色荧光。其实本色红光和绿色荧光一直都在，哪束光厉害，你看到的就是哪一种颜色。

比如在银碗里装酒，酒也在发出绿色荧光，但碗底反射的红光人多势众，绿队被压制，所以你看到本色的红。在黑碗里，碗几乎不反光，酒看着是黑色；即使打着光，反射的红光还是很弱，红队关闭，绿队又占领高地，你就能看到荧光的绿。

大酒坛子相当于黑碗的效果，它削弱红光、保留绿光，所以从坛口看被顶光照到的酒呈绿色。这个竞争关系解释了为什么同一杯青红酒在不同容器和光照条件下会呈现红、绿甚至黑色。
