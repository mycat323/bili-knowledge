# 选择城市即选择生活方式

## 一句话定义

在哪个城市生活，本质上不是地理或经济问题，而是选择一种生活方式；而人生不同阶段想要的生活方式大概率不同。

## 详细说明

毕导把「去北京还是去杭州」重新定义为一个生活方式问题，而不是城市优劣问题。

他给出三个阶段的例子：

| 阶段 | 想要的生活方式 |
| --- | --- |
| 二十几岁 | 在帝都仗剑走天涯 |
| 三十岁后 | 自己和公司小伙伴都要安家立业 |
| 六十岁的父亲 | 琢磨怎么去昆明养老 |

同一个人在不同年龄会给出不同答案，所以「哪个城市更好」这个问题本身就没有唯一解。天气、演出、美食这些维度因人而异，如人饮水冷暖自知。

把选择还原成「我想要怎样的生活」，比罗列城市优缺点更能帮助决策，也解释了为什么别人眼中的好选择未必适合自己。
