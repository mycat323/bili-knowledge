# 大脑合成水中两个虚像

## 一句话定义

人眼虽能接收到子午像和弧矢像两个虚像，但大脑会把它们合成为一个像，最终让人感觉水下物体仍位于实际位置的正上方。

## 详细说明

眼睛确实能看到一前一后两个像，但大脑会主动把它们合成掉。

原因在于：如果一个人站在水里，他的腿向观察者靠近，看起来会很奇怪。大脑为了避免这种不自然的视觉，把子午像合成掉，只让人感受到弧矢像的效果，于是你不会觉得水里的物体在靠近你。

用双眼看水下物体时，理论上可以看到三个像：左眼子午像、右眼子午像和双眼重合的弧矢像。如果两只眼睛竖着排列，甚至会看到左眼子午、右眼子午、左眼弧矢、右眼弧矢四个像。但大脑会把它们通通合成为一个，否则水里会出现四条鱼。

所以「水中的鱼在哪」要分层次回答：按折射定律作图，虚像更靠近人眼；考虑三维世界，物体有两个像；考虑大脑处理，最终感觉物体仍在实际位置正上方。
