# 纸张做刀

## 一句话定义

纸张能划破手是因为其厚度与菜刀刀刃最薄处相当，丹麦技术大学计算指出 65 微米厚的纸做刀最锋利，太厚只能压疼手指，太薄则一碰就弯。

## 详细说明

翻书写字时被纸划破手，是因为菜刀刀刃最薄的地方一般是 0.1 到 0.3 毫米，而一张 A4 纸的厚度也差不多，纸真能跟菜刀一样锋利。

一群来自丹麦技术大学的科学家通过理论计算指出，65 微米厚的纸最适合做刀：

- 纸太厚，不够锋利，最多只能把手指压疼；
- 纸太薄，一碰到手指自己就先弯了。

现实中接近这个理论最佳厚度的纸，正是 Science 和 Nature 这类期刊用纸。论文称它可以直接切开苹果、黄瓜甚至鸡肉，但视频作者实测自己买的那本啥也切不开。

这项研究的意义在于：印刷厂可以据此少用锋利的纸出书，保护读者的手。文章发表在 PRE 上，影响因子 2.2。
