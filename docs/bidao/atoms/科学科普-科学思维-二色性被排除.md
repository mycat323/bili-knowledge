# 二色性被排除

## 一句话定义

青红酒有薄层黄、厚层红的二色性，但薄层是黄色，与光照下的绿色荧光完全不同，所以二色性也不是光照变绿的原因。

## 详细说明

普通液体薄薄一层和厚厚一坨，颜色一浅一深，但基本是同一种颜色。某些特殊液体，比如按摩精油、南瓜籽油，薄薄一层是绿色，厚厚一层是深红色，这种薄一个颜色、厚另一个颜色的性质叫二色性。

有人据此认为青红酒和南瓜籽油一样是厚红薄绿，平时看到厚的红色，打强光时在局部看到薄的绿色。实验验证：把青红酒倒出来，桶中酒为红色，桶外液柱却为黄色；装在烧瓶里，从底下看薄层是黄色，从侧面看突然变成红色。把无机颜料和青红酒装在不同厚度的比色皿里，普通颜料只是颜色变深，青红酒的色调都变了，所以它有点二色性。但它的薄层是黄色，和光照下那种绿色完全不一样。因此二色性不是它光照变绿的原因。
