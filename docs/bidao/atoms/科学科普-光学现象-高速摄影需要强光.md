# 高速摄影需要强光

## 一句话定义

高速摄影机把快门拉到千分之一秒级别，进光时间极短，因此需要比常规视频强几十倍以上的照明才能正常曝光。

## 详细说明

影视飓风团队使用的高速摄影机最高可在画质很差的情况下拍摄四万帧每秒，而常规视频只有 25 帧或 50 帧。

帧率与曝光的关系：

- 常规 25 帧时，每帧曝光时间约 1/50 秒。
- 升格拍摄时快门要拉到约 1/1000 秒，单帧进光时间缩短到原来的几十分之一。
- 因此需要比正常视频强至少几十倍以上的光，团队形容现场「已经亮的我快瞎了，我根本就睁不开眼」。

另一个关键限制是**频闪**：拍慢动作必须使用 LED 灯，因为传统灯具的交流供电会产生频闪，在极短曝光下会表现为画面亮度不均或闪烁。团队为此使用了高功率 LED 灯（六百 D），亮度高到人站在灯前会直接过曝。

帧率换算示例：四万帧相对 25 帧是 1600 倍慢放。团队实际拍摄水射流时用的是约 1500 帧，拍特斯拉线圈电弧时拉到两万帧，此时画质会明显下降，但才能看清电弧形态。
