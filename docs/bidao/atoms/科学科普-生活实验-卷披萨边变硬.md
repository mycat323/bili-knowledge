# 卷披萨边变硬

## 一句话定义

把扇形披萨的边卷起来，披萨会沿另一方向自动挺直变硬，这是为维持高斯曲率为零而被迫产生的几何约束。

## 详细说明

一块扇形披萨本来是平面，高斯曲率为零。根据高斯绝妙定理，只要不发生拉伸，它无论怎么被拿起都必须保持高斯曲率为零。

具体机制是：如果沿某个方向把披萨卷弯，该方向曲率不再为零；为了维持两个主曲率之积等于零，另一个方向的曲率就必须为零，也就是必须保持笔直。于是披萨沿径向自动挺直，尖端不再下垂，可以优雅地拿着吃。

从材料力学看，卷起披萨使该方向的惯性矩变大，内部应力产生的抵抗力矩足以对抗自身重力矩，所以变硬。但几何上的解释更本质：物理上的应力是几何约束带来的必然结果。

同样的原理出现在很多地方：

- 瓦楞纸沿波浪方向容易掰弯，垂直波浪方向抗弯能力可增长几十倍。
- 小草和叶片常长成中间低、两边高的弧形，靠这种结构抵御风雨。

验证方法很简单：拿一块软披萨或一张纸，卷起一边，观察另一方向是否自动挺直。
