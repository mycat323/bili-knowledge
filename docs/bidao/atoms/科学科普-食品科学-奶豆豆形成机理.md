# 奶豆豆形成机理

## 一句话定义

奶豆豆是冲奶粉时水包住一小坨奶粉却无法渗透到内部形成的团簇，外层是湿奶糊，内部是未被水接触的干奶粉。

## 详细说明

奶豆豆的本质是水没能完成对奶粉的润湿和渗透。捞起一个奶豆豆观察，它的外面是一层湿的奶糊糊，内部是没有被水接触到的干奶粉。

为什么盐、糖、咖啡等粉末冲水不会起痘，唯独奶粉会？关键在于奶粉是疏水材料。把水滴在玻璃上会铺展成液膜，说明玻璃亲水；把水滴在疏水表面则形成圆滴，水滴越圆说明材料越疏水。把奶粉压成饼滴水上去，水珠也很圆，说明奶粉疏水，并不喜欢被水冲。

疏水材料不喜欢接触水，而喜欢接触空气。奶粉颗粒之间夹带着空气，水要进入奶粉团内部，必须先排开这些空气。如果润湿和渗透这两步没做好，水就只能包住外层，形成冲不开的奶豆豆。
