# 水中物体有两个虚像

## 一句话定义

三维世界中水下物点发出的光是一个光锥而非两条光线，不同方向平面内的光线分别相交，形成位置不同的子午像和弧矢像两个虚像。

## 详细说明

教材作图把水下物点简化成两条光线，等价于「一条二维鱼被二维纸片人的一维眼睛看到」。真实情况是：水下物点向人眼发出的是一个光锥。

把光锥按方向拆开看：

| 光线所在平面 | 相交形成的像 | 位置特征 |
| --- | --- | --- |
| 左右方向的竖直平面 | 子午像 | 离人眼更近，横向拉长成一条短横线 |
| 上下方向的仰角平面 | 弧矢像 | 在物点正上方，竖向拉长成一条短竖线 |

因此水下的一个点会形成两个虚像。用长焦浅景深相机对焦可以分别捕捉到它们：对焦到靠近镜头的位置时，钢球反光点变成一条清晰横线（子午像）；继续往里对焦到水缸后壁附近时，光点又变成一条清晰竖线（弧矢像），位置约在钢球实际位置的正上方。

由于子午像横向拉长、弧矢像竖向拉长，水下物体看起来一定是模糊的。
