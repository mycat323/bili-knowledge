# 贝弗洛定律

## 一句话定义

描述颗粒通过细口流量的经验定律，流量 F 等于 C 乘以根号 g 再乘以 ρA 的四分之五次方，其中 C、g、ρ、A 均为定值。

## 详细说明

贝弗洛（Beverloo）定律指出，颗粒通过细口的流量为：

F = C·√g·(ρA)^(4/5)

其中 C、g、ρ、A 都是定值。由于这些量都不随堆积高度变化，沙漏的下落速度几乎可以认为是固定的——这与液体完全不同。

对比液体的直觉：如果是水，应该是先快后慢，因为开始液面高压强大、流速快。但颗粒流遵循完全不同的规律。

与之配套的还有杰森（Janssen）定律：装有颗粒的圆柱筒底部压力与堆积高度几乎无关。这正是沙漏能匀速下落的原因——底部压力不随上方沙柱高度增加而增大。

不过这个「匀速」说法有破绽：如果能增大公式中的 g，就可以加速沙漏。根据爱因斯坦相对论等效原理，重力场和以一定加速度运动的参考系等效，因此旋转沙漏产生的离心力相当于给沙子一个额外的加速度。
