# 听觉分辨水温的统计

## 一句话定义

有统计称约百分之九十六的人能凭倒水声分辨冷水和热水，说明这种听觉分辨能力在人群中相当普遍，而非少数人的特殊天赋。

## 详细说明

视频中引用了一个统计数字：约百分之九十六的人都能听出冷水和热水的区别。

**这个数字说明什么**

如果统计可靠，那么听声辨水温就不是「金耳朵」的专利，而是绝大多数人日常具备的能力。只是平时很少有人刻意去注意，所以多数人并不知道自己有这个本事。

**怎么理解这类统计**

- 它描述的是人群中的比例，不代表每个人都能百分之百判断正确；
- 判断可能依赖多次尝试，单次听错并不矛盾；
- 统计来源和实验条件会影响结果，引用时应保留「有人统计过」这一限定。

**可以自己测一测**

找一个人帮忙，随机顺序倒冷水和热水，自己只凭声音判断，多试几轮统计正确率。这既是验证统计数字的方式，也是体验「耳朵能听出温度」这一现象的简单实验。
