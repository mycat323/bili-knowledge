# 水中花园生长原理

## 一句话定义

把三氯化铁投入硅酸钠溶液中，表面反应生成硅酸铁膜，水渗入膜内继续反应把膜撑破，反复进行便长出树枝状结构，形成「水中花园」。

## 详细说明

配制方法：称量一百八十克硅酸钠，加入九百克水，搅拌均匀。

把一坨三氯化铁投入烧杯中，三氯化铁表面发生反应生成硅酸铁，硅酸铁在表面形成一层膜。水会渗透到这层膜里面，膜内再反应一点，就把膜撑破，如此不断循环，结构就一点点长高。

理想状态下，三氯化铁表面会长出一个个像小树枝一样的结构，慢慢生长起来，像花园里的大树在生长。实际观察中，投入后表面颜色会由橘黄色变为暗红色，并先伸出一条「腿」，随后向上生长。

操作时用镊子夹取三氯化铁投入溶液即可，注意戴手套。
