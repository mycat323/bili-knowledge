# 电池充放电习惯影响寿命

## 一句话定义

深度放电和长期满电存放都会加速锂电池容量衰减，浅充浅放和约百分之三十电量保存更有利于延长寿命。

## 详细说明

科学家做过实验：在同样的充放电电流下，每次用到没电才充电的电池，500 次后容量只剩 80%；而每次用了一半就充满的电池，1800 次后才衰减到 80%。每一次深度放电，电池都感觉自己身体被掏空，长此以往越来越不行。

放电强度也有影响：一块满电电池放电越猛，能放出的总电量越少。用 1C 表示一块满电电池一小时放完的电流大小，20C 的电流下电压快速衰减，放出的电量也更少。不过手机正常工作电流远小于 1C，这个范围内区别不太大。

充满后也不要一直插着。虽然好的充电器有过充保护，但出于安全还是应该拔下来。长期不用的手机定期充满电保存也不好：满电状态下较高电压会使电解液和电极发生反应，形成钝化膜。新买的电子产品一般不是满电，而是百分之三十左右的电量，这正是最适合电池长期保存的状态。
