# 黄色是时间的颜色彩色是生命的颜色

## 一句话定义

氧化让万物随时间走向黄色，而生命体内复杂快速精准的化学反应持续合成有色分子，让地球保持多彩。

## 详细说明

黄色是氧化与时间共同作用的结果：纸张、白墙、塑料、排泄物都在氧化中红移变黄，所以黄色可以看作时间的颜色。

但世界从来不缺色彩。春天有七彩斑斓的花，秋天有五颜六色的果，蜘蛛微小却绚丽，皮皮虾简单却好看。合成有色分子在实验室里很难——合成肉桂酸要一整天、产率百分之五十；而生命体内每一刻都在发生复杂、快速而精准的化学反应。

火星看上去是个土黄色的球，地球之所以多彩，是因为这里有生命。所以彩色是生命的颜色，与黄色形成对照。
