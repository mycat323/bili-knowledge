# 右手坐标系

## 一句话定义

坐标系的 XYZ 三个常用方向按右手规则排列，即用右手三指分别指向三个坐标轴，这一约定决定了叉乘方向用右手而非左手描述。

## 详细说明

为什么叉乘规定用右手而不是左手？原因不在物理，而在数学史。更早的数学家规定坐标系 XYZ 的常用方向就是右手系，即伸出右手，食指、中指、大拇指分别指向三个坐标轴的方向。

叉乘的方向规则直接继承了这个约定：食指为 A 向量，中指为 B 向量，大拇指指向 A×B。所以用右手定义叉乘，本质上是因为坐标系创立时就是这么选的，没有更深层的物理原因。

这也解释了为什么物理学家发现电磁力方向恰好符合叉乘规则时，会感到一种数学与物理的奇妙巧合——数学规则完美描述了物理现象，难免让人怀疑造物主当年就是用这个姿势设计出电磁力的。
