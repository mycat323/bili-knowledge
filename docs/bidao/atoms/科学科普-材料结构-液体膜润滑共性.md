# 液体膜润滑共性

## 一句话定义

鱼、香蕉皮、湿瓷砖等特别滑的物体有一个共性：接触面上存在一层液体膜，摩擦不是固体与固体的直接接触。

## 详细说明

生活中有很多特别滑的东西，比如鱼、香蕉皮、湿的瓷砖。把它们放在一起比较，会发现一个共性：它们的摩擦都不是固体与固体的直接接触，而是在接触面上有一层液体膜起到润滑作用。

这一共性提供了一个判断思路：当某个表面异常滑时，可以先问它表面是否存在液体层，而不是先假设材料本身摩擦系数低。滑冰被归入同一类现象——冰刀与冰面之间有一层水膜，冰才这么滑。

需要注意的是，液体膜润滑只是解释了「为什么滑」的机制框架，具体到冰，水膜的来源仍需单独说明。转写稿强调科学家相信滑冰时存在这层水膜，因此冬奥选手看上去在滑冰，本质上都是在滑水。把鱼、香蕉皮、湿瓷砖与冰并列，正是为了说明液体膜润滑是一个跨材料的通用解释路径。
