# 荧光吸收高能发射低能

## 一句话定义

荧光是物质分子吸收高能光子后，电子跃迁到激发态，再发射出低能光子；发射光能量低于吸收光，因此颜色会向长波方向移动。

## 详细说明

案发现场某些痕迹在紫外灯下呈淡蓝色，是小学二年级学过的荧光。其过程为：物质分子吸收高能光子，电子跃迁到激发态，随后再发射出低能光子。

荧光物质在生活中很常见，衣服、鞋子、纸、周围灰尘都可能有荧光。许多液体也有荧光反应：用绿激光笔照食用油，中间光路呈黄色，透过后的激光仍是绿色，说明它吸收了高能绿色激光、发出低能黄色荧光；乌龙茶、咖啡、汤力水也有各自的荧光性格。

青红酒尤其特殊，它吸绿生黄、吸蓝生绿、吸紫生青、吸紫外深蓝，能打出一整套颜色阶梯。青红酒光照变绿，正是因为白光中的蓝光被酒中荧光物质吸收，发出绿色荧光。注意，荧光不是反射：反射光颜色不变，荧光则是吸收后再发射，颜色由物质决定。
