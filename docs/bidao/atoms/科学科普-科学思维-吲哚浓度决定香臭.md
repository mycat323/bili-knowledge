# 吲哚浓度决定香臭

## 一句话定义

吲哚又名粪臭素，是粪便臭味的来源之一，但在低浓度时却呈现茉莉般的清香，同一物质因浓度不同而气味相反。

## 详细说明

吲哚（indole）是一种含氮芳香杂环化合物，俗称粪臭素，是便便臭味的主要来源之一。但同一种分子在浓度极低时，嗅觉感受完全不同——它呈现的是类似茉莉花的清香，因此被稀释后可用于香精调配。

这一现象说明气味的「香」与「臭」并非由分子种类单独决定，浓度是关键变量。毕导据此解释体香：无论男生女生，微微出汗时身上的味道可以算作体香，汗再多一点就变成体臭，本质上是同一类代谢气味物质浓度升高后的感知翻转。

需要区分的是，网上流传的「女生体香来自化妆品腌入味」只是一种说法，转写稿中并未给出验证，只能作为一种可能解释并列提及。
