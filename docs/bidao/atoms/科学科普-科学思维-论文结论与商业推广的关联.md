# 论文结论与商业推广的关联

## 一句话定义

论文通讯作者李辉同时出版茶道经、诗集并复原唐代黄茶工艺用于扶贫带货，其学术结论与商业利益存在关联。

## 详细说明

论文通讯作者李辉除学术身份外，还出版过《茶道经》、诗集《茶多语》，并复原了唐代黄茶工艺，该工艺成为贵州的扶贫项目，实现了带货。

论文中有一节叫 tea making，详细介绍每种茶的产地、风味、最佳泡法，内容接近茶产品指南。论文还提到 M0 喝一个月黄茶后治好了自己的肾结石，而李辉推广的黄茶正是同一种茶。

这并不直接证明结论造假，但提示读者：当一项研究的结论同时有利于作者本人的商业产品时，对结论应保持更高标准的审视，需要独立第三方用同样方法复现，而不是仅凭作者自述和论文配图接受。
