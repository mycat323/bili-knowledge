# 树叶变黄的色素竞争

## 一句话定义

树叶中同时含有绿色的叶绿素和黄色的胡萝卜素、叶黄素，夏天叶绿素多显绿色，秋天日照变短叶绿素减少，原本被掩盖的黄色色素便显现出来。

## 详细说明

树叶的颜色并非单一色素决定，而是多种色素含量竞争的结果。叶绿素负责光合作用，在夏季光照充足时含量高，绿色压过其他颜色。

进入秋季，日照时间变短，叶绿素合成减少并逐渐分解，而胡萝卜素和叶黄素相对稳定，于是叶子显出黄色。这与白纸、白墙因氧化而变黄的机制不同：树叶变黄是色素比例变化，不是分子被氧化生成共轭结构。

把这两条路径放在一起看，能帮助区分「变黄」的两种成因——一种是色素此消彼长，一种是化学结构改变导致吸收光谱红移。
