# 麻将不完全信息博弈

## 一句话定义

围棋是完全信息博弈，局面公开、拼的是算力；麻将是隐藏信息极多的不完全信息动态博弈，拼的是对人心与不确定性的判断。

## 详细说明

有人觉得麻将比围棋简单，围棋都被阿尔法狗攻破了，麻将算什么。但两者哪个难并不好说。

- **围棋**：变化繁多的完全信息博弈，局面是公开的，双方看到的是同一个棋盘，拼的是算力。
- **麻将**：不完全信息动态博弈，隐藏的不确定信息太多，拼的是人心，而人心是世界上最难以捉摸的事情。

一个有意思的现象是，新手往往手气很臭，老手打不过他们，因为新手打牌放飞自我、不按概率走。正所谓无招胜有招，老手也挨刀。当然，打不过新手也可能单纯是手臭。

现实世界往往不是明朗而单纯的，就像人生有太多不确定信息。从这个意义上讲，麻将比任何棋牌都更加接近真实世界。麻将的每一次摸牌都像人生中的随机事件：你随手摸了张没用的一筒没打，可能几轮之后直接凑齐三张胡牌。
