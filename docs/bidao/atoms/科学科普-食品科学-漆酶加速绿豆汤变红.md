# 漆酶加速绿豆汤变红

## 一句话定义

漆酶是一种含四个铜中心的多酚氧化酶，滴入绿色绿豆汤后十分钟即可把多酚氧化成醌，使汤由绿变红。

## 详细说明

实验：取几杯绿色绿豆汤，滴入漆酶溶液，十分钟后汤就由绿变红，滴得越多红得越明显；放置三小时后全部彻底变成红色。

漆酶是一种强力的多酚氧化酶，由四个铜中心和组氨酸、半胱氨酸、甘氨酸的氮、硫、氧原子相连构成。几滴漆酶就能让蔬菜水果中的多酚快速氧化。

这个实验的意义在于把「绿豆汤变红是氧化」这一判断从推测变成可控验证：绿色绿豆汤本身不变色，加入多酚氧化酶后十分钟就变红，说明变色的关键步骤就是多酚被氧化。它和加热保温、接触空气导致变红是同一机理的不同加速方式。
