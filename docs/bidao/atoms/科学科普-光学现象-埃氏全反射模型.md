# 埃氏全反射模型

## 一句话定义

瑞典物理学家昂斯特伦1925年提出，湿物体变深是因为表面水膜把物体反射出的光全反射回物体内部，光被反复吸收，最终逃逸到眼睛的光减少。

## 详细说明

全反射指光由水射向空气时，入射角增大到一定程度后折射光彻底消失，光全部被反射回水中。用激光笔照射戳了洞的矿泉水瓶，光会沿水流弯曲传播，正是全反射把光困在水里。

按这一模型，衣服干燥时光射向纤维发生漫反射进入眼睛；变湿后纤维表面多了一层水膜，从纤维反射出的光有一部分被水膜全反射回纤维，撞在纤维上被吸收一部分，再漫反射出来又被全反射回去，如此反复，最终进入眼睛的光变少，颜色变深。

昂斯特伦还用朗伯余弦定律做积分与无穷级数求和，算出潮湿地面反照率约为干燥地面的百分之六十，即变暗约百分之四十，与实验数据吻合。该模型简洁、计算方便，在学术界应用广泛，例如用遥感测量从土地颜色反推土壤湿度。但它的前提是物体有水没水都发生漫反射、不存在镜面反射，这一假设后来受到质疑。
