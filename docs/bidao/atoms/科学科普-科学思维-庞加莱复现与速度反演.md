# 庞加莱复现与速度反演

## 一句话定义

世界完全可以把速度符号都反过来使系统熵减回到过去，这是洛施密特速度反演佯谬对玻尔兹曼的批评，质疑时间之矢是否真实存在。

## 详细说明

微观过程都可逆，宏观过程都不可逆，这个矛盾让物理学家不得不在对熵增的信念和对物理学对称美的忠诚之间做出选择。这就是庞加莱复现定理和洛施密特速度反演佯谬对玻尔兹曼的批评。

世界完全可以把速度符号都反过来，系统将熵减回到它的过去。那么时间之矢究竟还存在吗？时间可逆的物理规律从哪一步开始诞生了不可逆性？根据视频所讲，是从统计规律的引入这一步开始。从玻尔兹曼之后，时间之矢被贬低为一种表象，是人类作为不完善的观测者引入了统计的近似，造成了过去和未来的差异。

但普里高津提出反对意见，他的非平衡热力学理论认为自然法则建立于不可约的概率之上，不可逆性不再是一个具备了完善知识就会消失的表象，而是在自然中起到了基本的建设性的作用。时间之矢不再是错觉，而是秩序的源泉。在他的理论中，我们的宇宙本身就包括一个时间对称性破缺的起源，甚至时间是先于宇宙的存在。
