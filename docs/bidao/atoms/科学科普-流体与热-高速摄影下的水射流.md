# 高速摄影下的水射流

## 一句话定义

用高速摄影机配合旋转台拍摄水射流，可以看到常规速度下无法分辨的液滴形态和发光细节。

## 详细说明

团队把水射流实验放在可三百六十度旋转的旋转台上，用高速摄影机拍摄，目的是让观众看到三百六十度的慢动作射流。

拍摄中的观察：

- 升格画面里能看到清晰的液滴形态，团队评价「这个液滴，我就喜欢这样的画面」。
- 倒放升格素材比正放更好看。
- 水在画面中「还在发光」，这是强光照射下水体反射与折射形成的视觉效果。
- 团队先拍了方形/常规形态，再换圆形装置，预计圆形的效果更带劲。

旋转台的核心作用是为高速相机服务：让被摄物在慢动作中呈现完整的三百六十度视角。但旋转台带来一个矛盾——原有布光是为常规视频设计的，亮度远远不够，且部分灯会闪，所以必须换成高功率 LED 灯才能支撑高速拍摄。

这类拍摄的可复现要点是：高帧率 + 强 LED 照明 + 可旋转载物台，三者缺一不可。
