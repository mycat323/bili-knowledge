# 颗粒流

## 一句话定义

大量固体颗粒聚在一起时表现出的特殊物质形态，既能像液体一样流动，又能像固体一样静止，沙子、雪、大米的运动都属于颗粒流。

## 详细说明

单个玻璃微珠只是平平无奇的固体小球，但一堆微珠聚在一起就变成了一种全新的形态：它们可以像液体一样流动，又可以像固体一样静止。这种形态在化工上称为颗粒流。

颗粒流的研究价值在于它连接了固体与流体两种极端：

- 通过模拟计算，可以理解微小的扰动如何让雪花颗粒流动形成雪崩；
- 可以理解月球上如何形成陨石坑；
- 流动的沙子可以是欢乐的游泳池，也可以是化工厂里的流化床；
- 还能解释面里的臊子、螺蛳粉里的螺蛳为什么吃着吃着就被面埋到最底下去了。

沙漏中的玻璃微珠就是典型的颗粒流：颗粒的流动性再好，毕竟还是固体，因此它的下落规律与液体完全不同。
