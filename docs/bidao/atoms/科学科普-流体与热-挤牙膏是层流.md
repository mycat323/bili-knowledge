# 挤牙膏为什么是层流

## 一句话定义

牙膏粘度约三百帕秒、密度约两克每立方厘米、管径八毫米、流速约一厘米每秒，算出雷诺数约零点零零零五，属于极端层流。

## 详细说明

挤牙膏时彩条整体向前移动并从小口排出，还是彩条，不会混合。原因是这个过程处于层流状态。

代入牙膏的参数估算：

- 粘度约 300 帕秒
- 密度约 2 克每立方厘米
- 直径约 8 毫米
- 流速撑死约 1 厘米每秒

算出来雷诺数约等于 0.0005，层流的层的不能再层了。层流状态下牙膏各部分互不干扰，独立平行向前流动，所以彩条不会混合。

注意：把牙膏剪开狂搅一通，搅完真的会混成一坨，说明原视频说「剪开狂搅还是彩条」是不对的，应该只是搅得不够透彻。捏牙膏不混是因为层流，剪开搅拌则是人为制造了混合。

如果实在想让挤牙膏时变成湍流混合，需要让牙膏喷射速度达到约七万五千米每秒，差不多是 4.5 倍的第三宇宙速度。
