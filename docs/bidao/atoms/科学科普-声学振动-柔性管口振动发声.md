# 柔性管口振动发声

## 一句话定义

轻微闭合的柔性管口被气体冲开时会发生震动并发出声音，这是一个良好的放屁模拟装置，被用来研究「如何放出一个无声的屁」。

## 详细说明

放屁的声音来自哪里？转写稿给出的机制是：一个轻微闭合的柔性管口被气体冲开时会发生震动，这种震动构成了一个良好的放屁模拟装置。毕导找到的实验器材是一块屁垫，它的结构恰好符合「轻微闭合的柔性管口」这一描述。

这个装置被用来研究「如何放出一个无声的屁」这个选题，它与「SP 大一统」一起被列为团队遇到的最困难的选题，原因很直接：说实话很难做实验。

这个选题拖了很久。在观众的频繁催促下，毕导表示自尊再也不允许他把这个选题继续拖下去了。
