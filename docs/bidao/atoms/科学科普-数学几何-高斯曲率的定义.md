# 高斯曲率的定义

## 一句话定义

曲面上一点的高斯曲率等于该点在各个方向曲率的最大值与最小值的乘积，正负号反映曲面朝同侧还是异侧弯曲。

## 详细说明

一条曲线的曲率容易理解：某点的曲率等于该点最紧密相切圆的半径分之一，越弯曲率越大，直线曲率为零。

但曲面上一点的弯曲程度很难直接定义，因为不同方向的曲率往往不同。以半径为一的圆柱面为例：水平方向是个圆，曲率是 1；竖直方向是直线，曲率是 0；斜方向上则是 0 到 1 之间的某个数。这个点到底算多弯？

高斯的处理办法是：取该点在所有方向上的曲率最大值和最小值，把两者相乘，乘积就是这一点的高斯曲率。

- 球面：各方向曲率都等于半径分之一，高斯曲率为半径平方分之一，是正数。碗、西瓜、橘子皮同理。
- 圆柱面、圆锥面：最小曲率为零，零乘任何数都是零，高斯曲率处处为零。
- 薯片、马鞍面：一个方向朝上弯、一个方向朝下弯，两曲率一正一负，高斯曲率为负数。香蕉、坐垫也属于此类。

高斯曲率的符号和大小，正是区分不同曲面的最本质指标。
