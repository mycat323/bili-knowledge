# 随筑随冻建造策略

## 一句话定义

先用湿沙垒一层再泼水，让水在渗透过程中逐渐冻结，并借助大风加快冻结速率，是复现一夜筑冰城的关键策略。

## 详细说明

三战团队根据潼关气象局数据考证，三国时期潼关气温约为零下十五度到零下五度；又和清华建筑设计院考证了渭河流域沙子的级配分布，结合原著中单土泼水随筑随冻的方法，找出关键建造策略：先用像冰沙果泥一样的湿沙子垒一层，再泼水，水在渗透过程中逐渐冻结。其中需要精确计算湿沙子的含水量、泼水量、水的渗透速率、水的冻结速率。曹军当时应该是借助大风来加快冻结速率。毕导借鉴该方法，用每小时一层湿沙加一层干沙的方式，在十小时内建成了小冰墙。
