# 冰面低摩擦是反常现象

## 一句话定义

大多数物质摩擦系数都在零点几，冰却只有零点零二，这种反常才是值得追问的科学问题。

## 详细说明

面对「冰为什么这么滑」，一种常见的反应是：世界上东西有的就是滑的，有的就是涩的，这很正常。

但这个反应经不起推敲。回想一下，你划过其他东西吗？没有。描述接触面滑不滑，直观上就是看摩擦力大不大，学术上用动摩擦系数 μ 表示（F = μN）。橡胶路面零点五到零点八，玻璃与玻璃零点四，生活中大部分物质都是零点几，而冰只有零点零二，其他物质在冰面上的摩擦系数也只有零点零几。

也就是说，冰几乎是有史以来最滑的固体。我们能在冬天滑冰滑雪，是因为地球上最常见的物质在冬天表现出了反常的性质。

把「正常」和「反常」区分开，是提出好问题的关键：如果冰的摩擦系数和其他固体一样是零点几，就没有什么可研究的；正因为它是零点零二，才需要一个专门的解释。
