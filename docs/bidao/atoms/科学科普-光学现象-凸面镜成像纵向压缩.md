# 凸面镜成像纵向压缩

## 一句话定义

凸面镜中物体的倒影在纵向会被压缩，看起来比本体扁一些，这是凸面镜成像的几何特点。

## 详细说明

视频用生活中的拐弯处凸面镜做演示：平面镜里物体和倒影一样大，但在凸面镜里，倒影在纵向会被压缩。

观察结果：

- 凸面镜里的毕导、福南、书，从侧面看时，镜像都比本体要扁一些；
- 这种变扁是凸面镜成像的几何特点，与物体本身无关。

毕导由此提出关键类比：如果大海是平面镜，太阳在海里的倒影应该和海上的部分一样长；但论文照片中，水下的半个太阳倒影比水上的半个太阳要扁一点。这说明大海不是平面镜，而更像凸面镜，即大地不平，而是个球。
