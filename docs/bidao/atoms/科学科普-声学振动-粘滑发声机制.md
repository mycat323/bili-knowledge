# 粘滑发声机制

## 一句话定义

篮球鞋、拖桌椅、指甲划黑板等刺耳声都源于粘滑：接触点先粘住原地形变，再突然滑动，激发高频振动发出尖锐声音。

## 详细说明

以篮球鞋为例，鞋底有一道道条纹。当你发力前冲时，鞋底条纹并不会整体滑动，而是被静摩擦力按在原地发生微小形变，积累弹性势能——这是**粘**的阶段。脚继续往前，条纹形变到极限，就会往前一窜——这是**滑**的阶段。条纹在滑动瞬间激发高频振动，发出「吱」的一声。

同类例子：

- 推开年久失修的大门，门轴吱呀作响；
- 拉响小提琴，琴弦与弓的粘滑产生稳定乐音；
- 拉开一卷透明胶带，刺啦一声；
- 指甲划黑板、叉子划盘子，在微米尺度上也在发生粘滑。

视频中拖椅子时甚至能同时听到宏观卡顿的低频和微观粘滑的高频，产生呼麦般的效果。

容易出粘滑声的条件：静摩擦与动摩擦差距大、物体弹性好。篮球鞋在木地板上很吵，在冰上就很安静；长叉子齿有弹性容易粘滑，刚性石头就很安静；干木头拖动丝滑，沾点水增大摩擦力后反而容易粘滑。
