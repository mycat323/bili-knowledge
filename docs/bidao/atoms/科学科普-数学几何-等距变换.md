# 等距变换

## 一句话定义

等距变换是指曲面在弯折过程中不发生拉伸或压缩，曲面上任意相邻两点之间的距离始终保持不变的变形方式。

## 详细说明

判断一个变形是不是等距变换，标准只有一条：曲面上任意两点之间的距离在变形前后是否保持不变。

- 一张纸卷成圆筒、卷成圆锥，纸面上相邻点的距离都没变，属于等距变换。
- 一块布被拉长，点点之间的距离被改变，属于不等距变换。

等距变换的关键性质是：它只约束曲面内部的距离关系，不关心曲面在外空间里怎么摆放。但高斯绝妙定理指出，正是这种内在的距离关系，决定了曲面外在的弯曲性质——等距变换下高斯曲率保持不变。

因此，平面、圆柱面、圆锥面虽然外形差别很大，但高斯曲率都是零，彼此之间可以自由弯折、展平；而球面高斯曲率为正，无论怎么弯都无法变成高斯曲率为零的平面。

这一区分也解释了为什么悬链面和螺旋面外形完全不同，却可以相互变换——它们的高斯曲率相同。
