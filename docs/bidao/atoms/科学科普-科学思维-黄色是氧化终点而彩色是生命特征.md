# 黄色是氧化终点而彩色是生命特征

## 一句话定义

氧化无处不在，使白色物质普遍走向黄色，因此黄色可视为时间流逝的化学印记；而地球之所以色彩斑斓，是因为生命能持续合成结构复杂的色素分子。

## 详细说明

视频把「万物变黄」归结为一条统一规律：氧化无处不在、防不胜防，白色物质氧化后生成共轭结构、吸收光谱红移，最终显黄。纸张、白墙、空调外壳、塑料抗氧化剂、排泄物中的色素，走的都是这条路。

但世界并没有因此变成单调的黄色。番茄红素、叶绿素、黑色素等色素分子结构极其复杂，人工合成难度很高——视频作者大二有机实验课合成肉桂酸做了整整一天，产率只有百分之五十。而生命体内每一刻都在发生复杂、快速而精准的化学反应，持续制造这些分子。

所以视频给出的对比是：黄色是时间的颜色，彩色是生命的颜色。火星看上去是个土黄色的球，地球之所以多彩，是因为这里有生命。
