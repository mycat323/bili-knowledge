# 最快的冰

## 一句话定义

北京冬奥会打造了被称为世界最快的冰，许多速滑项目在此打破世界纪录，其丝滑程度与冰面本身的性质密切相关。

## 详细说明

北京冬奥会据说打造了世界最快的冰，许多速滑项目都打破了世界纪录。视频从这一现象出发，追问这坨冰里究竟有什么独门的丝滑秘籍。

要理解「最快的冰」，先要理解冰为什么滑。冰的动摩擦系数只有零点零二，远低于橡胶路面（零点五到零点八）和玻璃与玻璃（零点四），其他物质在冰面上的摩擦系数也只有零点零几。冰几乎是有史以来最滑的固体。

这种滑来自冰刀与冰面之间的水膜：选手看上去在滑冰，本质上是在滑水。因此冰面状态直接决定滑行体验，冬奥场馆的冰面之所以被认为特别快，与这层水膜及冰面本身的表面性质有关。

转写稿没有展开具体的制冰工艺参数，只把「最快的冰」作为引出冰面润滑原理的入口。要判断一块冰快不快，核心仍是看它能否维持稳定、低阻的水膜接触状态。
