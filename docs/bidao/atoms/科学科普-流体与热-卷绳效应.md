# 卷绳效应

## 一句话定义

粘性液体从合适高度竖直下落时，液柱末端会自发绕圈并堆叠成锥形螺旋结构，这一现象被称为卷绳效应（liquid rope coiling effect）。

## 详细说明

把一条麻绳或一串珠子缓慢释放到地面，会形成一圈圈的缠绕结构，这是日常可见的卷绳现象。1958 年，美国人乔治·巴恩斯和理查德·穆基指出，有些液体从高处下落时也会像绳子一样，竖直下落的液柱到末端突然开始疯狂绕圈，形成一个锥形的坨子，他们把这种反常现象命名为 liquid rope coiling effect，即卷绳效应。

卷绳效应在生活中随处可见：蜂蜜下落时会绕出均匀的圈圈；取麻酱时麻酱会像叠被子一样折来折去；洗头膏、沐浴露挤出来也会在掌心画圈圈。

但并非所有流体都会卷绳。洗澡时温暖的水流倾泻而下并不会绕圈，更不会产生水坨坨；甘油、食用油也是竖直流下去，不出现卷绳效应。同样是流体，蜂蜜、麻酱、便便会卷起来，关键在于它们都很粘。

二零零四年，Ribe 等人将流体下落过程描述为一个具有两个自由参数和十九个边界条件的十七阶非线性两点边值问题，说明这一看似简单的现象背后有相当复杂的数学结构。
