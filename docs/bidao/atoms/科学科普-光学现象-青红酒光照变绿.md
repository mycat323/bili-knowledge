# 青红酒光照变绿

## 一句话定义

青红酒本身是红褐色，用白光从上方照射时被照到的部分会呈现绿色，舀出后离开光照又恢复红色；短视频中舀出瞬间由绿变红是拍摄顺序造成的错觉。

## 详细说明

短视频声称青红酒在坛中为绿色、舀出瞬间变红。实际买到酒倒进碗里不会变色。把酒倒入坛子并从上方打顶光后，被顶光照到的液面附近呈现绿色，周围未照到的地方仍是红色；舀出的酒在正常环境中看着仍是原本的红色。因此真实关系是「光照下由红变绿」，而不是「舀出由绿变红」。

用白光手电筒直接照青红酒，照到的地方也会变绿；从顶上往下照，液面附近还能看到绿红渐变。类似现象也见于乌龙茶、料酒、咖啡等偏红褐色液体，白光照到的地方呈黄绿色；而红颜药水、碘伏、可乐照白光不会变绿。这说明现象与液体是否含荧光物质有关，而不是单纯的红色液体照白光必然变绿。
