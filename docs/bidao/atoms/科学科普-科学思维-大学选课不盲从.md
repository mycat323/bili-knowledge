# 大学选课不盲从

## 一句话定义

选课不要盲从，别只选绩点高的水课，要学就学点有料的；但所有人都不推荐的课也不要硬刚。

## 详细说明

毕导给选课的建议包含一正一反两条。

正面：选课不要盲从，别只选那些绩点高的水课。你要学就学点有料的。这背后的逻辑与「本科学习是为了培养认识世界的方式」一致——只刷 GPA 而不获得真才实学，等于把四年换成一串数字。

反面：但是所有人都不推荐的课也不要硬刚。也就是说，不必为了证明自己不怕难而专门去踩公认的坑，判断要基于信息而不是姿态。

与之配套的学习习惯还有：

- 翘课很容易，想做就能做到，一节课都不翘才真正值得炫耀。
- 给 PPT 拍照并不会让你学得更多，上课用心听讲比啥都强；实在想要可以直接下课去找老师要。
- 学好英语，就算四六级过了也还是要坚持学。

这几条的共同点是：把注意力放在真正吸收知识上，而不是放在看起来努力的动作上。
