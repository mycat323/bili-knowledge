# 玻璃态是未解之谜

## 一句话定义

能带理论只适用于晶体，而玻璃是长程无序的非晶体，用能带解释玻璃透明存在根本困难，玻璃态的本质至今无人说清。

## 详细说明

上面用能带理论解释玻璃透明，其实是有问题的：我们根本不知道玻璃哪来的能带。能带理论是从晶体推出来的，而玻璃根本不是晶体。

固体分为晶体和非晶体，晶体又分分子晶体、原子晶体、离子晶体和金属，玻璃是最标准的非晶体。区别如此重要，是因为秩序：晶体非常有序，给一个晶格再复制粘贴，就能造出一坨无穷大的晶体，有序赋予了我们推导它性质的资格。

而玻璃内部是不规则的二氧化硅长链组成的连续随机四面体网络，其中镶嵌着钠、钾、钙离子，是短程有序、长程无序的混乱结构。理论上不应该用能带理论解释结构无序的玻璃，所以对玻璃透明的解释只能暂且打补丁，说玻璃其实由很多微小晶体构成。

一九三二年扎卡里亚森提出了玻璃的第一个结构模型，直到今天仍没有人敢拍着胸脯说我懂什么是玻璃。有人说它是固态，有人说它是液态，科学家们单独为它定义了「玻璃态」。二零零五年《Science》创刊一百二十五周年时提出的一百二十五个最重要科学问题中，就有「玻璃态究竟是个啥」。
