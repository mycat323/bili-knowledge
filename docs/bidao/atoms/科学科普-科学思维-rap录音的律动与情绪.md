# rap录音的律动与情绪

## 一句话定义

录音棚里反复重录的核心问题往往不是音准，而是律动和情绪：录音老师会指出「律动差了一点点」「情绪少了一些」。

## 详细说明

毕导在录音棚里录八十八个字的副歌用了一个小时，录音老师的反馈集中在两点：

- 「它的律动可能还是稍微差了一点点」
- 「就差一句，情绪少了一些」

这说明rap录音的评价维度不只是唱对词，还包括：

| 维度 | 表现 |
| --- | --- |
| 律动 | 是否跟得上伴奏的节奏感 |
| 情绪 | 是否唱出了该段应有的状态 |
| 音色 | 是否压对了发声位置 |

罗翔老师录同样的内容只用了二十多分钟，毕导用了半个小时。罗翔给自己打零分，但录音老师认为「没有什么问题了，但是就有一点，就是权力的那个例子现在有一点点腻」。这说明录音是一个反复微调的过程，每次重录针对的是不同的细节问题。
