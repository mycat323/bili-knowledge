# 戴文赛算两小儿辩日

## 一句话定义

一九五四年，新中国天文学奠基人之一戴文赛在《太阳与观测者距离在一日内的变化》一文中，不厌其烦地算清了一天之内太阳与观测者距离的变化，回答了困扰两千多年的两小儿辩日。

## 详细说明

毕导说，自己并非第一个这么「无聊」的人。一九五四年，新中国天文学的奠基人之一戴文赛先生就在《太阳与观测者距离在一日内的变化》一文中算完了这个问题。

老教授算这个，应该不是因为问题有多大学术意义，而是因为两小儿辩日作为六年级课本中的经典故事，对中国人有特殊情感。毕导认为这篇课文真正想教的是：两小儿虽然都错了，但他们在辩日；孔子可能是当时全中国最渊博的人之一，却压根没想过这个问题。在对世界的好奇心上，孔子不如两小儿。

巧合的是，二零二五年和戴先生所计算的一九五四年，中午太阳更远的日子一模一样。毕导把视频献给戴先生，也献给所有对世界充满热情与好奇的大小孩子们。
