# rap语速的量化

## 一句话定义

说唱的语速可以用单位时间内吐出的字数或音节数来量化，语速快慢直接影响听感上的信息密度和情绪强度。

## 详细说明

这首歌的歌词密度很高，主歌部分连续堆叠长句，例如把物理、数学、考试、宇宙飞船等意象压缩在几行之内。

从听感上说，语速越快，单位时间传递的信息越多，但每个字被听清的时间也越短。歌词里「每次考试总是最快交出答卷」这类句子本身就在描述一种快节奏状态，语速和内容形成了呼应。

副歌则明显放慢并重复，用「千万别再等，不懂就要问」这样的短句反复出现，让听众能跟上并记住。快慢交替构成了整首歌的节奏骨架。

需要说明的是，视频本身没有给出具体的字数或时长数据，这里只描述快慢对比这一可感知的结构特征，不对具体语速数值下结论。
