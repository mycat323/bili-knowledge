# 游戏生态细节还原

## 一句话定义

《剑与远征启程》在竖屏大世界中还原了屎壳郎单腿推球、双腿合作、跳舞导航等动作，以及蝎子、秃鹫、蓝闪蝶等生态细节。

## 详细说明

开发组希望游戏里的屎壳郎更逼真，看过千百遍屎壳郎的创作者直接输出了一通动作细节，开发组当场连草图都画出来了：

- 单腿屎壳郎：独自用后腿推球，强而有力。
- 双腿屎壳郎：一前一后，合作共赢。
- 跳舞导航：写实而富有艺术氛围。

除了屎壳郎，沙漠中还有蝎子拖着尾刺诡秘行走；风沙四起时，作为猎食者的秃鹫在空中盘旋；生态位的上游，巨型钢颚兽撞破山石。玩家可以追逐蓝闪蝶，它用结构色打造的鲜艳蓝翅膀迷惑捕食者的视线；还有松鼠拖着绿尾巴在森林里嬉戏。

这些细节极少被玩家直接注意到，但正是它们的补充，让人感受到一个更真实的沙漠。竖屏的盲区里，万物都在生活。
