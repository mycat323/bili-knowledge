# 磁力搅拌器冲豆奶

## 一句话定义

用磁力搅拌器、烧杯和七十度热水冲泡豆奶，可观察粉末漂浮、气泡释放和奶豆豆在水下翻滚的全过程。

## 详细说明

这是一个可以在家复现的冲奶实验：取一包豆奶、一台磁力搅拌器、一个烧杯。

操作步骤：向烧杯中倒入奶粉，加入七十度的热水，开启磁力搅拌器。旋转的水流泛起波浪，淡黄的粉末漂浮着，粉末内部的气泡不断释放，奶豆豆在水下翻滚。

实验现象说明两点：一是奶粉倒入热水后并不会立刻全部沉入水中，部分粉末漂浮在水面，说明其疏水性使水难以润湿；二是粉末内部的气泡不断释放，说明颗粒间夹带的空气正在被水逐步排开。

值得注意的是，很多现代奶粉已经不那么容易起痘，而部分豆奶产品从过去到现在仍坚持起痘，这为观察奶豆豆提供了更明显的样本。
