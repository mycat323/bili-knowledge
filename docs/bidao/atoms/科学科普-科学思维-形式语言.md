# 形式语言

## 一句话定义

形式语言是希尔伯特纲领中的关键工具，把所有的句子都变成符号，例如把「f(x) 在 p 处的极限为 L」写成符号形式，使数学证明变成简洁优雅的符号推导。

## 详细说明

形式语言是希尔伯特纲领的核心思路之一：把所有的句子都变成符号。视频给出的例子是，把「f(x) 在 p 处的极限为 L」写成符号形式，非常简洁优雅。

在希尔伯特纲领中，公理被写成形式语言，用来证明其他一切。这样一来，原本强调灵感技巧的数学，突然变成一种暴力枯燥的符号推导游戏。视频用阿尔法狗类比：围棋不看本手、妙手、俗手，大力出奇迹就完了。

一九二五年，希尔伯特的天才学生、数学家外尔评价希尔伯特纲领称：「这是用毫无意义的公式游戏取代内容数学。」希尔伯特的公式清单只是个分析的冷酷幽灵，没有智力上的意义。

形式语言与公理、完备性、一致性、可判定性共同构成希尔伯特纲领的完整图景：公理是起点，形式语言是表达方式，三条品质是体系要证明的目标。
