# 拱形结构堵塞沙漏

## 一句话定义

沙漏脖子较细时，几粒沙子可能恰好堆积形成顽强的拱形结构堵住出口，把上面的沙子撑在沙壁上，导致下落停滞。

## 详细说明

颗粒流虽然能像液体一样流动，但颗粒毕竟是固体，存在堵塞的可能。

Kivi 等人通过简洁的计算指出：如果沙漏的脖子比较细，有时候漏着漏着，几粒沙子可能会恰好堆积，形成顽强的拱形结构，堵住沙漏出口，导致上面的沙子都被撑在沙漏的沙壁上、漏壁上、玻璃的壁上。

杨达等人发现，巧妙的震动可以破坏这种拱形结构，让沙漏下落更加通畅。这很可能就是左右晃动沙漏能够加速下落的原因——晃动提供的扰动打破了颗粒间偶然形成的力链拱。

这一机制说明：颗粒流的堵塞不是永久性的，外部扰动可以反复解除堵塞，因此震动频率越高，理论上加速效果越明显。
