# 结构色需要深色底色衬托

## 一句话定义

结构色往往需要一层深色底色吸收透射光，否则杂散光会冲淡干涉效果，颜色看起来就不明显甚至消失。

## 详细说明

蓝莓提供了一个直观案例。

磨掉果蜡后，蓝莓直接变成黑莓，说明蓝莓皮本身是黑色的。这层黑色底色很关键：如果底色是浅色，透过果蜡的光会被反射回来，与结构产生的颜色混在一起，蓝色就会被冲淡。

深色底色把透射过去的光吸收掉，只留下结构选择出来的颜色，蓝色才显得干净、饱和。

这也解释了为什么用油溶掉果蜡后，蓝莓表皮变成深黑色——结构被破坏，只剩下原本的黑色底色。

可以这样理解：结构色负责挑出颜色，深色底色负责把没被挑中的光吃掉。两者配合，颜色才成立。
