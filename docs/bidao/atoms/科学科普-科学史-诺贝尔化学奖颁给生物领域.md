# 诺贝尔化学奖颁给生物领域

## 一句话定义

近二十年诺贝尔化学奖有十二次颁给生物领域成果，生命科学成果获奖比例从创立之初每十年一个上升到每十年四五个。

## 详细说明

2020年诺贝尔化学奖颁给发明CRISPR基因编辑技术的两名科学家，颁奖词称其将生命科学带入新时代。CRISPR技术可以方便地给细胞切除某个特定基因，是本世纪最重要的生物成果之一。

梳理近三十年诺贝尔化学奖，按朴素第一印象分为物理、化学、生物三类，会发现化学奖越来越偏向生物。近二十年有十二次颁给生物领域。

2019年化学顶刊 Angewandte 发表一篇小论文，标题为《从诺贝尔化学奖到化学或生物奖的异变：透明和不透明的证据》，文章表明获得化学奖的生命科学成果比例稳步上升：从创立之初的每十年一个，到现在每十年四五个。
