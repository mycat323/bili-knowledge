# 迪菲赫尔曼密码

## 一句话定义

迪菲赫尔曼密码是一种现代密码，安全性建立在离散对数问题之上，该数学问题未解决前它相对安全。

## 详细说明

现代密码的安全性往往建立在一些困难的数学问题上，只要这个问题悬而未决，对应的密码就相对安全。迪菲赫尔曼密码就是基于离散对数问题的一种密码体系。

它与基于质因数分解的 RSA 属于同一思路：把安全性押在一个正着容易、倒着极难的数学问题上。视频没有展开离散对数的具体计算，只把它作为现代密码依赖困难数学问题的例子之一。

理解这类密码的关键在于区分「加密容易」和「破解困难」：合法用户掌握密钥可以快速完成加密解密，而攻击者即使拿到密文，也需要解决一个公认困难的数学问题才能还原原文。
