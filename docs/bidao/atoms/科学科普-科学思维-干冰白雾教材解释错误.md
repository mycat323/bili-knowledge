# 干冰白雾的教材解释错在哪

## 一句话定义

多版本初中物理教材把干冰白雾解释为空气中水蒸气遇冷液化，但实验显示干冰在空气中只产生极细的雾丝，浓密白雾必须把干冰放入液体中才会出现。

## 详细说明

沪科版八下、教科版八上、沪粤版等教材都给出同一套解释：干冰升华吸热使周围降温，空气中的水蒸气遇冷液化成小水滴，形成白雾。

但把干冰直接放在桌面上或空气中，只能看到几缕细雾向下飘散，远不是教材配图里那种翻滚的浓雾。舞台造雾机也是把干冰放进热水里才产生大量白雾。

教材的问题在于现象与解释错配：配图里的白雾来自盘中或杯中的液体，而不是空气。教科版让学生观察「干冰放到烧杯里有什么现象」，实际上干冰单独放在烧杯里几乎没有现象，必须再加半杯水。

这个错误解释流传很广，可考证的最早出处是化学教育家巴萨姆·沙卡西里 1983 年的《化学老师手册》，1998 年才有美国大学团队发表质疑论文，直到 2015 年昆斯曼等人才给出完整机理解释。
