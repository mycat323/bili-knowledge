# 毕业答辩与退场的双重性

## 一句话定义

博士毕业既是庆祝毕业喜悦的一天，也是退场离开的一天，同一件事同时承载完成与告别两种含义。

## 详细说明

毕导的毕业答辩在五月十七日，答辩委员会经无记名投票表决，一致同意通过博士论文，并建议授予他工学博士学位。答辩前，石油大学的王老师说他们课题组同学都是他的粉丝，如果今天答辩不给他过就不读王老师的博士了，答辩教室瞬间充满快活的空气。他答辩了整整一个半小时，在台上站麻了。

六月二十三日是系毕业典礼，他负责开场唱歌搞气氛；六月二十五日是全校毕业典礼，校长给他拨完穗，工作人员说「同学请从这边退场」。「退场」这个词突然击中了他：从2010年来到清华，十三年过去了，他终于等到博士毕业这一天，然而这一天既是他庆祝毕业喜悦的一天，也是他退场离开的一天。

当天下午他就收拾东西离开了做了两年半的实验室工位，也离开了陪伴他十三年的学校。他用「行至城门残酒醒，万重离恨一时来」形容这种双重感受。
