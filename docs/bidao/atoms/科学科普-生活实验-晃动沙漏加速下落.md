# 晃动沙漏加速下落

## 一句话定义

左右晃动沙漏可让三分钟的下落时间缩短约百分之十，上下晃动反而延长到四分钟，拍打只缩短几秒。

## 详细说明

视频用内壁通透、沙粒均匀的沙漏（下落时间稳定在 180 秒）测试了三种加速方法，每种方法正反各操作三次，记录下落时长取平均：

| 方法 | 效果 |
| --- | --- |
| 左右晃动 | 三分钟缩短到两分四十秒，约缩短 10% |
| 上下晃动 | 时间反而增加到四分钟 |
| 拍打 | 缩短几秒，差强人意 |

结论：左右晃动最有效。理论上如果能让沙漏更高频地震动，时间还能再缩短，生活中实现高频震动的道具就是手机。

左右晃动起作用的可能原因是：震动破坏了颗粒间偶然形成的拱形结构，让沙漏下落更加通畅。上下晃动之所以无效甚至反效果，是因为沙子似乎在原地按兵不动，没有形成有效的扰动。
