# 水凹透镜使物体变细

## 一句话定义

圆柱形容器浸入水中后，上方水面一面平一面凹，构成凹透镜，透过它看物体会变细，离得越远越细。

## 详细说明

把装有蜡烛的试管放进水里，蜡烛立刻变细，拿起来又变粗；圆球下水后看着变成椭球。只要容器是圆柱形，里面的物体浸水后看上去都会变细。

关键在上方水的形状：瓶子是圆柱形，上面的水就是一面平、一面凹的形状，相当于一个凹透镜。眼睛从上往下看，等于透过一层水做的凹透镜观察物体。用家中常备的凹透镜验证，透过它看物体确实变细，离得越远看着越细，只有紧贴物体时粗细不变。

因此一瓶化妆品泡在水里时，瓶身本身对料体粗细没有影响，是上方水层起了凹透镜的缩小作用。瓶身紧贴水凹透镜处粗细不变，料体离水凹透镜有距离，看着就变细。水里看到的细是被水扭曲后的结果，不是厂商在瓶身上做了手脚。
