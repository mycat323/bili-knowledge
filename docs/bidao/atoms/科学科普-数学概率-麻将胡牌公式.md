# 麻将胡牌公式

## 一句话定义

麻将胡牌要求手牌凑成 m 个刻子（AAA）加 n 个顺子（BCD）再加一对将（EE）的形式，其中 m 与 n 可为任意非负整数。

## 详细说明

麻将的基本流程是每轮摸一张牌、打一张牌，目标是把 14 张手牌整理成固定结构。

- **刻子 AAA**：三张完全相同的牌。
- **顺子 BCD**：三张数字连续的牌。
- **将 EE**：两张相同的牌，作为对子收尾。

胡牌条件写成公式就是 m 个 AAA 加 n 个 BCD 加一对 EE。除此之外还有三种利用别人打出的牌加速成型的操作：

| 操作 | 条件 | 说明 |
| --- | --- | --- |
| 吃 | 上家打出的一张牌与你手中两张能组成顺子 | 只能吃上家 |
| 碰 | 任意人打出的牌与你手中两张相同 | 可碰任意家 |
| 杠 | 别人打出的牌与你手中三张相同 | 可杠任意家 |

各地规则流派不同，但胡牌公式是共通的骨架。记住这个公式，才能判断一手牌离胡牌还差什么，进而决定该打哪张。
