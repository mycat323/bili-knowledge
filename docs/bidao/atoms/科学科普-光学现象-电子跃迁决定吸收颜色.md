# 电子跃迁决定吸收颜色

## 一句话定义

分子中的电子只能吸收特定能量的光子从基态跃迁到激发态，光的能量由波长决定，因此特定分子只吸收特定颜色的光。

## 详细说明

把分子放在那里，平时电子处于基态；光照时电子吸收光子能量变得 excited，跃迁到激发态。电子很挑剔，只有特定大小的能量能激发它们。

光的能量只取决于波长，波长又体现为颜色，所以「分子吸收什么颜色」由它的能级差决定。番茄红素吸收 443、471、502 纳米的蓝绿光，反射其余光，人眼就把它看成红色。

有机物的电子跃迁以前线电子从 HOMO 向 LUMO 跃迁为主。能级差越小，需要的光子能量越小、波长越长，吸收峰就越往长波方向走。这是理解「氧化变黄」的关键前提。
