# 速度的因果链

## 一句话定义

起飞公式只给出 v机、v带、v轮 三者的等式关系，判断传送带能否拦住物体，还要看哪个量是原因、哪个量是结果。

## 详细说明

公式相同，因果方向不同，结论就完全相反。

汽车：踩油门让轮子旋转，轮速决定车身速度，写成 v车 = v轮 − v带。传送带追踪轮子转速，就能把车身速度控制为零，车被定在原地。

飞机：发动机喷气直接推动机身，机身速度决定轮子速度，写成 v轮 = v机 + v带。传送带就算能追踪轮子的速度，也管不到发动机怎么喷，因此影响不到 v机。

所以「传送带能否拦住飞机」不能只看公式形式，必须先问清楚：在这套系统里，是轮子带动车身，还是机身带动轮子。这一点是整个问题里最容易被忽略、也最关键的一步。
