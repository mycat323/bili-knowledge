# 纸刀切割

## 一句话定义

纸张可以像菜刀一样划破皮肤，因为 A4 纸的厚度与菜刀刀刃最薄处相当，而理论计算表明 65 微米厚的纸做刀最锋利。

## 详细说明

菜刀刀刃最薄的地方一般是 0.1 到 0.3 毫米，而一张 A4 纸的厚度也差不多，所以纸还真就能跟菜刀一样锋利。

丹麦技术大学的科学家通过理论计算指出，65 微米厚的纸最好：

| 纸张厚度 | 结果 |
| --- | --- |
| 太厚 | 不够锋利，最多只能把手指压疼 |
| 65 微米 | 理论最佳厚度 |
| 太薄 | 一碰到手指自己就先弯了 |

现实生活中最接近这个理论最佳厚度 65 微米的是 Science 和 Nature 这类期刊用纸，含金量高的期刊物理伤害也是冠军。论文里说它可以直接切开苹果、黄瓜甚至是鸡肉。文章发表在 PRE 上面，影响因子 2.2。

这项研究的实际意义是：印刷厂可以据此少用锋利的纸出书，保护读者的手。
