# 玻璃透明源于宽能带隙

## 一句话定义

玻璃的主要成分二氧化硅带隙约九电子伏，远高于可见光的一点六到三点二电子伏，可见光无法激发电子跃迁，因此直接穿过玻璃。

## 详细说明

一束光打在物体上有反射、吸收、透过三种结局。物体反射或吸收的光越多，透过的光越少，看着就越不透明。

玻璃之所以透明，是因为它既不太反射光，也不太吸收光。吸收与否取决于电子跃迁：电子平时待在低能级，只有当光的能量恰好能让它跳到高能级时，电子才会吸收这束光。

对于晶体，电子的能量不是一条条精确能级，而是一条条宽泛的能带。只要光的能量大于两条能带的间隔（带隙），电子就愿意吸收。金属的带隙为零，电子不挑食，什么光都吸收，所以金属不透明。钻石带隙五点五 eV、冰八点八 eV、盐八点五 eV，都远高于可见光能量，所以它们对可见光透明。

玻璃的主要成分二氧化硅带隙也很宽，差不多九 eV，远高于可见光。可见光照上去，玻璃根本懒得吸收；只有能量更高的紫外线才会被它吸收。这就是玻璃透过可见光、吸收紫外线的根本原因。
