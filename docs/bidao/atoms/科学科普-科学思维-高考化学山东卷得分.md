# 做一遍高考化学山东卷

## 一句话定义

学了十几年化学的毕导挑战当年上过热搜、被称作最难的山东卷高考化学题，原计划三十分钟做完，最终只拿到十一分。

## 详细说明

山东卷化学是当年被称作最难的高考题之一，还上了微博热搜。毕导开考前的态度是「我学了十几年化学，做化学题那不是降维打击」，看到题目之后说的是「门捷列夫来了也不会」。

考场实况：

- 选项难度超出预期，题目做不完；
- 原计划是九十分钟的卷子，用三十分钟做第一遍、三十分钟检查，最后三十分钟对着镜头录满分感想；
- 结果第一遍根本没做完，考试时间到只能停止答题。

改卷后的得分是十一分，满分一百分。这场考试的结尾是毕导的一个请求：希望明年高考季不要再有人让他读这样的评论。
