# 巴西果效应

## 一句话定义

混合颗粒在震动摇晃后，尺寸较大的颗粒会浮到最上层，这一现象由外国科学家在干果麦片实验中发现，因大颗粒巴西果总在最上面而得名。

## 详细说明

把混合在一起的干果麦片摇晃后，颗粒最大的巴西果总是浮在最上面，科学家因此把这种现象命名为巴西果效应。

后来有科学家更换容器后发现，颗粒最大的也可能沉到最下面，这种相反的结果叫反巴西果效应。两者在学术上统称为颗粒对流。

目前学术界主流观点把原因归结为**空隙填充**：

- 大颗粒附近空隙更多；
- 若大颗粒密度小，摇晃时上面的小颗粒会跑到下面填充空隙，填着填着大颗粒就被抬起来；
- 若大颗粒密度大，就会在小颗粒之间凿一个坑，慢慢陷下去。

听上去简单，但这套解释发表在 PRL 物理学顶刊上。实际情况还要考虑颗粒直径之比、气体压力甚至容器形状。1909 年霍因廷和汤普森给出了一套简单判断公式：当直径比小于密度比的倒数时，大颗粒往上走，反之则沉下去。
