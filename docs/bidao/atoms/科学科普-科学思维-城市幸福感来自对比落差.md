# 城市幸福感来自对比落差

## 一句话定义

对一座城市的幸福感并不完全来自城市本身，而部分来自与其他城市的对比落差，待过条件更差的地方后再去哪都容易觉得幸福。

## 详细说明

毕导提到北京朋友常说的一句话：北京其实是一座非常有幸福感的城市，因为你在北京待久了，你去哪都感觉很幸福。

这句话揭示的是幸福感的相对性：感受不是由绝对条件决定，而是由参照系决定。同一座城市，对刚从小城来的人和对刚离开更拥挤城市的人，体验完全不同。

这与感知领域的普遍规律一致——人对刺激的判断依赖对比而非绝对值。理解这一点有两个实际含义：一是评价一座城市时要意识到自己的参照系；二是「换个环境更幸福」的预期，可能只是参照系切换带来的短期效应。
