# 自学新方向的信心

## 一句话定义

在互联网时代，想学的知识网上基本都有人教，知乎和B站上有大量整理好的学习资料与视频课程，跟着学基本都能学会。

## 详细说明

毕导复学后换了课题方向，从做膜转向做机器学习，并分享了自学新方向的感受。

核心判断是：不管在学校还是职场，都难免有自学新东西的需求；而这个时代你想学的东西网上基本都有人教。知乎、B站上有很多大神整理学习资料和视频课程，这些视频里的老师每天就在琢磨怎么把课教得更好。因此「你要有信心，跟着学完之后基本都是能学会的」。

这条结论的价值在于把「能不能学会」的问题转化为「愿不愿意跟着学」的问题：学习资源的供给已经足够充分，真正的门槛不在资源稀缺，而在是否开始并坚持。
