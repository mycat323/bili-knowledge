# 科研与视频难以兼顾

## 一句话定义

做科研本身就会带来忙碌与焦虑，即使提前做好时间规划，投入科研后仍会挤占做视频的时间，两者很难同时兼顾。

## 详细说明

毕导复学后发现自己无法一边做科研一边保持视频更新频率。他的结论是：做科研就是会忙碌而焦虑，你再怎么以为自己提前做好了准备，投入科研之后还是会忙碌而焦虑。

这个判断来自亲身经历而非理论推导：他原本以为可以兼顾，很快发现做视频的时间少了很多。对内容创作者而言，这意味着「提前规划」并不能消除科研带来的时间挤压，因为焦虑和忙碌是科研工作的固有属性，不是准备不足造成的。

可验证的方式是记录自己一周内实际可自由支配的时间，再对照科研任务的真实耗时，往往会发现规划时低估了科研的隐性时间成本。
