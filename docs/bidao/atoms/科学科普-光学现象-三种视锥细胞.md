# 三种视锥细胞

## 一句话定义

人眼视网膜上有 S、M、L 三种视锥细胞，分别对蓝光、绿光和红光最敏感，它们的响应曲线共同决定了人眼看到的可见光范围。

## 详细说明

光进入眼睛后会激发视锥细胞中的视色素发生顺反异构，从而产生视觉信号。三种视锥细胞的反应波峰分别落在蓝、绿、红对应的波长上，三条响应曲线拼在一起，就构成了人眼能感知的可见光范围。

当某个光的波长落在两条曲线峰值的中间时，会同时刺激多种视锥细胞，大脑就会陷入「这到底算绿还是算蓝」的纠结。不同人的视锥细胞敏感度不同，同一束光可能被不同人判断成不同颜色。

动物之间的视觉细胞数量差异很大：鸟有四种视觉细胞，能看到紫外线；皮皮虾有十几种视觉细胞，对各种波长都超级敏感。所以在皮皮虾眼中，人可能相当于色盲。
