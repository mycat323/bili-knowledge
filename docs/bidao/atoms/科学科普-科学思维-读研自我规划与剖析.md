# 读研自我规划与剖析

## 一句话定义

读研最重要的能力是自我规划与剖析，即找到适合自己的科研和生活节奏，而非单纯比拼科研水平。

## 详细说明

毕导在回顾自己两年半的博士复学生涯时提出，读研最重要的能力可能是自我规划和剖析的能力，核心是找到适合自己的科研和生活节奏。

他复学初期每天在迷茫中睡去、在困惑中醒来，陷入不能毕业的恐慌，甚至深夜搜索读研抑郁怎么办。真正让科研走上正轨的因素，他认为是与自己和解，而不是水平突然进步。

一位学术大神师兄告诉他：可以志存高远地科研，也可以心平气和地科研；擅长科研就追求优秀的毕业，不擅长科研就接受普通的毕业，只要堂堂正正达到毕业要求，两种选择都成立，关键是内心自洽、别拧巴。选前一条路别看不起选后一条路的，选后一条路别看不起自己。

毕导据此先做出点东西保底，发够一篇 paper 后获得信心，再逐步承担更多工业项目、写综述、发专利，最终完成毕业。他强调，不同的人有不同走出科研困境的方式，但自我剖析、找到自己的节奏是共通的前提。
