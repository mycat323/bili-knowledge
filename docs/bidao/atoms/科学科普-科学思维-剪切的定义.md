# 剪切是什么

## 一句话定义

剪切是让流体层间发生相对滑移的动作，相邻流体层向前运动并因粘度产生向后阻力，这对力与剪刀剪纸非常像。

## 详细说明

流体的剪切是一个不直观的概念，它不是用剪刀剪东西那种剪。

用剪刀剪切纸时，剪刀会给纸一对距离很近、方向相反的力。搅动一个流体时，玻璃棒带动相邻的流体层向前运动，附近的流体层与它发生相对滑动，并由于粘度产生向后的阻力。这对力和剪刀剪纸非常像，因此搅拌、涂抹、挤牙膏这些让流体层间发生相对滑移的动作就是剪切。

理解剪切是理解非牛顿流体的前提。非牛顿流体按剪切应力与剪切速率的函数关系分为几种：

| 类型 | 例子 | 表现 |
| --- | --- | --- |
| 剪切变稠 | 玉米淀粉糊糊 | 本来很稀，一砸剪切很大就瞬间变稠 |
| 剪切变稀 | 番茄酱 | 本来很黏，一剪切就瞬间变稀 |
| 宾汉 | 牙膏 | 有临界屈服应力，力小像固体，力大突然流动 |

牛顿流体的粘度不受外力影响，非牛顿流体的粘度会随剪切速率而变化。
