# 摩擦系数衡量滑涩

## 一句话定义

接触面滑不滑可以用动摩擦系数定量描述，它等于摩擦力与正压力之比，数值越小说明越滑。

## 详细说明

判断一个接触面滑不滑，直观上就是看摩擦力大不大。学术上通常用两个物体相对滑动时的动摩擦系数来表示，即 F = μN 中的 μ，μ 越小就越滑。

常见数值可以给出直观标尺：

| 接触面 | 动摩擦系数 |
| --- | --- |
| 橡胶路面 | 0.5~0.8 |
| 玻璃与玻璃 | 0.4 |
| 冰 | 0.02 |
| 其他物质在冰面 | 0.0x |

可以看出，生活中大部分物质的摩擦系数都是零点几，而冰只有零点零二，其他物质在冰面上的摩擦系数也只有零点零几。冰几乎是有史以来最滑的固体。

正因为冰的数值远低于常规材料，冰的润滑性才被视作一种反常现象，而不是理所当然。用摩擦系数做标尺，可以把「滑」这个模糊的日常感受转成可比较的数字，也便于理解为什么冬奥速滑能在冰面上达到极高速度。
