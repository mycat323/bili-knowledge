# 澳大利亚引进屎壳郎

## 一句话定义

1788 年英国人把牛羊马引进澳大利亚后，土著屎壳郎吃不惯牛马软粪，牧场粪便堆积，相关组织遂从外地引进屎壳郎清理，目前已野放四十四种。

## 详细说明

1788 年，英国人亚瑟·菲利普将牛羊和马引进澳大利亚发展畜牧业。然而土著屎壳郎习惯了袋鼠干燥的颗粒屎，吃不惯牛马的大块软粪，结果牧场上屎山遍布，生态堪忧。

面对滞销的粪便，相关组织不得不启动屎壳郎计划，从外地引进有志青年，分配工作，还包吃住。在屎壳郎军团的帮助下，粪便得到清理，土壤得到改良，还有效控制了苍蝇等虫害。

目前他们已经野放了四十四种屎壳郎，最新一批今年刚刚毕业，即将奔赴工作岗位。这个案例说明，一个物种的食性偏好可以成为生态治理的瓶颈，而引入合适的外来物种能补上这个缺口。
