# 大学考试不作弊底线

## 一句话定义

千万不要作弊，挂科都比作弊好，前者只是你不擅长学习，后者是你不擅长做人；同时「没挂过科等于白上大学」这类说法完全不可信。

## 详细说明

毕导在考试篇给出两条底线判断。

第一，不要相信「没有体验过挂科等于白上大学」这种话，挂太多课是真的会被劝退的。

第二，千万不要作弊，挂科都比作弊好。他的区分很清晰：挂科只是你不擅长学习，作弊就是你不擅长做人。

围绕考试还有几条可操作建议：

- 每个专业都有一两门极难的课程，从学期初就要玩命去学，不能拖到期末。
- 最后一节课一定要去，因为老师可能会划重点——虽然可能划的是个屁，但就算是屁也要听。
- 考前转发老师的照片和杨超越没有用，封建迷信要不得。

更根本的一点是：很多人考一门忘一门，所有努力都是为了刷 GPA，但本科学习是为了培养你认识世界的方式，需要真才实学，而不是高 GPA 加一知半解。
