# 知识区年终rap的分工结构

## 一句话定义

知识区年终说唱由不同创作者分段落承担不同职能，用对话和歌词串联起科普、法律、技术等板块。

## 详细说明

这首说唱的结构可以拆成三层：

第一层是对话框架。开头用「怎么又玩手机啦」「我上B站知识区呢」的日常争执引入，结尾又用「还在这唱歌呢，赶紧看书去」收束，把整首歌包在一个生活场景里。

第二层是创作者分工。歌词点名毕导负责物理与流体相关内容（涡心顿射流、控制变量、流体力学），罗翔负责法律内容（「你要永远相信法律公平，别在法外狂徒张三」），其余段落覆盖野生技术协会、财经频道等板块。

第三层是副歌重复。副歌「勇敢的少年快去面对未知的考验」「千万别再等，不懂就要问」在歌中多次出现，承担情绪动员功能，把各板块内容统一到同一个主题上。

这种结构的目的是让不同领域的观众都能在歌里找到自己熟悉的名字，从而被引导进入知识区。
