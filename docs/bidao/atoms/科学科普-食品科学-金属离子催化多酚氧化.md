# 金属离子催化多酚氧化

## 一句话定义

自来水中的微量铁离子、铜离子可能充当催化剂加速多酚变醌，金属离子也可能与多酚的黄酮结构络合导致吸收光谱红移。

## 详细说明

用四种水煮绿豆汤做对比：北京自来水（pH 8.09）、杭州某办公楼自来水（pH 8.29）、矿泉水（pH 7.84）、纯净水（pH 7.7）。结果是北京自来水和杭州自来水煮出的绿豆汤都是红色。

反常之处：按理说碱性越强多酚越易氧化，但碱性稍弱的北京自来水反而更快变红。这说明 pH 不是唯一变量，自来水中的各种离子在起作用。

两种可能的解释：一是金属离子与绿豆多酚中的黄酮结构发生络合，导致吸收光谱红移而显黄色；二是自来水中的微量铁离子、铜离子充当催化剂，让多酚加速变醌。转写稿明确指出这背后的机理复杂，属于化学中尚未完全厘清的部分，需要离子色谱和紫外分光光度计等设备进一步研究。

这一段的价值在于提醒：理想体系（纯净水调配）中原理清晰，真实体系（自来水）中多因素叠加，结论不能简单外推。
