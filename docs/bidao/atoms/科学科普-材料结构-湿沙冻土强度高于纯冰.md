# 湿沙冻土强度高于纯冰

## 一句话定义

湿沙子冻结后形成的冻土，其承重与抗冲击强度比同样条件下的纯冰块更大，足以站人、抗锤击。

## 详细说明

毕导用冰箱小规模实验冻湿沙，每小时装填一层湿沙再铺一层干沙，避免饱和湿沙的冻胀现象，熬了十小时建成小冰墙。他一百二十五斤站上去纹丝不动，用刀等工具挑战冰墙也没有掉血。文献指出湿沙子冻上后强度比纯冰块更大。三国志战略版团队在银川搭建的冰墙，大锤去砸结果锤先坏了。这说明曹操一夜筑冰城在材料强度上是站得住的。
