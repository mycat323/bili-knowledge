# 指数分布与泊松分布

## 一句话定义

当公交车到站完全随机时，相邻两车的时间间隔服从指数分布，单位时间内到站车辆数服从泊松分布。

## 详细说明

视频用 Python 模拟十万辆公交车，考察「从起点站均匀出发、但司机自由发挥」的到站情况。

结论是：如果公交车非常随机地到站，那么

- 两辆车到站的时间间隔服从指数分布；
- 一小时到站的公交车数量服从泊松分布。

这两种分布是描述随机到达过程的经典模型。在此情形下，乘客的平均等车时间等于发车的时间间隔——十分钟一班，平均就得等十分钟。这比「均匀到站、平均等五分钟」的直觉结果长了一倍。

该结论与等待时间悖论一致：随机化程度越高，慢车占据的时间区间越长，乘客越容易落入长等待区间。视频用模拟而非解析推导展示这一点，说明「听着很反直觉，但这就是数学」。
