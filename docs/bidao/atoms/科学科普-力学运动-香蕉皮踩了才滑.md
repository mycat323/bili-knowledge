# 香蕉皮踩了才滑

## 一句话定义

香蕉皮未被踩踏时摩擦系数高达1.2并不滑，被踩破后内部凝胶流出使摩擦系数骤降至0.066，才变得极滑。

## 详细说明

2012年，日本北里大学的 Kiyoshi Mabuchi 等人研究了香蕉皮为什么滑。

实验先把香蕉皮放在斜坡上，结果它在 45 度的陡坡上都滑不下来，测得摩擦系数高达 1.2——香蕉皮本身其实并不滑。但踩上一脚后，摩擦系数突然降到 0.066，变得非常滑。

显微镜观察显示：未被踩过的香蕉皮内侧网状结构整整齐齐；踩一脚会把毛囊踩破，里面滑滑的凝胶全部流出来，这才导致变滑。

论文发表在 Tribology Online 上，影响因子仅 0.9，但马布奇教授因此获得 2014 年诺贝尔物理学奖（搞笑版）。

论文还给出实用技巧：被踩着的香蕉皮摩擦角约为 3.8 度，只要迈步时腿分开的角度比这个小，迈着优雅的小碎步，香蕉皮也无法让你滑倒。
