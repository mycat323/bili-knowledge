# 喝茶看经络实验复现

## 一句话定义

毕导按复旦团队论文方法喝六种茶并拍红外图，未观察到某条经络区域温度相对周围明显上升，未能复现论文结论。

## 详细说明

复现流程严格照搬论文：采用绿、青、红、白、黑、黄六种茶，另加对照组热水和气氛组冰可乐、喜茶、咖啡；先脱衣静坐二十分钟，再在半小时内分三次喝五十到六十度的茶，每次三百毫升，喝完两分钟内拍红外图。

判读方法上，由于设备精度问题，拍摄前后整体 color map 可能有差异，因此重点关注是否有某一块区域的温度相对周围上升，而不是看绝对温度。

结果：身体各部位温度确有差异，脖子胸腔较热，胸和肚子较凉；但喝完茶后除整体似乎热了一点，看不出某条经络被激活。喝咖啡后背下方变热、喝可乐肚子变热，毕导自己推测可能与憋尿有关。

这说明论文结论至少不是随手一喝就能重现的，需要第三方独立重复验证。
