# 绿豆汤变红源于多酚氧化

## 一句话定义

绿豆中的多酚在煮制时溶入汤中使汤呈绿色，多酚被氧气氧化成红黄色的醌及深色聚合物后，汤就由绿转红。

## 详细说明

用纯净水煮绿豆，十分钟汤呈清澈淡绿色，三十分钟变成经典绿色。把绿色绿豆汤放在七十度热台上保温三小时，颜色由淡绿渐渐变红；室温放置的对照组三小时几乎不变，说明加热会加速这一反应。

原理是：苯环上接羟基的结构叫酚，苯环上连多个酚羟基就叫多酚。多酚容易被氧化成具有环己二烯二酮结构的醌，醌大多是红黄色物质，还会继续聚合使颜色更深。绿豆中含大量多酚，煮汤时多酚溶出，汤因此显绿；与空气接触越久，氧气把多酚氧化成醌和深色聚合物，汤就变成红褐色。

同类现象：苹果咬开后变褐、香蕉放久长黑斑、绿茶放一夜变成红色隔夜茶，都是多酚被氧化导致颜色变深。
