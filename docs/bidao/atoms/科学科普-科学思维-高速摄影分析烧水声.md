# 用高速摄影分析烧水声

## 一句话定义

用超高速摄影配合声音分析，可以把烧水过程中不同温度阶段的声音变化记录下来，从而区分响水与开水的不同发声机制。

## 详细说明

面对「响水不开，开水不响」这个日常俗语，仅凭耳朵听很难判断声音到底来自哪里。视频采用的方法是：用超高速摄影（20000 帧）拍摄烧水过程，同时进行声音分析。

这种方法的思路是：

- 把连续变化的烧水过程拆成可观察的阶段：初期安静、六七十摄氏度响声达到顶峰、八九十摄氏度响声减弱、完全沸腾后转为低沉声音。
- 把「声音」和「画面」对应起来，看每个阶段水里到底发生了什么。
- 区分响水和开水的声音，确认它们是两种不同的声音，而不是同一声音的强弱变化。

这类做法的价值在于：日常俗语往往把多个不同机制混为一谈，只有把过程分阶段、把现象拆开，才能分别找到每个阶段声音的真正来源。
