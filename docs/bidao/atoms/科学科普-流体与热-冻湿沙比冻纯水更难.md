# 冻湿沙比冻纯水更难

## 一句话定义

湿沙中的水分布在无数毛细管内，会形成过冷水，冰晶尺寸越小凝固点越低，因此冻湿沙又慢又难冻透。

## 详细说明

在冰箱里冻一块纯冰块很容易，但冻一块湿沙子时，水是在无数个毛细管内冻结，水会形成过冷水。根据开尔文方程，冰晶的尺寸越小，凝固点就越低，所以冻沙子又慢又难冻透。毕导在北京零下五度左右尝试冻湿沙，两个小时过去几乎冻不上。三战团队也失败了很多次，后来借助多方专家才攻克。这说明一夜筑冰城需要足够低的夜间气温和正确的建造策略，不是随便泼水就能成。
