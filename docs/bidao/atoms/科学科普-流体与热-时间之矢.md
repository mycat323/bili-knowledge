# 时间之矢

## 一句话定义

随着时间流逝世界的熵总在增加，物质自发变得更加混乱无序，时间的箭头和熵的箭头方向一致，这就是时间之矢的由来。

## 详细说明

物理学家一直在思考一个深刻的问题：时间为什么在单向地从过去向未来流逝？解决这个问题的思路是看一看世界上有什么东西是随着时间一起变化的——熵。

随着时间的流逝，世界的熵总在增加，物质会自发变得更加混乱而无序。在这个意义上，时间的箭头和熵的箭头方向是一致的。热的地方会不断向冷的地方传热，直到温度相同；两坨纯净的物质会自发地混合均匀而难以分开；能量会不断被我们利用而质量退降，直到变成热能再也用不了了。这就是所谓的时间之矢。

《信条》的设定是熵增理论的加强版，它直接定义了时间就是熵增，熵减就是时间倒流。可以脑补一个反向热二的世界：冷的东西会自发向热的东西传热，男主靠近火的时候火会疯狂吸收他的热量把他冻死；混合在一起的液体会自发分离；脚在地面上摩擦之后会变冷，而这个热量会变成动能让你滑起来。所以熵减的世界是可以想象的，但诺兰那套时光倒流相当于比熵减苛刻得多，他相当于把每个东西的速度都从 v 变成了负 v。
