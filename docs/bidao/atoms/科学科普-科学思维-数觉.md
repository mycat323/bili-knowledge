# 数觉

## 一句话定义

数觉是人能对小于五个的物体数量进行瞬间准确自信判断的能力，无需在脑中逐个计数即可直接得出结果。

## 详细说明

数觉（subitizing）的核心特征是「不数就知道」。当物体数量在一到三个时，人的判断速度和准确率都相当高，且彼此差别不大；从四个物体开始反应变迟钝、容易出错；到五个、六个时大脑就「干烧」，必须切换到慢慢数数。

数觉与数数的机制完全不同。数数时注意力要先放在第一个物体上数一，再转移到下一个数二，如此循环，相当于程序里遍历所有元素的 O(n) 算法；数觉则没有注意力逐个转移的过程，直接用直觉给出结果，复杂度降为 O(1)。

有研究提出，数觉可能依靠图形记忆：把物体很少时的形状在脑中存成一张图，两个苹果像一条线，三个葡萄像一个三角形，下次见到类似形状就瞬间唤醒。四边形的形状有凸有凹、彼此不像，大脑就开始宕机；五个以上能组合出的几何形状更是千变万化，无法全部记住，于是数觉的范围停留在五以下。

数觉广泛存在于世界各地的人身上，两岁的宝宝就开始显示出这种能力。
