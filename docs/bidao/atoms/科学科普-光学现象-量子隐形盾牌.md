# 量子隐形盾牌

## 一句话定义

所谓量子隐形盾牌是一块被加热掰弯的亚克力板，靠弯曲透明材料改变光线传播方向，让人体局部看起来消失。

## 详细说明

视频中的「量子隐形盾牌」号称由美国军方资金支持，实际材料就是常见的亚克力板。制作方法只有一步：用热风枪把亚克力板加热到变软，再把它掰弯成特定弧度。

弯曲后的透明板相当于一个折射面，人体或物体位于板后时，从观察者方向射来的光线经过弯曲板面发生偏折，使原本应被挡住的背景光绕过来，于是被遮挡部分看起来「消失」了。

需要强调的是，视频并未给出该盾牌的具体光学参数、弯曲角度或隐身效果的定量数据，只演示了加热掰弯这一制作过程。因此「量子」二字属于营销包装，与量子力学无关，本质是几何光学中的折射现象。
