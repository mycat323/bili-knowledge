# 组会前一天突击出科研进展

## 一句话定义

许多科研狗都有同一个被动技能：组会前一天总能突击出一些科研进展，或至少表现得仿佛有一些科研进展。

## 详细说明

毕导在描述复学后的日常时提到，他相信每一个科研狗都有一个被动技能，那就是组会前一天总能突击出一些科研进展，或者至少能在组会上表现得仿佛有一些科研进展。

与之配套的是组会后的仪式：每周组会和工业项目会之后，兄弟们就会去南门外吃一顿烧烤，再打一场台球，庆祝又活过了一次组会。

他描述的日常节奏还包括：上午看文献、泡茶、配置环境（pip、conda），临近中午实验室渐渐嘈杂，经常一事无成就去吃午饭；下午一般效率最高，但也经常一事无成地去吃晚饭；晚饭后有灵感就继续科研，科研烦躁就回家打游戏。

这些细节说明科研的时间投入与产出并不线性对应，组会周期会人为制造阶段性的产出压力。
