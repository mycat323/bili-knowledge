# 前向散射增强理论

## 一句话定义

纤维或颗粒间由空气变为水后，介质与物质的折射率更接近，光在米氏散射中更倾向向前传播，向后散射回眼睛的光减少，物体因而变深。

## 详细说明

光遇到小颗粒会向各方向散射。颗粒远小于波长时发生瑞利散射，波长越短散射越强，所以天空是蓝色；颗粒比波长大一些时发生米氏散射，对不同波长基本一视同仁，所以白云是白色。衣服纤维、沙子都比光的波长大，适用米氏散射。

米氏散射中向前的散射强于向后。计算表明，物质与周围介质的折射率越接近，向前的散射就越多。裤子纤维间原本充满空气，变湿后空气被水取代，水和纤维的折射率更接近，光在裤子里更向前散射、钻得更深，向后进入眼睛的光更少，裤子看着就变深。

这同时解释了薄衣服湿了会变透：光本来穿不透衣服，湿后能走得更深，就能穿透，所以变透和变深是一回事。玻璃砂在空气中因与空气折射率相差大而散射成白色，加入甘油后折射率接近，光可穿透，玻璃砂变透明；纸沾油变透明、有些花雨后变透明同理。该理论最早可追溯到1970年，1983年和1986年由Boring等人用于解释湿沙子变深。
