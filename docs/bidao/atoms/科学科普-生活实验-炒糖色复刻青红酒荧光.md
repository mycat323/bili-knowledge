# 炒糖色复刻青红酒荧光

## 一句话定义

用做饭用的炒糖色加水调出类似青红酒的红褐色，再加入少量维生素 B2 水搅拌，用白光照射即可复现青红酒的绿色荧光，成本不到三块钱。

## 详细说明

青红酒里究竟是什么物质在发荧光，转写稿中并未确定，但作者凭人眼色谱隐约感觉里面有维生素 B2。验证方式：取做饭用的炒糖色加入水中，颜色已经很像青红酒；再加入少量维生素 B2 水，搅拌，打光后绿色效果和青红酒一模一样，甚至比青红酒更青红。

再兑点白酒进去，就色香味俱全，和青红酒很像。别人酿了三年的黄酒才有的变色现象，三分钟就能调出来，成本不到三块钱。这个复刻实验说明：只要液体本身呈红褐色、能反射红光，同时含有能在蓝光激发下发出绿色荧光的物质，就可能在白光照射下呈现绿色。
