# 叉乘只在三维存在

## 一句话定义

赫维茨定理表明所有维度中只有三维和七维能定义叉乘，七维叉乘性质不佳无法构建物理世界，因此能用左右手定则是生活在三维空间的铁证。

## 详细说明

叉乘对空间维度极其挑剔。二维世界的纸片人根本没有三个垂直的方向，想叉乘也叉不起来；四维空间的高级生命有四个垂直方向，两个向量一叉乘叉不出唯一的第三个方向；五维六维同样不行。

赫维茨定理告诉我们，在所有维度中只有三维和七维世界能够定义出叉乘，但七维叉乘没有良好的性质，规则丑陋，没法用于构建物理世界。

这意味着：没有叉乘，麦克斯韦方程就写不出来，纸片人的物理课中根本不会有电磁学。只有恰好处于三维空间的我们才拥有叉乘的权利，才能体会左右手定则带来的乐趣。当我们在物理公式中大量使用叉乘时，这在数学上竟然成为我们生活的空间是三维的铁证。正如费曼在介绍叉乘时的感慨：这是一个十分幸运的奇迹。
