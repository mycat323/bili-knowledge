# 高分子链缠绕

## 一句话定义

塑料、橡胶、纤维等一切高分子在微观上都是长长的链，长了就容易弯、弯了就容易打结，高分子链因此总是缠绕在一起，这种缠绕打结状态赋予高分子独特的动力学和流变学行为。

## 详细说明

普通分子在微观上长得像小球，而高分子是一条长长的链。链一长就容易弯，弯了就容易打结，所以高分子链都是缠绕在一起的。

正是这种缠绕打结的状态，赋予了高分子独特的动力学和流变学行为。视频中列举的现象——橡胶柔软、防弹衣坚硬、口香糖能开椰子、玉米糊能水上漂——看似毫不相干，都可以归结为高分子链不同的打结方式。

高分子与纽结理论的联系在于：高分子本质上就是一坨扭结。真正掌握了打结的科学家甚至可以给分子打结。1961年Frisch等人在JACS上发表论文Chemical Topology，把两条分子链打成结，形成机械互锁、很难写出化学式的分子，命名为索烃。此后还出现了手铐烃、饼干烃、奥林匹克烷、三叶结等分子结，分子小车也有分子打结的参与。
