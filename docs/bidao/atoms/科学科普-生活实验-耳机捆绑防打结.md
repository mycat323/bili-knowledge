# 耳机捆绑防打结

## 一句话定义

让耳机线自我缠绕、把耳机头固定住，使耳机头不再在线圈之间穿梭，打结就无从发生，这是防止耳机打结的第一种方法。

## 详细说明

原理：耳机打结的必要条件是耳机头穿过两圈耳机线之间的空隙。只要让耳机线自我缠绕、把耳机头捆绑固定，耳机头就无法在空隙间穿梭，结自然无法形成。

操作要点：把耳机线绕好后，用线自身或配件把整团线连同耳机头一起捆住，让耳机头不再自由晃动。

与另一种方法「露出机头法」相比，捆绑法把耳机整体收在裤兜内，适合不想让耳机露在外面的场合；露出机头法则把耳机两端留在裤兜外，同样切断耳机头穿梭的路径。两种方法都针对同一个打结条件，可以按使用习惯选择。
