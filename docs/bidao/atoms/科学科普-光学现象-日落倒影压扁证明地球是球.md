# 日落倒影压扁证明地球是球

## 一句话定义

日落照片中水下太阳倒影比水上部分扁一点，说明海面不是平面镜而是凸面镜，从而证明大地是球面。

## 详细说明

普林斯顿大学教授范德北的论文《密歇根湖上的日落照片能揭示我们星球的形状吗？》里有一张奇怪的日落照片：太阳一半在水上，一半在水下，但水下的半个太阳倒影比水上的半个太阳要扁一点。

推理链条：

1. 如果地球是平的，无风状态下的大海应像一个平面镜，人类、轮船、太阳在海底的倒影应该和海上的部分一样长；
2. 但照片中太阳在海里的倒影比海上扁了一点点；
3. 凸面镜成像的几何特点是倒影在纵向被压缩、变扁；
4. 因此大海不是平面镜，而是凸面镜，大地不平，而是个球。

视频用凸面镜落日的实验复现了倒影被压扁的样子，与论文照片相似。
