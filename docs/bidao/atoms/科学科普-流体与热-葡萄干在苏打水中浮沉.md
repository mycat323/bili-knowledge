# 葡萄干在苏打水中浮沉

## 一句话定义

葡萄干放入苏打水后会反复上浮下沉，因为过饱和二氧化碳析出的小气泡附着在粗糙表面把它托起，到水面气泡破裂后浮力减小又沉下去。

## 详细说明

苏打水中溶解了过饱和的二氧化碳，开盖后大量小气泡析出。葡萄干表面粗糙，气泡容易附着其上，气泡群提供的浮力把葡萄干托到水面；到达水面后气泡破裂，浮力减小，葡萄干翻滚几圈后重新沉底，如此循环。

2017 年，美国威斯康星大学麦迪逊分校的 Savvas Hatzikiriakos 教授和女儿一起做了这个观察，并开发了一套数学模型计算葡萄干的运动，论文发表在 Nature Communications 上，标题是《过饱和流体中物体的悬浮和动力学》。此前还有人研究过啤酒里花生的翻滚。

这个现象说明：看似无聊的生活问题，只要用严谨的数学建模去描述，同样可以成为正经的科研课题。
