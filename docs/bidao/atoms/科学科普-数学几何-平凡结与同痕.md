# 平凡结与同痕

## 一句话定义

一拉就开的结叫活结，学术上称为平凡结，相当于没打结；那些本质上一样的结在数学上称为同痕，扭、交叉、移动是判断结是否同痕的最简单方法，即Reidemeister moves。

## 详细说明

生活中最简单的结，旋转一下会变复杂，再交叉、移动，看起来越来越复杂，但这些操作并不改变结的本质，它仍等价于最开始的那个结。

判断两个结是否本质相同，靠的是扭、交叉、移动这三类基本操作，即Reidemeister moves。只通过拉扯和扭转，一个结可以变成另一个看起来完全不同的结，视频中演示了四步完成这种变换。

由此得到两个反直觉结论：

- 长得像的结之间可能存在本质区别；
- 看起来差得很远的结可能其实是一样的。

像翻花绳、一拉就松的鞋带，都是平凡结。爱翻花绳的小学生，其实就是在复杂的Reidemeister移动组合中探究花绳的同痕不变量。1985年琼斯发现了一个多项式族，可以用来描述一个结的结构，例如外科结和懒散结都有各自的琼斯多项式。
