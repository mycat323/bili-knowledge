# 沙子剪胀性

## 一句话定义

湿沙被挤压时颗粒相互滑动让出更多空隙，反而吸水，所以踩出的脚印是干的；晃动沙子则会让深层水跑到表面。

## 详细说明

走在海边踩出的脚印竟然是干的：你一踩不会把沙子里的水压出来，反而会把外面的水压回沙子里。有位青岛大娘用一根手指就能封印住一片海水，毕导在天津沙滩也勉强复刻。这些现象源于沙子独特的剪胀性，由奥斯本雷诺于一八八五年率先描述。原理在于沙子颗粒本来相互堆积得挺紧密，你大力挤压，相互咬合的颗粒不得不相互滑动，让出了更多的空隙，反而能吸水。而只要晃动一下沙子，深层的水都会跑到表面，这就是土壤液化现象。
