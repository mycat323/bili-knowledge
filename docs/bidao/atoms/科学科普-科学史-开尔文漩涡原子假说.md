# 开尔文漩涡原子假说

## 一句话定义

1867年开尔文勋爵提出原子可以描述为漩涡的结，这一假说虽未获得多少人支持，却促使数学家从拓扑学中开辟出纽结理论这一分支。

## 详细说明

1867年，开尔文勋爵提出原子可以描述为漩涡的结。这个想法在当时没有多少人理会，但它把「打结」变成了一个严肃的科研话题。

受此影响，数学家们从拓扑学中开辟出一个分支，即纽结理论。此后打结一直是数学和物理中有趣的研究对象，1985年琼斯发现的多项式族可以用一个多项式描述结的结构。

这段历史说明，一个最终被证明不成立的物理假说，也可能催生出重要的数学分支。
