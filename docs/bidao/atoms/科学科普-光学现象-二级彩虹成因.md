# 二级彩虹成因

## 一句话定义

光线在水滴内部反射两次，平行光被水滴变成五十二度光锥，在四十二度彩虹上方形成外紫内红的二级彩虹，学名叫霓。

## 详细说明

彩虹上方还有一道外紫内红的二级彩虹，学名叫霓，霓虹二字分别指上下两道彩虹。

回到光路图：没有人规定光线只能在水滴内反射一次，它还可能在水滴内部反射两次，形成另一条光路。这时相当于平行光入射被水滴变成了一个五十二度的光锥。在视野中，四十二度彩虹的上方就出现了一个五十二度的外紫内红的彩虹。

两道彩虹之间的区域看起来特别暗，被称为亚历山大带。
