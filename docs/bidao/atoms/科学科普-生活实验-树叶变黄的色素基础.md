# 树叶变黄的色素基础

## 一句话定义

树叶同时含有绿色的叶绿素和黄色的胡萝卜素、叶黄素，夏天叶绿素多显绿，秋天叶绿素减少就显出黄色。

## 详细说明

树叶中并非只有一种色素：叶绿素呈绿色，胡萝卜素和叶黄素呈黄色，它们同时存在。

夏天光合作用强，叶绿素含量高，绿色盖过黄色，叶子显绿。秋天日照变短，叶绿素合成减少、逐渐分解，原本被掩盖的黄色色素显露出来，叶子就变黄。

这是「变黄」现象中最简单的一类：不是新生成黄色物质，而是原有黄色色素因绿色色素退场而显现。它和纸张、白墙那种氧化生成共轭结构变黄的机制不同，但终点都是黄色。
