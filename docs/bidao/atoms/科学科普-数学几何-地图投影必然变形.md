# 地图投影必然变形

## 一句话定义

地球是高斯曲率为正的球面，地图是高斯曲率为零的平面，两者曲率不同，因此不存在无变形的世界地图。

## 详细说明

制图学家几百年来一直想画出完美的世界地图，但高斯绝妙定理给出了否定答案：球面永远不可能等距展开成平面。

原因是地球近似球面，各点高斯曲率为正；地图是平面，高斯曲率为零。曲率不同，两者之间不存在等距变换，所以任何地图都必然在某些区域产生扭曲。

最常见的墨卡托投影就是典型例子：它把球面展平的代价是越靠近南北极，面积变形越严重。格陵兰岛靠近北极，在墨卡托地图上看起来和非洲差不多大，实际上它的面积只有非洲的约十三分之一。

这一结论与手机膜气泡、膏药贴膝盖属于同一类问题：曲率不匹配的两个曲面无法完美贴合。
