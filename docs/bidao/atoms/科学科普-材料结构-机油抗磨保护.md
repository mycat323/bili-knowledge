# 机油抗磨保护

## 一句话定义

机油在活塞与缸壁等运动件之间形成润滑膜，减少金属直接接触，从而降低磨损并维持发动机运转状态。

## 详细说明

发动机内部活塞与缸壁持续高速往复运动，若金属直接接触，会迅速产生划痕与磨损。机油的作用是在接触面之间形成润滑膜，把金属与金属隔开。

视频中通过双缸对比展示：加入参比油的气缸在长时间运转后满身伤痕，而加入美孚速霸的气缸肉眼可见没有磨损。

视频还提到美孚速霸经过权威机构实测验证，保护长达三十万公里，验证方式包括油样检测、引擎拆机、数据追踪，对应的结论有：

| 检测维度 | 结论 |
| --- | --- |
| 油样金属含量 | 低，抗磨保护认证 |
| 主要零部件沉积物 | 无明显油泥，清洁保护认证 |
| 高温下机油粘度 | 稳定，高温保护认证 |
| 燃油消耗与 GPF | 消耗稳定，有效帮助防止 GPF 堵塞 |

这些指标分别对应抗磨、清洁、高温稳定和排放系统保护几个方面。
