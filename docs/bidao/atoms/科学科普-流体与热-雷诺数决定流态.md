# 雷诺数决定流态

## 一句话定义

雷诺数等于流体密度乘以速度乘以尺度再除以粘度，小于两千为层流，大于四千为湍流，中间为过渡态。

## 详细说明

1883 年，奥斯本·雷诺做了一个著名实验：玻璃管中有水流，管道中心射入一小束颜料。

- 水流缓慢时，颜料只平行向前，绝不扩散。
- 水流加速后，颜料上下摆动，跳起舞步。
- 水流湍急时，颜料胡乱运动扩散。

雷诺当场总结出，决定染料流动状态的是一个无量纲数，等于流体密度乘以速度乘以尺度除以粘度。1908 年，德国物理学家索末菲正式宣布这个无量纲数叫雷诺数。

用雷诺数可以把流体分为三种流动状态：

| 雷诺数 | 流态 | 特征 |
| --- | --- | --- |
| 小于 2000 | 层流 | 各部分互不干扰，平滑规整向前流动 |
| 2000~4000 | 过渡态 | 如蜡烛熄灭后可观察到层流向湍流转捩 |
| 大于 4000 | 湍流 | 压力和流速无规律变化，内部相互扩散混合，常伴漩涡 |

木星的红眼就是一坨比地球还大的湍流。雷诺数揭示了一条法则：速度竟然能决定流体的性质，快水和慢水有本质区别。
