# 沟槽反射光锥

## 一句话定义

平行光照射在平行的沟槽表面上时，沟槽上的每一点都把光线反射成一个半圆锥面，在暗室中让光屏缓慢后退并长曝光，就能看到一个完整的光锥。

## 详细说明

案板竖着放时，激光笔在墙上打出一条竖线；把案板慢慢旋转，这条线渐渐弯下来；转到案板横着放时，墙上的亮线变成了一个完美的半圆。也就是说，激光打在这个方向的沟槽上，反射出的是一整片锥面。

把环境调暗，用滑轨让光屏缓慢后退，曝光三十秒，就能直接看到沟槽的反射构成一个完美的光锥，黑暗的房间里闪耀着数学的光辉。

微观上可以这样理解：沟槽相当于一排小镜子。射到沟槽中心的光线沿正常方向反射；射到左半沟槽的光线被反射到右边；射到右半沟槽的光线被反射到左边。所有反射光都遵守反射定律，反射角等于入射角，所以它们与沟槽的夹角都一样大，相当于绕着沟槽在空中转了半圈，刚好构成半个圆锥面。
