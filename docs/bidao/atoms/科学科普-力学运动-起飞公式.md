# 起飞公式

## 一句话定义

描述传送带上物体运动的三个速度关系：轮子滚动线速度等于机身地速与传送带后退速度之和，即 v轮 = v机 + v带。

## 详细说明

设传送带表面向右运动、速度大小为 v带，上面的飞机机身相对地面速度为 v机，轮子在传送带上不打滑地旋转，线速度为 v轮。

在一段时间内，轮子总共向前滚过 v轮 的距离，传送带向后跑了 v带 的距离，于是机身实际向前移动了 v轮 − v带，即 v机 = v轮 − v带，移项就得到 v轮 = v机 + v带。

举例：v机 = 1、v带 = 2，则 v轮 = 3，意思是飞机以 1 m/s 前进，传送带以 2 m/s 后退，轮子就以 3 m/s 旋转。把传送带上的飞机换成汽车、人，甚至汽车人，这个公式都成立。

它是整期讨论中唯一需要的公式，作用是给出三个速度之间必须满足的等式关系；但它本身不说明谁决定谁，这一点决定了后面两种「同步」理解的成败。
