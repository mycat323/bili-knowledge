# 无动力跑步机

## 一句话定义

一种由使用者脚步驱动、传送带转速实时跟随脚速的跑步机，能把人的身体控制在原地，是「追踪轮速」的现实原型。

## 详细说明

无动力跑步机的工作原理就是传送带转速与脚速实时保持一致：慢跑时传送带慢转，冲刺时传送带同步加速，脚永远踩在同一个位置上，身体被控在原地无法前进。

汽车工业里的对应装置是转鼓台：测噪音时把车开上转鼓，转鼓与轮子同速反转，就算油门焊死，车身也不会前进，只留下轮子和转鼓在转。

这两个装置都说明，「追踪轮速」这套机制对靠轮子驱动前进的对象确实有效。但飞机前进靠的是发动机喷气推动机身，轮子只是随动件，所以同样的机制搬到飞机身上就失效了。把现实装置拿来对照抽象设定，正是判断这类问题最有效的办法。
