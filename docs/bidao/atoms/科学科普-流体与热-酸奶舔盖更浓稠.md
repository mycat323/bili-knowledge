# 酸奶舔盖更浓稠

## 一句话定义

运输中酸奶反复浸润盖子，乳清因重力分离回落，留在盖上的酸奶比瓶内更浓稠、蛋白质含量更高，所以舔盖感觉更好吃。

## 详细说明

酸奶并非均相体系。在运输过程中，酸奶会浸润到盖子上，随后乳清逐渐分离析出，由于重力作用回落瓶中。如此反复，盖子上留下的酸奶被不断浓缩，最终比瓶内的酸奶更浓稠，蛋白质含量也更高。

喜欢舔盖，本质上就是喜欢舌头被粘稠液体包裹的感觉。视频中提出一个替代思路：与其不优雅地舔盖，不如直接选择浓稠口感的酸奶。

网上流传的用吸管旋转盖子可以把盖子刮干净；也有厂家借鉴荷叶表面的乳突结构研发超疏水材料，号称酸奶不会粘盖。实践中发现，浓稠一点的酸奶本身也不容易沾盖。
