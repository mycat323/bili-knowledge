# 荧光增白剂流失导致泛黄

## 一句话定义

白色布料中常添加荧光增白剂来抵消泛黄，洗涤和晾晒会使增白剂逐渐流失，失去补偿后布料原本的微黄底色就显现出来。

## 详细说明

床单、白衬衣等白色织物用久了会变黄，原因之一是布料中的荧光增白剂在反复洗涤和晾晒中逐渐流失。荧光增白剂的作用是吸收紫外光并发出蓝光，用蓝光补偿织物本身的微黄色调，让布料看起来更白。

一旦增白剂减少，这种补偿消失，织物原本的微黄底色就暴露出来，视觉上就是泛黄。这与纤维素被空气氧化生成醛基而变黄是两条并行的路径，实际织物变黄往往是多种原因叠加。

视频中还提到另一个常见原因：背上的汗和渍泥蹭到床单上。区分「添加剂流失」和「污渍附着」，有助于判断该用增白洗涤剂还是该加强清洁。
