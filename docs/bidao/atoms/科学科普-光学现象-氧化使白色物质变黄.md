# 氧化使白色物质变黄

## 一句话定义

纸张、白墙漆、空调外壳、塑料抗氧化剂等白色物质被氧化后生成共轭结构，吸收光谱红移，于是肉眼看上去变黄。

## 详细说明

多个日常变黄案例的化学反应路径不同，但都指向氧化：

| 物品 | 化学变化 |
| --- | --- |
| 纸张 | 长链纤维素上的氧被空气氧化 |
| 白墙聚氨酯白面漆 | 紫外线照射下氧化变成醌 |
| 空调外壳聚碳酸酯 | 光致重排环氧化，生成双键结构 |
| 塑料抗氧化剂 | 二叔丁基对甲酚被空气氧化成醌类物质 |
| 排泄物 | 胆素原氧化生成粪胆素和尿胆素 |

规律是：氧化加氧去氢，引入碳碳双键和羰基，形成共轭体系，吸收光谱红移，于是显黄。氧化无处不在、防不胜防，所以人只要碰到氧气就难免变黄。
