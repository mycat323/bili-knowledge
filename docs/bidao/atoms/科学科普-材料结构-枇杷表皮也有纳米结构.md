# 枇杷表皮也有纳米结构

## 一句话定义

枇杷表皮同样存在纳米级的微观结构，说明利用结构产生颜色或表面效果并非蓝莓独有，而是植物中较普遍的现象。

## 详细说明

蓝莓的蓝色来自果蜡的微观结构，这并不是孤例。

枇杷表皮也被观察到具有纳米结构。这类结构可以影响光的行为，也可能影响表面的润湿性等性质。

把蓝莓和枇杷放在一起看，可以得到一个更普遍的结论：植物表皮经常在微观尺度上做文章，用结构而不是色素来实现某些视觉效果或表面功能。

这也提醒我们，看到一种颜色时，不要默认它一定来自某种有颜色的化学物质，结构同样可以是颜色的来源。
