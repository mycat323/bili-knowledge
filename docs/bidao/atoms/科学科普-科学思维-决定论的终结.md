# 决定论的终结

## 一句话定义

拉普拉斯妖认为宇宙现在状态是过去的果与未来的因，但普里高津的非平衡热力学提出不可逆性是自然中基本的建设性作用，时间之矢不是错觉。

## 详细说明

牛顿、量子、相对论都含有决定论的色彩。如果你投下一枚硬币，只要知道硬币现在的形状、质量、手的力，那么硬币未来的运动已经被客观规律所决定了，你能精确算出它怎么翻滚几秒落地。你还能算出世界的过去和未来：过去一亿年的地球气温，未来一亿年里哪天会有月食，喜马拉雅山会长得多高，太阳哪天会熄灭。你如果算不准，只是因为你的知识不够丰富，但本质上它们是确定的。这就是拉普拉斯妖的概念：我们可以把宇宙现在的状态视为其过去的果以及未来的因，对于智者来说没有事物是含糊的。

混沌运动只是很难算而已，在客观上也是被决定的。量子力学测不准原理中各种物理量用概率来表达，但这个概率的规律依然被薛定谔方程所决定，怎么个不确定法是确定的。

把决定论推广到人身上：人说白了无非是一堆原子的组合，每个原子也符合牛顿量子相对论。如果我能知道一个人所有原子这一刻的性质，那理论上每个原子未来的运动都是被决定了的。这个恐怖的想法被称为伊壁鸠鲁的二难推理。

普里高津提出反对意见，他的非平衡热力学理论认为自然法则建立于不可约的概率之上，不可逆性不再是一个具备了完善知识就会消失的表象，而是在自然中起到了基本的建设性的作用。时间之矢不再是错觉，而是秩序的源泉。
