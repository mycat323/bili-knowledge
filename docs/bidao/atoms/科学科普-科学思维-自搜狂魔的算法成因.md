# 自搜狂魔的算法成因

## 一句话定义

被误认为「自搜狂魔」，往往不是本人高频搜索自己，而是推荐算法根据观看行为持续推送同类内容造成的假象。

## 详细说明

毕导在视频中澄清自己并非高频自搜，大约一周才搜一次自己的名字。真正让他频繁看到自己的原因是推荐系统的反馈回路：他平时会看自己的视频，系统监测到这一偏好后，就会持续推送同类的二创、鬼畜视频。

此外还有两个放大因素：一是被大量艾特，粉丝在评论或动态中反复 @ 他，消息堆积到九十九加，很难不点进去看；二是看到屏幕上出现自己的脸，几乎必然会点开并留言。

结果是外部观察者只看到「他总出现在关于自己的视频下面」，从而得出自搜狂魔的结论。这是一个典型的观测偏差：看到的是行为结果，忽略了算法推送这一中间环节。
