# 巴雷诺数

## 一句话定义

颗粒流中重要的无量纲数，用于验证沙漏下落波动来自下落颗粒流与上升空气流之间的耦合。

## 详细说明

巴雷诺数（Bagnold number）是颗粒流里面重要的无量纲数，用于刻画颗粒惯性力与粘性力的相对大小。

在沙漏问题中，它被用来验证沙漏下落波动的核心机制：沙子下落时上层空气体积膨胀、压强降低，下层空气体积减小、压强增大，这个微小压差使沙漏下落减速；随后上下气体重新连通，压差消失，沙漏下落加速，如此反复。

通俗地讲，波动来自于下落的颗粒流与上升的空气流之间的耦合。通过计算巴雷诺数可以验证这一耦合机制。

论文还指出，只要用手捂住沙漏下面，就能增加下部的气压，直接封印沙漏的流动。不过视频作者实验了半天发现并没有什么用——但科研狗不打诳语，paper 这么说一定是有道理的。
