# 防耳机打结的两种方法

## 一句话定义

把耳机线自我缠绕捆绑，或让耳机两端露出裤兜外，都能避免耳机头在线圈空隙间穿插，从而防止打结。

## 详细说明

基于耳机打结的机制——耳机头跳进线圈之间的空隙并反复穿插——可以设计两种防打结方法。

**方法一：耳机捆绑法。** 让耳机线自我缠绕，把整条线捆成一团，耳机头被固定住，不再有机会在线圈之间穿梭。捆绑让打结变成玩笑。

**方法二：露出机头法。** 把耳机的两端露出到裤兜外面。只要耳机头不在线圈之间穿梭，光是耳机线自己打圈是不会形成结的。

此外，史密斯实验还证明绳子在狭小空间内打结概率显著降低，所以把耳机装在小盒子里也是有效的做法，几乎不会打结。
