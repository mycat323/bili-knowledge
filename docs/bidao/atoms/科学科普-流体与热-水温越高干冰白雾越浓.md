# 水温越高白雾越浓

## 一句话定义

水的温度越高，饱和蒸气压越大，水向二氧化碳气膜蒸发越快，干冰产生的白雾就越浓密，冷水、温水、开水三杯对比效果依次增强。

## 详细说明

机理预测：水温升高使水的饱和蒸气压增大，水更容易向干燥的二氧化碳气膜内蒸发，单位时间进入气膜的水蒸气更多，冷凝出的小水滴更多，白雾就更浓。

实验对比三杯水：

| 水温 | 白雾表现 |
| --- | --- |
| 冷水 | 白雾毫无活力，难以飘出 |
| 温水 | 白雾姿态优雅，沉稳内敛 |
| 开水 | 白雾像沸腾一样翻滚 |

这个结果与机理预测一致，是支持「白雾来自浸泡液体」这一结论的定量方向性证据。它也解释了为什么舞台造雾机要用热水而不是冷水。
