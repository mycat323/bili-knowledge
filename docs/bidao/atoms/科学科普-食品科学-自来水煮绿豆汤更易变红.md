# 自来水煮绿豆汤更易变红

## 一句话定义

自来水中的金属离子可能与多酚的黄酮结构络合使吸收光谱红移，或作为催化剂加速多酚变醌，使汤更快变红。

## 详细说明

实验：用北京自来水、杭州某办公楼自来水、矿泉水、纯净水分别煮绿豆汤。测得 pH 分别为 8.09、8.29、7.84、7.7。结果是北京自来水和杭州自来水煮出的绿豆汤都是红色。

反常之处在于：碱性稍弱的北京自来水煮的绿豆汤反而更快变红，说明不能只用 pH 解释。转写稿给出的猜想有两个：一是自来水中的金属离子与绿豆多酚的黄酮结构发生络合，导致吸收光谱红移而显黄色；二是自来水中的微量铁离子、铜离子充当催化剂，让多酚加速变成醌。具体机理复杂，属于化学中尚未完全说清的部分。

结论：用纯净水调配的理想体系成分简单、原理清晰，而自来水中多种离子让变色机理复杂化。
