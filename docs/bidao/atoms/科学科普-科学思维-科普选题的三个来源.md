# 科普选题的三个来源

## 一句话定义

科普视频的选题主要来自观众私信投稿、学术期刊新发表的论文，以及团队日常冲浪发现的怪异现象，其中团队日常发现是最主要的来源。

## 详细说明

毕导团队把选题来源分成三条：

1. **观众私信投稿**。B 站后台设置了自动回复，无论给毕导发什么私信，都会弹出一条投稿问卷的入口；每天大约收到二三十条投稿，其中一些直接做成了视频。
2. **学术期刊**。期刊上解释生活现象背后原理的论文很对胃口，「蓝莓为什么是蓝色」那一期，就是四月看到新论文、六月发出的视频。
3. **团队日常冲浪**。这是最主要的来源。团队日常就是发现怪异的科学现象，像饿虎扑食一样开始研究，定期交流研究成果，看哪个能做成选题。青红酒那期来自深夜刷到的内容，光的折射第一期则来自一个美妆博主的视频。

周期上，长视频从发现现象或产生灵感，到发布一般要两三个月甚至更久：青红酒一月买酒、三月写实验报告梳理思路、五月才发视频；短视频一期可能不到一个月。团队的选题储备相当超前，值得做的选题很丰富。
