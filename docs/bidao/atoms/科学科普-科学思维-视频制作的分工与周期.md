# 视频制作的分工与周期

## 一句话定义

一条科普视频从选题到成片通常需要一到两周，其中学知识环节最耗时，短则一周多，长则一个月。

## 详细说明

毕导介绍了自己的创作流程与分工。他本人负责学知识和写脚本，核心目标是把科学故事串起来，并传达科学中的美感，日常工作是挖掘生活中好玩的科学现象。

耗时最长的是学知识：他自认掌握的是三传一反、四大化学、高分子，遇到不属于化工的领域就要从头学，短则一周多，长则一个月。构思时间差异也很大——尿液动力学在脑中构思了几个月，衣架套头一天就看完文献，SNP 大一统的收尾纠结了一两个月。

脚本完成后，由编导拍摄剪辑，其他人参与小剧场演出，后期负责调色、加英文字幕等。整个流程大约一到两周。他强调团队存在，因此难免要接商业合作。
