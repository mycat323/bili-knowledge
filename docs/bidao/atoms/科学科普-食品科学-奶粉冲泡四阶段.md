# 奶粉冲泡四阶段

## 一句话定义

奶粉冲泡分为润湿、渗透、溶解固体桥、小颗粒溶解四步，其中润湿和渗透是最关键的前两步。

## 详细说明

2011年，Forny 等人在《粉末技术》上发表论文，把奶粉的冲泡过程分为四个阶段：

1. **润湿**：水润湿奶粉的表面。
2. **渗透**：水向奶粉之间的空隙内渗透。
3. **溶解固体桥**：水溶解奶粉团内颗粒之间的固体桥，使大团奶粉分散成小颗粒。
4. **溶解**：小颗粒溶解在水中，形成一杯牛奶。

其中最关键的是前两步——润湿和渗透。这两步搞不好，奶粉就无法被润湿和渗透，就会变成奶豆豆。

润湿是液体在固体表面的倾覆和铺展。渗透则是水进入奶粉颗粒之间的空隙。由于奶粉疏水且颗粒间夹带空气，这两步都容易受阻，因此冲奶时水温、搅拌方式和奶粉本身的性质都会影响最终能否冲出没有奶豆豆的牛奶。
