# 导电固体多不透明

## 一句话定义

金属电子能自由运动，既吸收所有光而不透明，又导电性强；绝缘体电子被束缚，既不吸收可见光而透明，又不导电。

## 详细说明

能带理论给出一个把光学和电学联系起来的惊人结论：导电的固体大多是不透明的，透明的固体大多是绝缘的。

在金属里，电子能随便乱动，就像固定的阳离子飘在电子的海洋里，电子可以随意流淌。所以金属的带隙直接就是零，金属里的电子不挑食，什么能量的光都吸收，因此金属都不透明。而电子能随意运动，也恰好说明金属导电性强。

钻石、玻璃这类物质，电子处在共价键、离子键的稳定状态，需要很高的能量才能让它们动起来，所以它们不吸收可见光，看着透明。而电子比较懒，也恰好说明它们是绝缘的。

光学和电学中两个看似无关的性质，就这样有了深邃的内在联系。
