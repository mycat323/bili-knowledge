# 扫描电镜观察水果表皮制样

## 一句话定义

用扫描电镜观察水果表皮需要先固定、脱水、干燥并喷镀导电层，因为生物样品不导电且含水，直接放入电镜无法成像。

## 详细说明

水果表皮是含水的生物样品，不能直接放进扫描电镜。

原因有两点：一是生物样品不导电，电子束打上去会积累电荷，图像会漂移、发亮甚至无法成像；二是样品含水，电镜内部是高真空，水分会迅速挥发，破坏表面结构。

所以制样通常要经过固定、脱水、干燥等步骤，把水分去掉并保持形貌，最后在表面喷镀一层很薄的导电金属，让电子束有通路。

只有经过这些处理，才能拍到果蜡等微观结构的清晰图像，进而判断蓝莓的蓝色是否来自结构。
