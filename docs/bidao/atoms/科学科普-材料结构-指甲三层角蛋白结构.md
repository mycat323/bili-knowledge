# 指甲三层角蛋白结构

## 一句话定义

健康指甲由纤维和片状角蛋白组成复合结构，看似铁板一块，实际分为上、中、下三层，中间层纤维横向排布。

## 详细说明

指甲并非均匀的一块硬板，而是由角蛋白构成的复合结构，分为上、中、下三层。其中最主要的中间层里，纤维呈横向排布。

这一结构差异直接决定了断裂的难易：因为纤维是横向排列的，横向断裂所需的能量比纵向断裂更小，所以横着剪指甲比竖着剪更容易剪断。

理解这一点的意义在于，剪指甲时指甲的断裂方向并不是随机的，而是由内部纤维的排布方向决定的。这也解释了为什么指甲刀沿指甲宽度方向施力时更容易让指甲断开。
