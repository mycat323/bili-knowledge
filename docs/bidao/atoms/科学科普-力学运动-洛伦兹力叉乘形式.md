# 洛伦兹力的叉乘形式

## 一句话定义

带电粒子在磁场中受力的公式 F = qv×B，用向量叉乘把方向规则封装成一个简洁表达式，是左右手定则背后的大一统理论。

## 详细说明

高中教材把洛伦兹力写成 F = qvB，大学教材则写成 F = qv×B，多出的乘号不是省略的普通乘号，而是向量叉乘。

叉乘形式与左手定则结果完全一致：食指代表正电荷速度方向 v，中指代表磁感线方向 B，大拇指刚好指向正电荷受力方向。用左手定则判断和用右手叉乘判断，得到的受力方向相同。

叉乘的简洁性带来更深的洞察：一个电子感受到的力和自己的速度成正比，这一规律在叉乘形式下一目了然。麦克斯韦方程组在 1865 年原始版本有二十个方程，1880 年左右赫维赛德和吉布斯用向量和 nabla 算子把它写成四个方程的标准版本，如今电磁学考试常以默写麦克斯韦方程为第一题。
