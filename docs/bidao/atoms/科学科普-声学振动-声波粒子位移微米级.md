# 声波粒子位移微米级

## 一句话定义

声波引起的空气粒子位移等于声压除以二派乘以频率乘以密度乘以声速，量级只有微米，远不足以对火焰产生可观测的影响。

## 详细说明

面对「声波振动带动火焰微粒运动」这一流行解释，熊才义在论文中给出了定量估算。声波传播时空气粒子的位移公式为：

位移 = 声压 / (2π × 频率 × 密度 × 声速)

代入典型参数计算，声波引起的空气粒子位移大约只有微米级别。这个尺度比蜡烛火焰的尺寸小好几个数量级，对火焰整体运动几乎没有影响。

这个估算直接否定了「声波把火焰震灭」的直觉解释。人们之所以觉得声音有力量，是因为耳朵对声压极其敏感，加上低音炮振膜大幅振动带来的视觉冲击，容易把「听到的响」和「能推动物体」混为一谈。实际上，若真要靠声波能量把蜡烛震灭，理论预测需要一百四十五分贝以上的声压级，相当于站在火箭发射现场，蜡烛灭了人也受不了。

毕导的实测也印证了这一点：用九十分贝的重低音才能艰难熄灭一根贴得很近的蜡烛，而九十分贝重低音的灭火效果甚至不如随手一吹。真正起作用的是振膜推动空气形成的风，不是声波本身携带的能量。
