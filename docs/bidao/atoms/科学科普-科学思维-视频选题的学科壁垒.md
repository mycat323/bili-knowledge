# 视频选题的学科壁垒

## 一句话定义

一个跨学科选题的推进难度，取决于各子问题分属哪些学科，以及其中哪些环节根本做不了实验。

## 详细说明

毕导以「SNP 大一统」选题为例，说明选题难度的两个来源。

理论层面：S 和 N 属于流体力学，而他是化工出身，流体力学是本行；P 是声学问题，大部分人本科不学声学，因此理论准备成本高。

实践层面：S 可以做实验，比如捏面团扔进水里；N 可以做实验，比如把水喷在瓷砖上；但 P 只能靠自己，而他自己是「少屁的人」，实验条件匮乏，机会不多。

这揭示了一个通用规律：选题的可行性不只由理论难度决定，还由「能否获得实验样本」决定。当研究对象本身难以按需产生时，实验进度就不可控，这也是该选题拖了三个多月的原因。
