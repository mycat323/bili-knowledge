# 离心力加速沙漏

## 一句话定义

把沙漏空的一侧向外抡起手臂形成大摆锤，产生的离心力相当于给沙子一个向外的加速度，可把沙子加速甩下去。

## 详细说明

根据爱因斯坦相对论等效原理，重力场和以一定加速度运动的参考系等效。把沙漏空的一侧向外，抡起手臂形成大摆锤，产生的离心力就相当于给沙子一个向外的加速度，把沙子加速甩下去。

实验效果：原本三分钟的沙漏，抡起来后一分钟直接甩空。随便抡抡就有十几个 G 的加速度。

操作要点：

- 轮的越快，沙漏下落越快；
- 但动作也会越大，更容易被发现，需要与店家斗智斗勇；
- 视频作者的极限是十秒能抡二十五圈。

这是加速沙漏最完美的方法，原理上直接增大了贝弗洛定律中的等效重力加速度。
