# 辩论无法说服闭环逻辑

## 一句话定义

面对用自洽闭环逻辑解释一切的人，持续举证无法取胜，因为对方从一开始就没打算被说服。

## 详细说明

毕导在与地平说支持者辩论后陷入迷茫，曾以为只要给出更强力的证据，总可以说服对方。他每天在脑内左右互搏，模拟对线，无时无刻不在想如何证伪地平说。

最终他悟到：网络上有很多人从一开始就没打算被说服，和他们辩论，你只会不停举证，但永远无法取胜。想通之后他再没理过对方。

但他也承认佩服对方：对方至少在自己认定的观点上思考得非常深入。他把对方比作穿越到现代的中国古人，只怀着天圆地方的信念；而自己像一个穿越到古代的现代人，要说服古人地球是个球。

这段经历也让他保留了对方传授的怀疑一切的精神：计算所依据的日落照片他本人从未亲眼见过，因此只能说如果照片真实存在，推理是精彩的。
