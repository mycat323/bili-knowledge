# 重大决定源于一时冲动

## 一句话定义

人生中真正重大的决定往往不是理性权衡的结果，而是在某个瞬间被情绪与直觉推动的拍脑瓜式选择，事后再用理性去解释。

## 详细说明

毕导在决定把工作室从北京搬到杭州时，回顾了自己在北京十四年的生活。他发现，当把北京和杭州的优缺点掰开揉碎做理性对比时，只会陷入难以比较的虚无：北京风沙大、冬天冷，但演出丰富；杭州青山绿水多、下雨多、夏天热，但美食与北京平分秋色。这种对比没有胜负。

真正让他下定决心的，是一个具体瞬间——看到父母带着狗在西湖边快乐玩耍的照片，而自己刚加完班走在北京的寒风里。那一刻他感到「走吧」。

这提示一个普遍规律：重大决定常常不是可以理性决策的事情，而是先有冲动，再由理性去补理由。理性对比适合处理可量化的小事，面对生活方式级别的选择时，它反而会失效。
