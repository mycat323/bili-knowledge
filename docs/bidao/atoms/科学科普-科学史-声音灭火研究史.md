# 声音灭火研究史

## 一句话定义

从 1857 年丁达尔记录声音影响火焰，到 2021 年熊才义证明灭火的是振膜风，声音灭火研究历经一百六十余年。

## 详细说明

声音灭火的研究脉络：

- 1857 年，爱尔兰科学家丁达尔率先发现并记录声音能影响火焰的现象，但他并不知道原因。
- 1905 年，德国物理学家鲁本斯发明鲁本斯管，演示声音可以影响火焰的大小。
- 1926 年，美国人凯洛格向消防员表演口技模仿鸟叫声熄灭火焰。
- 此后有人畅想用大喇叭扑灭森林火灾，科学家们争相研究声音灭火原理，实验装置却都很简单：摆音响、照筒子、汇聚声音、点蜡烛、播放声音、熄灭蜡烛。
- 十篇文献能提出十种机理，包括空气微粒振动使火焰失稳、火焰吸收声能离开烛芯导致燃料中断、热火焰被震开遇冷蜡蒸气熄灭等。
- 2021 年，香港理工大学博士后熊才义以第一作者发表论文，宣布声音灭火机理被完全破解：灭火的是音响振膜产生的风。

熊才义现为华南理工大学副教授，研究方向仍是火。
