# 镁火不能用水和二氧化碳

## 一句话定义

镁燃烧温度可达两千度以上，高温下镁会与水反应生成氢气、与二氧化碳反应，因此水基和二氧化碳灭火器都会让火更剧烈。

## 详细说明

金属火灾由钠、镁、铝等活泼金属引发，虽然不常见，但一旦发生就极难扑灭，危害极大。这些金属燃烧温度非常高，可能达到两三千度。高中化学知识指出：高温下镁会与水反应并产生氢气，氢气本身可燃，会让燃烧更加剧烈；镁同样会与二氧化碳反应，所以水基灭火器和二氧化碳灭火器都不能用来灭镁火。

视频中演示了一种反直觉的说法——用汽油灭镁火。原理是汽油与镁竞争氧气，汽油燃烧更剧烈，先把氧气消耗完，镁没有氧气可用了自然就熄灭。实验中短期内火焰确实烧得更旺，但燃烧一段时间后火焰慢慢小了下来。

真正有效的是 D 类火灾专用干粉灭火器，例如粉状石墨、氯化钠等。实验中镁火把锅底烧穿，出现了银白色的液态镁。

常见误解：认为所有灭火器都能通用。实际上火灾按类型划分，选错灭火剂可能助燃甚至引发爆炸。
