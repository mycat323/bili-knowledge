# 奶粉疏水性

## 一句话定义

奶粉是疏水材料，水滴在压成饼的奶粉上会形成圆珠而不铺展，疏水材料不喜欢接触水而喜欢接触空气。

## 详细说明

判断一种材料亲水还是疏水，可以看水滴在其表面的形状：水滴铺展成液膜说明亲水，水滴保持圆珠说明疏水，水滴越圆越疏水。

把奶粉压成一个饼，滴水上去，水珠也挺圆，所以奶粉其实是疏水的，它并不喜欢被水冲。

Crossoska 等人指出，疏水材料不喜欢接触水，而喜欢接触空气。Hansen 等人测量发现，奶粉内部也存在相应的疏水特性。这解释了为什么冲奶粉比冲盐、糖、咖啡更容易起痘：奶粉颗粒排斥水、亲近空气，水难以自动渗入奶粉团内部。

这一性质也意味着，冲奶时单纯把奶粉倒进水里并不够，需要借助水流、搅拌或合适的水温来帮助水克服疏水阻力，完成润湿和渗透。
