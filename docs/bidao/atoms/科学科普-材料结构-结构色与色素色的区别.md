# 结构色与色素色的区别

## 一句话定义

色素色来自物质吸收特定波长光后反射剩余颜色，结构色则来自微观结构对光的干涉、衍射或散射，与物质本身的化学颜色无关。

## 详细说明

蓝莓是区分这两种颜色的好例子。

色素色的逻辑：物质本身吸收某些波长的光，反射剩下的波长，于是我们看到颜色。蓝莓果肉、果汁、果皮内壁都是紫红色，因为里面含有红紫色调的花青素，这是典型的色素色。

结构色的逻辑：物质本身可能无色，但它的微观结构让特定波长的光被加强或削弱，从而呈现出颜色。蓝莓表皮的果蜡就是无色的，用油溶掉果蜡后皮肤上没有任何蓝色印记，可它偏偏让蓝莓看起来是蓝色。

判断方法：如果颜色来自色素，那么把色素提取出来，提取液应该带有颜色；如果颜色来自结构，那么破坏结构（比如磨掉果蜡）颜色就会消失或改变。

蓝莓磨掉果蜡后变成黑色，说明蓝色确实由结构产生，而不是由某种蓝色物质产生。
