# 石头剪刀布的绝对随机方法

## 一句话定义

要做出不受意志干扰的绝对随机出手，可以借助基金收益等外界参数，例如持有收益除以三取余数决定手势。

## 详细说明

只要一方绝对随机出手，任何针对人类偏好的策略都会失效。但人很难靠动脑子做到随机，需要参考一个不受意志干扰的外界参数。

视频给出的具体方法：打开一只基金，用持有收益除以 3 取余数，余数为 0 出石头，余数为 1 出剪刀，余数为 2 出布。基金涨跌很难预测，这样出手就是绝对随机的。

这一方法的思路与算法预测形成对照：算法之所以能赢，是因为人类出手带有可统计的偏好；而一旦用外部随机源切断偏好，算法就失去了预测依据。

它同时也说明，石头剪刀布中「随机」不是一种态度，而是一个需要外部机制保证的技术条件。
