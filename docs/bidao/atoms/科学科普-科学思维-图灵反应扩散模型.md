# 图灵反应扩散模型

## 一句话定义

图灵提出用激活剂与抑制剂两种物质、两条规则解释动物斑纹：激活剂自我促进并产生抑制剂，抑制剂扩散更快从而抑制激活剂，二者相生相克形成稳定斑图。

## 详细说明

图灵的想法是：动物身上复杂的斑点条纹并不需要基因逐个精确控制，只要两种物质和两条规则就够了。

- **激活剂**：负责提供颜色，能促进产生更多激活剂，也能产生更多抑制剂。
- **抑制剂**：抑制激活剂的产生，且扩散速度比激活剂快。

两种物质阴阳调和、相生相克，结果就是抑制剂能稳定地把有颜色的激活剂限制在一个小区域里。最简单的情况是激活剂产生的抑制剂向外扩散后把激活剂包在中心，形成一个小斑点；调整参数就能从斑点变成条纹，造就各种生物身上千变万化的斑纹。

图灵斑图是个笼统概念，可能是很多种方程，比如 FitzHugh–Nagumo 方程等，激活剂和抑制剂也可能不止一种。生物学家要完全理解某种具体生物的条纹仍然困难，因为每种动物还有自己的特殊机制：花栗鼠的平行条纹需要稳定的浓度梯度，江豚清晰的条纹边缘要加上扩散电泳。
