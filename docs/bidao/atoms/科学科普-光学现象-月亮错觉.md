# 月亮错觉

## 一句话定义

日出日落时太阳或低空月亮看起来更大，并非天体真的变大，而是周围较小的参照物（树、房子）衬托所致，太阳升高后参照物变成整个天空，看起来就小了。

## 详细说明

人眼判断物体大小依赖周围参照物：参照物大，物体看着就小；参照物小，物体看着就大。日出时太阳附近有树、房子等较小的参照物，衬托得太阳显得大；太阳升到天上后，参照物变成整个天空，太阳看着就小了。

毕导用同一台相机、同一位置拍摄日出和中午的太阳并叠合对比，发现两者大小其实差不多。月亮也有类似现象：低空的月亮感觉比高空的大，但其实也差不多大，这个现象有专有名词叫「月亮错觉」。

最著名的解释是艾宾浩斯错觉：两幅图中同样大的玩偶，周围参照物不同会让人觉得大小不同；两盘同样多的菜，也会因盘子大小显得一多一少。艾宾浩斯错觉一九零一年才被提出，所以两千多年前的小孩错得情有可原。
