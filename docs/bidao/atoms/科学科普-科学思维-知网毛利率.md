# 知网毛利率

## 一句话定义

根据同方集团年报，知网 2020 年主营业务收入达 11.68 亿元，毛利率高达 53.93%，仅统计的 50 所高校一年就能贡献约五千万。

## 详细说明

知网的吸金能力可以从两个层面看。

微观层面：仅统计的 50 所高校，知网一年就能收约五千万，加上中科院就是六千万。

宏观层面：根据同方集团年报，知网 2020 年主营业务收入达到 11.68 亿元，毛利率高达 53.93%。

知网赚的钱主要花在三个方向：一是给作者发稿酬，硕士论文 60 元、博士论文 100 元；二是给员工发工资，招聘网站上知网岗位薪资约三千二一个月；三是自身建设，包括大数据人工智能挖掘、知识资源互联网传播扩散与增值服务平台、知识资源深度开发利用平台等。

母公司年报中还提到，知网在疫情最严重时期为高校职教用户提供免费校外漫游服务，免费开放知网研学平台，但免费版功能极其有限，往上还有高校版、初级版、高级版、畅享版、尊享版。
