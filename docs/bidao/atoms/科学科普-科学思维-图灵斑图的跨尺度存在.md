# 图灵斑图的跨尺度存在

## 一句话定义

反应扩散机制不只出现在动物斑纹上，从原子尺度的铋晶体、地球尺度的沙纹与石圈，到星系尺度的螺旋结构，都能找到图灵斑图的踪迹。

## 详细说明

图灵斑图升华为一种思想，成为反应扩散系统，可以拓展到极广的尺度。

| 尺度 | 例子 | 激活与抑制 |
| --- | --- | --- |
| 化学 | BZ 反应 | 培养皿中涟漪般的蓝色圈圈浮现又湮灭 |
| 原子 | 铋晶体 | 铋原子垂直位移为激活剂，水平位移为抑制剂 |
| 地球 | 沙纹、沙丘 | 风把沙子吹高是激活，高处挡风、滑落是抑制 |
| 地球 | 斯瓦尔巴群岛石圈 | 冻土推动石头的复杂运动，方程仍是反应扩散方程 |
| 宇宙 | 星系螺旋结构 | 1996 年 Lee Smolin 论文提出类似反应扩散的方程 |

在人体上也能找到：手指是一根一根的，很像条纹，小老鼠用图灵机制产生条纹再靠 Hox 基因控制缩放长出爪子；指纹靠 EDAR、WNT 两种激活剂和拮抗 BMP 作为抑制剂；上颚的整齐褶皱则与纤维细胞生长因子和 SHH 基因有关。
