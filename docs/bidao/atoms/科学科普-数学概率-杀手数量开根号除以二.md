# 杀手数量开根号除以二

## 一句话定义

在杀人游戏数学模型中，为使双方胜率接近百分之五十，杀手数量应约为玩家总数的平方根除以二。

## 详细说明

2013年华沙大学理论物理研究所的 Mikael 发表论文《杀人游戏的数学模型》。设场上有 n 个玩家，其中有 m 个杀手，经过推导可以得到杀手获胜概率的表达式（其中出现的双阶乘符号是数学记号，不是用来加强语气的感叹号）。

把胜率函数画成图像后可以看出，杀手数量越多，杀手胜率越高。为了让游戏更公平，理想配置应让双方胜率都在百分之五十左右。据此可以算出：杀手数量最好约为玩家总数的平方根除以二。

举例来说，玩家数越多，所需杀手比例反而越低。这个结论可以用来检验日常局里的身份配置是否失衡——如果狼人比例明显高于这个值，好人就会长期处于劣势，游戏体验会变差。

需要注意的是，这是简化模型下的理论结果，真实狼人杀还有女巫、预言家等角色，实际配置会在此基础上调整。
