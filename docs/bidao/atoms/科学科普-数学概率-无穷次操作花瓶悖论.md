# 无穷次操作花瓶悖论

## 一句话定义

在有限时间内完成无穷多次「放入十个球、取出一个球」的操作后，花瓶中的球数不是无穷大，而是零个。

## 详细说明

设想一个花瓶和编号的小球。第一轮放入 1~10 号球，取出一个；第二轮放入 11~20 号球，取出一个；如此重复。每次操作所花的时间都是上一次的一半，例如第一次用半小时，第二次用十五分钟，第三次用七分半钟，依此类推。由于等比数列求和收敛，这些时间加起来正好是一小时，所以在一小时内可以完成无穷多次操作。

直觉上，每次净增加九个球，无穷多次操作后应有「九倍无穷」个球。但结论恰恰相反：最后花瓶里一个球都没有。

关键在于「无穷」不是一个可以照常做加减乘除的数。有限次操作时「每次净增九个」的推理成立，但取极限后，逐次操作的顺序和编号方式决定了最终结果。这个思想实验说明，涉及无穷的过程不能简单套用有限情形的算术直觉。
