# 大龄博士生融入新课题组

## 一句话定义

大龄博士生换方向进入新课题组时，放下资历主动请教同组同学，是快速解决技术问题、融入新环境的有效方式。

## 详细说明

毕导复学后换了课题方向，从做膜转向做机器学习，进入新课题组。他的做法是遇到问题就多问，组里同学没少被他烦。

身份关系上出现了一个反转：以前在学校里他是这些同学的辅导员，现在组里他们都是他大哥。平时他不管出了啥 bug，大哥们都热情地帮他解决。

这段经历说明，换方向读博时资历和年龄不构成障碍，主动暴露自己的不懂反而能换来实际帮助。毕导还提到，同样的场景往往只出现在互联网公司的女生身上，用来自嘲这种「被照顾」的处境。
