# 反射亮线是双曲线

## 一句话定义

案板上能被眼睛看到的反射亮线，就是眼光锥被案板平面截出的交线；由于这相当于一个竖直平面截圆锥面，所以它是一条标准的双曲线。

## 详细说明

平行光照射案板时，案板上每一个点都在发出半个光锥。哪些点的光锥能通过眼睛，这些点在视野中就是亮的。

换位思考：如果一个点发出的光锥能通过眼睛，那么根据光路可逆，从眼睛发出的同样形状的光锥必然也通过这个点。因此整条亮线都位于「从眼睛发出的光锥」上；它又位于案板这个平面上。所以这条亮线就是眼光锥被案板截出的交线。由于此时相当于一个竖直平面截圆锥面，由阿波罗尼奥斯的结论可知，它是一条标准的双曲线。

随着案板不断旋转，激光笔在墙面（光屏）上打出的线会依次变形：从直线变成双曲线，变成抛物线，变成椭圆，变成圆。
