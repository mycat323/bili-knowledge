# 耳机打结过程演示

## 一句话定义

把耳机绕成圈后，只要耳机头穿过两圈耳机线之间的空隙，拉开就形成一个结；反复在其他空隙间穿插，结会越来越复杂，最终变成一坨。

## 详细说明

演示方法：在桌面上把耳机绕成圈圈，让耳机头穿过两圈的中间，拉开一看就是一个结；如果多穿过几次，结就更复杂。

模拟走路震动的透明包实验显示：团成团的耳机线在震动中摩擦、扭曲，圈与圈之间形成空隙，耳机头上下震动，一旦跳进某两圈之间的空隙，就形成一个结；如果继续在其他空隙间反复穿插，最后就变成一坨。

结能否自己解开？只有当耳机线在震动中沿着打结的路径原路退回才可能解开，这个概率很小。因此从热力学角度看，打结是比解结更稳定的结局。
