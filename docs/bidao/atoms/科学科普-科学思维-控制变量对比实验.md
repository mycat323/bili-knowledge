# 控制变量对比实验

## 一句话定义

要判断某个因素是否造成差异，必须让其他条件保持一致，只改变这一个因素，再比较结果。

## 详细说明

视频中的双缸装置是控制变量思路的直观演示：两组缸体结构相同、由同一动力源驱动、运转同样时长，唯一不同的是加入的油品。

如果两组缸体转速不同、时长不同或缸体本身新旧不同，那么即使磨损出现差异，也无法归因到油品上。

控制变量的要点：

1. 明确要检验的因素（这里是油品）。
2. 列出所有可能影响结果的其他因素（动力、时长、缸体状态、温度等）。
3. 让这些因素在两组之间保持一致。
4. 只比较目标因素带来的差异。

这也是判断一则对比实验是否可信的通用方法：先看它有没有把其他变量控住，再看结论是否只落在目标因素上。
