# 石头剪刀布心理战术

## 一句话定义

石头剪刀布不只是策略比拼，还有心态斗争，蒙眼玩、敲山震虎、观察出手前零点零六秒的手势变化都是有效的心理战术。

## 详细说明

在石头剪刀布全球锦标赛上，常有奇装异服的选手，目的就是打心理战。

几种可操作的心理战术：

- 蒙眼玩：无视这场决斗，不被对方节奏和心态左右，给对方造成极大心理压迫——对方输一局会觉得你乱出都能赢，侮辱性极强。
- 敲山震虎法：出拳瞬间喊一个手势，喊的气势强，对手被震慑后反而会出你喊的那个。
- 观察出手前的手势：研究表明人在出手前的 0.06 秒内手势已经变化，出拳的五指会紧紧相拥，剪刀的两指会提前放松，出布的手掌会完全放空，全都会提前暴露行踪。在汉诺威工业博览会上，有机器人利用摄像头捕捉人出拳前的手势，百战百胜。
