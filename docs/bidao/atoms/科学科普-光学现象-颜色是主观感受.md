# 颜色是主观感受

## 一句话定义

颜色归根到底是一种主观感受，每个人看到的同一种颜色并不完全相同，你眼中的黄色是什么样只有你自己知道。

## 详细说明

即使两个人看同一束光，由于视锥细胞的敏感度差异，大脑得到的信号也可能不同。视频中举的例子是：同一个颜色，有人觉得偏绿，有人觉得偏蓝，取决于各自的绿色视锥细胞是否更敏感。

这带来一个根本限制：皮皮虾眼中的世界再绚丽，它也没法告诉你它看到了什么。颜色无法像长度、质量那样被直接传递，只能通过语言和坐标间接描述。

正因为颜色是主观的，学术界才需要一套统一而量化的标准来描述它，这就是 CIE 色度坐标出现的动机。
