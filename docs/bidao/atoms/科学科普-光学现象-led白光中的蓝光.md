# LED白光中的蓝光

## 一句话定义

常见 LED 白光由蓝光 LED 先发出蓝光，再照到黄色荧光粉上激发出黄光，蓝光与黄光混合成白光，所以 LED 白光里含有很强的蓝光成分。

## 详细说明

生活中的手电筒、照明灯多为 LED 白光。它们的内部结构是蓝光 LED 先发出蓝光，再照到黄色荧光粉上激发出黄光，蓝光加黄光凑成白光。因此 LED 白光本身含有很强的蓝光成分，这正是青红酒光照变绿的关键。

验证方法：用白炽灯照青红酒，由于白炽灯光里蓝光成分非常少，酒看着仍偏红；换成有蓝光的 LED 灯照，酒就变绿。用红、黄、绿、蓝光手电筒分别照射：青红酒对红光毫不理会，黄光下只有淡淡点缀，绿光中颜色暧昧，而蓝光下酒绿得鲜明纯粹，红色几乎不可见，眼前几乎是它发出的纯净绿色荧光。由此可知，没有蓝光照它就不会变绿。
