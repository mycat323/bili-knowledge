# 机翼升力

## 一句话定义

飞机升力来自前进时气流掠过机翼、使机翼上下表面产生压强差，因此机身必须相对地面获得前进速度才可能起飞。

## 详细说明

飞机要起飞，得在跑道上快速向前冲，气流掠过机翼，机翼上下表面产生压差，才能获得升力。

这意味着：如果机身停留在原地，发动机喷得再猛也没有升力，因为升力并不来自喷气本身。能原地起飞的东西叫直升机，不是固定翼飞机。

所以「飞机能不能在这台跑步机上起飞」这个问题，本质上是在问「飞机能不能在跑步机上相对地面往前进」；只要能相对地面前进，就认为它能起飞。把起飞问题转化为前进问题，是后面所有分析的前提。
