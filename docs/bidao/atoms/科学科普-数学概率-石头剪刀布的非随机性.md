# 石头剪刀布的非随机性

## 一句话定义

人在石头剪刀布中自以为随机的出手其实带有可统计的偏好，因为人的一切想法源自主观思考，只能随心而无法真正随机。

## 详细说明

理论上只要有一方绝对随机出手，胜率就是五五开。但人不是机器，人的行为会无意间暴露内心的潜在偏好，而偏好就成为博弈中的弱点。

一个直观演示：让人从 0 到 10 中随机选一个数，理论上各数应差不多多，但弹幕里出现最多的往往是 7。这说明人自以为随机的选择其实有规律。

2014 年浙江大学、浙江工商大学、中科院物理所发表论文，招募 360 名浙大学生分成 60 组，每组连玩约两小时石头剪刀布循环赛，按胜率发奖金，平均每人 50 元。结果表明玩家出石头、剪刀、布的概率分别约为 36%、32%、33%——石头最多，剪刀最少，出手并不平均。

因此石头剪刀布不是纯运气游戏，而是可以研究和利用的智力游戏。
