# 眼见为实原则的局限

## 一句话定义

眼睛看到的颜色会随观察条件改变，同一桶香油在桶里和碗里颜色不同，说明眼见不一定为实。

## 详细说明

火锅店的香油桶看起来是黑色的，接到碗里却是浅黄色；可乐在瓶里是黑色，倒进培养皿是淡棕色；一杯水无色，一缸水浅蓝。这些例子都指向同一件事：眼睛看到的颜色并不是物体的固定属性，而是光经过一段介质后进入眼睛的结果。

当介质厚度改变，被吸收的光量改变，看到的颜色就跟着变。所以「眼见为实」在颜色判断上会失效——不是眼睛坏了，而是它忠实地反映了当时的观察条件。

要判断一种液体「真正的颜色」，需要控制厚度等条件，或者用分光光度计测吸收光谱，而不是凭一次肉眼观察下结论。
