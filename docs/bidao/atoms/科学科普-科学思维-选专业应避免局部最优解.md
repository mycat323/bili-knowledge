# 选专业应避免局部最优解

## 一句话定义

在视野狭窄时过早按「哪个专业赚钱多」做选择，容易收敛到局部最优解，而它未必是匹配个人本质的全局最优解。

## 详细说明

毕导针对环化材生劝退与选专业问题给出的核心判断是：人应该在年轻时多发现自我，逐渐收敛到一个能匹配自我本质的工作，而不是看哪个专业钱多就选哪个。

他承认科研人普遍焦虑，但认为主要焦虑并非毕不了业——只要肯吃苦，导师通常会按时放人——而是担心科研积累的技能对未来没用。因为多数人读研不是为了一辈子做科研，而是想用学历找好工作，而环化材生对应的产业岗位相对不够丰富。

他给出的判断标准是：一件有价值、大部分人做起来觉得辛苦、而你做起来乐在其中的事情，就是匹配你的。寻找方式是「多试」，找到时心里会有感觉。他强调自己学化工学得很快乐，甚至能用这套体系做视频。
