# 大学学习是局部最优解

## 一句话定义

大学里迷茫是常态，对未来焦虑通常在大三达到顶峰，实在不知道干什么时先好好学习，因为学习至少是人生的局部最优解。

## 详细说明

毕导结合自己当清华辅导员的经验指出，迷茫是大学的常态，对未来的焦虑通常在大三达到顶峰。当一个人不知道方向时，最稳妥的选择不是空想，而是先把学习做好。

原因在于：评奖学金、读研究生、申请出国、找工作，主流的评价标准都是成绩，学习好能保留更多选择权。所以学习是「局部最优解」——它未必通向最终答案，但在信息不足时不会让你变差。

需要注意两点：

- 学习是最重要的事，但不是唯一重要的事。大学是极其丰富多彩的世界，要多尝试、多感受，找到自己的兴趣所在。
- 迷茫时不要用「先玩一玩」来逃避，因为试错成本虽低，时间成本仍在。

这个思路可以迁移到任何信息不足的决策场景：先做保底收益为正的事，再探索方向。
