# 音乐驱蚊

## 一句话定义

大声外放 Skrillex 的电子音乐能显著降低蚊子的进食与交配频率，研究者推测原因是这首歌过于闹腾，干扰了蚊子的正常行为。

## 详细说明

2019 年一项研究把一大群伊蚊分成两组，分别关入一只仓鼠：一组处于安静环境，另一组用音响大声外放 Skrillex 的格莱美获奖作品《可怕的怪物和漂亮的精灵》。

结果：安静组的蚊子平均每 30 秒就会落到仓鼠身上；听歌组的蚊子进食次数降低 40%，交配频率降低 80%。作者认为这可能是因为这首歌太闹腾，直接让蚊子失去了世俗欲望。论文发表在《热带学报》上。

需要注意，这是特定音乐、特定音量下的实验结果，不能直接推广成「放歌就能驱蚊」的通用方法。它更像一个用严谨方法回答古怪问题的案例。
