# 液体颜色随厚度变化

## 一句话定义

同一种液体在不同厚度下呈现不同颜色，厚度越大颜色越深，黑色香油、可乐、咖啡、水都遵循这一规律。

## 详细说明

在火锅店接香油时，桶里看起来乌漆嘛黑，接到碗里却变成正常的浅黄色。把香油倒进杯子，越倒颜色越深；从侧面看是清澈的橙黄色，转到下面看却变成深深的红褐色。

可乐也是同样的道理：倒进培养皿只有浅浅一层时是淡淡的棕色，倒进容量瓶后，细脖子处厚度小、颜色很淡，胖肚子处厚度大、颜色很黑。咖啡也不是纯黑色，而是咖啡色。

水同样如此：一杯水看起来无色，放满一浴缸后却呈现浅蓝色，从缸里舀出一杯又变回无色。这说明水本身就带一点点蓝色，只是一杯水太少看不出来，水越多越蓝，大海更蓝，深海甚至蓝得发黑。

所以「液体是什么颜色」这个问题本身不完整，必须连同厚度一起说。眼睛看到的颜色是光穿过液体一段距离后的结果，而不是液体本身的固有标签。
