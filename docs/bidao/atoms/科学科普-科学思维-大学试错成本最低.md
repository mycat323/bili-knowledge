# 大学试错成本最低

## 一句话定义

大学是人生试错成本最低的阶段，这四年想做什么就大胆去做，在不断的尝试中认清自己是谁、喜欢什么。

## 详细说明

毕导在建议的结尾强调：听过了许多大道理，却依然过不好这一生，有时候只有栽了跟头才会记住。好在大学是人生试错成本最低的阶段。

「试错成本低」体现在几个方面：

- 学生证半价，旅游、看展、参加活动的经济门槛低，这种福利一旦毕业就没有了。
- 换方向、换社团、换室友、换专业的代价远小于工作后跳槽或转行。
- 失败不会直接威胁生存，挂科、社团退出、恋爱分手都还有补救空间。

因此他呼吁：这四年想做什么就大胆去做，在不断的尝试中认清我是谁、我喜欢什么。这听着简单，却是他认为最最重要的事。

与之相对的是「为了合群而合群」——不喜欢的社团勉强参加、不合适的圈子强加融入，那样在群里也不会开心，等于白白浪费了低成本试错的机会。
