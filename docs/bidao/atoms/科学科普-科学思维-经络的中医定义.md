# 经络的中医定义

## 一句话定义

经络是中医概念，被视为人体运行气血、联络脏腑、沟通内外、贯穿上下的通路，任督二脉属于这一体系。

## 详细说明

论文标题声称茶激发的红外图像表明经络存在，因此需要先明确经络是什么。按论文与中医语境，经络是运行气血、联络脏腑、沟通内外、贯穿上下的通路，武侠小说中的任督二脉也属于这个体系。

论文的论证逻辑是：招募四十二名志愿者（十五男二十七女），半裸上身喝十二种不同的茶，喝完后两分钟内用红外成像仪拍照，发现不同部位温度迅速上升，且上升部位恰好对应十二条经络，一种茶对应一条经络，例如龙井对应足太阳膀胱经。

需要注意，经络是中医理论中的功能性概念，其解剖学实体并未被现代科学确认；论文用体表温度变化来论证经络存在，属于把功能概念与可测量物理量直接挂钩，这一步推理本身需要额外证据支撑。
