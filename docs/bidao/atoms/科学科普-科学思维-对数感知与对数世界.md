# 对数感知与对数世界

## 一句话定义

物理世界的数值以对数形式跨越数量级，大脑又用对数运算把它们压缩回可感知范围，两者相遇才让人能同时欣赏极弱与极强的刺激。

## 详细说明

视频把韦伯-费希纳定律和本福特定律放在一起，指出一个巧合：物理世界的数值以对数形式跨越着数量级，而大脑又用对数运算把它们压缩回可感知的空间中。本福特和韦伯费希纳相遇，在世界的结构和人类的感知之间跳起了和谐的舞蹈。

正因为如此，人既能聆听耳畔的私语，也能听到雷电的喧响；既能凝望星河的微光，也能迎接灼目的骄阳；既能感到羽毛的触摸，也能感到人体的力量。这些刺激的强度可能相差一万、一亿倍以上，但人都能欣赏。

如果人是线性感知的生物，就只能二选一：能听到润物细无声的静谧，就会觉得飞流直下三千尺吵得神经衰弱；能在白天看到白日依山尽的美景，在床前明月光的环境里就会变成瞎子。视频引用津巴多《普通心理学》的话：知觉赋予感觉以意义，因此知觉产生的是对世界的解释，而不是对世界的完美表征。
