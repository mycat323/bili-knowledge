# 搬家打包的取舍检验

## 一句话定义

跨省搬家时被迫对每件物品做「丢弃还是带走」的二元判断，这种极端约束会暴露出一个人真正需要的东西其实极少。

## 详细说明

毕导这次跨省搬家的第一件事，是给屋里每一件东西打标签，决定丢弃还是带去杭州。

过程中翻出大量「在公司待了很久但几乎没什么用」的物品：唱 rap 的墨镜、做紫菜蛋花汤的桶、反射的衣架、公众号里的老员工健美男，还有七年前刚办公司时印的一批名片——一张都没发出去。

当他抱着「只带随身必须的东西」的心态打包时，结论是：没有什么是必须带的，只有电脑、衣服和几根笛子。

这说明搬家是一种强制的取舍检验：日常环境里物品会自然堆积，只有被迫二选一时，才会发现真正不可替代的东西少得惊人。这一方法也可以迁移到清理数字文件、订阅和待办事项上。
