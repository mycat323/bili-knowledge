# 深水狼策略被压制

## 一句话定义

深水狼指夜间杀人、白天装好人的狼人打法，2016 年东京大学论文证明好人存在策略可以压制这种怂狼玩法。

## 详细说明

深水狼是狼人杀里最常见的狼人打法：晚上正常杀人，白天完全伪装成好人，不悍跳、不冲锋，混在好人堆里。

2016 年东京大学的一篇论文专门讨论了如何应对深水狼。论文用十页复杂计算，结合 Epsilon Nash 均衡理论，得出的结论是：深水狼策略并不好（strategy is not very good），好人存在策略可以压制怂狼。

这条结论对小白的意义在于：如果你想从新手成长为高玩，悍跳是必须掌握的技能。观察高玩局会发现，场上几乎人人都在跳预言家，而不是安静地当深水狼。

视频里也提到，大部分人玩狼人时用的就是深水狼打法，所以学会主动悍跳、主动制造信息，才是脱离小白状态的关键一步。
