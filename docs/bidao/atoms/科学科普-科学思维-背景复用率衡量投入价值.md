# 背景复用率衡量投入价值

## 一句话定义

判断一笔固定投入是否值得，可以看它被重复使用的次数与总产出时长，复用率越高，单次成本越低，投入越划算。

## 详细说明

毕导为工作室的拍摄背景算了一笔账：这个背景一共拍了十二期长视频、二十四期短视频，总产出时长三小时四十六分钟十二秒。

有人调侃「装修的 up 主都搬家了，他又白装了」，但按复用率计算，这笔装修投入被摊薄到三十六期内容上，并不算浪费。

这是一个通用的成本核算思路：固定成本除以使用次数，才是单次真实成本。一次性布景、设备、软件订阅、甚至学习一项技能，都可以用同样的方式评估。

反过来，如果一件东西只被用一次，即使单价不高，单次成本也可能很高。判断「白装没白装」，关键不在搬家时它还在不在，而在它已经被用了多少次。
