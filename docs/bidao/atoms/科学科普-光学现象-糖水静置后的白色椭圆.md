# 糖水静置后的白色椭圆

## 一句话定义

糖水在厚缸中静置数小时后，白糖变少、液面下降，在蓝白两层之间出现一个白色椭圆形，上下移动机位时它还会忽大忽小。

## 详细说明

这是视频结尾留下的未解现象，作者称之为厚缸里的又一个未解之谜，并明确表示不知道为什么。

观察到的变化过程是：糖水在缸中放置几个小时以后，白糖变少了，液面下降了，而在蓝白两层中间出现了一个神秘的白色椭圆形，形状像一个飞艇；上下移动机位去拍它，它还会忽大忽小。

需要注意，视频只给出了现象描述，没有给出成因解释，所以这张笔记记录的是一个待解释的观察结果，而不是一条已有结论。把它和「糖水浓度梯度形成锥形液柱」放在一起看，可以知道糖水的分层结构会随时间继续演化：先是形成锥形液柱，几小时后又出现新的分层特征。

可复现的实验条件：300毫升水加370克糖，不搅拌，倒入亚克力厚缸，静置数小时后从侧面观察并移动机位拍摄，记录白色椭圆的形状随视角的变化。
