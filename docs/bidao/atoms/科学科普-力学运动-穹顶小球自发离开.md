# 穹顶小球自发离开

## 一句话定义

小球静止放在穹顶顶端，按牛顿力学它可以在某个时刻不借助任何外力自发离开穹顶滑下，这一结果挑战了决定论的确定性。

## 详细说明

设想一个小球静止放在一个穹顶的顶点上。按照直觉和决定论，如果没有任何外力扰动，小球应该永远停在顶端不动。

但视频展示的物理分析给出另一种可能：小球可以在某个时刻自发地离开穹顶、开始下滑，而整个过程不需要任何外力干扰。也就是说，在完全相同的初始条件下，牛顿力学允许两种不同的后续演化——一直静止，或在某个时刻开始运动。

这个现象的意义在于，它说明牛顿力学本身并不总是给出唯一的未来。初始条件确定，未来仍可能不唯一，决定论的「未来已被完全拿捏」因此受到挑战。视频把它称为决定论的终结。
