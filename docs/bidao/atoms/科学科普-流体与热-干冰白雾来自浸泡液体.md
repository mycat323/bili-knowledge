# 白雾来自泡干冰的液体

## 一句话定义

干冰产生的浓密白雾来自它所浸泡的液体，而非空气中的水蒸气；用长试管观察可见上升的气泡内部已充满白雾，到水面才释放出来。

## 详细说明

判断白雾来源可以用一个简单实验：把干冰放进长试管的水中。如果白雾来自空气中的水蒸气冷凝，应该看到无色透明的二氧化碳气泡升到水面，再在水面上方形成白雾；如果白雾来自杯中液体，气泡内部就应该已经充满白雾。

实际观察结果是后者：泡泡里明显已经充满白雾，在管中上升，到水面破裂后向空气喷射出白雾。往水里加洗衣液让泡泡维持更久，可以看到白雾全都在泡泡里，水面上方并没有出现空气水蒸气冷凝的雾。

换液体也能验证：干冰放进白酒产生的是带酒香的白雾，放在酒精测试仪旁会让仪器报警；放进冰醋酸产生的白雾能让湿润的 pH 试纸变红。说明白雾的成分随浸泡液体而变，是酒雾、醋雾，而不是空气中的水雾。
