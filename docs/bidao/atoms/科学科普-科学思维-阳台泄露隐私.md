# 阳台泄露隐私

## 一句话定义

阳台晾晒的衣物会暴露职业、作息、感情状况等信息，是手机和银行卡之外容易被忽视的隐私泄露渠道。

## 详细说明

人们通常只关注手机隐私和银行卡隐私，却没想到阳台也能暴露大量信息。视频举了几个例子：挂在阳台的衣服上全是黄色，说明实验失败，因为实验成功时应该是无色的，博士生的难言之隐就这样被阳台出卖。

再比如一个阳台，衣服尺码都差不多、以职业装为主，可以推测主人是职场独居女性；上次晾的衣服还没收，只好推到一边晾新的，说明工作很忙、经常加班。如果结合更多细节，甚至能推理出年龄、工作、生活作息、感情状况。这些信息被坏人利用会很可怕。

解决办法很简单：没法给衣服加密，但可以选择不晾，或者拉上窗帘。
