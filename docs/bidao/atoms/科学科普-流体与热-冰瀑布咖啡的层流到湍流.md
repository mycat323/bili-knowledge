# 冰瀑布咖啡的层流到湍流

## 一句话定义

自制冰瀑布咖啡倾倒时，液体刚流出的一段特别直，属于层流；越往下流动发展越充分，逐渐出现扰动，转变为湍流。

## 详细说明

网上流行的自制冰瀑布咖啡经常翻车，但成功时能看到明显的瀑布感。

观察到的关键现象是：液体刚留下来的时候特别直，这一段是层流；随着它越往下，流动发展得越充分，就会变成带扰动的湍流。

也就是说，同一股液流在自上而下的过程中完成了从层流到湍流的转变，流态并不是全程固定的。

这类现象属于日常中常见却很少被注意的细节，常被用作科普视频的切入点：从一个接地气的事情出发，再讲中间的科学原理，最后延伸到原理在生活中的其他应用。
