# 大学尊重差异与包容

## 一句话定义

大学里会遇到很多来自不同省份、城市的人，成长环境和教育有差异，不要拿这些事取笑他人，要试着理解每一个人。

## 详细说明

毕导在心态篇的最后一条提出：尊重差异，学会包容。

具体场景是：你会遇到很多来自不同省份、不同城市的人，大家成长环境不同，接受的教育有差异，每个人拥有的机会条件不同。不要拿这些事来取笑他人，学习上、生活上都是如此，试着理解每一个人。

这条建议与「大学是慢慢发现自我的过程」互为补充：发现自我不等于只关注自我，理解他人也是认识世界的一部分。

与之相关的还有几条生活层面的建议：

- 室友是接下来四年相处最密切的人，保持礼貌和尊重；但原则问题上该撕还得撕。
- 女生在宿舍洗完澡后自觉清理干净头发。
- 闹钟闹不醒自己就不要定闹钟，只闹醒室友的闹钟等于生化武器。

这些细节都指向同一个判断：公共空间里的行为边界，本质上是对他人处境的承认。
