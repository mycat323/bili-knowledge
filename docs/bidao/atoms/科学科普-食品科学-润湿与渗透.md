# 润湿与渗透

## 一句话定义

润湿是液体在固体表面的倾覆和铺展，渗透是水进入粉末颗粒之间的空隙，二者是冲开奶粉最关键的两步。

## 详细说明

润湿和渗透是奶粉冲泡四阶段中最关键的前两步。

**润湿**是液体在固体表面的倾覆和铺展。把水滴在玻璃上，它会铺展成一层液膜，说明玻璃喜欢跟水在一起，水能润湿玻璃，玻璃具有亲水性。把水滴在疏水表面，它不会铺展，只能形成一个个水滴，这就叫疏水。材料表面的水滴越圆，说明材料越疏水。

**渗透**是水向奶粉之间的空隙内推进。奶粉颗粒之间夹带着空气，水要进入内部，必须排开空气。由于奶粉疏水，水不会自发地快速渗入，于是外层被水包住、内部仍是干粉，就形成了奶豆豆。

润湿和渗透做不好，后续的溶解固体桥和小颗粒溶解就无从谈起。因此冲奶的核心，是帮助水完成对疏水奶粉的润湿与渗透。
