# 喝茶实验的严谨设计

## 一句话定义

李辉团队的喝茶实验在志愿者筛选、饮食控制、预实验和泡茶规范上都做了严格设计，实验流程本身完整可查。

## 详细说明

志愿者筛选：四十二名志愿者（十五男二十七女）必须身体健康、器官健全且不能胖，男性平均 BMI 二十二，女性二十二点九，BMI 大于二十六直接淘汰，因为脂肪会掩盖体内热量，红外只能拍到一身热乎乎的肉。

实验地点：二零一八年七月在福建福鼎太姥山的一个茶叶庄园进行，该庄园本身是度假景点。

饮食控制：实验期间志愿者不能摄入任何盐和调料，只能吃蔬菜、水果、清水煮肉。

预实验：代号 M0 的特殊实验员早在二零一七年就开始预实验，先绝食三天，再独自喝五百一十二种茶，优选出最适合本次实验的十三种茶。

泡茶规范：论文有一节 Tea Making，详细记录每种茶的产地、风味和最佳泡法。

这些细节说明实验是精心设计的，成果也有原始数据，作为学术研究是完整的。
