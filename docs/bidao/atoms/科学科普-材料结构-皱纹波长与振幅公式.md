# 皱纹波长与振幅公式

## 一句话定义

奶皮皱纹的波长正比于弯曲刚度除以刚度的四分之一次方，振幅正比于压缩应力的二分之一次方乘以波长，遵循 Föppl-von Kármán 方程。

## 详细说明

2002 年起 Cerda 和马哈德文对膜进行拉伸、在膜上滴水产生皱纹并计算规律，成果发表在 Science、Nature 和 PRL。他们发现膜上的皱纹遵循 Föppl-von Kármán 方程。

由此可以给出皱纹的定量描述：

| 量 | 关系 |
| --- | --- |
| 波长 | 正比于（弯曲刚度 / 刚度）的四分之一次方 |
| 弯曲刚度 | 等于杨氏模量 × 厚度的三次方 ÷ [12 × (1 − 泊松比的平方)] |
| 振幅 | 正比于压缩应力的二分之一次方 × 波长 |

Föppl 是钱学森的导师冯·卡门的导师，也是普朗特的老师。二十世纪初起，张力场理论等理论被提出，用来定量描述皱纹的发生条件和图案规律，皱纹从此有了方程。科学家据此解释了蒙娜丽莎袖子上规则皱纹图案：1951 年吉村（Yoshimaru Yoshimura）解释了薄壁圆柱体轴向压缩时出现的三角形网格屈曲图案。
