# 向量叉乘

## 一句话定义

两个向量相乘得到一个新向量的运算，新向量方向同时垂直于原来两个向量，方向由右手定则确定，只在三维和七维空间可以定义。

## 详细说明

标量只有大小，向量既有大小又有方向。向量乘法有两种：点乘（内积）结果是一个数，例如计算功 W = F·D；叉乘（外积）结果仍是一个向量，方向垂直于参与运算的两个向量。

叉乘由十九世纪的数学家定义，方向规则用右手描述：伸出右手三根手指，食指指向 A 向量，中指指向 B 向量，大拇指指向 A×B 的方向。

叉乘的特殊之处在于它对空间维度极其挑剔。二维世界只有两个垂直方向，叉不出第三个方向；四维空间里两个向量叉乘得不到唯一的第三个方向；五维六维同样不行。赫维茨定理指出，在所有维度中只有三维和七维能定义叉乘，而七维叉乘性质不好、规则丑陋，无法用来构建物理世界。因此叉乘几乎只在三维空间才有实用价值。
