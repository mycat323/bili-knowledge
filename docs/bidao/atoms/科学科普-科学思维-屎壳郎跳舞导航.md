# 屎壳郎跳舞导航

## 一句话定义

屎壳郎推粪球时会站上球顶转圈，尤其在遇到障碍物或球滚出去之后必定触发，研究者推测这是它在重新定位方向。

## 详细说明

屎壳郎在推球过程中经常站上球顶转圈圈，像一种神秘的舞蹈。这个动作不是随机出现的：遇到障碍物，或者球不小心滚出去之后，一定会触发。研究人员推测，这是屎壳郎在重新定位，就像打开导航会先跟着光标转上几圈再出发。

于是屎壳郎的旅途可以概括为一个循环：推屎、跳舞、导航，推屎、跳舞、导航。这个动作细节也被游戏开发组还原，做出了屎壳郎跳舞导航的场面。

需要区分的是，跳舞导航解决的是「当前朝向偏了、需要重新对准天体线索」的问题，而它依赖的天体线索本身（太阳、偏振光、星空）是另一套机制。
