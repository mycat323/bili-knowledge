# 黑色香油接出变黄

## 一句话定义

桶里看似黑色的香油接到碗里立刻变成浅黄色，原因是桶中油层厚、碗中油层薄，与灯光和容器材质无关。

## 详细说明

在重庆火锅店的小料台上，一整桶香油从顶上看和侧面看都乌漆嘛黑，但接到碗里就变成正常的浅黄色，看起来像变魔术。

第一个猜想是店家打了绿光灯，黄色香油在绿光下看着发黑。但把一碗香油怼到绿光灯边，它并没有变黑，这个猜想不成立。

真正的原因与光路厚度有关：桶里的油层很厚，光穿过时被吸收得多，透出来的光很弱，看起来就接近黑色；接到碗里后油层很薄，吸收少，透出的光多，就显出香油本来的浅黄色。

所以这不是科技狠活，桶也不是特制的，只是同一桶油在不同厚度下的两种观感。
