# 大学是发现自我的过程

## 一句话定义

大学是一个慢慢发现自我的过程，从大一开始的所学所获、所作所为、所思所想都会塑造人格，要尽早回答自己想成为什么样的人。

## 详细说明

毕导把大学定位为一个自我发现的过程：你从大一开始的所学所获、所作所为、所思所想，都会塑造你的人格。

由此他提出一个需要尽早回答的问题：我究竟想成为一个什么样的人？并且尽早朝着这个答案前进。如果暂时想不清楚，就参考学习篇的做法——先好好学习，因为学习至少是人生的局部最优解。

这个观点与「本科学习是为了培养认识世界的方式」相呼应：很多人考一门忘一门，所有努力都是为了刷 GPA，但本科学习真正的价值是获得真才实学，而不是高 GPA 加一知半解。

配套的心态建议是：去了好大学，学着接受自己的平凡；去了差大学，也学着接受自己的牛逼。这两种调整都是为了让自我认知不被学校标签绑架。
