# 热力学第二定律

## 一句话定义

热量不能自发从低温物体传向高温物体，孤立系统中的自然过程总是沿着熵增方向进行，直到达到平衡时熵最大。

## 详细说明

热力学第二定律有无数种等价表述，最简单的克劳修斯表述是：热量不能自发从低温物体传向高温物体。两个温度不同的物体放在一起，热量会自发从高温物体流向低温物体，直到温度相同达到平衡。

从微观上看，热二的本质是一切自然过程总是沿着让分子热运动更混乱的方向进行。系统会自发熵增变得更加混乱。热力学第二定律也可以表述为：孤立系统中的自然过程总是沿着熵增的方向进行，直到达到平衡时熵最大。

自然界的一切宏观过程都有自己的方向，反过来就不会发生：破镜难以重圆，青春不会永驻，钱一旦花掉就再也回不来。固体入水溅起水花是正常的，反过来就令人意外。想要逆转这些过程就得额外消耗能量。

热二是一条统计规律，几个分子的时候会有例外，大量分子是不可能观察到违背热二的情况的。
