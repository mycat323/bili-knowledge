# 衣架反射

## 一句话定义

把衣架不对称地套在头上，头皮受到一侧的轻微绷紧力，脖子在放松状态下会不由自主地向一侧转动，这一现象称为衣架反射（hanger reflex）。

## 详细说明

衣架反射的关键在于衣架本身不对称，套在头上时会把头皮往某一侧绷紧。这个力非常微小，但脖子此时处于放松状态，于是这点微小的力就足以让头不由自主地转过去。

实验要诀：把衣架的某个边对准左前额或右前额，位置太靠上会失效。

这个实验最大的 bug 是：每次转头之后，旁边的人都会说「你演的吧」。也就是说，它依赖的是人对假想感觉的感知，主观上很难自证。

可以自己动手验证：换一个大小合适的衣架，调整边对准前额的位置，感受那种「不自觉但又能感知到」的转动趋势。
