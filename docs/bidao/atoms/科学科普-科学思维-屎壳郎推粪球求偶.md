# 屎壳郎推粪球求偶

## 一句话定义

粪球对屎壳郎不只是食物，两只屎壳郎一起推球是爱的交流，情到深处还会在粪球里产卵，父母一起把产房加食堂推回家。

## 详细说明

便便对于屎壳郎不光吃着香、滚着棒，还能求偶找对象。两只屎壳郎一起推球，那是它们爱的交流；情到深处，它们还会在粪球里面产卵。屎壳郎父母一起推着这个产房加食堂回家。

这段描述把粪球的功能从单一食物扩展为三重角色：食物储备、求偶媒介、育幼场所。也正因为粪球同时承担这些功能，屎壳郎才必须走直线火速撤离现场——当一坨新鲜便便出现时，现场往往群贤毕至，有同类想零元购，走直线有利于保住自己的劳动成果。
