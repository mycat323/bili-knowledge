# 冰表面预融化水膜

## 一句话定义

冰之所以异常光滑，是因为其表面在低于熔点时就存在一层准液体水膜，冰刀实际是在这层水膜上滑动而非直接接触冰面。

## 详细说明

生活中大部分物质的动摩擦系数都在零点几量级，例如橡胶路面约零点五到零点八，玻璃与玻璃约零点四；而冰的摩擦系数只有零点零二，其他物质在冰面上的摩擦系数也只有零点零几，冰几乎是有史以来最滑的固体。

这种滑是一种反常现象。鱼、香蕉皮、湿瓷砖之所以滑，共性是接触面上有一层液体膜起润滑作用。科学家相信滑冰同理：冰刀与冰面之间存在一层水膜，冬奥选手看上去在滑冰，本质上是在滑水。

关键问题是这层水膜从何而来。转写稿指出，它并非单纯由摩擦生热或压力融化产生，而是冰表面本身在低于熔点时就会形成一层预融化的准液体层。这一性质使冰在冬天表现出反常的润滑性，也解释了为什么地球上最常见的物质之一能带来滑冰滑雪这种独特乐趣。
