# 贴壁放大倍率等于折射率

## 一句话定义

物体完全贴紧圆柱壁时，圆柱壁相当于一次折射的透镜，放大率等于前后折射率之比，即容器材料的折射率。

## 详细说明

根据斯涅尔定律可以算出，圆柱壁透镜只折射一次时的放大率等于前后折射率之比。对空气来说，放大率就等于容器材料的折射率。

实验验证：一根折射率约 1.5 的亚克力管，从侧面看内径明显被放大，用尺子量内径正好是真实值的 1.5 倍。

如果管内装的是液体，放大率恰好等于液体的折射率：水约 1.33，油约 1.47。往管里分别装水和油，水柱会变粗到 1.33 倍，油柱变粗到 1.47 倍，实测油柱确实比水柱粗一圈，两者直径之比几乎等于折射率之比。

当物体与内壁之间隔着一层空气时，两次折射的放大率刚好约掉，等于 1，所以不贴紧就不放大。这也解释了为什么薄壁容器看不出放大效果——不是壁薄，而是物体没有贴紧。
