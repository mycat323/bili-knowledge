# 预期之外的实验结果

## 一句话定义

实验中出现了与预期不符的结果，既可能是失败，也可能是新发现的起点，关键在于判断它是否推翻或修正了原有假设。

## 详细说明

带着「蓝莓的蓝色来自果蜡结构色」这一预期去观察，结果枇杷也出现了精细的纳米结构，而枇杷并不蓝。这个结果直接挑战了原有预期。

面对意外结果，有两种态度：一是当成实验失败，二是当成新线索。视频中的处理方式是承认「有这样的结构也可以不蓝」，并尝试给出解释——枇杷底色是黄色，结构色可能被底色掩盖；蓝莓底色是黑色，蓝色更显。但这个解释被自己评价为「有点立不住脚，有点强行」。

这说明：意外结果出现后，仓促给出的解释未必成立，需要进一步验证。真正有价值的做法是把它当作新问题，而不是硬套一个说法。

科研中，预期之外的实验结果往往比符合预期的结果信息量更大，因为它迫使你重新审视原有假设。
