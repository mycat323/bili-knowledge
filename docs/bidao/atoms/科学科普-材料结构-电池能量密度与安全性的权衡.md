# 电池能量密度与安全性的权衡

## 一句话定义

电池能量密度越高，通常安全性挑战越大，从磷酸铁锂到三元锂的升级就伴随着这种取舍。

## 详细说明

想让电动车续航长，最直接的办法是多装电池，但车会更重、耗能更大，耗能更大又要多装电池，形成恶性循环。打破僵局只能靠能量密度更大的新电池材料。

问题在于，从铅酸电池到锂电池，从磷酸铁锂电池到三元锂电池，能量密度的提升往往伴随着对安全性更大的挑战。锂离子电池本身娇弱敏感，太热太冷都不太想工作。

材料学科的不确定性也加剧了难度：很多时候错了不知道为什么，成功了也不知道为什么，新材料的出现依赖大量试错。因此一辆好的电动车要懂得平衡性能和安全，既保证日常续航，又提供安全舒适的乘车体验。视频以宝马 iX3 为例，说明其采用宁德时代镍钴锰电芯，相比镍钴铝电池稳定性更高，并通过机械顶盖防挤压、防爆阀泄压、铝制外壳抗压等设计保护电芯。
