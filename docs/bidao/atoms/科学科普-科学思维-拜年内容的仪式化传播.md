# 拜年内容的仪式化传播

## 一句话定义

拜年内容以固定格式、固定时机、固定收尾语反复出现，其功能是确认关系而非传递新信息。

## 详细说明

这套广播体操以「哔哩哔哩祝全国人民新春快乐」收尾，并反复出现「恭喜恭喜恭喜你」的合唱段落。这类内容的信息量很低，但重复出现本身就是它的功能。

仪式化传播的特点是：内容可预期、形式固定、参与者共同完成。观众不需要从中获得新知识，只需要通过跟做、跟唱、转发来确认「我在参与这个春节」。这与春联、鞭炮、拜年话的作用类似。

理解这一点有助于区分两类内容：一类以传递新信息为目标，另一类以完成仪式为目标。对后者评价「有没有新东西」是错位的，它的价值在于被重复、被共享、被记住。
