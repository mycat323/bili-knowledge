# 厚缸放大的几何光学推导

## 一句话定义

液体边缘一点发出的光线经内壁、外壁两次折射后进入空气，观察者沿反向延长线看到像，计算后视直径恰好等于真直径乘以液体折射率。

## 详细说明

推导模型：大厚缸内装液体，观察者的眼睛位于右侧远处。液体内部一点发出的光线经历内壁、外壁两次折射进入空气。若某条光线能抵达眼睛，观察者就看见这个点，并认为它的像在光线的反向延长线上，于是液柱看起来被放大了。

关键步骤：设液体中很靠近内壁的一点向外发出 180 度的光线，在内壁折射进入容器壁后变成一个小扇形，其扇角恰好等于全反射临界角的两倍。小扇形在外壁折射后变成一个大扇形。当液体边缘 A 点发出的光线变成小扇形、大扇形，其边界的光恰好水平向右射出时，就能抵达远处观察者的眼睛，此时点 B 就是观察者眼中液柱放大后的外边缘。

一通计算后各项约掉，得到结论：液柱的视直径恰好等于真直径的 n 液倍。固体则相当于浸泡在折射率等于空气的介质中，放大率等于 1。
