# 马兰戈尼效应

## 一句话定义

液体表面层分子受力不平衡、能量高于内部，当低表面能物质落到水面并铺展覆盖时，会挤开原来的水分子，使水向四周退散。

## 详细说明

水最表面的一层水分子受力不平衡，拥有比内部分子更高的能量，这就是表面能。自然界的物体倾向于降低自身能量以变得更稳定。

降低表面能有两种途径：一是减少表面积，比如失重状态下的水会缩成一个球；二是让表面能更低的东西覆盖自己的表面。水的表面能很大，而肥皂、洗洁精等表面活性剂表面能很小，它们落到水上就会占领水面、把水挤开。

日常可见的例子：洗洁精滴在一滩水上，水会迅速退散；肥皂掉在湿地面上，周围地面会迅速变干。这些都是马兰戈尼效应的表现。

辣椒素虽然不是表面活性剂，但它疏水、表面能比水低，同样会铺满水面降低整体表面能，因此也能驱水。
