# 从做科普中反哺科研

## 一句话定义

抱着做科普视频的心态去做科研课题，会顺手很多，心态上也不那么焦虑，说明科研与科普可以相互促进。

## 详细说明

一种可借鉴的经验是：回去做科研课题时，抱着做科普视频的心态，结果顺手了非常多，心态上也不那么焦虑。

这背后的逻辑是，科普要求把问题讲清楚、找到接地气的切入点，这个过程会反过来帮助梳理科研问题本身。

与之配套的心态建议是：不要一开始就追求自己喜欢什么，可以先从不讨厌开始。先做了，做了之后可能会喜欢；能找到一件不讨厌的事情，本身已经蛮难得。

大学阶段的试错成本非常低。当找到一件投入再多精力都兴奋、为它熬夜都觉得是在为自己而活的事情时，内心会清晰地告诉你「我找到了」。
