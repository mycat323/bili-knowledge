# 彩虹下方天空更亮

## 一句话定义

彩虹位置的水滴把光锥边缘送入眼睛形成彩色弧，彩虹下方水滴把光锥中部白光送入眼睛，所以下方天空比上方更亮。

## 详细说明

平行光入射水滴后会变成夹角约八十四度的光锥，光锥边缘是七色的，内部七色光混在一起是白光。

考察彩虹及其上下方的水滴：

| 位置 | 进入眼睛的光 | 视觉效果 |
| --- | --- | --- |
| 彩虹处 | 光锥边缘 | 看到七色彩虹 |
| 彩虹下方 | 光锥中间部位 | 更多白光进入眼睛，更亮 |
| 彩虹上方 | 光锥不经过眼睛 | 光少，看着更暗 |

所以彩虹下面的天空比上面更亮，道理就这么简单：下方水滴贡献的是白光，上方水滴的光压根到不了眼睛。
