# 高维空间球密堆积纠错

## 一句话定义

把包含一百个数据的消息视为一百维空间中的一个球心，误差对应半径，接收方把落在球内的数据纠正回球心，即实现自动纠错。

## 详细说明

用纠错码发送更复杂的消息时，可以应用到高维空间球密堆积理论。

比如要传输包含一百个数据的消息，可以把消息视为一百维空间中的一个球的球心，每个分坐标是一个数据。传输过程中可能出现误差，导致数据偏移到以初始坐标为球心、误差为半径的高维球内。接收方收到消息后，只要判定数据落在球心一定范围内，就把它纠正回球心，从而实现自动纠错。

高维空间密堆积的球占体积比例更小，相当于容错率更高，但同样伴随数据分布太稀疏的问题。可检索维度之咒、汉明码、Delaunay set 等关键词进一步了解。
