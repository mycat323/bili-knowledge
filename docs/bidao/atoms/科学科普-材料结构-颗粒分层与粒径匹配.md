# 颗粒分层与粒径匹配

## 一句话定义

密度相近的两种颗粒若粒径差别大，震动后仍会分层；把粒径改成相近大小，就能混合均匀，这是巴西果效应在生活中的直接应用。

## 详细说明

有人做过实验：把盐和芝麻粒放在一起很难混合均匀。原因是两者的密度差不多，但芝麻的粒径比盐大，于是产生了巴西果效应，芝麻浮到上面。

如果换用粒径和芝麻粒差不多大的盐，两者就能均匀混合。这说明决定分层与否的关键不只是密度，粒径之比同样重要。

由此可以推出一个有趣的推论：想让主食和拌料混合均匀，可以把它们做成相似的形状。比如把臊子面里的丁丁做成条状，或者把螺蛳粉里的粉剪成段段，混合就会更均匀，一口下去超级满足——当然，这样看起来就变成炸酱面和螺疙瘩汤了。

判断依据可以借用霍因廷和汤普森的公式：直径比小于密度比的倒数时大颗粒上浮，反之下沉。
