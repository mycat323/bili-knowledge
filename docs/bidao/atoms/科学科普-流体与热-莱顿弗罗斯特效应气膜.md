# 干冰周围的气膜

## 一句话定义

干冰浸入水中时，极冷的干冰让接触的水迅速气化，形成一层二氧化碳气膜把干冰与水隔开，这与高温铁板上水滴的莱顿弗罗斯特效应机理相同。

## 详细说明

莱顿弗罗斯特效应指水滴落在远高于沸点的铁板上时，底部水快速气化出一层蒸汽，把水滴与铁板隔开，水滴因此悬浮滑动。

干冰浸入水中是同一效应的镜像版本：对零下几十度的干冰而言，常温水就是「滚烫的」，接触干冰的水迅速气化，形成一层二氧化碳气膜包裹住干冰。仔细观察水中的干冰，可以看到一层巨大的气泡膜把它包住。

充满白雾的二氧化碳泡泡正是从这层气膜中不断释放出去的。气膜既隔绝了干冰与水的直接接触，又成为水蒸气进入并冷凝的场所，是白雾形成的关键中间结构。
