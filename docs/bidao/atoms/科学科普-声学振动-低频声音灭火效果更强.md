# 低频声音灭火效果更强

## 一句话定义

在声音灭火实验中，六十赫兹左右的低频声音让火焰摆动达到巅峰，频率越高效果越差，原因是低频时音响振膜运动幅度更大、产生的风更强。

## 详细说明

毕导用能播放不同频率的 app 配合蓝牙音箱，对蜡烛逐一测试：

- 二百赫兹：蜡烛完全没反应
- 一百赫兹：蜡烛不悲不喜
- 八十赫兹：蜡烛仍无动于衷
- 七十赫兹：火苗开始身不由己
- 六十赫兹：火苗魂不附体
- 五十赫兹：火苗摇摆明显

规律是六十赫兹左右的低频声音让火苗摆动达到巅峰。在一千五百帧高速摄影下，火焰像丝绸一样在烛心前后律动；三千帧下能看到火焰仿佛要离开蜡烛奔向远方，最终熄灭化作白烟，连白烟也在六十赫兹下前后摆动。

为什么低频更有效？熊才义的论文解释：音响播放低频声音时振膜运动幅度更大，推动空气形成的风更强。这也解释了生活中的直觉——听高音只是耳朵受不了，低音炮却能震得人神魂颠倒。

一个有趣的巧合：普通人能唱的最低音差不多就是六十赫兹，所以理论上可以用低音哼唱来熄灭生日蜡烛。
