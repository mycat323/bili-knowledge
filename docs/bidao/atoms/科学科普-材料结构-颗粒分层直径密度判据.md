# 颗粒分层的直径密度判据

## 一句话定义

一九零九年霍英廷和 Thompson 给出判断公式：当颗粒直径比小于密度比的倒数时大颗粒往上走，反之则沉下去。

## 详细说明

一九零九年，霍英廷和 Thompson 给出了一套简单的判断公式，用来预测震动后大颗粒是上浮还是下沉：当直径比小于密度比的倒数时，大颗粒会往上去，反之则沉下去。

这一判据也解释了日常混合的难易。有人做过实验：把盐和芝麻粒放在一起很难混合均匀，因为两者密度差不多，但芝麻的粒径比盐大，产生了巴西果效应；如果换用粒径和芝麻粒差不多大的盐，就能均匀混合。

由此可以推想，若把臊子面里的丁丁做成条状、把螺蛳粉里的粉剪成段段，让主食和拌料形状相近，理论上能混合得更均匀。
