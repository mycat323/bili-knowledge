# 三十万公里活塞摩擦量级

## 一句话定义

一辆车行驶三十万公里时，单个活塞累计摩擦约 5.4 亿次，相当于绕地球约七圈或地球到月球的距离。

## 详细说明

三十万公里是一个常被用来衡量车辆耐久性的里程数。

从空间尺度看，三十万公里约等于绕地球七圈，也约等于地球到月球的距离。

从机械动作看，按四冲程发动机、转速 1800 转/分钟、车速 120 公里/小时估算，单个活塞每公里摩擦 1800 次，三十万公里累计约 5.4 亿次。

作为对比，有报告统计中国乘用车的黄金年龄约为六到八年，一般车主在这段时间内的行驶里程大约为十万公里。也就是说，三十万公里相当于普通车主用车周期的三倍左右。

这个量级说明，发动机在长期使用中承受的是持续、高频的往复摩擦，抗磨性能直接关系到引擎能否长期保持状态。
