# 知网涨价幅度

## 一句话定义

知网采购费年年上涨，部分高校三年涨幅超过 20%，北邮涨 23%、中南财经政法大学涨 24%，而复旦同济涨幅始终极低。

## 详细说明

对比同一所高校不同年份的知网采购费，可以看到明显的上涨趋势。

部分高校三年涨幅：

| 学校 | 涨幅 |
| --- | --- |
| 北邮 | 23% |
| 中南财经政法大学 | 24% |
| 中南大学 | 19% |
| 电子科大 | 15% |

北邮从 2019 年的 71 万涨到 2021 年的 87 万。而复旦和同济的涨幅始终维持在极低的 6% 甚至 1%，有力打击了知网的嚣张气焰。

采购意向的变化也能反映需求波动：浙大 2020 年只买 84 万，2021 年狂买 112 万；北航 2020 年 72 万，2021 年直接梭哈 110 万；北体 2019 年 85 万、2020 年 90 万，2021 年变成 50 万。
