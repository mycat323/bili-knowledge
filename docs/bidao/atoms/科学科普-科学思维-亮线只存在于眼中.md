# 亮线只存在于眼中

## 一句话定义

沟槽反射的亮线不是盘面上客观存在的条纹，而是由观察者眼睛位置决定的一条视觉曲线，人一走动，看到的亮线就会换成另一条。

## 详细说明

沟槽反射的亮线是「所有能把光锥送进眼睛的点」的集合，因此它取决于眼睛的位置。换一个视角、走开几步，看到的就是另一条线。

回头看路口的大圆盘：X 反射并不是第三种反射，它从头到尾都是镜面反射；周围的灯光照亮的也并不是直径，只是复杂曲线在盘面上比较直的一段。如果一个观察者那天靠近它一点、姿势怪一点，也许就会发现圆盘上的世界远比直线丰富。

这条亮线最妙的地方在于，它从来就不客观地存在于圆盘之上，只主观地存在于你的眼睛里。想看到反常的形状，就需要你认真去找它。
