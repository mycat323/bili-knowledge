# 辣椒素驱水

## 一句话定义

切开辣椒释放的辣椒素是一种疏水低表面能物质，落到水面后会迅速铺展，把水分子向四周挤开，形成肉眼可见的驱水结界。

## 详细说明

把切段的小米辣放到案板的水上，水会瞬间四散而逃；在水面撒胡椒粉再戳入辣椒，胡椒粉会被推着向四周躲避，形成一圈明显的空白结界。

实验对比发现，驱水能力与辣度正相关：杭椒效果一般，螺丝椒、薄皮椒、青尖椒依次增强，小米辣最强，不辣的甜椒完全没有效果。葱姜蒜也有一定驱水效果，而土豆、蘑菇、秋葵周围的水一动不动。

用纯辣椒素（白色粉末）做实验，胡椒粉当场溃败；在高速相机下可以看到辣椒素挤开胡椒粉，以极快的速度铺满整个水面。这说明驱水的本质原因就是辣椒素本身。

辣椒素不是表面活性剂，但它疏水且表面能比水低，因此能铺满水面降低整体表面能，把水挤开。
