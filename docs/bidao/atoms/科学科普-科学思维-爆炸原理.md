# 爆炸原理

## 一句话定义

爆炸原理指一对矛盾同时成立时，可以推出任何命题为真，即从矛盾出发一切都可以证明、一切也都可以证伪，数学体系因此崩坏。

## 详细说明

爆炸原理的拉丁语原文是 Ex contradictione quodlibet。视频用一个玩笑式证明展示它：

- 已知「毕导爱拖更」为真，则可推出「毕导爱拖更或黎曼猜想成立」为真；
- 又已知「毕导不爱拖更」为真，所以前半句不成立；
- 于是只能是「黎曼猜想成立」为真。

黎曼猜想就这样从「毕导爱不爱拖更」中被证明出来了。这个证明当然是玩笑，但它严格展示了爆炸原理的威力：一对矛盾的存在就可以爆炸性地涌现出一切你想证明的东西。

正因为如此，数学中绝不允许出现罗素悖论这样的矛盾。矛盾模糊了真与假的概念，一切都可以证明，一切也都可以证伪，数学也就崩坏了。这也是希尔伯特纲领要求「一致性」的原因：体系不能从公理出发推出一个命题又推出它的反面。
