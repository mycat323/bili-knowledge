# 追踪轮速

## 一句话定义

把「速度一致」理解为传送带转速实时跟随轮子转速（v带 = v轮），这能把人和汽车定在原地，对飞机却行不通。

## 详细说明

第二种理解是：轮子转得快，传送带就转得快；轮子转得慢，传送带就转得慢，从而保证轮子永远无法前进，机身也被钉在原地。

现实中确实有这种装置。无动力跑步机就是「我跑多快，传送带就同步转多快」，慢跑时慢转、冲刺时加速，人的身体被控在原地无法前进。汽车测噪音的转鼓台同理：车轮在转鼓上转，转鼓与轮子同速反转，哪怕油门焊死，车身也不会前进。代入公式即 v轮 = v车 + v带，限定 v带 = v轮，就解出 v车 = 0。

但飞机和汽车原理不同：汽车靠踩油门让轮子旋转，传送带追踪轮子就能控制车身；飞机靠发动机喷气直接推动机身，传送带追踪轮子管不到发动机怎么喷，影响不到 v机。所以在飞机身上，这种传送带会触发自指悖论。
