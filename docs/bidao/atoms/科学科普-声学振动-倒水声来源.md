# 倒水声来源

## 一句话定义

倒水声是水流冲击容器壁与水面时激发容器和水体振动产生的，其音色取决于水流形态、气泡行为以及容器本身的共振特性。

## 详细说明

倒水时听到的声音并不是水本身在「说话」，而是水流与容器相互作用的结果。

**发声环节**

- 水流从壶口流出，形成水柱或水滴，冲击杯底或已有水面；
- 冲击使杯壁和水体发生振动，振动通过空气传到耳朵；
- 水中卷入的气泡生成、振荡与破裂，也会贡献声音成分。

**为什么同一杯水声音会变**

随着杯中水位升高，水面到杯口的距离改变，水柱落点处的冲击条件随之变化，所以倒水声的音调会一路变化。这也是「响水不开、开水不响」这类经验说法背后的物理基础之一。

**与水温的关系**

水温改变水的粘度、表面张力等性质，进而改变水流形态和气泡行为，因此冷水和热水倒出来声音不同。视频中正是利用这一点，让观众凭听觉判断水温。
