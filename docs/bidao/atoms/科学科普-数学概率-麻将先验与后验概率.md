# 麻将先验与后验概率

## 一句话定义

先验概率是不依赖新信息的初始判断，后验概率是引入新证据修正后的判断，贝叶斯学派认为概率代表你对事件是否发生的信念。

## 详细说明

麻将中判断该打哪张牌，靠的是概率计算，而概率分两层。

**先验概率**：只看当前局面、不引入新信息时算出的概率，符合直观感觉。例如下家没打过筒，你想打四筒或七筒，两张点炮概率差不多，没有信息表明二者有区别。

**后验概率**：引入新信息后修正过的概率。如果桌面上已经打出过三张六筒，原本胡四筒和七筒的分布就变了——对手拿有五六筒、六八筒的概率被这个新条件降低，此时打四筒点炮的概率变成七筒的 1.5 倍。

贝叶斯学派的核心观点是：概率代表你对一件事是否会发生的信念和判断，新增信息会修正你对局面的判断，收集的证据越多，判断越准。

麻将口诀如「幺鸡不能打，一打就是俩」「二五先打八，拆边不拆卡」，都是麻将名家总结的定式，每一条背后都有概率层面的原理。把概率论用在麻将上有两大理念：一是每次出牌算出局部最优解，不断打掉最没用的牌；二是根据别人的出牌反推他的手牌。
