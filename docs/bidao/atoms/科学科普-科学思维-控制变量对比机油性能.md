# 控制变量对比机油性能

## 一句话定义

要比较两种机油的抗磨效果，必须让两组缸体的结构、运动方式和动力输入完全一致，只改变所加的油。

## 详细说明

对比实验的核心是控制变量。在比较两种机油抗磨性能时，如果两组缸体的结构、活塞运动方式、动力输入、运行时间中任何一项不同，观察到的差异就无法确定是油造成的。

视频中的装置正是按这个思路设计的：两组真实引擎缸体，同一套连接轴传送动力，同样的踩踏驱动，唯一区别是一组加美孚速霸、一组加同类别参比油。

这样得到的对比结果才有意义：如果两组活塞运动的顺畅程度或磨损表现出现差异，可以归因到油的抗磨性能上。

常见的误解是只看「哪组更顺」而不追问其他条件是否一致。控制变量不是实验的装饰，而是让结论能够成立的前提。
