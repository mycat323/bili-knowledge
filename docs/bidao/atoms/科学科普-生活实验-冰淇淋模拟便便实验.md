# 冰淇淋模拟便便实验

## 一句话定义

用冰淇淋代替便便做控制变量实验，通过调节下落高度、质地软硬和出口直径，复现螺旋成型并找出最优参数组合。

## 详细说明

打冰淇淋的过程和拉出螺旋便便的过程几乎一模一样，说明它们遵循相似的物理原理：懂了怎么拉冰淇淋，就学会了怎么打螺旋便便。

实验器材是一台非牛顿流体低温挤出机。经过三天的加工实验，制备出与便便性状相似的冰淇淋，随后依次改变三个变量：

| 变量 | 操作 | 现象 |
| --- | --- | --- |
| 下落高度 | 从约二十厘米逐步缩短 | 二十厘米时半空断裂；缩短后开始卷曲；继续缩短卷速放缓、形成螺旋 |
| 质地 | 软翔与冷冻后的硬翔对比 | 软翔塌得快，硬翔成型持久 |
| 直径 | 改变出口大小 | 细翔同高度下断裂，降低高度后绕出完美螺旋 |

实验结论是：下落高度控制在十厘米左右，质地适当硬一点，并根据直径调整高度。这套方法把「如何拉出螺旋便便」变成了可复现的控制变量实验。
