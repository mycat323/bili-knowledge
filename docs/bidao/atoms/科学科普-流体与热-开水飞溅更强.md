# 开水飞溅更强

## 一句话定义

液体温度越高，射流冲入液面时产生的飞溅越强，开水飞溅显著强于冷水。

## 详细说明

视频通过对照实验比较了不同温度液体的飞溅强度。实验用装满约四十度温水的水准瓶模拟膀胱，向铺有硬纸板的烧杯中喷射射流，统计纸板上的水点分布来表征飞溅强度。

冷水条件下，水花四处跃动，纸板渐渐打湿，飞溅大致呈二维正态分布，纸板边缘相对安全。换成持续沸腾的开水后，烧杯里热气升腾，开水的沃辛顿射流强得恐怖，纸板中间都溅湿一片，两张纸板对比触目惊心。

原因在于开水具有更低的粘度和表面张力，更容易分裂成小水滴。二零零三年 Manzano 等人的研究也发现，液体越烫，临界韦伯数越小，飞溅越强力。结论：往开水里尿尿并不推荐，溅起的水花容易烫伤脚部。
