# 气体的折射率不被放大

## 一句话定义

气体的折射率基本都在1.00几，可以近似当成1，因此厚缸里的气体直径不会被放大，看起来完全落在真实直径之内。

## 详细说明

有色气体实验因为材料管制做不了，但可以按厚缸的规律做理论分析：气体的折射率基本是1.00几，可以就当成1。既然厚缸对内部介质的放大倍率等于该介质的折射率，那折射率为1就意味着放大1倍，气柱直径不会被放大。

这个预测有旁证。作者在做厚缸选题的同时还在做干冰白雾的选题，当时往厚缸的水里扔过干冰，可以看到白雾的直径没有被放大，完全在真实直径之内。所以如果真能往缸里加有色气体，看到的现象应该和白雾差不多。

视频里设想过三种自制有色气体的路线：浓硝酸加铜生成红棕色的二氧化氮，浓盐酸加高锰酸钾生成黄绿色的氯气，浓硫酸加碘化钾生成紫色的碘蒸气。它们都因为原料管制而只能停留在设想阶段。

这条笔记的意义在于，它把「厚缸放大」的适用范围从液体推广到了气体，并给出一个用白雾替代有毒有色气体的安全验证方法。
