# 氧化导致吸收光谱红移

## 一句话定义

白色物质被氧化后引入碳碳双键和羰基，形成单双键交替的共轭体系，电子跃迁所需能量降低，吸收光谱向长波方向移动，开始吸收紫光而显黄色。

## 详细说明

白色物质的电子跃迁需要很大能量，只吸收紫外光、不吸收可见光，所以看上去是白色。氧化过程加氧去氢，可能向分子中引入碳碳双键和羰基；当单键与双键交替排布时，就形成共轭体系。

按前线轨道理论，有机物的电子跃迁主要是前线电子从 HOMO 向 LUMO 跃迁。共轭体系越大，π→π* 跃迁所需能量越小。原本只有高能紫外光才能激发电子，氧化后能量更低的可见光也能激发，吸收光谱曲线向长波方向移动，这就是红移。

红移一点点后，物质开始吸收紫光，而紫色的补色是黄色，于是看起来就变黄了。这就是纸张、白墙、空调外壳、塑料抗氧化剂乃至粪胆素、尿胆素变黄的共同化学本质。
