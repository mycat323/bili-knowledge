# 分形

## 一句话定义

分形是在不同尺度上具有自相似结构的图形，无论怎样放大都会暴露出更丰富的曲折，永远不会更接近直线。

## 详细说明

1967 年，数学家贝努瓦·曼德布罗在 Science 发表论文《英国的海岸线有多长》，开启了分形这一概念。

分形的核心特征是自相似：卷心菜的中间还是卷心菜，罗马花椰菜放大后变成无数颗罗马花椰菜；闪电、血管、钱塘江退潮留下的大地之树，都是主干上长出分支，细节中又有着整体。海岸线也是分形，它在每个尺度上都有相似的尖角、折叠和锯齿边缘。

曼德布罗的经典表述是：云不只是球体，山不只是圆锥，海岸线不是圆形，树皮不是那么光滑，闪电传播的路径更不是直线。

分形的意义在于，它让大自然在每一个尺度上都记得自己：一座小山的走向足以让自然回忆出山脉的形状，一根枝条的分叉也能让自然还原出完整的大树。在欧几里得几何中，部分总比整体更小更简单；在分形中，部分既承载着整体的本质。
