# 五节动作的主题映射

## 一句话定义

把抽象愿望映射为具体动作名称，是创意编排常用的手法，让观众在跟做动作时同步接收主题信息。

## 详细说明

这套新春广播体操把五个主题分别装进五节动作：健康运动对应身体状态，上分运动对应游戏与学业，致富运动对应收入与前途，甜蜜运动对应感情与宠物，全家运动对应团圆祝福。

这种映射的逻辑是「动作即隐喻」：前进、上举、左右摆动等动作本身没有语义，但被命名后就成了主题的载体。观众做「前进」动作时，接收到的信息是「前途向前」；做「上分」动作时，接收到的信息是「段位提升」。

从传播角度看，主题映射让一套体操同时承担了健身和拜年两个功能。动作是否标准并不重要，重要的是动作名称能否被记住并复述——这也是它适合在春节期间传播的原因。
