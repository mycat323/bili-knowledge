# 对数均匀分布

## 一句话定义

数据大小跨越多个数量级、取对数后在数轴上分布均匀，这类对数均匀分布的数据集必然符合本福特定律。

## 详细说明

符合本福特定律的数据有一个共同特点：大小跨越好几个数量级，但取对数后分布比较均匀，也就是接近对数均匀分布。

视频用斐波那契数列演示：把前几项画在普通直角坐标系上，数与数的间隔开始很密集、越来越稀疏；但画在对数坐标纸上（从一到十和从十到一百的间隔相等），它竟然变得非常均匀。视频点赞量、世界各国面积、A 股股票价格画在普通数轴上参差不齐，画在对数坐标上就均匀多了。

数学上非常容易证明，对数均匀分布的数据集就是会符合本福特定律。在自然过程中随机演变而来的数据很多都分布平滑，而且跨越多个数量级，就会不由自主地具有对数尺度均匀的特征，所以符合本福特定律。至于为什么自然界的这些数据是对数均匀的，视频坦言目前没有公式能描述人口、河流长度、物理常数，更无法分析其成因。
