# 物质颜色来自吸收光谱

## 一句话定义

物体呈现的颜色并非它反射了对应颜色的光，而是它吸收了某些波长的光后，大脑对剩余混合光的主观感知。

## 详细说明

小学常教「番茄是红色因为它反射红光」，但更准确的描述是：番茄皮中的番茄红素吸收波长约 443、471、502 纳米的蓝绿光，反射其余波长的光，大脑把这种混合光处理为红色。

微观机制是电子跃迁：分子中的电子吸收光子能量后由基态跃迁到激发态，但电子只接受特定大小的能量。光的能量由波长决定，波长又对应颜色，所以特定分子只吸收特定颜色的光。

因此「物质是什么颜色」等价于「它吸收了什么颜色的光」，看到的是被吸收颜色的补色。这也解释了为什么同一种色素在不同厚度、不同背景下观感会变。
