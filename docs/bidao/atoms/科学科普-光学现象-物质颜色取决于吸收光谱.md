# 物质颜色取决于吸收光谱

## 一句话定义

物体呈现的颜色由它吸收哪些波长的可见光决定，未被吸收的剩余光混合后被大脑感知为某种颜色，而非物体只反射单一颜色的光。

## 详细说明

小学常教的「番茄只反射红光」是一种简化说法。实际上番茄皮中的番茄红素会吸收波长约 443、471、502 纳米的蓝绿光，反射其余波长的光，大脑把这种混合光处理为红色。

微观机制是电子跃迁：分子中的电子平时处于基态，吸收光子后跃迁到激发态。电子只接受特定大小的能量，而光的能量由波长决定，波长又对应颜色，因此特定分子只吸收特定颜色的光。

由此可推出一个反直觉结论：物体不是「挑食」地不吃某种颜色，而是主动吃掉某些颜色。理解这一点是理解「万物变黄」的前提——变黄的本质是分子吸收光谱发生了变化。
