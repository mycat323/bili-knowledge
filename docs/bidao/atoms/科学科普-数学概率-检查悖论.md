# 检查悖论

## 一句话定义

你看到什么取决于你在看哪：当抽样单位与观测对象不匹配时，样本会系统性偏向规模更大的群体，使感知偏离真实平均。

## 详细说明

检查悖论是等待时间悖论和友谊悖论的共同本质：你的经验会因为观察世界的方式而变化。

典型例子是调研学校班级平均人数。随机问十个同学「你班有多少人」再取平均，结果一定偏大——因为大班人多，这十个人天然更可能来自大班。注意：如果随机抽样测的是平均身高，就没有这个问题；问题出在「在人数中抽样来调研班级的平均人数」，抽样单位与研究对象不匹配。

生活中检查悖论无处不在：

- 司机觉得走哪条道哪条道堵——堵的道上车多，更多司机正在堵车队伍里抱怨；
- 航空公司统计平均上座率不高，乘客却觉得飞机很挤——更多乘客挤在那些很挤的航班里；
- 你觉得没怎么见过鸡，鸡却觉得世界挤满了鸡——因为鸡都聚在一起。

它提醒我们：自以为随机公平的采样，采样方式本身可能就是偏见的来源。你对世界的接触构成了你对世界的认知，但世界很大，要学会接纳。
