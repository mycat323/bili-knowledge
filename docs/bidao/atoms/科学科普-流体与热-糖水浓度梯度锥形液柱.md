# 糖水浓度梯度形成锥形液柱

## 一句话定义

不搅拌的糖水会因糖溶解不均形成自下而上的浓度梯度，折射率从下往上逐渐变小，在厚缸侧面就能看到粗细连续过渡的锥形液柱。

## 详细说明

实验配方是300毫升水加370克糖，不做搅拌。糖溶解时底部糖多、浓度大，上方糖还没有溶上来、浓度小，中间不是完美线性过渡，但整体是自下而上逐渐变稀的分布。

因为厚缸对液柱的放大倍率等于折射率，浓度分布直接变成了宽度分布：底部是饱和糖水，折射率最高，液柱最粗；顶部糖还没溶上来，液柱就比较细；中间糖水交界之处，液柱粗细优雅过渡。三者拼起来就是一个完美的锥形液柱。

这个结果出乎作者预料——他原本认为糖溶解时中间不会是完美线性过渡，不可能出现锥形，还打赌如果真有锥形液柱就把糖水喝掉。观众的建议最终被实验证实。

可复现的做法：取一个厚壁透明亚克力缸，先倒水再加糖，静置不要搅拌，从侧面观察液柱轮廓随时间的变化。糖溶解越慢、梯度保持得越久，锥形越明显。
