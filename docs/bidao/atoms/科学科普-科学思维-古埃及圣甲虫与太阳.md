# 古埃及圣甲虫与太阳

## 一句话定义

公元五世纪埃及学者霍拉波罗描述屎壳郎一边向东看一边把粪球从东向西滚，古埃及人由此认为太阳在天空中的运动由屎壳郎决定。

## 详细说明

早在公元五世纪，埃及学者霍拉波罗就描述过屎壳郎的运动：一边向东看，一边将粪球从东向西滚动。古埃及木乃伊的裹尸布里会有一个雕刻着屎壳郎（圣甲虫）图案的护身符。

古埃及人觉得太阳在天空中的运动是由屎壳郎决定的：太阳像粪球一样被屎壳郎埋葬在西边，在黎明时分又从东边重生。

几千年后，科学家发现了事情的真相：不是屎壳郎决定着太阳的运动，而是太阳决定着屎壳郎的运动。2003 年昆虫学家马库斯·伯恩等人捕捉五种屎壳郎，放置在实验场地中，发现它们都会朝着太阳的方向滚粪球。这段历史因此成为「观察正确、解释颠倒」的典型案例。
