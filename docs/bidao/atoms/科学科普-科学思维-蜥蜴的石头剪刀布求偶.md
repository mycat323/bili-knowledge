# 蜥蜴的石头剪刀布求偶

## 一句话定义

加州侧斑蜥蜴的三种喉色雄性形成类似石头剪刀布的循环相克求偶策略，这一策略已持续约一点七五亿年。

## 详细说明

加州侧斑蜥蜴在求偶中存在一种奇妙现象：雄性蜥蜴的喉咙有橘、黄、蓝三种颜色，雌性只有黄色。

三种雄性的策略构成循环相克：

| 颜色 | 角色 | 行为 |
| --- | --- | --- |
| 橘 | 进攻者 | 很强，会打败蓝蜥蜴和雌蜥蜴 |
| 黄 | 伪装者 | 很弱，但会伪装成雌性，潜入橘蜥的后宫 |
| 蓝 | 守护者 | 战斗力不强，但会守着老婆，让黄蜥没有下手机会 |

结果是：橘蜥打败蓝蜥蜴，黄蜥骗过橘蜥，蓝蜥赶走黄蜥蜴，三者像石头剪刀布一样形成美妙的循环相克。

这种古老的求偶策略已经持续了约 1.75 亿年，主导丛林的蜥蜴颜色在橘黄蓝之间循环往复，从恐龙时代至今生生不息。人类用石头剪刀布决策可有可无的事情，蜥蜴却用它讨老婆。
