# 牛顿力学决定论

## 一句话定义

牛顿定律、麦克斯韦方程组、薛定谔方程和相对论都是时间对称的，由底层物理定律直接支配的过程不包含过去与未来的区别。

## 详细说明

如果你把一个遵循牛顿定律的过程倒放，它也是可以发生的。倒放一个自由落体，它就是一个正常的竖直起跳；两个球的碰撞，正放倒放你都觉得它是真的、可以发生的。所以我们说牛顿定律是时间对称的。同样的，麦克斯韦方程组、薛定谔方程、相对论都是时间对称的。

所以由底层物理定律所直接支配的过程不包含过去与未来的区别。我们宇宙的第一级规律没有时间之始的概念，因此爱因斯坦坚定地说时间是一种错觉。

但实际上大部分自然过程你倒放就觉得很诡异。两种不同的液体混合，从微观上看就是一个个小球的碰撞，它是时间可逆的，倒放也是完全可以发生的。但这些小球碰撞表现出的总体行为却是不可逆的，这就让人陷入了矛盾：我们这个世界，微观过程都可逆，宏观过程都不可逆。我们不得不在对熵增的信念和对物理学对称美的忠诚之间做出选择。这就是庞加莱复现定理和洛施密特速度反演佯谬对玻尔兹曼的批评。
