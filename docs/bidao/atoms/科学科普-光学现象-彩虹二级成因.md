# 彩虹二级成因

## 一句话定义

光线在水滴内部反射两次时，平行光被水滴变成约五十二度的光锥，于是在四十二度彩虹上方出现外紫内红的二级彩虹，学名叫霓。

## 详细说明

彩虹上方还有一道外紫内红的二级彩虹，学名叫霓。霓虹霓虹，分别指的就是上下两道彩虹。

成因并不复杂：没有人规定光线只能在水滴内部反射一次。当光线在水滴内部反射两次时，会形成另一套光路，相当于平行光入射后被水滴变成了一个约五十二度的光锥。

在你的视野中，四十二度彩虹的上方就出现了一道五十二度、外紫内红的彩虹。

两道彩虹之间看起来特别暗，这个暗带被称为亚历山大带。
