# 湿筷子测油温的气泡原理

## 一句话定义

湿筷子插入热油时，筷上水分受热汽化产生气泡，气泡的形态和密集程度随油温升高而变化，据此可以判断油温。

## 详细说明

把湿筷子插进油里，筷子会冒泡并发出炸裂声，这些气泡是筷子上的水受热变成的水蒸气。

研究指出，水进入油中会产生三种形态的气泡：在表面直接炸开的爆炸型、向下伸长的拉长型、在油里不停变形的震荡型。三者相互配合，就会溅人一身油。湿筷子上水比较少，气泡属于情绪稳定的震荡型，因此能安全地用来检测油温。

油温与气泡表现：

| 油温 | 气泡表现 |
| --- | --- |
| 三四成 | 细腻的小气泡 |
| 五六成 | 密集气泡不停冒出 |
| 七八成 | 大颗气泡扩散越来越快 |

作者提醒测油温最好别用金属筷子，因为它不沾水、没气泡。论文 2022 年发表在 Physics of Fluids 上，三位作者分别来自日本、印度、中国。
