# 热二违背概率极小

## 一句话定义

熵减现象理论上可能发生但概率极低，空气缩在一半屋子的概率约为均匀分布概率的十的十的二十三次方分之一，实际永远不会出现。

## 详细说明

熵增定律在历史上遭到过许多质疑，违背热二的熵减现象真的就不会发生吗？可以做一个思想实验：一个单摆摆起来最后肯定会由于空气分子碰撞而停下来，动能完全变成了空气的热能。但如果静止的单摆周围只有少数空气分子，就那么几个，那的确有可能空气分子碰撞单摆让它摆起来，那岂不是空气的热能自发变成了单摆的动能，这不就违背热二了吗？对，违背了。

再比如，有没有可能周围的空气突然熵减，全部缩在左半边屋子里面，右半边屋子变真空呢？当然是有一定概率发生的，但用斯特林公式算一下就会发现，空气锁在一半屋子里的概率是空气均匀分布在整间屋子里的概率的大概十的十的二十三次方分之一。就算它发生了，下一秒它也会瞬间回来。

所以热二是一条统计规律，几个分子的时候会有例外，大量分子是不可能观察到违背热二的情况的。我们的世界熵减不是理论上不可能，只是实际上永远不会出现。
