# 铁盘反射图案验证

## 一句话定义

用一块定制的巨大铁盘放在黄昏的阳光下，可以在盘面上看到计算预示的反常反射图案，说明这些形状确实来自沟槽反射的几何规律。

## 详细说明

为了验证计算，作者联系了一位铁器卖家，定制了一个尽可能大的铁盘，最终以三百八十元成交。黄昏时分，他们把这块「大铁饼」搬到钱塘江畔，用太阳光当光源。太阳真的按照计算，在铁盘上画下了反常的图案。

这些图案的来源是参数变化：调节参数后，圆盘上可以算出各种奇形怪状的反射线，比如十字架、回旋镖、棒棒糖、一个勾带一个圈、两个顶在一起的角。这些形状平时在盘子上根本见不到，却能被一块铁盘和一束阳光还原出来。
