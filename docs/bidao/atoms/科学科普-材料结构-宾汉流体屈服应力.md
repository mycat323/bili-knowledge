# 宾汉流体的屈服应力

## 一句话定义

宾汉流体在静止时具有固体般的屈服应力，外力小于临界值时表现为固体，超过临界值后颗粒网络被破坏才开始流动。

## 详细说明

宾汉流体是一类特殊的非牛顿流体，它的核心特征是存在一个临界屈服应力。

- 外力小于临界值：流体表现为固体，宁死不屈服，静止不动。
- 外力超过临界值：内部固体颗粒网络被破坏，流体突然开始流动，粘度降低。
- 松手后有时会先探出一个小脑袋又缩回去，正是屈服应力恢复的表现。

1916 年，宾汉（Bingham）在开山之作中给出解释：悬浮物中的固体颗粒网络让流体在静止时具有固体般的屈服应力，当外力超过临界值，颗粒网络被破坏成小结构，流体就开始流动。

牙膏就是典型的宾汉流体：无机物磨料颗粒悬浮在水、山梨醇、甘油等保湿剂和羟乙基纤维素、卡拉胶等增稠剂中，恰好形成这种性质。所以牙膏放在那里不动，就是一坨安静的固体，放一年也不会混合。

近年来也有文献把牙膏归为卡松流体，可以理解为一种剪切变稀的宾汉流体。
