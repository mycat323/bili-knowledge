# 日地距离的尺度对比

## 一句话定义

地球半径约六千多千米，而日地距离约一点五亿千米，两者相差约两万五千倍，因此从早上到中午地球自转带来的距离变化在整体尺度上几乎可以忽略。

## 详细说明

把尺度换算成直观模型：如果地球缩成一个篮球大小，那么太阳与地球的距离相当于西湖这头到西湖那头的距离。在西湖这头把篮球挪动一点点，它到西湖那头的距离当然没有可察觉的变化。

这就是「第一层」的认识：从早上到中午，太阳与地球的距离变化完全可以忽略不计，所以「早上近还是中午近」在粗略层面没有区别。

但这个结论只是起点。地球半径六千多千米虽然相对日地距离很小，却并非零：日出时人位于晨昏线上，相当于站在球的侧面；中午转到球的正面，半个白天里人确实向太阳靠近了大约一个地球半径的量级。这个靠近量随纬度和太阳直射纬度变化。所以「忽略不计」在更精细的层面并不成立，需要进入下一层分析。
