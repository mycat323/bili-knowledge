# 拉平效应

## 一句话定义

在水中，所有比水合氢离子更强的酸都会被水拉平到同一强度，因此完全电离的强酸在水溶液中的pH相同，无法比较强弱。

## 详细说明

拉平效应说的是：水作为溶剂会把强酸的酸性「拉平」。盐酸、硝酸、硫酸在水中都完全电离，放出的氢离子立刻与水结合成水合氢离子（H₃O⁺），溶液中能存在的最强酸就是水合氢离子本身。所以一摩尔每升的盐酸和硝酸，pH 都是 0，比不出胜负。

视频里用足球类比：想知道德国和法国谁更强，让直布罗陀队当参照物各踢一场，是看不出来的——水就是那个太弱的参照物。

要比较强酸的真实强弱，必须换用 pKa 这种不依赖水拉平的评价体系。拉平效应也解释了为什么「强酸在水里都一样强」这句话只在水中成立。
