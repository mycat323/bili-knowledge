# 酸奶粘稠来自酪蛋白网络

## 一句话定义

酸奶的粘稠质地源于乳酸菌发酵产酸，使酪蛋白胶束解离并聚合形成三维网络结构，把水分包裹其中。

## 详细说明

yogurt 一词来自土耳其语，本意就是浓稠。酸奶制作时，乳酸菌把乳糖分解成乳酸，体系酸度达到酪蛋白的等电点，酪蛋白胶束解离形成酪蛋白胶粒，胶粒聚合形成三维网络结构，从而带来粘稠质地。

酸奶是利用微生物的天才发明：给乳酸菌合适的温度和时间，它们既能帮助分解难以消化的乳糖，又带来独特风味。研究发现这种香味来源于发酵产生的微量乙醛。

世界各地的美食家各自习得了类似技巧：法式酸奶油、中亚的马奶酒、北欧的增稠乳都是酸奶的近亲。泡菜、火腿、酸菜、腊肠同样是细菌发酵的杰作——微生物把糖和氨基酸变成更具风味的小分子，人类通过千百年实践让它们为我所用。
