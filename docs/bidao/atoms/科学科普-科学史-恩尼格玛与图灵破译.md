# 恩尼格玛与图灵破译

## 一句话定义

恩尼格玛是二战德军使用的转轮式密码机，当时暴力破解毫无办法，后来图灵和同事在英国布莱奇利庄园将其破译。

## 详细说明

恩尼格玛是一种转轮式密码机，二战时期德军使用它加密军情。它的加密方式让当时的暴力破解方法毫无办法，纳粹德军借此开始了侵略之路。

后来在英国布莱奇利庄园，图灵和他的同事们破解了恩尼格玛。这次破译不仅拯救了无数生命，也为日后的计算机科学开辟了宏伟蓝图。

这段历史说明：难以破解的密码体系带给世界的并不一定是安全，也可能是战争和更深的灾难；而密码的成功破译也不一定让世界无密可守，甚至可能带来人类文明的开拓性进步。密码学家一边探索更难破解的加密方法，一边也在寻找现有密码体系的破绽。
