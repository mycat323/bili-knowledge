# 液体的荧光颜色阶梯

## 一句话定义

某些液体在绿、蓝、紫和紫外光照射下会发出不同颜色的荧光，例如青红酒吸绿生黄、吸蓝生绿、吸紫生青、吸紫外深蓝，形成一套颜色阶梯。

## 详细说明

青红酒不只有一种荧光。用不同波长的光照射它，它吸绿生黄、吸蓝生绿、吸紫生青、吸紫外深蓝，在你面前打出一整套颜色阶梯。这种多色荧光说明酒中含有能吸收不同高能光子并发射低能光子的荧光物质。

转写稿中提到，从人眼色谱隐约感觉里面有维生素 B2；维生素 B2 是橙黄色粉末，放在水里用白光照射就会发出绿色荧光。除了青红酒，食用油用绿激光笔照时中间光路呈黄色，乌龙茶、咖啡、汤力水也各有荧光。

要注意，并非所有深色液体都这样：碘伏、可乐、红颜药水白光照上去不会变绿。液体的荧光颜色取决于其中荧光物质的吸收与发射特性。
