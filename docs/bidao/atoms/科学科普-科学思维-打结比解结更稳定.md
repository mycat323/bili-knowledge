# 打结比解结更稳定

## 一句话定义

耳机结只有在震动中沿打结路径原路退回才可能自己解开，这个概率很小，因此从热力学上讲打结是比解结更稳定的结局。

## 详细说明

耳机打结后能否自己解开？理论上可以，但条件是耳机线在震动中沿着它打结的路径原路退回，这个概率很小。

从热力学角度看，打结是比解结更稳定的结局。这与日常经验一致：把线捋顺放进裤兜，它很快会乱成一团；而一团乱麻几乎不会自己变回顺滑的线。

这一结论也解释了为什么防打结要靠主动干预——捆绑耳机头或把机头露出裤兜外，切断耳机头穿梭空隙的路径，而不是指望它自己解开。
