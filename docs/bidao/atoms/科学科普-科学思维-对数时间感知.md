# 对数时间感知

## 一句话定义

人对时间长度的感受取决于该时段占已有人生的比例，比例随年龄增大而减小，因此同样一年在感觉上越来越短。

## 详细说明

视频用韦伯-费希纳定律解释「长大后时间越过越快」。八岁上小学二年级时，一年占据人生的八分之一，在感觉上会留下更长的回忆；到三十岁，同样增加一年只是又一个三十分之一，就感觉转瞬即逝。你越长大，一年在生命中占的比例越小，就觉得时间越过越快。

视频进一步给出一个推算：假设活到八十岁，按线性感觉生命的终点当然是四十岁；但假设四岁开始有记忆，在对数感觉里，生命的终点其实是十八岁。八十岁回首往事，会觉得过了十八，人生的一半已经结束了。

这个解释说明时间越过越快不是心理学上的错觉，而是大脑用对数比例感知时间的结果。
