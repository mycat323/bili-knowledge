# 狼人杀马尔可夫过程建模

## 一句话定义

狼人杀本质上是一个心理博弈游戏，有学术观点把它简化成马尔可夫过程中的离散时间纯死亡过程。

## 详细说明

狼人杀的核心是玩家之间通过语言进行的心理博弈。为了用数学处理它，有学术观点把游戏简化成一个马尔可夫过程中的离散时间纯死亡过程。

所谓「纯死亡过程」，是指游戏状态的变化只体现为玩家一个接一个出局，而不考虑其他连续变化的量。所谓「马尔可夫」，是指下一步的状态只取决于当前状态，与更早的历史无关——换句话说，在模型里，之前谁说过什么、谁投过谁，都不影响下一步的概率。

这种简化当然丢掉了狼人杀最精彩的部分：悍跳、归票、盲毒、自刀，以及被查杀时的情绪反应。但它让问题变得可以计算，从而能推出随机策略最优、深水狼被压制、杀手数量配置等结论。

理解这个建模思路的意义在于：数学模型能解出游戏的最优策略，却解不透人性。模型给出的结论要放回真实对局中检验，而不能直接当成必胜法则。
