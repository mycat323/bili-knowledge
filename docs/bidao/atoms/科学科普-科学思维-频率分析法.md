# 频率分析法

## 一句话定义

频率分析法通过统计密文中字母和字母组合出现的频率，与自然语言的统计规律比对，从而反推密钥并破译密文。

## 详细说明

频率分析法针对的是替换式密码。自然语言中每个字母的使用频率并不相同：英文里 e 出现的频率一骑绝尘，达到 12.7%。如果一种加密方法对同一个字母永远替换成同一个符号，那么密文中出现最多的符号大概率就是 e。

除了单字母频率，字母组合也有统计特征。某些单词或字母组合会反复出现，比如一段加密文本里反复出现同一串字母，它可能对应某个常见单词。把频率最高的字母先假设成 e，再结合反复出现的组合猜测单词，就能逐步反推出密钥，进而破译整段密文。

频率分析法失效的前提是：同一个明文字母在不同位置被加密成不同密文，也就是密钥每次都在变。这正是后来一次一密要解决的问题。
