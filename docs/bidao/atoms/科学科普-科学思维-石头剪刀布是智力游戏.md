# 石头剪刀布是智力游戏

## 一句话定义

石头剪刀布是最简单的非传递性博弈，三足鼎立的规则看似公平，但大量算法和策略表明它和围棋、象棋、麻将一样是智力游戏。

## 详细说明

石头剪刀布之所以让人着迷，是因为它是最简单的非传递性博弈：三足鼎立的巧妙规则让人觉得它很公平很简单，没有任何人能在上面占到便宜。

但浙大等机构的实验数据、Kaggle 上超过 1600 支队伍参赛的算法大赛、以及能百战百胜的摄像头机器人，都在说明石头剪刀布并不简单。它和围棋、象棋、麻将一样，其实是个智力游戏。

不过视频最后给出了另一层思考：生活中石头剪刀布往往决定的是谁去拿外卖、谁去换水、谁去倒垃圾——都是简单但没人愿意做的事。每次都逃过去未必赚到什么；去做反而给集体带来快乐、赢得大家好感，还得到带薪放空的机会。有时候放下胜负才是更大的智慧。
