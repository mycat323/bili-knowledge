# 橡皮筋拉物体观察粘滑

## 一句话定义

用橡皮筋或弹簧测力计代替刚性绳拉手机、小木块做匀速直线运动，就能亲眼看到物体周期性前窜停顿的粘滑卡顿。

## 详细说明

这是一个在家就能复现粘滑现象的小实验。

**材料**：手边任意可拖动的物体（手机、小木块）、橡皮筋或弹簧测力计、一个平面。

**步骤**：

1. 先用刚性方式（直接用手推或硬杆拉）拖动物体做匀速直线运动，动作很丝滑。
2. 换用橡皮筋或弹簧测力计去拉，尽量保持匀速。
3. 观察结果：物体不再丝滑，而是周期性突然向前、再停下，一卡一卡地往前窜。

**原理**：橡皮筋/弹簧具有弹性，能储存弹性势能。静摩擦被突破后摩擦力骤降，储存的弹性势能释放，物体弹射起步；冲过头后弹簧松弛，拉力小于动摩擦力，物体停下，动摩擦又变回静摩擦，循环往复。

中学课本用弹簧测力计测小木块滑动摩擦力的实验，理论上很美好，实操时也可能变成这种卡顿状态。
