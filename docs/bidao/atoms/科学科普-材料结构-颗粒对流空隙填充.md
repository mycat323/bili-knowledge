# 颗粒对流的空隙填充解释

## 一句话定义

学术界主流观点认为，震动导致大小颗粒分层的原因是空隙填充：大颗粒附近空隙更多，小颗粒会钻入填充从而把大颗粒抬起或让大颗粒下陷。

## 详细说明

为什么震动会让大小不同的颗粒分层？目前学术界主流的观点把原因归结为空隙填充。

大致机制是：大颗粒附近的空隙更多。如果大颗粒密度小，摇晃过程中上面的小颗粒就会跑到下面去把空隙填充起来，填着填着大颗粒就被抬起来了；如果大颗粒密度大，它就会在小颗粒之间凿一个坑，慢慢陷下去。

听上去简单，但这套解释发表在 PRL 物理学顶刊上。实际情况还要考虑颗粒的直径之比、气体的压力甚至容器的形状。
