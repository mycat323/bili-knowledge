# 颗粒材料休止角

## 一句话定义

颗粒材料堆成的堆堆与水平面的最大角度叫休止角，颗粒越细小粗糙，相互咬合越强，休止角越大、堆得越尖。

## 详细说明

干沙子的休止角只有三十几度，所以只用沙子垒墙顶多堆个坟头，马超的马直接就冲上去。颗粒材料的大小、形状、光滑度都会影响休止角：越细小粗糙的颗粒能垒出越尖的堆堆，因为细小粗糙的颗粒之间相互咬合可以提供更大的强度。这也就是为什么用漏勺去舀米浆颗粒无收，去舀面粉反而能舀满满一勺。休止角是理解沙子为何需要加水才能筑墙的基础概念。
