# 热力学第二定律与能量品位

## 一句话定义

能量总是自发地从高品位向低品位耗散，电能是高品位能量，热能是低品位能量，所以充电后放出的能量必然少于充入的。

## 详细说明

往卡里存钱，存多少就能取多少；但充电不一样，充一度电放不出那么多。原因在于热力学第二定律：电能是高品位的能量，热能是低品位的能量，能量总是会由高品位向低品位耗散。

视频里用一句形象的话概括这个规律：每当我们得到，我们就将减少一些再得到的机会，直到最终不再有得到。这句话说明耗散是单向的、累积的，无法靠普通手段逆转。

这个原理是理解电池效率上限的起点：无论电池技术怎么进步，充放电过程中的能量损耗都无法完全消除，只能通过降低损耗来逼近极限。它也是电动车续航焦虑的物理根源之一——不是工程师不够努力，而是热力学第二定律不允许。
