# 宾汉流体

## 一句话定义

宾汉流体是一类具有临界屈服应力的非牛顿流体，外力小于临界值时表现为固体不流动，超过临界值后突然像流体一样流动。

## 详细说明

普通流体分为牛顿流体和非牛顿流体：牛顿流体的粘度不受外力影响，非牛顿流体的粘度随剪切速率变化。宾汉流体是非牛顿流体中最特殊的一种，它的核心特征是存在一个临界屈服应力。

- 外力小于临界屈服应力时，宾汉流体像固体一样保持形状，宁死不屈；
- 外力超过临界值后，它突然开始流动，粘度随之降低；
- 有时挤一下再松手，它会先探出一点又缩回去。

1916 年宾汉（Bingham）在开山之作中给出解释：悬浮物中的固体颗粒网络让它在静止时具有固体般的屈服应力；当外力超过临界值，颗粒网络被破坏成小结构，流体就开始流动、粘度降低。1949 年英国流变学家 Oldroyd 率先使用 Bingham solid 一词，1954 年日本学者平井一二首次使用「宾汉体」「宾汉流体」的说法。宾汉本人 1945 年去世，并不知道这类物质以他命名。

牙膏就是典型宾汉流体：无机物磨料颗粒悬浮在水、山梨醇、甘油等保湿剂和羟乙基纤维素、卡拉胶等增稠剂中。放着不动它就是一坨安静的固体，放一年也不会混合。
