# 解释现象的两条路径

## 一句话定义

面对同一个现象，可以先假设存在某种物质，再去找它；也可以先怀疑是结构或相互作用，再通过破坏结构来验证。

## 详细说明

蓝莓为什么是蓝色，有两条思路。

第一条：蓝莓是蓝色，所以它里面应该有蓝色物质。顺着这条思路去找，结果切开果肉没颜色，榨汁是紫红色，果皮内壁也是紫红色，提取不出蓝色物质。这条路走不通。

第二条：蓝莓是蓝色，但不一定需要蓝色物质，可能是表皮结构对光的作用。顺着这条思路，先注意到表面那层洗不掉的白霜，再用砂纸磨掉果蜡，蓝莓变成黑莓；用油溶掉果蜡，表皮变深黑而皮肤上没有蓝色印记。结构假说得到支持。

两条路径的差别在于：第一条默认颜色必须来自色素，第二条允许颜色来自结构。当第一条走不通时，及时换第二条，问题才有解。
