# 解释现象的两条路径

## 一句话定义

生活中的反常现象未必有现成论文解释，解释它只有两条路径：查论文学习理论，或者亲手做实验格物致知，再把论证讲给观众。

## 详细说明

很多生活中的反常现象，背后未必存在一篇精准解释它的论文或文章。这时候就需要自己把现象研究清楚，并向观众给出一个有说服力的论证。

解释一个现象的方法有两种：

1. **查论文、学习理论**：先看学术界有没有现成解释，把背后的原理学会。
2. **做实验、格物致知**：亲手把现象复现出来，用实验说话。

这两条路都是毕导本人很喜欢做的事情，也是团队比较特色的环节。完成这两个环节之后，团队的理工科同学会在科学选题会上互相介绍自己的选题成果，互相讨论、互相质疑，形式很像组会。选题确定之后，才是写稿、拍摄、剪辑这些大家都差不多的流程。
