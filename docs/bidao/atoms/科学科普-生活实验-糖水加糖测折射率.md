# 糖水加糖测折射率

## 一句话定义

往颜料水中逐渐加糖，糖水折射率随浓度升高，液柱在大厚缸中肉眼可见地变粗，用尺子量视直径除以真直径即可算出折射率。

## 详细说明

实验操作：往大厚缸里倒 200 毫升颜料水，然后逐渐加糖，一共融入 350 克糖。随着糖慢慢溶解，糖水浓度升高、折射率增大，液柱在眼前逐渐膨胀变粗。

观察到的三件事：浓糖水的直径变得好大；颜色变绿了；液面涨得很高。

测量方法：量出最终液柱的视直径，再除以容器的真直径，就等于这杯糖水的折射率。不需要阿贝折射仪，只要一把尺子和一个大厚缸，就得到一种测量未知液体折射率的新方法。

这个实验把「放大倍率等于折射率」从静态对比变成了动态演示：同一种液体，只改变浓度，就能看到放大倍率连续变化。
