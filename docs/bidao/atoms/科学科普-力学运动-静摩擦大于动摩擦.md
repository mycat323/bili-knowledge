# 静摩擦大于动摩擦

## 一句话定义

最大静摩擦力略大于滑动摩擦力，这个微小差异是世界底层设定之一，它打破了运动的连续与丝滑，让许多物体的运动变得卡顿。

## 详细说明

摩擦力不是一个恒定的力，它分两种状态：

| 状态 | 大小 | 特点 |
| --- | --- | --- |
| 静摩擦力 | 随外力增大而增大，有最大值 | 物体不动时起作用 |
| 滑动摩擦力 | F=μF_N，近似定值 | 物体运动时起作用 |

关键在于：**最大静摩擦力 > 滑动摩擦力**，而且只大一点点。

这个差异带来的后果是：物体一旦从静止被拉动，摩擦力会突然变小，拉力相对变大，物体就会弹射起步、冲过头、再停下，形成粘滑。

如果静摩擦等于动摩擦，物体就能被弹簧拉着做丝滑的匀速直线运动；正因为二者不等，世界才处处卡顿。视频把它称为「世界底层代码」的一项奇妙设定。
