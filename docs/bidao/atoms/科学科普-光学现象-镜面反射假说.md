# 镜面反射假说

## 一句话定义

衣服干燥时纤维凌乱发生漫反射所以较亮，变湿后水填充纤维间隙可看作一个个镜面，进入眼睛的光线变少，因此颜色变暗。

## 详细说明

镜面反射看上去比漫反射更暗，这一现象本身成立。雨后的路面更接近镜面，能反出天空的光芒，整体却显得更暗；一块磨砂玻璃加点水，从漫反射变为镜面反射，看着也变暗；石头变湿后有了镜面般的光泽，颜色同样变深。

该假说把湿衣服变深归因于水分子填充纤维间隙，使原本凌乱的纤维表面变成许多小镜面，反射光方向集中，进入眼睛的份额减少。

不过这一解释与埃氏全反射模型存在矛盾：埃氏模型的第一个假设就是物体有水没水都发生漫反射、不存在镜面。前向散射理论的支持者则指出，镜面这种由粗糙度变化带来的变暗，只不过是前向散射理论的一种特例。此外，一层水导致的镜面反射案例与湿衣服的情形并不十分相似，纤维加水能否真正形成镜面仍值得研究。
