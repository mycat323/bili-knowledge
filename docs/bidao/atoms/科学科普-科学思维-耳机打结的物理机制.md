# 耳机打结的物理机制

## 一句话定义

耳机线在裤兜等狭小空间中随身体震动，线圈之间形成空隙，耳机头跳入空隙并反复穿插，最终自发形成复杂绳结。

## 详细说明

耳机打结不是人为系出来的，而是震动环境下的自发过程。把耳机绕成圈放进透明包里模拟走路震动，可以看到：团成团的耳机线互相摩擦扭曲，圈与圈之间形成空隙，耳机头上下震动，一旦跳进某两圈之间的空隙，就形成一个结；如果继续在其他空隙间反复穿插，最后就变成一坨复杂的结。

打结与解结的概率并不对称。结要自己解开，需要耳机头在震动中沿着打结的路径原路退回，这个概率很小。因此从热力学角度看，打结是比解结更稳定的结局。

这也解释了为什么电源线、数据线放在包里很少打结，而耳机线三分钟就卷成一坨：又粗又硬的线不容易弯折，难以形成可供穿插的空隙。
