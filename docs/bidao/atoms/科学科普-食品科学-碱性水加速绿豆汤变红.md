# 碱性水加速绿豆汤变红

## 一句话定义

碱性条件下酚更易去质子化形成酚阴离子，更容易向氧化剂给出电子被氧化，因此碱性水煮的绿豆汤更快变红。

## 详细说明

实验：三杯纯净水分别加入少量柠檬酸、不加东西、加入少量小苏打，用 pH 试纸测出酸性、中性、碱性。各加十五克绿豆同煮二十分钟，酸性和中性水煮出的汤都偏绿色，碱性水煮出的汤是红褐色。

原因：碱性条件下酚更容易去质子化，形成电子密度更高的酚阴离子，从而更容易向氧化剂给出电子、自身被氧化，所以碱性水中绿豆汤更快变红。

这解释了「南绿北红」的说法：北方水质偏硬、碱性可能更强，煮出的绿豆汤更容易发红。有的人煮绿豆会加一点碱让它更容易煮烂，这也会让汤变红。
