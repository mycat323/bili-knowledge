# 反射线极限为双曲线

## 一句话定义

描述圆盘上反射亮线的复杂四次曲线，在观察高度趋于无穷大时方程化为 y = 1/x，也就是初中就学过的两支标准双曲线。

## 详细说明

描述圆盘上反射亮线的沟槽方程看起来丑陋得无法化简，但注意到把它的 h 平方项展开后会恰好抵消。令观察高度 h 趋向无穷大，方程中的一次项系数必然趋向于零，再做一次坐标变换，方程就变成了 y = 1/x。

也就是说，只要你站得足够高、足够远，这条复杂的四次曲线就会变成标准的两支双曲线——这正是每个人在初中就学过的第一条双曲线。

这也解释了为什么它在日常观察中很难被认出来：灯装在房顶、人站在远处时，曲线被压得很平，看起来就像直线；只有把观察条件推向极端，它才露出本来的形状。
