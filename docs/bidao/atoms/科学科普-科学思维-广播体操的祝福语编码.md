# 广播体操的祝福语编码

## 一句话定义

新春广播体操把健康、上分、致富、甜蜜、全家五类祝福分别编码进五节动作，每节对应一个生活主题和一句押韵祝词。

## 详细说明

视频把五节动作与五类祝福一一对应，形成一套可对照的编码表：

| 节次 | 主题 | 祝福内容 |
| --- | --- | --- |
| 第一节 | 健康运动 | 腰不酸腿不疼、戴口罩勤洗手、身在福中不发福 |
| 第二节 | 上分运动 | 轻松上岸、不塌房、超神五杀、五步起飞 |
| 第三节 | 致富运动 | 光明前途、下班早、财神到、送红包 |
| 第四节 | 甜蜜运动 | 白月光、二杯半价、猫狗双全、人生赢家 |
| 第五节 | 全家运动 | 牛年新转机、恭喜恭喜你 |

这套编码的特点是每节祝词都押韵，且用词贴近网络日常语汇，例如「上分」「上岸」「塌房」「超神五杀」都来自游戏和社交平台语境。

从结构上看，五节覆盖了个人身体、事业、财富、情感、家庭五个层面，形成从个体到全家的递进顺序，最后一节以集体拜年收束。
