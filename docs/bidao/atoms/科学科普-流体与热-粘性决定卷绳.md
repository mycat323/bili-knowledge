# 粘性决定卷绳

## 一句话定义

流体能否卷绳取决于粘性大小：粘性大的流体下落时来不及向两侧散开，只能被后续流体推着绕圈堆叠，粘性小的流体则迅速躺平流走。

## 详细说明

慢放十倍观察水和蜂蜜的下落，可以清楚看到两者的差别。水柱遇到阻碍时会选择快速躺平，灵活地向两边流走，因此不会形成螺旋。蜂蜜粘性很大，第一滴蜂蜜缓慢着陆，还没来得及散开，立刻赶到战场的是更多的蜂蜜；后来的蜂蜜只好往一边让开，顺势躺倒在前面蜂蜜的身边。就这样，蜂蜜在重力和粘性的拉扯下躺了一圈又一圈，逐渐长高，形成了锥形的坨子。

便便的下落也是同样的原理：粘度大、高度合适，就容易形成漂亮的螺旋。

由此可以归纳出卷绳效应的两个必要条件：一是流体要有足够大的粘性，二是下落高度要合适。水、甘油、食用油粘性不足，所以只竖直下落不绕圈；蜂蜜、麻酱、洗护用品粘性足够，所以能卷出圈圈。

在科学家眼中，一花一世界，一便一方程，螺旋形的便便是大自然对人类流体力学的启迪。
