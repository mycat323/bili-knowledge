# 耳机线打结实验

## 一句话定义

物理学家道格拉斯·史密斯2007年用透明盒旋转不同长度软硬的绳子做了三千多次实验，发现软绳更易打结，46厘米以下的绳子不易打结，长度增至150厘米时打结概率急剧上升，超过1.5米后稳定在约50%。

## 详细说明

史密斯把不同长度、不同软硬的绳子装进透明盒子，用各种速度旋转盒子，累计进行了三千多次实验，凭此获得搞笑诺贝尔奖。

主要结论：

| 变量 | 观察结果 |
| --- | --- |
| 软硬 | 软的绳子更容易打结，数据线这类又粗又硬、不易弯折的线很难打结 |
| 长度 | 46厘米以下不易打结；从46厘米增加到150厘米，打结概率急剧上升；超过1.5米后基本稳定在约50% |
| 空间 | 绳子在狭小空间内打结概率显著降低 |

耳机线长度约1.5米，恰好落在打结概率趋于稳定的区间，因此被称为「天选之线」。实验还提示，把耳机装进小盒子里，利用狭小空间降低打结概率，是可行的防结思路。
