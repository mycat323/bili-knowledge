# 奥利奥流变学

## 一句话定义

奥利奥奶油是一种屈服应力流体，平时呈固体，压力大到一定程度才开始流动，因此扭开时奶油通常整块留在一边饼干上。

## 详细说明

麻省理工的科学家研究了为什么扭一扭奥利奥后，奶油永远只会留在一面，并宣布开创了一个全新的学科：Oreology 奥利奥流变学。

他们发现新鲜奥利奥的奶油就是应该只待在一面上。原因是奥利奥奶油是一种屈服应力流体，平时是固体，压力大到一定程度才开始流动，类似于牙膏、冰淇淋。扭奥利奥的时候力量不大，奶油就还是一整块固体的状态，就会整个粘在饼干上。

据说也可以热一热，等奶油有点化开再把它们压紧。他们还造了个扭奥利奥机，方便大家自己在家测量自己买的奥利奥能顶住多少的应力。文章发表在 Physics of Fluids 上面，影响因子 4.1。
