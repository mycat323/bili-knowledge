# 冰面摩擦系数零点零二

## 一句话定义

冰与冰之间的动摩擦系数约为零点零二，远低于橡胶路面（零点五到零点八）和玻璃（零点四），是已知最滑的固体之一。

## 详细说明

描述接触面滑不滑，直观上就是看摩擦力大不大。学术上用两个物体相对滑动时的动摩擦系数 μ 来表示，公式为 F = μN，μ 越小越滑。

常见材料的摩擦系数对比：

| 接触面 | 动摩擦系数 |
| --- | --- |
| 橡胶路面 | 0.5~0.8 |
| 玻璃与玻璃 | 0.4 |
| 冰与冰 | 0.02 |
| 其他物质在冰面 | 0.0x |

生活中大部分物质的摩擦系数都是零点几，而冰只有零点零二，其他物质在冰面上的摩擦系数也只有零点零几。所以冰几乎是有史以来最滑的固体。

这意味着冰的滑是一种反常现象：地球上最常见的物质之一，在冬天表现出了反常的低摩擦性质，才让我们能滑冰滑雪。理解这一点，是研究「冰为什么滑」的起点。
