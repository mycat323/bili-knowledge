# 排泄物黄色的来源

## 一句话定义

血红蛋白经胆素原循环生成黄褐色的粪胆素和尿胆素，把排泄物染成黄色，所以黄色是健康的颜色。

## 详细说明

无论色泽多么诱人的食物饮料，在身体里走一圈后都变成黄色的液体或固体。原因是血红蛋白经过胆素原循环，生成黄褐色的粪胆素和尿胆素，从而染色。

粪胆素和尿胆素本身也是胆素原氧化生成的产物，与纸张、白墙变黄同属氧化路径。

所以黄色是健康的颜色——除非你昨天吃了红心火龙果，那上厕所回头看一眼会有惊喜。
