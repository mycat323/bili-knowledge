# 论文结论的第三方验证

## 一句话定义

李辉回应称该研究是非常初步的探索，绝对称不上完美，但完全可以由第三方独立重复验证，已有团队联系跟进重复实验。

## 详细说明

面对质疑，李辉的高情商回应是：这是一个非常初步的探索研究，绝对称不上完美，但是完全可以第三方独立重复验证，已经有很多团队联系跟进重复实验和深入探索。

毕导给出的低情商版本解读是：已经有很多人来找李老师买茶了。

从科学方法角度看，这个回应本身是合理的姿态：一项结论玄乎的研究，最有力的检验方式就是让独立团队按同样方法重复，看能否得到同样结果。毕导自己的复现就没能看出经络被激活。

这也提示读者：面对「实验摆在那」的论文，既不应先入为主地否定，也不应仅凭论文存在就接受结论，可重复性才是关键。
