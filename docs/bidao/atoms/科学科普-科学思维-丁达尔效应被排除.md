# 丁达尔效应被排除

## 一句话定义

青红酒有丁达尔效应，但氢氧化铁胶体、加牛奶的红颜料水同样有丁达尔效应却不光照变绿，因此丁达尔效应不是青红酒光照变绿的原因。

## 详细说明

有人提出，青红酒由糯米发酵而成，酒中含淀粉颗粒，光通过时会散射产生丁达尔效应；波长长的红光更容易向前穿透，波长短的绿光更容易四面八方散射回来，所以看到绿色。

验证：用红色激光笔照射青红酒，能看到清晰光路，说明它确实有丁达尔效应。但如果丁达尔效应能让青红酒光照变绿，那其他有丁达尔效应的红色液体也应如此。氢氧化铁胶体是教科书演示丁达尔效应的标准案例，用手电筒照它不会变绿；红颜料水里加几滴牛奶也有丁达尔效应，用手电筒照也不会变绿。

既然它们都有丁达尔效应却都不变绿，丁达尔效应就不是青红酒光照变绿的原因。这是一个用对照实验排除假说的例子。
