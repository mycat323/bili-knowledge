# 玻璃推动科学进步

## 一句话定义

从五千年前古埃及烧出第一块人造玻璃，到望远镜、显微镜和相机，玻璃的透明与化学惰性成为人类科学革命的基础材料。

## 详细说明

玻璃的意外发明推动了科学的进步，科学的进步又让人们好奇地研究玻璃。

五千年前，古埃及人把纯碱和沙子混合，烧出了第一块人造玻璃。两千年前，汉代人烧出仿玉的玻璃，为贵族下葬时披上铜缕琉璃衣。一千年前，中世纪欧洲教堂用彩绘玻璃作画与装饰，一时间蔚然成风。四百年前，科学先贤们利用玻璃的透明和化学惰性，为人类打开了启蒙之窗。

如果没有玻璃，就没有望远镜探索宇宙，没有显微镜揭示微观，没有拍视频的相机和看视频的手机，甚至会没有生化环材专业。

在塑料被发明之前，玻璃几乎是唯一常见的透明固体。它不像钻石水晶那样稀有，也不像冰一样会轻易融化，有恰到好处的硬度，还能加工成各种形状，这些性质让它成为人类文明进步和科学革命的基础。而在科学如此发达的今天，回看这个陪伴了几千年的老朋友，我们竟只能问出一句：你是谁？
