# 拍摄间改造机位优先

## 一句话定义

做拍摄间设计时，应先定义机位，再定义场景陈设，最后放灯，否则灯会阻碍其他布置，导致本末倒置。

## 详细说明

影视飓风团队在改造毕导拍摄间时给出的核心原则是：**先定义机位，再定义场景陈设，最后放灯**。

原因在于三者存在依赖关系：

1. **机位决定画面**：机位确定了观众能看到什么、看不到什么，是所有布置的起点。
2. **陈设服务于机位**：置景道具、柜子、沙发等要摆在镜头能拍到且构图合理的位置。
3. **灯最后放**：如果先布灯，灯架、灯体本身可能挡住机位或陈设，调整时又要重新挪动前面的东西，造成返工。

毕导的拍摄间原本采用无主灯设计，团队指出这种设计拍视频会导致人脸阴影非常重，不建议这样设计。好在毕导用的是可任意转动角度的轨道灯，用来营造气氛和背景很好用；人物则用常规柔光箱作主光，与背景形成区分。

置景方面还有两条经验：一是要考虑画面的层次感和配色，可以用基本三维软件先大致陈列软装设计，避免翻车；二是元素不是越多越好，过多会让观众注意力放在背景而非人物本身，所以「克制」很重要。
