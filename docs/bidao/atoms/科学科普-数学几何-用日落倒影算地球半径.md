# 用日落倒影算地球半径

## 一句话定义

利用日落倒影照片，结合身高、正弦定理与等价无穷小替换，可算出地球半径约六千一百公里。

## 详细说明

论文给出的计算方法：站在海边看日落，身高约一米八五，极目远眺看到海平线末端，太阳光线经过海平面反射进入眼睛。定义一些小字母，列出一个方程组，用到正弦定理、和差化积、等价无穷小替换。

代入身高一米八五后，算出的地球半径约为六千一百公里。地球的真实半径是六千三百七十八公里，结果相当精确。

这个方法的特别之处在于：

- 不需要知道世界有时差；
- 不需要知道巴西能看到哪颗星星；
- 只需要一张照片、一点点数学，就能从你小小的身高揭示地球大大的尺度。

毕导强调，这一计算基于范德北教授拍到的奇怪日落照片，他本人从未亲眼看过这种形状的日落；如果倒影压扁的日落真实存在，这个推理相当精彩。
