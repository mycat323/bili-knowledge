# 埃拉托色尼测地球周长

## 一句话定义

公元前 240 年，埃拉托色尼用夏至日两地日影夹角与距离，算出地球周长约四万公里，与真实值相差无几。

## 详细说明

公元前 240 年夏至日正午，埃拉托色尼在亚历山大城观察到太阳光有七度夹角，而八百公里外的塞伊尼，太阳可以直射井底，井壁上没有留下任何影子。

两地同一时刻太阳高度角相差约七度，而七度约等于圆周的 1/50。既然七度对应八百公里，那么整个圆周就对应约四万公里。这就是他算出的地球周长，与真实值相差无几。

这个测量的关键在于：

- 利用太阳光近似平行这一前提；
- 利用两地已知距离和日影夹角；
- 只需一口井和一点点数学。
