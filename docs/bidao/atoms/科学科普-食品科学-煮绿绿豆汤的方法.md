# 煮绿绿豆汤的方法

## 一句话定义

想煮出绿色绿豆汤，应换用纯净水、加柠檬汁或醋使水偏酸、并盖上锅盖煮，以减少多酚被氧化和碱性加速变红。

## 详细说明

综合实验结论，绿色绿豆汤的保持条件与变红条件正好相反：

| 做法 | 结果 |
| --- | --- |
| 纯净水煮 | 偏绿 |
| 加柠檬汁或醋（酸性） | 偏绿 |
| 加小苏打（碱性） | 红褐色 |
| 自来水煮 | 红色 |
| 开盖久放、加热保温 | 逐渐变红 |

因此煮绿汤的要点是：用纯净水，加柠檬汁或醋让水偏酸，盖上锅盖煮，减少与空气接触和水分蒸发带来的碱性上升。

从成分看，绿色绿豆汤多酚更丰富、抗氧化性更强；红色绿豆汤的多酚已被氧化成醌和深色聚合物。颜色之争本质是氧化还原之争，是酚和醌之争。
