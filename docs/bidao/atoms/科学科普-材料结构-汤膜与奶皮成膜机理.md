# 汤膜与奶皮成膜机理

## 一句话定义

热肉汤中的动物油脂与变性蛋白质冷却时在表面聚集凝固形成薄膜，牛奶加热后乳清蛋白变性、蛋白质间通过二硫键与疏水作用聚集，同样在表面成膜。

## 详细说明

肉汤表面的膜来自动物油脂和变性蛋白质在冷却时的聚集凝固，它的成分与汤本身基本相同，撇掉与否不影响营养摄入。

双皮奶的皮是同一类膜。复刻工艺：把牛奶加热到 80°C 保持 5 分钟，此时乳清蛋白发生变性；取下自然冷却，蛋白质在液体表面聚集成膜。成膜的驱动力包括半胱氨酸残基的硫醇基团之间通过氢键或二硫桥键结合、蛋白质之间的疏水相互作用，以及未折叠氨基酸链构象自由度增加带来的熵增。

实测这层膜厚度约 58.4 微米，膜上皱纹波长约 5 毫米，呈近似正弦的形状；轻轻戳膜会出现星形放射状折叠。相传清朝广东顺德的董奶奶把牛奶煮沸冷却后发现皱巴巴的奶皮好吃，由此发明双皮奶。
