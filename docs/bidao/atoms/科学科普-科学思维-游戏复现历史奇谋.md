# 游戏复现历史奇谋

## 一句话定义

游戏团队为还原潼关之战，联合历史、建筑、土木、地理等专家论证一夜筑冰城的可行性，并把科研成果做成新玩法。

## 详细说明

三国志战略版想做一个潼关之战新版本，为了还原历史，他们从史书寥寥几句出发，找多方专家论证曹操一夜筑冰城的可行性。这段历史在科研领域很少被提及，他们坚持探索历史真相，补全了一段空白的三国历史。他们还把科研成果做成游戏新玩法：天气变化会改变地形，气温降低后沙土变成冻土，城池和河流被冰封；河流原本只能走码头穿行，冰封后哪里都畅通无阻，军队可以随机开辟新进攻路线进行侧翼包抄或绕后偷袭；低温下建冰面建筑只需三小时。
