# 希尔伯特纲领

## 一句话定义

希尔伯特纲领是二十世纪初希尔伯特提出的宏大计划，试图在每个数学领域规定基本公理，把公理写成形式语言，用来证明其他一切，为数学提供绝对严谨的基础。

## 详细说明

一九二零年左右，在饱受战火蹂躏的欧洲废墟中，二十世纪的数学王者希尔伯特从罗素悖论引发的数学危机中认识到数学还不够清楚明白，提出了希尔伯特纲领。

核心思路：

1. 在每个数学领域规定一些基本的公理。公理通常是显然成立、不证自明、大家都接受的命题，比如两点确定一条直线。
2. 把公理写成形式语言，即把所有的句子都变成符号，比如「f(x) 在 p 处的极限为 L」写成符号形式，简洁优雅。
3. 从公理出发一步步证明其他命题是真是假，就绝对严谨。例如从算术领域的皮亚诺公理出发，只要五十多步就可以方便又严谨地证明一加一等于二。

希尔伯特还要求这个体系具备三条美好品质：完备性（所有真命题都可从公理出发得到证明）、一致性（体系不存在矛盾）、可判定性（存在算法能判定任意命题是否可从公理出发证明），此外还有一条保守性。

如果这三条都能证明，数学将无懈可击，甚至能造出一台「数学制造机」，定理在流水线上被源源不断生产出来。一九二五年，希尔伯特的天才学生外尔评价称：这是用毫无意义的公式游戏取代内容数学，公式清单只是分析的冷酷幽灵，没有智力上的意义。
