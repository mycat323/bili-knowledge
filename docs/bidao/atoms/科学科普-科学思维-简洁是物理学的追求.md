# 简洁是物理学的追求

## 一句话定义

物理学把复杂规律压缩成更简洁的高阶形式，简洁不只是省纸，而是提升对世界洞察力、体现物理内在结构之美的终极追求。

## 详细说明

从记四条独立的左右手定则，变成记一个叉乘公式加一套右手定则，表面上公式更简洁，代价是额外引入叉乘的定义。但在物理学中，简洁就是力量。

简洁的优越性随公式复杂度放大：麦克斯韦方程组从二十个方程缩到四个；流体力学最基础的纳维斯托克斯方程用向量和 nabla 算子后大幅简化；爱因斯坦场方程的张量形式比第一层展开简洁得多。在专业玩家那里，麦克斯韦方程还能进一步简化成两个，代价是要懂爱因斯坦求和约定、电磁张量、四矢势等知识。

理性上讲，方程未必因为简洁而诞生新知识，一段代码封装得再简洁，功能可能和屎山一样。但感性上，方程的确会因为简洁而带来更深刻的洞察和更纯粹的美。物理规律能以更简洁的形式写出，正说明世界有内在结构：七分之一等于 0.142857142857……有完美结构所以能写成两个数字，而随便挑一个无理数大概率是一坨混乱的数，无法压缩。世界上无规律、不可压缩的事物是常态，有结构能变得简洁的东西才是稀少的。
