# 长焦相机对焦找虚像

## 一句话定义

用景深极浅的长焦镜头对焦水缸中的小钢球，通过反光点从模糊变清晰的位置，可以分别定位子午像和弧矢像两个虚像。

## 详细说明

实验装置：长焦镜头景深调得很浅，只能看清对焦点上的物体；水缸后壁贴一个小钢球，旁边放一把尺子；以钢球上的小反光点作为对焦判据。

操作与现象：

1. 让相机对焦点从近到远移动，钢球反光点从模糊逐渐显现。
2. 反光点变清晰时，它变成一条横线，此时尺子上数字「六」最清晰——说明子午像就在这个位置，比钢球实际位置向镜头靠近了几厘米。
3. 继续把对焦点往里移，横线变模糊；对焦到水缸后壁附近时，光点再次变清晰，这次变成一条竖线，尺子上数字「一」「二」比较清楚——说明弧矢像位于钢球实际位置的正上方。

这个实验把「水中物体有两个虚像」从理论变成了可复现的观察，也解释了为什么教材插图里看不到第二个像：普通作图只画了两条光线，无法体现光锥的完整结构。
