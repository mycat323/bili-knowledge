# 疏水粉末铺展

## 一句话定义

胡椒粉、咖啡粉、可可粉、眼影粉等疏水低表面能粉末落到水面后会迅速铺满整个水面，表面能越低铺展能力越强。

## 详细说明

在水面角落撒一勺胡椒粉，胡椒粉会瞬间跑满整个水面，仿佛肩负着占满整个水面的使命。咖啡粉、可可粉、眼影粉也有同样的表现。

铺展能力可以用来做粉末 PK：谁的表面能越低，谁的粉就战斗力越强，越能挤开别人。实验顺序是：胡椒粉先铺满水面，再加辣椒素，胡椒粉被挤开；再加可可粉，辣椒素又被挤开。

这类粉末的共同点是疏水且表面能低，落到水上会主动铺展以降低整体表面能，因此能挤开原本占据水面的物质。
