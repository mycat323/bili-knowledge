# 湿身问题三种模型并存

## 一句话定义

湿物体变深有全反射、前向散射增强、镜面反射三种解释，它们分别适用于不同情形，都能与部分实验数据吻合，并非只有一个正确答案。

## 详细说明

1988年Lechner和Dorf比较全反射模型与前向散射模型，发现两个如此不同的模型竟都能与实际数据高度一致。Lackner总结：全反射理论适用于固体表面有一层水，如板子；前向散射理论适用于固体颗粒内部有水，如沙子；衣服纤维位于两者之间。

判断依据在于水的位置。往裤子上浇水后低头观察，水充满纤维之间，更接近沙子的情形，因此前向散射理论更适用；而不吸水的平面湿后变深，用全反射解释是可以的。

三种模型各有适用范围：全反射模型简洁、计算方便、应用广泛；前向散射对固体颗粒和纤维更有效，还能解释物体变透；镜面反射假说可描述固体表面有水时变深的现象，但与全反射模型的前提相矛盾。

科学上，只要一个理论能自洽地解释和预测现象、能派上用场，它就是好理论，直到被不能解释的现象推翻或更新。湿身模型已被用于遥感反演土壤湿度、动画渲染湿身效果、自动驾驶从路面颜色推测潮湿状况，这正是模型对复杂世界提供简化与理解的意义。
