# 酸奶包装专利的产业化困境

## 一句话定义

针对酸奶残留问题，学术界和民间涌现出大量包装专利设计，但因缺乏产业界扶持，许多设计最终因交不起专利年费而失效。

## 详细说明

酸奶浪费问题早已引起关注。视频提到，去年有人设计了一款大瓶盖酸奶，喝完后可以倒置再接一瓶盖，获得了设计大奖。相关专利层出不穷：

- 让内部残留聚集在一处的瓶体设计；
- 附带刮棒的暗藏机关设计；
- 底部能上推或干脆能分离的设计；
- 号称适用于各种瓶装粘稠饮料、还能带来旋转乐趣的内壁清理装置。

可惜这份乐趣没有得到产业界扶持，该内壁清理装置两年后连一千多元的专利年费也交不起了。视频作者由此产生灵感：脚气膏管壁是刚性的，能保持形态并持续给管内加压，抹完还会冒出一截。若酸奶采用类似设计，或许能解决浪费问题，只是喝酸奶可能感觉像在治脚气。
