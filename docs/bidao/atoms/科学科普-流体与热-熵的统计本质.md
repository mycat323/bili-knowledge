# 熵的统计本质

## 一句话定义

熵是描述分子热运动无序性的物理量，玻尔兹曼定义熵正比于热力学概率的对数，微观状态数越大则熵越大、出现概率越高。

## 详细说明

假设一个箱子里有四个球，晃一晃，打开观察左右两半各有多少个球。宏观上有左四右零、左三右一、左二右二、左一右三、左零右四这五种状态，对应的微观状态数分别是 1、4、6、4、1，就是杨辉三角。球分布在一边是更有序规整的状态，球一边两个是更均匀混乱的状态。

如果有二十个球，各个宏观状态对应的微观状态数曲线更窄，也就是说这二十个球有更大的概率均匀分布在箱子左右，而很小的概率会左零右二十。球越多，这个曲线越窄。

我们这间屋子里大概有 6.02×10²³ 个分子，可以把它看成一个个小球。如果盒子里有这么多球，曲线就变成一条竖线，几乎就是左右各一半。这说明周围大量空气分子有极大的概率均匀混乱地分布在整间屋子里，而不会所有分子都缩在左半边屋子、右半边是真空。

微观状态数 Ω 越大，这种状态出现的概率就越大，分子运动也越混乱。Ω 被称为热力学概率。1887 年玻尔兹曼定义熵 S 正比于 log Ω，用来描述分子热运动的无序性或者混乱度。
