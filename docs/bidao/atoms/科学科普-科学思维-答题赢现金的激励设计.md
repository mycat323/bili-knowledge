# 答题赢现金的激励设计

## 一句话定义

用答题这种需要主动参与的任务换取现金奖励，是把用户的注意力与操作转化为可量化行为的一种激励设计，常见于拉新与促活场景。

## 详细说明

这类设计的结构通常包含三部分：**触发**（下载并打开应用）、**行为**（完成答题）、**奖励**（现金）。答题之所以被选作行为，是因为它比单纯点击更有参与感，且能自然延长用户在应用内的停留时间。

从用户角度看，答题赢现金的吸引力来自两点：

- **确定性任务**：题目有明确对错，用户知道努力方向；
- **即时反馈**：答对答错立刻可见，奖励预期清晰。
