# 奶皮皱纹源于蒸发

## 一句话定义

2017 年 Alice 等人在 Soft Matter 提出，奶皮是多孔弹性膜，牛奶通过奶皮蒸发在孔内形成压力，产生面内应力，最终形成皱纹。

## 详细说明

奶皮安静地浮在奶上，没有外力拉伸或挤压，压应力从哪来？不是膜的重力，不是水的浮力，也不是表面张力。2017 年 Alice 等四位科研人员把牛奶在不同条件下加热冷却制备奶皮，用共聚焦显微镜和轮廓曲线仪观察，在 Soft Matter 发表论文《奶皮的皱纹是蒸发导致的》。

他们把奶皮看作一层多孔弹性膜，内部充满牛奶。牛奶通过奶皮蒸发，会在膜的孔里形成孔瘤，孔瘤意味着孔内有压力，这个压力产生奶皮平面内的应力，进而产生皱纹。压差是流动的推动力，牛奶能通过奶皮蒸发是因为上方压力小；蒸发通量与压力梯度成线性关系，即达西定律，由此可以算出奶皮孔里的奶压。

牛奶蒸发向上运动时，奶皮给奶一个阻力，奶给奶皮一个向上的渗透力。根据太沙基有效应力原理，奶皮竖直方向的有效应力降低；再根据广义胡克定律，奶皮在水平方向收缩。由于不同部位蒸发不均匀，有的地方收缩多、有的地方收缩少，相互拉扯形成复杂应力，最终形成皱纹。作者在不同湿度下制备奶皮，发现湿度越大、蒸发越慢、皱纹越少，证明皱纹确实来源于蒸发。这套计算属于土木与材料交叉的孔隙弹性力学。
