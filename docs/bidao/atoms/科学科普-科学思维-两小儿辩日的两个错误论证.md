# 两小儿辩日的两个错误论证

## 一句话定义

两小儿分别用「近大远小」和「近热远冷」推断太阳早晚距离，两个前提都站不住脚：太阳视大小一天内基本不变，而太阳光近似平行光，距离微变不改变地面受热。

## 详细说明

第一个小孩认为日出太阳大所以早上近。毕导用同一台相机、同一位置在日出和中午各拍一张太阳照片叠加对比，发现两者大小基本一致；网上的日出日落延时摄影也显示太阳大小一天内基本不变。日出太阳显大是参照物造成的错觉：日出时太阳附近有树、房子等小参照物衬托，升到高空后参照物变成整个天空，就显得小了，月亮也有同样的「月亮错觉」。

第二个小孩认为早上冷中午热，所以中午近。但太阳与火苗不同：火苗小，光向四面八方发散，离得远单位面积能量就少；太阳离地球约一点五亿千米，照到地球的光几乎是平行光，地球稍微靠近或远离，接收到的能量几乎没有区别。真正决定冷热的是太阳光入射角度：日出斜射，能量分散在大片区域；中午直射，能量集中在小片区域。此外日出时光线在大气层中走的路更长，热量被大气吸收更多。

两个小孩的结论都错，但他们的观察、推理与质疑精神值得肯定。
