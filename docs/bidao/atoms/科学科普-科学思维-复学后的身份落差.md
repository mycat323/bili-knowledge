# 复学后的身份落差

## 一句话定义

大龄博士生复学时，与比自己低十届的新生同处校园，会产生「行走的活化石」式的身份错位感。

## 详细说明

毕导回校第一天感慨：自己是二零一零级的，现在的新生却是二零二零级的，他们可能很难想象有一个比他们高十届的学长还在上学。他在校园里走路，觉得自己就是个行走的活化石。

时间跨度带来的对照很具体：清华百年校庆时他在台下摇小旗，到一百一十周年校庆时，当年一起摇旗的同学都已经成了返校的老校友，而他还在读书。校园本身也变了：当年爱吃的食堂窗口有的已经没了，当年住的宿舍楼已经快要关了，当年上学时生活很单纯，现在大家每天都在聊内卷。

他提到，可能因为已经看遍世间繁华，内心其实还挺平静的。
