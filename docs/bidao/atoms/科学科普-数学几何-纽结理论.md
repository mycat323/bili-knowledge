# 纽结理论

## 一句话定义

纽结理论是拓扑学的一个分支，研究结在连续变形下哪些本质相同、哪些本质不同，用数学工具解构结的世界，同痕与琼斯多项式是其中的核心概念。

## 详细说明

1867年开尔文勋爵提出原子可以描述为漩涡的结，此后打结成为有趣的科研话题。开尔文的想法没有多少人理会，但数学家们从拓扑学中开辟出纽结理论这一分支。

纽结理论研究的问题包括：

- 哪些结在连续变形下本质相同（同痕）；
- 如何用不变量区分本质不同的结；
- 1985年琼斯发现的多项式族，可以用一个多项式表达一个结的结构。

纽结、拓扑这些概念很考验空间想象力。视频中举了两个例子：一个插头看着拔不出来，一通操作就能取出；另一个结看着密密麻麻，实际能轻松拉开，而有的结又小又简单却越拉越紧。这说明结的复杂度不能只看外观，必须用数学工具判断。
