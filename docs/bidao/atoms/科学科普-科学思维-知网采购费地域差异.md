# 知网采购费地域差异

## 一句话定义

统计 50 所高校近四年知网采购费可见地域共性：北京高校普遍豪气，武汉也不差，上海则精打细算，没有一所上百万。

## 详细说明

把各校知网采购金额按城市排列，能看出明显的地域风格差异。

北京高校普遍出手大方：北师大 198 万、清华 188 万、人大 165 万、地大 117 万。武汉同样不差：华科 179 万、武汉理工 128 万。上海则明显精打细算，没有一所高校超过百万：同济 98 万、复旦 83 万、上海理工仅 42 万。

同样是理工大学，上海理工的同学看一篇论文，武汉理工的同学得看三篇，才能对得起学校多掏的那几十万。

需要说明的是，各校人数、专业结构、订阅的数据库内容和范围都不同，价格高低不等于一定被坑，地域差异只能作为一种有趣的观察。
