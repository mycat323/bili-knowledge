# 大学社交不迷信学长学姐

## 一句话定义

学长学姐只是比你多待了一两年的普通人，他们的建议仅供参考，不要因为一句「微积分难」或「社团无聊」就放弃尝试。

## 详细说明

毕导提醒新生不要迷信学长学姐，理由是他们的评价往往带有个人局限：学长说微积分难，可能只是因为他自己学得不好；学姐说轮滑社无聊，可能只是因为她自己学不会。

核心判断是：学长学姐只是比你多待了一两年的普通人，他们的建议仅供参考——毕导特意补了一句「我的建议也是」。

由此延伸出几条社交原则：

- 不喜欢的社团不要勉强，不合适的圈子不要强加，不要为了合群而合群。
- 室友是接下来四年相处最密切的人，要保持礼貌和尊重；但原则问题上该撕还得撕，严重不合尽早换室友。
- 收到通知时冒个泡回复一下，负责发通知、打字的人比你更麻烦，举手之劳是尊重别人。
- 当了学生组织干部别沾染官僚主义，要记得为人民服务。

这些建议的共同点是：把判断权留给自己，而不是交给身份更高的人。
