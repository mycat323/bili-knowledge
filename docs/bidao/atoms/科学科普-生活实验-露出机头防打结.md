# 露出机头防打结

## 一句话定义

把耳机两端露出裤兜外面，使耳机头无法在线圈之间穿梭，仅靠耳机线自己打圈不会形成结，这是防止耳机打结的第二种方法。

## 详细说明

原理：耳机线自己绕圈并不会形成真正的结，结的形成需要耳机头穿过线圈之间的空隙。把耳机两端露出裤兜外，耳机头就失去了在空隙间穿梭的机会，因此不会打结。

这一方法与「耳机捆绑法」针对的是同一个必要条件：耳机头必须在线圈之间穿插。区别在于，捆绑法把耳机头固定在整团线里，露出机头法则让耳机头留在裤兜外。

视频中还提到，把耳机装进小盒子、利用狭小空间同样能显著降低打结概率，这与史密斯实验中「狭小空间打结概率显著降低」的结论一致。
