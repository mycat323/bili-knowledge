# 史密斯耳机打结研究

## 一句话定义

物理学家道格拉斯·史密斯2007年研究绳子打结问题并获得搞笑诺贝尔奖，他用透明盒旋转绳子做了三千多次实验，得出软绳更易打结、46厘米以下不易打结、1.5米以上打结概率稳定在约50%等结论。

## 详细说明

2007年，物理学家道格拉斯·史密斯研究了绳子打结的问题，并因此获得搞笑诺贝尔奖。

实验设计：把不同长度、不同软硬的绳子装在透明盒子里，用各种速度旋转盒子，累计进行了三千多次实验。

主要发现：

- 软的绳子更容易打结，又粗又硬的数据线很难打结；
- 46厘米以下的绳子不容易打结；
- 长度从46厘米增加到150厘米，打结概率急剧上升；
- 超过1.5米后打结概率基本稳定在约50%；
- 绳子在狭小空间内的打结概率显著降低。

这项研究把日常的耳机打结现象变成了可量化、可复现的实验问题，也是视频中「耳机拓扑学」讨论的起点。
