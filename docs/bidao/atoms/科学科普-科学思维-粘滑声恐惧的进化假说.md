# 粘滑声恐惧的进化假说

## 一句话定义

有科学家提出假说：老虎狮子咬骨头时牙齿与骨头摩擦会发出尖锐粘滑声，古人类听到就警觉逃跑，于是进化出对这类声音的本能恐惧。

## 详细说明

为什么人类会本能地讨厌粘滑声？视频介绍了一个**假说**（注意是假说，不是定论）：

大型动物如老虎、狮子在咬骨头时，牙齿和骨头之间的摩擦会发出尖锐的粘滑声。古人类一旦听到这种声音，就意味着附近有猛兽正在进食，跑得慢的可能就成为下一根骨头。于是对粘滑声敏感、听到就警觉逃跑的个体更容易存活，这种本能被写进了基因。

几百万年后的今天，篮球鞋、叉子、泡沫塑料能轻而易举复刻出与牙齿啃骨头同一原理的粘滑声，于是我们依然会背后发凉、头皮发麻。

这个解释的价值在于：它把「声音频率特征」和「进化选择压力」联系起来，而不是简单说「难听所以讨厌」。
