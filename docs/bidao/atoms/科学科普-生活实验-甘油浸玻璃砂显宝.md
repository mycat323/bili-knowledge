# 甘油浸玻璃砂显宝

## 一句话定义

把藏在玻璃砂中的小物件浸入甘油后重新显现，因为玻璃砂与甘油折射率接近，光不再被强烈散射而是穿透，直观演示了前向散射增强。

## 详细说明

实验装置很简单：把一个小物件（视频中称为神秘宝藏）埋进玻璃砂里，此时看不见它；往容器中加入甘油，稍等片刻，物件就重新显现出来。

原理是折射率匹配。玻璃砂与空气的折射率相差很大，光在砂粒表面被散向四面八方，整体看上去是一坨白色，埋在其中的物件自然被遮住。甘油的折射率与玻璃砂接近，光在界面上的散射大幅减弱，能够穿透砂层，于是物件重新可见。

这一现象与湿裤子变深、薄衣服湿了变透、纸沾油变透明、有些花雨后变透明共享同一机制：当颗粒间介质由空气换成折射率更接近颗粒的液体时，前向散射增强、后向散射减弱，光能钻得更深。视频还提到，若用折射率更高的液体（如苯、硝基苯、溴、二硫化碳）润湿，效果会更明显。
