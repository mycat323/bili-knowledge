# 韦伯费希纳定律

## 一句话定义

人对刺激强度的感受取决于变化的相对比例而非绝对差值，感觉强度与物理量的对数成正比，因此同样增幅在低强度时更易被察觉。

## 详细说明

韦伯-费希纳定律指出，人对外界变化的感受不是变化的绝对值，而是变化的相对比例。视频用多个例子说明这一点：一块一斤的菜涨到两块一斤，涨幅百分之百，感觉强烈；一万的工资涨到一万零一块，涨幅万分之一，几乎无感。已经堆了九个大作业时再布置一个，感觉无所谓；从零到一却会崩溃。

把这一规律写成数学形式并积分，得到感觉强度与物理量的对数成正比。正因如此，物理学家用分贝定义声音响度，化学家用 pH 定义酸碱度，地质学家用里氏震级定义地震强度，天文学家用视星等定义星星亮度——这些都是对数尺度。

视频强调，人在高一学对数之前，大脑其实早就在用对数感知世界。这一规律也解释了「长大后时间越过越快」：八岁时一年占人生的八分之一，三十岁时只占三十分之一，比例变小，感受自然变短。
