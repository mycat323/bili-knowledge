# 蓝莓蓝色来自果蜡结构色

## 一句话定义

蓝莓果肉和果汁都是紫红色，不含任何蓝色物质，它的蓝色来自表皮那层无色果蜡对光的作用，属于结构色而非色素色。

## 详细说明

切开蓝莓，果肉白里透黄，几乎没有颜色；榨成汁是紫红色的；撕下蓝莓皮用内壁蹭一下，也是紫红色的。科学家研究发现，蓝莓中只含有红紫色调的花青素，提取不出任何蓝色的物质。

那蓝色从哪来？蓝莓表面总有一层洗不掉的白霜，像荷叶一样疏水，这层白霜是蓝莓皮上的果蜡。凡是有果蜡的位置，蓝莓看着就有一种哑光蓝。

用砂纸磨掉蓝莓表层的果蜡，蓝莓直接变成黑莓，对比相当明显。这说明蓝莓皮本身是黑色的，是果蜡让它看着是蓝色。

果蜡不溶于水但溶于油，用油溶掉果蜡后，蓝莓表皮变成深黑色，而皮肤上并没有留下任何蓝色印记，说明果蜡本身没有颜色。

结论：蓝莓的蓝色不是来自蓝色色素，而是无色的果蜡与光相互作用产生的结构色。
