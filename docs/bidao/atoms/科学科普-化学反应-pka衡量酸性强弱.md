# pKa衡量酸性强弱

## 一句话定义

pKa是酸解离平衡常数的负对数，衡量酸在溶液中解离出氢离子的绝对能力，pKa越小酸性越强，每差1酸性差十倍。

## 详细说明

当 pH 体系对强酸失效后，化学家用 pKa 来客观比较酸性。pKa 是酸解离方程平衡常数的负对数，数值越小，酸给出氢离子的能力越强，每相差 1，酸性相差十倍。

视频给出的三大强酸 pKa：硝酸 −1.3，硫酸 −3，盐酸 −7。结论出人意料——看似强大的硝酸最弱，只有两个原子的 HCl 反而是三者中的酸老大。

卤化氢的规律是：卤原子半径越大，氢卤键能越低，酸性越强。所以氢溴酸、氢碘酸都比盐酸更强，氢碘酸（HI）是这一组里最强的。

pKa 的局限在于它仍以水溶液中的解离为背景，遇到酸性远超纯硫酸的超酸时，其假设被打破，需要改用哈米特函数 H0。
