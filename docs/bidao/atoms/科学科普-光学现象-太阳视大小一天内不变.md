# 太阳视大小一天内不变

## 一句话定义

用同一台相机在同一位置拍摄日出与正午的太阳并叠加对比，两者大小基本相同，说明太阳的视大小在一天之内并不随高度变化。

## 详细说明

验证方法很直接：固定相机位置和焦距，在日出和中午各拍一张太阳照片，把两张照片叠在一起比较。毕导实测的结果是两者差不多大；网络上的日出日落延时摄影同样显示太阳大小一天内基本不变。

既然视大小不变，为什么人眼觉得日出太阳特别大？最著名的解释是艾宾浩斯错觉：周围参照物大，物体看着就小；参照物小，物体看着就大。日出时太阳贴近地平线，旁边有树、房子等小参照物衬托，显得大；升到高空后参照物变成整个天空，显得小。月亮在低空显得比高空大，也是同一类现象，专称「月亮错觉」。

这个结论直接推翻了「近大远小所以早上太阳近」的前提。值得注意的是，艾宾浩斯错觉一九零一年才被提出，春秋时期的小孩不可能知道，所以这个错误情有可原。
