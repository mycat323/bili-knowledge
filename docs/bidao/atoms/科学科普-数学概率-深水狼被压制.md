# 深水狼被压制

## 一句话定义

深水狼指夜里杀人、白天装好人完全不暴露的狼人打法，2016年东京大学论文证明好人存在策略可以压制这种怂狼。

## 详细说明

深水狼是狼人杀中的一种打法：晚上正常杀人，白天完全以好人身份发言，不悍跳、不主动带节奏，尽量让自己看起来像平民。大部分新手狼人实际上都在这样玩。

2016年东京大学毕笑憨的论文讨论了如何应对深水狼。论文结合 Epsilon Nash 均衡理论，经过复杂计算得出结论：深水狼策略并不好（strategy is not very good）。也就是说，好人一方存在某种策略，能够系统性地压制这种装傻的狼人。

这个结论对新手有直接指导意义：如果你拿到狼人牌又不自信，一味装好人、少说话，并不是安全的保命打法，反而会被好人的针对性策略识别和淘汰。想成长为高玩，悍跳是必须掌握的技能——高玩局里全场都是「预言家」，主动争夺话语权比被动隐藏更有效。
