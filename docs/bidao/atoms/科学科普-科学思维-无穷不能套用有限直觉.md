# 无穷不能套用有限直觉

## 一句话定义

花瓶悖论表明，把有限次操作中成立的「每次净增九个球」直接推广到无穷次操作，会得出与严格计算相反的结论。

## 详细说明

在有限次操作中，每次放入十个球、取出一个球，净增加九个球，这个推理完全正确。于是人们很自然地认为，无穷多次操作后瓶中的球数应该是「九倍无穷」，也就是无穷多个。

但严格计算给出的答案是零个球。矛盾出在哪里？出在把「无穷」当成一个普通的数来使用。有限次操作时，我们可以数清瓶里有多少球，也可以对球数做加减；而无穷次操作没有「最后一次」，瓶中的球数只能通过极限来定义。

这个思想实验的价值不在于花瓶本身，而在于提醒我们：凡是涉及无穷的过程，直觉和有限情形的算术规则都可能失效，必须回到严格的定义和计算。类似的悖论在数学史上多次出现，推动了极限与集合论的发展。
