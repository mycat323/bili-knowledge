# 游戏精炼度GR值

## 一句话定义

Game Refinement Theory 用游戏进行速度和结果不确定性算出一个 GR 值，GR 在零点零七到零点零八之间的游戏最令人兴奋。

## 详细说明

2017年凶硕等人详细探讨了狼人杀的配置问题，使用了一套叫 Game Refinement Theory（游戏精炼理论）的工具。该理论通过游戏的进行速度和结果的不确定性，计算出一个 GR 值，用来衡量游戏好不好玩。

研究认为，GR 值落在零点零七到零点零八之间的游戏最令人 excited（兴奋）。文章用大量推导得出的结论是：狼人杀里人太多的话就会很无聊。这个结论看似平平无奇，但 GR 值提供了一种把「好玩程度」量化的思路。

Game Refinement Theory 的创立者是该论文的通讯作者 Hiroki Iida。他原本是日本将棋七段选手，不满足于只会下棋，还想用下棋来发论文。2004年研究麻将时他提出了这套理论，此后把它套用到各种棋牌、球赛、贪吃蛇、抓娃娃、跳一跳、星际、炉石、刀塔、宝可梦、UNO、斗地主等游戏上，每套一个就发一篇论文，他也从将棋大师转型为日本游戏学术带头人。
