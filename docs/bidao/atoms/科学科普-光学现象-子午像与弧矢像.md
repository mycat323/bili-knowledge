# 子午像与弧矢像

## 一句话定义

水下物点经水面折射后形成的两个虚像：子午像由左右方向平面内的光线相交而成、更靠近人眼；弧矢像由上下方向平面内的光线相交而成、位于物点正上方。

## 详细说明

子午像和弧矢像本是光学专业教材中的概念，这里用来解释水中物体成像。

- 子午像：来自左右方向各个竖直平面内的光线，最终相交在离人眼更近的位置，像被横向拉长成一条短横线。
- 弧矢像：来自上下方向各个仰角平面内的光线，最终相交在物点的正上方，像被竖向拉长成一条短竖线。

眼睛位置改变时，子午像会沿焦散线前后移动，弧矢像会在物点上方升升降降。

为什么日常只看到一个像？因为眼睛、子午像、弧矢像永远排成一条直线，人眼看到的是两个像的叠加，只有用相机前后对焦才能分别捕捉。若放松眼睛实现虚焦，理论上可以同时看到两个像。

初中教材里有的画的是子午像，有的画的是弧矢像，也有的画法本身就是错的——这正是同一问题出现三种矛盾插图的原因。
