# 皱纹的跨尺度存在

## 一句话定义

皱纹从细胞内膜、大脑皮层、海蝓体表，到褶皱山脉、火星月球皱脊乃至中子星表面普遍存在，是不同尺度上压应力主导的同一类结构。

## 详细说明

皱纹并非只出现在汤膜和奶皮上，它在各个尺度上普遍存在：

- 微观：细胞内膜结构的起皱反映细胞的生命健康状态。
- 生物：大脑皮层皱纹丰富是人类智慧发达的象征；海蝓通过皱纹增大自身面积，盗取更多藻类中的叶绿体进行光合作用。
- 地质：大陆板块在漫长岁月里相互推动，压应力主导的造山运动形成褶皱山脉。喜马拉雅山是印度板块和欧亚板块挤压形成的褶皱，其下地壳至今仍被压缩，所以每年还能长高一厘米。
- 天体：火星和月球上的皱脊是滚烫熔岩冷却时产生压应力形成的几百公里长的皱纹；有研究表明中子星表面也会形成皱纹，星壳应力变化时产生约零点几毫米高的山脉，正是这零点几毫米的起伏造成的不对称性，让中子星旋转时放出引力波。

随着对皱纹规律的理解加深，人们开始尝试可控地让皱纹按需产生：制造更灵活的柔性机器人、控制石墨烯表面皱纹以获得特殊力学电学催化性能、用激光控制材料定向起皱、研究泡泡破裂时的表面皱纹等。
