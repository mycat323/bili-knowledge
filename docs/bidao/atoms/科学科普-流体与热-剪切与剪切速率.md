# 剪切与剪切速率

## 一句话定义

剪切是让流体相邻层发生相对滑移的一对方向相反、距离很近的力，搅拌、涂抹、挤牙膏都属于对流体施加剪切。

## 详细说明

剪切这个概念不直观，它和用剪刀剪纸很像：剪刀给纸一对距离很近、方向相反的力。

搅动流体时，玻璃棒带动相邻流体层向前运动，附近的流体层与它发生相对滑动，并由于粘度产生向后的阻力。这对力与剪刀剪纸非常像，因此搅拌、涂抹、挤牙膏这些让流体层间发生相对滑移的动作，就是剪切。

剪切速率描述的是这种相对滑移的快慢。牛顿流体的粘度不随剪切速率变化；非牛顿流体的粘度会随剪切速率变化，由此分出多种类型：

| 类型 | 例子 | 表现 |
| --- | --- | --- |
| 剪切变稠 | 玉米淀粉糊糊 | 本来很稀，一砸（剪切大）瞬间变稠 |
| 剪切变稀 | 番茄酱 | 本来很黏，一剪切就变稀 |
| 宾汉流体 | 牙膏 | 有临界屈服应力，力小像固体，力大才流动 |

此外还有触变、振凝等类型。近年来也有文献把牙膏归为卡松流体，可以理解为一种剪切变稀的宾汉流体。
