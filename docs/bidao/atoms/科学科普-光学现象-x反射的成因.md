# X反射的成因

## 一句话定义

大圆盘上的 X 并不是某种特殊反射，而是同心圆沟槽（车削痕迹）造成的镜面反射，被灯照亮的那条「直径」其实只是一段看起来比较直的复杂曲线。

## 详细说明

有 X 反射的圆盘有一个共性：圆里有圆，盘面上有无数细微的同心圆划痕沟槽，这往往是车削加工留下的痕迹。用光照没有沟槽的盘子就没有 X 反射，说明 X 反射由沟槽结构带来。

同心圆沟槽上每一点的沟槽方向，就是该点所在圆的切线方向，因此每一小段都遵循平行沟槽的反射规律。但同心圆沟槽比平行沟槽复杂：盘上每一点反射出的光锥大小和方向都不同。经过计算画出的反射亮线必过圆心，所以中间一段确实很像直径；把圆盘放大一点再看，完整的反射亮线根本不是直径，只是一条复杂曲线中比较直的一部分。

为什么平时看着像直径？家里的灯一般装在房顶，照到圆盘上的入射角很小，而入射角越小，这条曲线越接近直线。灯多，就会亮起多条像直径的线，加在一起就像个 X。如果灯离盘子较近、相对盘子较宽，亮线还会变宽，从一条线变成一个扇形。换个角度看盘子，就能看出圆盘上的反光是弯的。
