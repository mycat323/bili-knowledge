# 学术观点难以强行说服

## 一句话定义

熊才义试图发文澄清声音灭火机理被拒稿，说明在学术上强行说服持固有认识的同行相当困难。

## 详细说明

熊才义的论文发表后，审稿意见认为其工作把问题过分简化，甚至用 ridiculous 形容，作者据理辩驳但效果有限。他后来还试图发文章澄清自己的观点，但都被拒稿。

他本人的反思是：当时比较激愤，现在想想，在学术上希望把自己的观点强行说服别人相对比较难，尤其是如果别人也坚持做相似研究做了有一段时间，会有自己固有的认识。两三年过去，随着调职、写其他文章、做其他分析，他对这段研究的情绪也没有当时那么强烈了。

这一案例说明，科学中陷入盲区几十年是常有的事，而在某一瞬间有人云淡风轻地走出盲区也并不奇怪。
