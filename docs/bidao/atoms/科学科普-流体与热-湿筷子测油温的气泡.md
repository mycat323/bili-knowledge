# 湿筷子测油温的气泡

## 一句话定义

湿筷子插入热油时，筷上水分受热汽化形成气泡，气泡的细腻程度、密集程度和扩散速度随油温升高而变化，可据此判断三四成到七八成油温。

## 详细说明

把湿筷子插进油里会冒泡并发出炸裂声，这些气泡是筷子上的水受热变成水蒸气形成的。2022 年发表在 Physics of Fluids（影响因子 4.1）上的论文指出，水进入油中会产生三种形态的气泡：在表面直接炸开的爆炸型、向下伸长的拉长型、在油里不停变形的震荡型，三者相互配合，会把油溅到人身上。

湿筷子上水量少，气泡属于较稳定的震荡型，因此可以安全地用来检测油温：三四成油温时气泡细腻而小；五六成油温时气泡密集不断冒出；七八成油温时大颗气泡扩散越来越快。

作者建议测油温时不要用金属筷子，因为金属不沾水、不产生气泡。该论文的一、二、三作分别来自日本、印度和中国。
