# 麻将等待胡牌的概率修正

## 一句话定义

随着牌堆剩余张数减少，你要胡的牌被别人捏在手里的概率反而升高，一味等待往往等不来，该拆牌时就得拆。

## 详细说明

打麻将时常遇到这种情况：自己要胡的牌一张都没出来，等死也等不来。这本质上是概率算错了。

**例题**：假设你胡一万，桌上一张一万都没打，但有人碰了二万。二万被碰意味着一万成了孤零零的单牌，如果有人拿到单张一万，大概率会打出来。可桌面上依旧没人打一万，说明目前有人手里有单张一万的概率很低。

设牌堆还剩 65 张牌，四张一万随机分布在三位玩家和牌堆中，玩家出牌有出或不出两种情况。用贝叶斯方法求后验分布可得：

| 牌堆剩余 | 别人手里有两张以上一万的概率 |
| --- | --- |
| 65 张 | 约 47% |
| 39 张 | 约 67% |
| 26 张 | 将近 80% |

其中牌堆剩 65 张时，一万全在牌堆里的概率约 37%，别人手中有单张一万的概率只有约 16%。

结论是：随着牌堆数目减少，一万更有可能被别人捏死在手里。你在那傻等「怎么四张一万一张都不出来」，其实他们永远不会打出来。所以该拆牌时就得拆。
