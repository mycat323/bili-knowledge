# 卷绳效应的高度窗口

## 一句话定义

产生螺旋需要下落高度落在合适区间：太高液柱会在半空断裂，太低则螺旋无法维持，实验测得的最优高度约为十厘米。

## 详细说明

用冰淇淋模拟便便做控制变量实验，出料口离底座约二十厘米时，冰淇淋在半空中直接断裂，螺旋的期待当场幻灭。这说明要想产生螺旋，下落高度不能留得太充足，否则会先使下落未半而中道崩。

缩短高度后，原本竖直下落的冰淇淋突然卷了起来，在空中跌跌撞撞，触地之后盘旋而上，但仍呈现随机的扭动方向。继续缩短高度，卷速明显放缓，冰淇淋开启圆周运动，螺旋辗转，正是经典的便便造型。

实验表明，只有合适的高度才能产生完美的螺旋：太高，会达到钢体的洛西极限，导致便便被地球引力撕裂；太低也不好，拉一会它长高了，你可能会坐实上。实测的最优高度在十厘米左右。

现代马桶设计的局部地区高度在二十五厘米，太高了。要想拉出完美的螺旋，最好舍弃马桶，直接蹲地上。
