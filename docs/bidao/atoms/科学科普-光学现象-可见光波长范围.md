# 可见光波长范围

## 一句话定义

人眼能感知的电磁波波长约为四百纳米到七百六十纳米，这段电磁波被称为可见光，其余大部分太阳光被大气层拦截。

## 详细说明

牛顿最早发现光的颜色取决于光的频率，而不只是我们主观的叫法。太阳光本身包含连续的光谱分布，但大部分会被大气层拦截，真正到达并被人眼感知的只有约 400 nm 到 760 nm 这一段。

| 波段 | 大致颜色 |
| --- | --- |
| 约 400 nm 附近 | 紫/蓝 |
| 中间波段 | 绿 |
| 约 760 nm 附近 | 红 |

这段范围之外的红外、紫外等电磁波人眼无法直接看到。所以「苹果是红的」「铁烧热是红的」「脸红是红的」虽然都叫红，但它们对应的光谱成分并不必然相同。
