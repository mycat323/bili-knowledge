# 先预言再验证的研究路径

## 一句话定义

面对一个待解释的现象，先根据假说预言「应该观察到什么」，再用实验去验证预言，是区分竞争假说、避免事后附会的有效研究路径。

## 详细说明

干冰白雾的判定过程是这条路径的范例。面对「白雾来自空气水蒸气」和「白雾来自浸泡液体」两个竞争假说，先分别推出可观察的预言：

- 若来自空气：应看到无色透明的气泡升到水面，白雾在水面上方形成。
- 若来自液体：应看到气泡内部已充满白雾，到水面破裂才释放。

再用长试管做实验，直接观察气泡内部，结果支持第二种假说。后续更换液体（白酒、冰醋酸）和水温的对照实验，进一步给出方向性预言并逐一验证。

这种「先预言、再验证」的顺序，比先有结论再找证据更可靠，也能让一个看似幼稚的问题得到可检验的答案。干冰白雾问题从 1983 年的教材解释到 2015 年的完整机理，用了三十多年才走完这条路。
