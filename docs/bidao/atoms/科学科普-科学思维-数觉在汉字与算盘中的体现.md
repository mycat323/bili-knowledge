# 数觉在汉字与算盘中的体现

## 一句话定义

汉字一二三直接画道、罗马数字一二三用竖杠、算盘下珠不超过五颗，都是把数量控制在数觉可瞬间识别的范围内。

## 详细说明

数觉的界限在文化设计里留下了清晰的痕迹。

汉字方面：一二三就是画几道，非常直观，看到「三」字从来不用数三下才知道是三。但四和五不再是画道道，而是单独造字，说明古人造字时可能也发现从四往上画道道就数不清楚了。罗马数字异曲同工：一二三是竖着的杠，五是个 V，四还得靠五减一做个减法——罗马人宁肯算一下五减一等于四，也不愿意数四道杠。不过据懂甲骨文的李尤西老师介绍，甲骨文里四就是四横，五有一种写法就是五横，说明中国老祖宗数四横五横应该也挺快。

算盘方面：中国算盘下半部在古代是四颗珠子，现代是五颗珠子，要表示比五大的数就靠上半部进位，这样数珠子很快。如果上下连在一起用十进制，不仅要多用好多珠子，六七八九颗珠子一眼也数不清。俄罗斯的十进制算盘 shorty 则把最中间的两颗专门涂黑，用来方便数数。

麻将同理：条子筒子数字较大时都得靠颜色分组，否则容易数错。
