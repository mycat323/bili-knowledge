# 高折射率液体的放大极限

## 一句话定义

当液体折射率超过亚克力的1.49时，厚缸对液柱的放大不会突破缸的内径，而是止步于内径边界，外观与普通高折射率液体差别不大。

## 详细说明

验证这个问题卡在材料上：折射率比1.49还大的液体不多，而且大多不好惹。视频中列举的有苯、硝基苯、液溴、二硫化碳、一溴代萘、二碘甲烷，要么有毒，要么很贵，要么会腐蚀亚克力厚缸。

作者花380元买了50毫升宝石折射油，成分是一溴代萘，折射率1.64，把它倒进新买的厚缸。结果折射率再大也只是抵达厚缸的内径边界，视觉上和上一期用的土蜂蜜看着差不多，并没有把液柱放大到超过缸的内径。

结论是：液柱被放大的上限由缸的内径决定，也就是由亚克力的折射率1.49决定。液体折射率再往上加，只是让液柱一直撑到内径边界，不会继续变粗，因此外层缸壁始终还在视野里。

这个实验的实用价值在于给出了一个边界条件：想用厚缸做放大演示，选折射率接近但不超过1.49的液体，效果最接近极限。
