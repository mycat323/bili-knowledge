# 海岸线悖论

## 一句话定义

海岸线没有客观确定的长度，用越短的尺子测量，得到的数值越大，且永远不会收敛到一个固定值。

## 详细说明

在舟山群岛实测中，用一公里长的尺子量出海岸线约 5.42 公里，换成五百米的尺子得到 6.93 公里，换成两百米的尺子得到 8.62 公里，用一把小三角尺量了三天三夜，结果是一百二十点八七千米。尺子越小，测出的长度越大。

原因在于海岸线具有无限曲折的细节：看整个岛时只有大大的海湾，放大后出现小小的海湾，再放大还有大石头、小石头的轮廓。越想精确测量，就会涌现出越多之前被忽略的曲折。

这不同于圆或光滑曲线。圆的周长可以用一条条小线段逼近再求和，微积分能保证结果收敛；海岸线却处处不光滑，微积分方法失效。有论文统计，选择不同尺子，中国海岸线能测出从五千到一万五千公里的各种长度，而官方介绍的大陆海岸线是一万八千多公里。理论上，这种无限复杂的曲线长度是无限的。
