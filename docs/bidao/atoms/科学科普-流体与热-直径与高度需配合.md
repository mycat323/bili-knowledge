# 直径与高度需配合

## 一句话定义

便柱直径会影响螺旋状态：细柱在同样高度下容易断裂，需要降低下落高度才能回到舒适区绕出完美螺旋，粗细则可适当抬高。

## 详细说明

改变出口大小可以控制便柱的直径。粗翔出发，留下了浓墨重彩的一坨；紧随其后的是细翔，在同样的高度下，细翔却断了。调整高度、缩短距离后，细翔回到了舒适区，绕出了完美的螺旋。

可以看出，翔的粗细会影响螺旋的状态。经过实测可以得到一条对应关系：翔细，就降低下落高度，往下蹲一点；翔粗，就尽量撅着点。

综合三个因素，拉出完美螺旋的建议是：第一，下落高度控制在十厘米；第二，让它适当硬一点；第三，根据直径调整高度，随机应变。不同的人当然千变万化，但万变不离其宗，勤加练习就能找到最适合自己的方法。
