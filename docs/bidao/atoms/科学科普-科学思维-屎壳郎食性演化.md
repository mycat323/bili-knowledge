# 屎壳郎食性演化

## 一句话定义

屎壳郎祖先的主食是腐烂的枯枝落叶，粪便只算小零食；中生代脊椎动物变大变多、新鲜粪便俯拾皆是，才促使它们转向以粪便为主食。

## 详细说明

科学家认为，屎壳郎祖先的主食其实是腐烂的枯枝落叶，粪便也就算个小零食。到了中生代，脊椎动物们变高变大了，吃得好也拉得多，新鲜的便便俯拾皆是，屎壳郎们只能含泪享受大自然的馈赠。

这段演化史解释了一个常见疑问：屎壳郎把自己进化成天文学家，只是为了好好吃屎吗？答案是食物来源的转变先发生，导航能力等适应性特征随之被强化。

食性转变也带来了连锁影响。澳大利亚的案例说明，当地土著屎壳郎习惯了袋鼠干燥的颗粒屎，吃不惯牛马的大块软粪，于是牧场粪便堆积、生态堪忧。食性是否匹配，直接决定了一个地区能否靠本地屎壳郎完成粪便清理。
