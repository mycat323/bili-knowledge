# 挡板控制变量排除声波

## 一句话定义

在蜡烛与音响之间插入挡板，声音的频率和响度不变而火焰不再摆动，据此可判定灭火因素不是声波。

## 详细说明

熊才义 2021 年发表的论文用极简实验推翻了此前几十年的声音灭火机理研究。做法是：把蜡烛放在音响前，播放六十赫兹声音，火焰疯狂摆动；在蜡烛和音响中间放一块板子，火焰几乎不动；拿开板子，火焰又动。

关键在于：一块小板子挡不住声音，人耳听到的声音几乎没有变化，蜡烛接收到的频率和响度也都没有变化。既然加板子后声音没变、火焰却从动到不动，根据控制变量法，熄灭火焰的根本不是声音，而是被板子挡住的某个东西——风。

论文正文只有四页三张图。审稿意见认为该工作把问题过分简化，甚至用了 ridiculous 一词，作者据理辩驳但效果有限，后来试图发文章澄清观点也被拒稿。
