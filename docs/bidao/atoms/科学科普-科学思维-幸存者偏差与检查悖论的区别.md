# 幸存者偏差与检查悖论的区别

## 一句话定义

等车总比预期久不是幸存者偏差，而是检查悖论；前者是只记住坏结果，后者是抽样方式本身系统性偏向大群体。

## 详细说明

面对「等车总比预期久」，常见的解释是幸存者偏差：你只记得运气差时吐槽，一分钟就上车时不会发朋友圈庆祝。

但视频明确指出这不是幸存者偏差，而是等待时间悖论，其本质是检查悖论。两者的区别在于：

- 幸存者偏差：样本被筛选，只留下「幸存」或「倒霉」的那部分，是记忆与记录的选择性；
- 检查悖论：抽样方式本身有偏，即使你客观、完整地记录，样本仍会系统性偏向规模更大的群体。

等车时，你是在用自己的时间去感受公交车的平均到站时间，因此有更大概率落入占据时间更长的慢车区间。这不是记错了，而是采样机制决定的必然结果。

区分二者有实际意义：如果误判为幸存者偏差，就会以为「多记几次好运气」能解决问题；而检查悖论说明，只要抽样单位与观测对象不匹配，偏差就无法靠调整心态消除。
