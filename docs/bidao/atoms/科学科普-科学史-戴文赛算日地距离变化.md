# 戴文赛算日地距离变化

## 一句话定义

一九五四年，新中国天文学奠基人之一戴文赛在论文《太阳与观测者距离在一日内的变化》中，完整计算了太阳在一天内与观测者距离的变化，是这一问题的先行者。

## 详细说明

毕导在视频中说明，自己并非第一个认真计算这个问题的人。一九五四年，新中国天文学的奠基人之一戴文赛先生发表《太阳与观测者距离在一日内的变化》一文，不厌其烦地算完了一天内太阳与观测者距离的变化。

毕导认为，老教授算这个并不是因为问题有多大学术意义，而是因为《两小儿辩日》作为六年级课本中的经典故事，对中国人有特殊的情感价值。

一个巧合是：尽管每年「中午太阳更远」的具体日期都不太一样，但二零二五年与戴先生所计算的一九五四年，这个日期完全一致。毕导把视频献给戴先生，也献给所有对世界充满热情与好奇的大小孩子们。
