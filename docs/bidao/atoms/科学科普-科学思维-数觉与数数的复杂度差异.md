# 数觉与数数的复杂度差异

## 一句话定义

数数需要注意力逐个遍历物体，复杂度为 O(n)；数觉不转移注意力、直接给出结果，复杂度为 O(1)。

## 详细说明

把两种能力翻译成程序员的语言，差别非常直观。

数数的流程是：注意力先放在第一个物体上，在脑海里数一；再把注意力转移到下一个物体上数二；一直重复这个过程。这相当于用了一个循环遍历所有元素，程序运行的复杂度是 O(n)——物体越多，耗时越长。

数觉的特殊之处在于，脑子里完全没有注意力从一个物体转移到另一个物体的过程，而是用直觉直接给出结果，复杂度顿时降为 O(1)。这是码农梦想中的算法。

这个差异也解释了一个常见现象：当物体超过五个时，人经常会先把它分割成五个以下，再用数觉计数。比如看七筒，很多人并不是数出一二三四五六七，而是在脑中瞬间聚类成上三下四，再算三加四等于七。麻将里条子筒子数字较大时靠颜色分组，也是同样的策略。
