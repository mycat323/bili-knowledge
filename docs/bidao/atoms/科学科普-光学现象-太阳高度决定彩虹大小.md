# 太阳高度决定彩虹大小

## 一句话定义

太阳高度越低，观察者看到的彩虹越大，因此彩虹往往出现在傍晚太阳下山之前，高纬度地区理论上更容易看到彩虹。

## 详细说明

太阳高度越低，看到的彩虹就越大。所以彩虹往往出现在傍晚太阳下山之前。

按这个逻辑，东北比海南更容易看到彩虹：东北中午太阳也没多高，理论上就有更多机会看到彩虹。

这也解释了周杰伦在台湾唱「哪里有彩虹告诉我」的困境——按这个理论，得去东北找。
