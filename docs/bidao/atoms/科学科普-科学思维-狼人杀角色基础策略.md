# 狼人杀角色基础策略

预言家应上警并留警徽流，平民要主动发言不划水，狼人不自信时把悍跳交给队友本色出演，女巫解药毒药大胆用。

## 详细说明

预言家：拿到预言家不用紧张，本质是工具人。公开身份竞选警长，验两轮人，留好警徽流。最怕预言家玩潜伏，狼人不刀你，队友也要削你。预言家一定要上警，这样才能利用警徽流在只活两轮的情况下打出活三四轮的效果。
