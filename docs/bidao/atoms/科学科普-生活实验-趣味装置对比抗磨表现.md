# 趣味装置对比抗磨表现

## 一句话定义

用人力踩踏驱动两组真实引擎缸体做活塞运动，一组加美孚速霸、一组加参比油，直观对比两者的抗磨表现。

## 详细说明

这个趣味装置把抽象的机油抗磨性能变成可以看见的对比实验。

装置结构大致是：人用双脚踩踏提供动力，动力通过连接轴传送，驱动两组真实的引擎缸体进行活塞运动。两组缸体分别加入不同的油：一组加入美孚速霸，另一组加入同类别参比油。

实验的逻辑是控制变量：两组缸体结构相同、运动方式相同、动力来源相同，唯一差别是所加的油不同。这样活塞运动的顺畅程度、磨损表现的差异，就归因到油的抗磨性能上。

视频中先以较轻的骑行量（如三十公里）进行初步对比，观察两组缸体在活塞运动中的表现差异。这种装置的价值在于把「抗磨」这个通常只能靠长期使用才能体现的指标，压缩成短时间内可观察的对比现象。
