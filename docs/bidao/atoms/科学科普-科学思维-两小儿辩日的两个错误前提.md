# 两小儿辩日的两个错误前提

## 一句话定义

两小儿辩日中「近大远小」和「离热源近就更热」两个推理前提都不成立：太阳在一天内视大小基本不变，而太阳光近似平行光，距离微变不改变地面接收的能量。

## 详细说明

第一个小孩认为日出太阳大所以早上近。毕导用同一台相机、同一位置在日出和中午各拍一张太阳照片叠合对比，发现两者大小差不多；网上的日出日落延时摄影也显示太阳大小在一天内基本不变。所以「日出太阳更大」这个前提本身就是错的。

第二个小孩认为早上冷、中午热，所以中午离太阳近。但太阳与火不同：火苗向四面八方发光，离火越远光线越稀疏，单位面积能量越少；而太阳离地球太远，照到地球的光几乎是平行光，地球离太阳稍近稍远，接收到的光线能量没有区别。影响冷热的主要因素是太阳光的角度：日出时斜射地面，能量分散在大片区域，所以冷；中午更接近直射，能量聚在小片区域，所以热。此外日出时光线在大气层中走的路程更长，热量被大气层吸收更多。
