# 手机膜气泡消不掉

## 一句话定义

平整手机膜的高斯曲率为零，气泡处高斯曲率大于零，刮膜是等距变换，因此气泡无论怎么刮都无法消除。

## 详细说明

手机膜起泡后，很多人反复刮却怎么也刮不平，常怀疑是自己手法不对。真正的原因是几何约束。

平整手机膜是平面，高斯曲率为零；气泡是鼓起的曲面，高斯曲率大于零。刮膜的过程只是让膜在平面上滑动、弯折，属于等距变换，而等距变换不改变高斯曲率。曲率不同的两种状态无法互相转化，所以气泡永远消不掉。

同样的道理适用于贴膏药：膏药是高斯曲率为零的矩形，膝盖表面高斯曲率不为零，因此膏药贴膝盖必然起褶子，无法完美贴合；而肩、背、腿等部位表面近似高斯曲率为零，贴上去就比较平整美观。

这类现象说明，日常生活中的贴合问题往往不是手艺问题，而是曲面几何的必然结果。
