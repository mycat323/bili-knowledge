# 危险化学品实验的法律限制

## 一句话定义

水银、浓硝酸、浓盐酸、浓硫酸等受管制的危险化学品，个人购买或储存会面临罚款乃至刑事处罚，很多演示实验因此无法在家里完成。

## 详细说明

视频里想做却做不了的两个实验，都卡在材料上。

- 水银：属于危险化学品，个人不可购买。视频中称个人购买处五千元以下罚款，并可按刑法第一百二十五条追究非法买卖危险物质罪，还以玩笑口吻说最高可判死刑。
- 强酸：浓硫酸、浓盐酸属于易制毒化学品，浓硝酸属于易制爆化学品，各地购买和储存需实名，视频中同样以玩笑口吻说情节严重的也可以重判。
- 高折射率液体：苯、硝基苯、液溴、二硫化碳、一溴代萘、二碘甲烷，要么有毒，要么很贵，要么会腐蚀亚克力厚缸。

面对这些限制，视频给出的处理方式不是硬做，而是换路：用理论分析给出预测，再用安全可得的替代现象做旁证。比如用干冰白雾代替有色气体，验证折射率接近1的介质在厚缸里不会被放大；用能合法买到的宝石折射油（一溴代萘）代表高折射率液体。

判断一个实验能不能做，除了「做得到吗」，还要问「原料合法吗、容器受不受得了」。
