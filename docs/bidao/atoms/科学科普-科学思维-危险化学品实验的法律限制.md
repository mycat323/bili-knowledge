# 危险化学品实验的法律限制

## 一句话定义

强酸、超酸等危险化学品的获取与实验受法律严格限制，个人不应自行尝试视频中演示的腐蚀性实验。

## 详细说明

视频里出现的浓硫酸、氢氟酸、高氯酸、发烟硫酸、氟锑酸等，都属于强腐蚀性或剧毒的危险化学品。氢氟酸滴到手上会渗入皮肤、剧毒入骨；高氯酸、发烟硫酸与金属或有机物接触可能剧烈反应甚至爆炸。

这些物质的购买、储存和使用在多数国家和地区都受到法律与资质限制，个人不具备防护条件时自行实验，风险远大于科普收益。

观看这类科普内容时，应把「知道它有多强」和「动手去试」分开：理解酸性强弱体系靠的是 pKa、H0 这些概念，而不是亲自接触试剂。
