# 电池技术是科技发展瓶颈

## 一句话定义

电池无法安全大量存储电能，这一局限使电池技术被普遍认为是当今科技发展最大的瓶颈。

## 详细说明

尽管锂电池之父 Goodenough 获得了诺贝尔奖，人们仍普遍认为电池技术已经成为当今科技发展最大的瓶颈。核心局限是：电无法安全地大量存储。

这个瓶颈在电动车上表现得最清楚：想续航长就多装电池，车更重、耗能更大，耗能更大又要多装电池，形成恶性循环。只有能量密度更大的新电池材料出现，才能打破僵局。

视频还指出，将有限空间全部塞满电池虽然能获得更长续航，但代价是牺牲控制系统空间、压缩车内空间。所以真正的出路不只是堆电池，而是电芯材料、电池组封装和电池管理技术的综合进步。宝马 iX3 的例子展示了这种思路：可靠电芯、模块化电池组、智能电池管理技术三者配合，才称得上可靠安全的电动车。
