# 微距镜头放大倍率

## 一句话定义

超级微距镜头可以把被摄物体在画面上放大到实际尺寸的数倍，本次拍摄中螃蟹被放大到约五倍。

## 详细说明

团队带来的第三件设备是超级微距镜头，此前用它拍过微缩景观、显微摄影以及蚜虫生长等题材。

本次拍摄对象是一只螃蟹（团队称「蟹哥」），现场说明放大倍率为**五倍**，即画面上的成像尺寸约为实际物体的五倍。

微距拍摄的观察细节：

- 螃蟹的眼睛在五倍放大下呈现出类似马赛克的纹理。
- 团队还拍了筷子伸入水中的画面：木头结构疏松，气泡要产生必须找到粗糙的点，所以筷子一伸进去就出现很多气泡。

微距镜头的价值在于把肉眼无法分辨的表面结构呈现出来，与高速摄影解决「时间太快看不清」相对，微距解决的是「物体太小看不清」。团队强调设备本身只是工具，「最终还是看你能用来干嘛」。
