# 杀人游戏随机最优策略

## 一句话定义

在狼人杀简化版杀人游戏中，杀手夜间随机杀、白天玩家随机投票，是双方在博弈论意义上的最优策略。

## 详细说明

2008 年 Braverman 等人从理论上证明，杀人游戏里杀手夜里随机杀人、白天大家随机投票，就是双方的最优策略。

这意味着：无论你发言多么卖力、逻辑多么缜密，在纯策略层面都无法比随机获得更高收益。视频里用一句顺口溜总结：「拼命发言猛如虎，全票推你气鼓鼓，两眼一闭随机打，高玩也成二百五。」

对小白来说，这条结论的实际意义是：你哪怕煽不动别人，至少可以做到「我不听我不听」，不被他人的发言带偏，也是一种策略。

需要注意的是，这个结论针对的是简化版杀人游戏（只有狼人和平民两个身份），并不直接等同于完整狼人杀（含预言家、女巫等技能角色）的结论。
