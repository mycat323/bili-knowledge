# 两千到四千赫兹刺耳

## 一句话定义

让人本能觉得尖锐难受的声音多集中在两千到四千赫兹，粘滑声常落入这个区间；更高的六千赫兹反而只像水烧开的哨音，不会令人头皮发麻。

## 详细说明

视频指出，人类觉得尖锐难受的声音频率往往在 **2000~4000 Hz**，而粘滑声经常落在这个区间，所以拖桌椅、篮球鞋、指甲划黑板才会让人起鸡皮疙瘩。

对比实验式的观察：

- 2000~4000 Hz：背后发凉、头皮发麻；
- 约 6000 Hz：只会觉得「谁家水烧开了」，不难受。

也就是说，刺耳感不是音量问题，而是特定频段触发了人的本能反应。这为后面「进化假说」提供了频率上的对应关系。
