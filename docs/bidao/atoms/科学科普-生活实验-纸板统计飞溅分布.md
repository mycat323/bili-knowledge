# 纸板统计飞溅分布

## 一句话定义

在烧杯下铺硬纸板，通过统计纸板上水点的分布来定量表征射流飞溅强度的方法。

## 详细说明

为了安全地研究往开水里尿尿的飞溅问题，视频设计了一个可复现的实验方案：用装满约四十度温水的水准瓶作为膀胱模拟器，向烧杯中释放射流，烧杯底下铺一张硬纸板，最终统计纸板上的水点分布来表征飞溅强度。

实验结果显示，飞溅的水花大致呈现二维正态分布，纸板边缘相对安全。换成持续沸腾的开水后，纸板中间被溅湿一片，对比明显。

这个方法的优点是：不直接接触高温液体，通过水点分布间接量化飞溅范围与强度，适合家庭或教学场景复现。注意实验时仍需远离沸腾液体，避免烫伤。
