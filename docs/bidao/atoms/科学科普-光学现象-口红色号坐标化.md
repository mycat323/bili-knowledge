# 口红色号坐标化

## 一句话定义

把口红的颜色对应到 CIE 色度图上，就能用一组坐标代替番茄色、南瓜色、砖红色等容易产生歧义的名称，从而精确区分口红色号。

## 详细说明

日常描述口红用的是番茄色、南瓜色、砖红色、吃土色、想你色、斩男色这类词，问题在于同一个词指向的对象并不唯一：番茄可以是平谷一号番茄、宁夏高原番茄或千禧小番茄，南瓜可以是板栗南瓜、贝贝南瓜或普通老南瓜。

把大热口红色号对应到 CIE 色度图上之后，每个色号就有一组明确坐标，不再产生分歧。视频中给出的例子包括：某支口红对应坐标零点五四、零点二五；某人旧发色坐标零点六一、零点二八，新发色坐标零点六四、零点三零。

这套方法的意义在于：直男眼中的口红是「涂了没涂」的是非题，而坐标把口红变成了可查询、可比较的数据库。
