# 圆柱容器贴壁放大

## 一句话定义

圆柱形容器中的物体只有完全贴紧内壁、排净空气层时才会被放大，未贴紧时无论容器壁多厚都不产生放大效果。

## 详细说明

把火腿肠塞进内径相同的厚壁试管，只要火腿肠与管壁之间残留哪怕几微米厚的空气缝，粗细看起来就完全不变；而一旦某处贴紧内壁，该处就突然变粗，仿佛穿透玻璃壁充满试管外缘。同一根火腿肠上可以同时出现放大与不放大两种状态。

原因是光路发生了突变：物体与内壁之间有空气时，光线要经过内壁、外壁两次折射，反向延长后像几乎落在物体旁边，粗细不变；完全贴紧后空气层消失，光不再在玻璃内壁折射，两次折射变成一次折射，像的位置陡然外移，物体看起来就变粗了。

能否贴紧取决于材料：水、气球、指纹、化妆品料体柔软，能真正排净空气；沙子、餐巾纸、带皮火腿肠很难在微观上贴紧。至于空气层薄到多少才算贴紧，视频中没有查到明确结论，只是猜想在亚波长量级（如四分之一波长以下），此时界面附近的折射可能已不能简单用几何光学解释。
