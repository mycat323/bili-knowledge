# 染发褪色露出黄色本色

## 一句话定义

头发本身含黑色和偏红黄色色素，染发先漂浅黑色露出黄色底色，染发剂色素随水洗日晒流失后又露出黄色。

## 详细说明

头发里本来就有黑色和偏红黄色的色素。托尼老师染发的第一步是把黑色漂浅，头发的本色就从黑色变成黄色。

染完新发色后，随着水洗和日晒，染发剂的色素慢慢流失，又露出当前头发的本色，也就是黄色。所以无论花多少钱染的神仙发色，褪色后一律是黄毛。

这个案例说明「变黄」不一定是氧化，也可能是外加色素被去除后底色暴露。判断一个变黄现象属于哪类机制，要看黄色是新生成了还是原本就在。
