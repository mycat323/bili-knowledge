# 干冰白雾的形成机理

## 一句话定义

干冰先升华出冷而干燥的二氧化碳气膜，水向气膜内蒸发，水蒸气遇冷凝结成小水滴形成白雾，气泡不断把白雾带到水面释放，循环产生浓雾。

## 详细说明

完整机理分三步：

1. 干冰在水中升华，形成一层紧贴干冰、极其寒冷的二氧化碳气膜。
2. 这层气膜是纯二氧化碳，对周围的水而言完全干燥，水的饱和蒸气压远高于气膜内的水蒸气分压，水蒸气便向气膜内部快速蒸发。
3. 进入气膜的水蒸气紧贴极冷的干冰，瞬间冷凝成小水滴，形成白雾，被上升的二氧化碳泡泡一波带走，到水面释放。

气泡带走白雾后，水又向新生成的气泡里蒸发，如此循环，所以在水中产生白雾的效率极高。而在空气中，干冰只能被动等待大气中极少量的水蒸气靠近冷凝，因此只有一丝丝白雾。

这套解释对应的是「干冰泡在液体里冒浓雾」这种现象，教材的错误在于把它套用到了「干冰在空气中」的配图上。
