# 绳子长度与打结概率

## 一句话定义

物理学家道格拉斯·史密斯2007年用旋转盒实验发现，46厘米以下的绳子不易打结，长度增至150厘米时打结概率急剧上升，之后稳定在约50%。

## 详细说明

物理学家道格拉斯·史密斯在2007年研究了绳子打结问题，并获得搞笑诺贝尔奖。他把不同长度、不同软硬的绳子装在透明盒子里，用各种速度旋转盒子，进行了三千多次实验。

实验的主要结论：

| 变量 | 结果 |
| --- | --- |
| 绳子软硬 | 软的绳子更容易打结，粗硬的线很难打结 |
| 绳子长度 | 46厘米以下不容易打结 |
| 长度增加 | 从46厘米增加到150厘米，打结概率急剧上升 |
| 长度超过1.5米 | 打结概率基本稳定在约50% |

耳机线长度通常正好是1.5米左右，按这个规律属于「天选之线」，不打结反而奇怪。实验还证明，绳子在狭小空间内的打结概率会显著降低，这为防打结提供了思路。
