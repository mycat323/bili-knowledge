# 纠错码与高维球密堆积

## 一句话定义

把数据重复多份并取多数即可实现自动纠错，更复杂的纠错码可把消息视为高维空间中的球心，用高维球密堆积理论判定并纠正误差。

## 详细说明

数据在保存和传输中可能因光盘划伤或网络故障而损坏，需要让计算机自动纠错。

最简单的办法是重复存储：把每组数据存三份，三个数据不一样时以两份一样的为准。比如约定发一一一表示接受、发零零零表示拒绝，收到一零一就可以判断对方本想发一一一，只是手抖打错一位。约定五位数时容错能力更强，即使收到一零一零一，仍能判断出对方愿意看电影，只是该提醒他治治手抖。

我国兵哥哥喊话用「幺两三四五六拐八」代替普通话数字，在噪音环境中鲁棒性更好：喊「詹姆斯邦德零零七」可能被误听成「零零一」，喊「洞洞拐」就不容易错。

更复杂的消息可以应用高维空间球密堆积理论：把包含一百个数据的消息视为一百维空间的一个球心，每个分坐标是一个数据；传输误差使数据偏移到以初始坐标为球心、误差为半径的高维球内，接收方只要判定数据落在一定范围内，就把它纠正回球心。高维空间密堆积的球占体积比例更小，容错率更高，但也会带来数据分布太稀疏的问题。可检索维度之咒、汉明码等关键词进一步了解。
