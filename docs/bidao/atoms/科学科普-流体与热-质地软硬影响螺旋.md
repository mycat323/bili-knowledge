# 质地软硬影响螺旋

## 一句话定义

相同下落高度下，流体越软坨子越小、螺旋成型快但塌得也快；越硬坨子越大、成型后更持久，但过硬可能把自己撑起来。

## 详细说明

用调配的软翔从十厘米下落，只见它飞流直下，对着盘子狂轰滥炸，然而坨子始终软软趴趴，上面一停，下面的螺旋结构也随之崩塌。把软翔冷冻一段时间得到硬翔，下落时印象淡定从容、稳扎稳打，在盘子之上聚沙成塔，坚如磐石。

由此可以总结质地与螺旋的关系：相同高度下，翔越软，坨子越小，螺旋成型快，但塌得也快；翔越硬，坨子越大，成型后更加持久。是想要转瞬即逝的绚烂，还是一坨永流传的心安，全凭选择。

但也不要追求理想刚性，过硬可能会把自己撑起来。

质地的控制方法可以来自观众的经验分享。这一因素与下落高度、直径共同决定螺旋的最终形态，三者需要配合调整。
