# 声音灭火机理的百年误判

## 一句话定义

从一八五七年丁达尔记录声音灭火现象起，科学家提出十几种机理却始终没有定论，直到二零二一年熊才义证明声音本身灭不了火，能灭火的是音响振膜产生的风。

## 详细说明

声音灭火的研究史是一条典型的科学盲区之路：

- 一八五七年，爱尔兰科学家丁达尔率先发现并记录声音能灭火的现象。
- 一九零五年，德国物理学家鲁本斯发明鲁本斯管，演示声音可以影响火焰大小。
- 一九二六年，美国人凯洛格向消防员表演口技模仿鸟叫熄灭火焰。
- 此后科学家们争先恐后研究原理，甚至畅想用大喇叭扑灭森林火灾。

问题在于，这些研究的实验装置都非常简单——摆个音响、照个筒子、汇聚声音、点个蜡烛、播放声音、熄灭蜡烛、提出理论，就可以发论文。十篇文献能提出十种机理：有人说声波是纵波，空气微粒前后振动带动火焰振动导致不稳定；有人说火焰分子吸收声能转化为动能，火焰离开烛芯导致石蜡蒸汽跟不上；有人说热火焰被震到一边，冷蜡蒸气温度达不到着火点。百家争鸣，却没人验证过这些机理是否成立。

二零二一年，香港理工大学博士后熊才义以第一作者发表论文，正文只有四页三张图，用一块挡板证明灭火的根本不是声音。审稿人一度认为论文过于简化、甚至用 ridiculous 形容，他据理辩驳后仍坚持发表。后来他试图再发文章澄清观点却被拒稿，多年后他已是华南理工大学副教授，研究方向仍是火。这段历史提醒我们：陷入盲区几十年是科学中常有的事，而有人云淡风轻地走出盲区也并不奇怪。
