# 斑马黑底白纹

## 一句话定义

斑马是黑底白纹的动物，斑马宝宝刚出生时全身是黑的，在妈妈肚子里慢慢长出条纹状的黑色素缺失，没长好的小斑马就是一匹小黑马。

## 详细说明

斑马到底是白底黑纹还是黑底白纹？答案是黑底白纹。

斑马宝宝刚开始就是全黑的，在妈妈肚子里慢慢长出了条纹状的黑色素缺失，没长好的小斑马就是一匹小黑马的样子。所以斑马的白色条纹本质上是黑色素缺失的区域，底色是黑色。

这与猫猫狗狗的着色过程形成对比：很多猫猫狗狗身上有颜色，但肚子是全白的，这是因为色素细胞从它们背上的脊柱位置开始往下长，长到哪算哪，没墨了就停，经常长到肚子就没墨了。这个过程就像拿着盆墨水往背上一泼，颜色染到哪全看缘分。而斑马条纹则是规整的黑色素缺失图案，属于图灵斑图机制塑造的复杂而规整的斑纹。
