# 水本身带蓝色

## 一句话定义

水并非无色透明，它本身带一点蓝色，只是少量水看不出来，水量越大蓝色越明显。

## 详细说明

从小我们学的是水无色透明，但把浴缸放满水后会发现整缸水呈浅蓝色，而从缸里舀出一杯水又变回无色。

这说明水本身就有一点点蓝色，只是一杯水太少，蓝色淡到看不出来；水越多，光穿过的水层越厚，蓝色就越明显。大海更蓝，深海甚至蓝得发黑，就像那桶厚油层一样。

如果去打一份水的可见光吸收光谱，会发现水吸收红黄光，所以它本来就是蓝色的。

这个现象和可乐、香油、咖啡随厚度变色是同一类规律：液体的观感取决于光穿过的厚度，而不是液体「本来是什么颜色」这么简单。
