# 两小儿辩日的最终答案

## 一句话定义

综合自转、公转、其他天体引力扰动和地球轨道进动后，两小儿辩日的答案是：在大雪前的一两天到谷雨前的四五天，中午的太阳更远；其余时间是早上的太阳更远。

## 详细说明

毕导把答案分成几层递进：

第一层：日地距离一点五亿千米，早上到中午的变化可忽略，基本一样远。

第二层：地球自转使人从晨昏线转到正对太阳，半个白天靠近约一个地球半径（几千公里）。

第三层：地球公转轨道是椭圆，一月到七月公转在远离太阳，可能与自转的靠近抵消，具体日期需计算。

第四层：公转还受月球和太阳系其他行星引力影响，每年日子会有几天偏差。

第五层：地球轨道在进动，近日点日期每年晚二十多分钟。孔子时代距今约两千五百年，那时近日点在十一月二十号，比现在早四十三天，所以孔子围观两小儿辩日时，十二月六号到四月十六号是中午的太阳更近。

最终换算成二十四节气：在大雪前的一两天到谷雨前的四五天，是中午的太阳更远；剩下的时间是早上的太阳更远。
