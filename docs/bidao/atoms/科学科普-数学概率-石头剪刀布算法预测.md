# 石头剪刀布算法预测

## 一句话定义

利用人类玩家强烈的马尔可夫性，算法通过统计历史对局中相邻轮次的条件概率来预测下一手，对人类的胜率可超过 70%。

## 详细说明

Kaggle 曾举办石头剪刀布算法大赛，超过 1600 支队伍参加，前五名奖品是 T 恤和杯子。基础算法包括复制你的上一轮、克制你的上一轮、反克制你的上一轮，本质是判断「这波我在第几层」。

稍复杂的算法使用马尔可夫决策过程，考虑对手相邻轮次选择的条件概率。例如你可能出完石头后更大概率换成剪刀而不是布；大部分人在连出两个一样的手势后会想变一变。这种条件概率特征很容易统计出来。

马尔可夫性指一个随机过程未来状态的条件概率分布仅依赖于现在的状态。人类玩家往往具有非常强的马尔可夫性，因为多数人只根据当前这轮结果决定下一轮出什么，而记不住更早的历史。计算机则能完整记住历史对局，匹配历史序列即可预测下一手。

这类基于数据集的算法打得越多胜率越高，对人类的胜率应该都能超过 70%。最终第一名用的是基于多步超前法构造的多智能体狄利克雷分布采样算法。
