# 沙子加水增强强度

## 一句话定义

沙子颗粒间的水会形成毛细管桥，像胶水一样把颗粒拉在一起，使沙堆能突破休止角限制、垒出垂直沙柱。

## 详细说明

干沙子只能堆成一个堆堆，堆面与水平面的最大夹角叫休止角，干沙的休止角只有三十几度，所以单用沙子垒墙顶多堆个坟头。沙子是亲水材料，加水后水填补到颗粒空隙中，形成大量毛细管桥，把沙粒彼此拉住，强度大幅提升。有科研人员研究沙柱最大高度 h 与底座半径 r 的三分之二次方成正比。垒沙堡的最佳沙水比约为八比一。古埃及壁画中有人往驮运石像的沙橇前方沙土泼水，二零一四年有科学家指出这正是利用少量水增强沙土强度的早期实践，百分之几的水还能让沙面动摩擦系数大幅下降。
