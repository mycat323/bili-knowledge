# 图灵斑图与生物条纹

## 一句话定义

图灵斑图机制不仅解释动物斑纹，也存在于人体结构中，如手指分叉、指纹和上颚褶皱，分别由不同的激活剂与抑制剂基因组合形成。

## 详细说明

图灵斑图并非只存在于斑马、猎豹、老虎等动物身上，人体中也有它的踪迹。

- **手指分叉**：小老鼠用图灵机制产生条纹，再靠 Hox 基因控制缩放长出小爪子，人类也差不多。
- **指纹**：靠 EDAR、WNT 两种激活剂和拮抗 BMP 作为抑制剂，三种基因形成图灵斑图。
- **上颚褶皱**：卷起舌头舔一舔上颚，会感受到整齐的褶皱，这是纤维细胞生长因子和 SHH 基因的功劳。

所以身上没有好看的条纹不必烦恼，只是对它们的存太习以为常了。动物斑纹方面，猫猫狗狗的颜色可以轻松染上，因为色素细胞从背上脊柱位置开始往下长，长到哪算哪，没墨了就停，经常长到肚子就没墨了。但简单如豹子的斑点和老虎的条纹，大自然也懒得一笔一笔画上去，它们的基因并不会精准控制哪里长出一个斑点，而是用图灵斑图这一统一规则，大自然唯一需要做的就是对不同生物调一波参数。
