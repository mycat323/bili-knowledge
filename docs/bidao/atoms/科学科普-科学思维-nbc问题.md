# NBC问题

## 一句话定义

NBC 是 Nobody cares 的缩写，指那些看起来神奇、但没有明显科学价值、因此没人研究过的问题，作者认为科学的美有时就藏在这类缝隙里。

## 详细说明

作者做科普多年，以前都是把学到的好玩知识分享给大家，但最近常遇到一些自己觉得很神奇、却没什么科学价值、所以没人研究过的问题，内部把这种问题叫 NBC 问题，即 Nobody cares。

作者对做实验研究 NBC 问题很着迷。厚缸放大现象就是典型：它无非是初中光的折射就能解释的问题，科学上很平凡，但亲眼看到时仍然带来巨大的快乐。

作者打算把这个现象整理成一篇科学教育类的小论文投稿，并预判大概率会被审稿人说太简单。

这个概念的启发是：选题价值不一定要用「有没有人研究过」来衡量，一个没人关心的小缝隙里也可能藏着让人惊喜的规律。
