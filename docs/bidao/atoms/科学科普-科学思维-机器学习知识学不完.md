# 机器学习知识学不完

## 一句话定义

机器学习、深度学习中的每个算法都深不可测，不可能全部学完，只能找到自己的目标，用梯度下降法尽快逼近目标。

## 详细说明

毕导把读博的学习比作一座大海，指出机器学习、深度学习里每个算法都深不可测，你不可能全部学完。

应对方式是：努力找到自己的目标，然后努力用梯度下降法尽快去逼近你的目标。这里借用梯度下降的比喻，强调学习不是穷尽所有知识，而是朝着一个明确目标持续迭代逼近。

他同时承认现实困难：大部分时候你并不知道梯度下降的方向在哪，不知道怎样才能少做无用功。此时的办法就是多问——他组里的同学没少被他烦。以前他在学校是这些同学的辅导员，现在组里他们都是他大哥，平时出了 bug 大哥们都热情帮忙解决。
