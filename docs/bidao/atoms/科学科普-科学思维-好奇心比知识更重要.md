# 好奇心比知识更重要

## 一句话定义

两小儿虽然结论都错，但他们主动观察、推理、质疑；孔子可能是当时全中国最渊博的人之一，却压根没想过这个问题，在对世界的好奇心上反而不如两小儿。

## 详细说明

《两小儿辩日》的结局是「孔子不能决也」，两小儿反问「孰为汝多知乎」。毕导指出，这个故事真正想教给我们的不是谁对谁错，而是：尽管两小儿都错了，但他们在辩日——他们观察现象、逻辑推理、大胆质疑、追求真理，一个从几何角度想，一个从物理角度想。

相比之下，孔子可能是当时全中国最渊博的人之一，但他压根没想过这个问题。在对世界的好奇心上，孔子不如两小儿。

这也解释了这篇课文为什么放在六年级很巧妙：学到它的同学正好和两小儿差不多的年纪，刚好能从两小儿身上感受到对世界本能的好奇。知识会过时、会被修正，但提出问题的冲动是探索的起点。
