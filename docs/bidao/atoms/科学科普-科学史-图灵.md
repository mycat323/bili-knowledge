# 图灵

## 一句话定义

图灵是计算机科学与人工智能之父，二战中破译纳粹德国密码，提出图灵机与图灵测试，1952 年提出图灵斑图，同年被判处化学阉割，两年后死于氰化物中毒，年仅四十二岁。

## 详细说明

图灵是计算机科学与人工智能之父。如果做过图灵测试，会知道他；如果懂一些历史，会尊敬他在二战中破译了纳粹德国的密码；如果学计算机，开学第一课必讲图灵机。但很少有人知道图灵还有当生物学家的业余爱好，他的成果就是图灵斑图。

1952 年图灵提出图灵斑图时，世界上没有任何一台计算机有能力计算如此复杂的偏微分方程组，他完全是用大脑的直觉预见了这些图案。然而这个概念提出时竟然没有掀起一丝波澜，早年间生物学界也一直对这个模型很反感，因为没有人真的找到过激活剂和抑制剂，生成条纹的数学模型也远远不止一种。直到七十年代，他死后近二十年，Gierer 和 Meinhardt 才又复刻了他的结果。到了二十一世纪，分子生物学大发展，终于在很多体系中找到了图灵预言的激活剂和抑制剂，比如指纹、手指分叉和上颚条纹等，一个个蛋白和基因证明了它的正确。

可惜图灵没有机会看见这些。在他提出图灵斑图的当年，他被判处化学阉割，两年后便死于氰化物中毒，英国官方认定为自杀，年仅四十二岁。英国政府和女王迟来五十多年的道歉与赦免，实在微不足道。
