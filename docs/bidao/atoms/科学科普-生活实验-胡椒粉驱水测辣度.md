# 胡椒粉驱水测辣度

## 一句话定义

在水面撒胡椒粉，放入待测辣椒，观察胡椒粉被推开的范围，就能粗略判断辣椒的辣度，越辣驱水越强。

## 详细说明

操作步骤：在案板或水面上撒一层胡椒粉，把切开的辣椒戳进水里，观察胡椒粉向四周躲避的范围。范围越大，说明辣椒释放的辣椒素越多、辣度越高。

视频中的实测排序为：杭椒小于螺丝椒约等于薄皮椒小于青尖椒小于小米辣；不辣的甜椒作为对照组完全没有效果。卡罗莱纳死神辣椒泡两下后，水面中间出现的圈比前面所有辣椒都大；云南魔鬼椒效果也很强。

这个实验的原理是辣椒素作为疏水低表面能物质铺展水面、挤开胡椒粉。不确定菜辣不辣时，可以当场用胡椒粉做驱水小实验来判断。
