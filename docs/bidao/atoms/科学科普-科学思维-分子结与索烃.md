# 分子结与索烃

## 一句话定义

1961年Frisch等人在JACS发表Chemical Topology，将两条分子链打成结实现机械互锁，形成难以写出化学式的分子，命名为索烃。

## 详细说明

真正掌握了打结的科学家甚至可以给分子打结。

1961年，Frisch等人在JACS上发表了论文Chemical Topology，将两条分子链打成了结，从而机械互锁，形成了很难写出化学式的分子，被命名为索烃。

此后化学家合成了更多带结的分子结构，包括手铐烃、饼干烃、奥林匹克烷、三叶结等，甚至分子小车也有分子打结的参与。

创造闻所未闻的分子结构，是化学家展示他们真正掌握了分子规律的最好方式。他们努力打出更复杂的分子结，挑战着物质合成技巧的边界，也探索着微观的美学。
