# 喊话数字的鲁棒性

## 一句话定义

在噪音环境中用幺两三四五六拐八等特殊读法喊数字，比普通话读法有更好的鲁棒性，避免一和七等音近数字被误听。

## 详细说明

我国兵哥哥喊话时用「幺两三四五六拐八」代替普通数字读法，在噪音环境中比普通话有更好的鲁棒性。

原因是普通读法里一些数字发音相近，容易被误听。比如喊「詹姆斯邦德零零七」，可能被误听成「詹姆斯邦德零零一」；而喊「詹姆斯邦德洞洞拐」，就不容易听错。

这与纠错码的思路相通：通过增加发音上的区分度来降低误判概率。
