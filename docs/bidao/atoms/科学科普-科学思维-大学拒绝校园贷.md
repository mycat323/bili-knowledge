# 大学拒绝校园贷

## 一句话定义

校园贷是大学期间必须坚决拒绝的东西，毕导在建议中连续重复三次「拒绝校园贷」以强调其严重性。

## 详细说明

在毕导整理的 50 条建议中，第十四条是唯一被连续重复三次的条目：拒绝校园贷，拒绝校园贷，拒绝校园贷。这种重复本身就是一种信息压缩——用最少的字传达最高的优先级。

与之并列的还有几条涉及风险与自我管理的建议：

- 不要沉迷游戏，除非你是职业电竞选手，否则沉迷游戏的最后就是一无所有；而且电竞选手也没有想象中那么容易当，先试试每天训练十二个小时打游戏，一周就会发现自己其实根本不会玩这个游戏。
- 生病尽早看医生，特别是牙疼，学校有医保，很便宜。
- 下雨天学校的伞容易丢，但就算自己的伞被偷了，也不要拿别人的伞。

这些条目共同指向一个原则：不要用短期便利换取长期代价，尤其是涉及金钱和健康时。
