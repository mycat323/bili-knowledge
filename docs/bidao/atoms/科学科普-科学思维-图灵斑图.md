# 图灵斑图

## 一句话定义

图灵斑图是图灵提出的用两种物质和两条规则解释动物斑纹形成的机制：激活剂促进自身与抑制剂产生，抑制剂扩散更快并抑制激活剂，二者相生相克形成稳定斑点或条纹。

## 详细说明

图灵认为，动物身上复杂的斑点与条纹不需要基因精准控制每个细胞合成什么色素，只需两种物质和两条规则。

- **激活剂**：负责提供颜色，能促进产生更多激活剂，也能产生更多抑制剂。
- **抑制剂**：抑制激活剂的产生，且扩散速度比激活剂快。

两种物质阴阳调和、相生相克，结果就是抑制剂能把有颜色的激活剂稳定限制在一个小区域里。最简单的情况是激活剂产生的抑制剂向外扩散后，把激活剂包在中心，形成一个小斑点。调整参数后，同样的规则可以生成条纹等更复杂的图案。

图灵斑图是一个笼统概念，可能对应多种方程，如 Gray Scott 方程、Ermentrout 方程、FitzHugh Nagumo 方程，激活剂和抑制剂也可能不止一种。因此生物学家想完全理解某种具体生物的条纹仍然困难。每种动物还有自己的特殊机制，例如花栗鼠的平行条纹需要稳定的浓度梯度，江豚条纹边缘清晰需要加上扩散电泳。在图灵最基础的规则上叠加每种动物特殊的部分，才是大自然塑造动物的全貌。
