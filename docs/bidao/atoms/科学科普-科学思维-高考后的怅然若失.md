# 高考后的怅然若失

## 一句话定义

走出高考考场的第一感觉往往既不是解脱也不是快乐，而是一种怅然若失：三年时间在两三天的几个瞬间里过去了，同学很快各奔东西。

## 详细说明

回忆高考结束那一天，第一感觉不是解脱感，也不是快乐感，而是一种怅然若失。过去三年的时间，在简简单单两三天里的几个瞬间中过去了。

具体印象只剩下「数学做得不太好」这类模糊片段，当时的具体感觉反而迅速远离。再看到同学，会意识到再过两天大家就各奔东西。

所以高考后那一天的情绪是复合的：怅然若失，同时也期待未来的生活，有一点期待，也有一点惶恐。

这种情绪与毕业离校时的感受相通：真正离校那天，很多想做的事都没做，大家不知什么时候就都走了，告别平平常常，像和之前的每一天一样。
