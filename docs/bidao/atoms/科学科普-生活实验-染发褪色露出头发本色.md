# 染发褪色露出头发本色

## 一句话定义

头发本身含有黑色和偏红黄色的色素，染发第一步是把黑色漂浅使头发本色变为黄色，染发剂色素随水洗日晒流失后，最终露出的仍是黄色本色。

## 详细说明

染发的过程可以拆成两步。第一步是漂浅：把头发中原本的黑色色素去掉，头发的本色就从黑色变成黄色。第二步是上色：染发剂的色素附着或渗入头发，呈现托尼老师调出的新发色。

随着日常水洗和日晒，染发剂的色素逐渐流失，而头发自身的黄色本色不会消失，于是无论当初染的是什么颜色，褪色后一律变成黄毛。

这个现象与纸张、塑料变黄的机制不同：它不是氧化生成共轭结构，而是外加色素被去除后露出固有底色。但两者都指向同一个结论——黄色常常是物质「褪去装饰」后的稳定底色。
