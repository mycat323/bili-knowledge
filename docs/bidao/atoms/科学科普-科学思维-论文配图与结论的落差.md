# 论文配图与结论的落差

## 一句话定义

论文红外图显示人体各部位温度确有差异，最热约三十四度、最低约二十七八度，但两分钟内局部升温七八度打通经络的说法与常识差距过大。

## 详细说明

论文红外图中最热的大红色约三十四度，最低的蓝紫色约二十七八度，人体各部位温度本身就有差异。

论文主张喝一口茶两分钟后就能打通经络，毕导用反证调侃：如果真是这样，脑子瞬间被肚子热了七八度，那当场嚼一包茶叶就能打通任督二脉。

复现时毕导也观察到身体各部位温度差异：脖子胸腔比较热，胸和肚子比较凉，喝咖啡后背下方变热、喝可乐肚子变热，但这些变化很难归因于经络激活。

这提示判读红外热图时要注意：整体 color map 差异、局部相对升温、以及憋尿等生理因素都可能造成温度变化，不能只看颜色就下结论。
