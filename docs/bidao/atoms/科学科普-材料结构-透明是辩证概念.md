# 透明是辩证概念

## 一句话定义

透明与否取决于观察所用的光：黑色垃圾袋对可见光不透明却对红外光透明，玻璃对可见光透明却对紫外光不透明。

## 详细说明

透明不是物体的固有属性，而是物体与特定波段光之间的关系。

用手机的紫外线检测模式拍摄玻璃，玻璃会变黑，玻璃后面的字也看不见了——在紫外线下玻璃是不透明的。反过来，用红外成像仪可以轻松看透黑色垃圾袋，在红外线下这层垃圾袋就像不存在一样。

所以结论是：垃圾袋在可见光下不透明，但对红外光很透明；玻璃在可见光下透明，但对紫外光不透明。如果有一个只能看见紫外线的外星生物，它近视了可千万不能配玻璃眼镜。

判断透明要问的是「对什么光透明」，而不是「是不是透明」。
