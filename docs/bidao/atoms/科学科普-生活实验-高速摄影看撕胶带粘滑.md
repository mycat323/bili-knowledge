# 高速摄影看撕胶带粘滑

## 一句话定义

用高速相机慢放撕胶带过程，能看到胶带一直在走走停停，每次停顿形成不透明暗纹，一瞬间的撕扯包含无数次粘滑。

## 详细说明

视频用高速相机记录了撕胶带的过程，验证粘滑的微观机制。

**现象对比**：

- 慢拉胶带：胶水被另一面拉出丝，显微镜下形成许多小凸起和小气泡，把光散射掉，看起来不透明。
- 猛拉胶带：胶还没反应过来就和另一面分开，胶带看着透明，但仔细看上面仍有一道道不透明的暗纹。

**高速摄影结果**：

- 每秒 38400 帧、慢放 1280 倍：表面瞬间拉开的胶带，其实一直在走走停停，停下的地方形成不透明暗纹。
- 每秒 30 万帧、慢放 1 万倍：走走停停本身又由更小尺度的走走停停组成，每走几百微米就停一下。

一瞬间的撕胶带经历了无数次粘滑运动，每一次粘滑都形成一个小音爆，每秒几千次音爆合起来，就是你听到的那一声「刺啦」。
