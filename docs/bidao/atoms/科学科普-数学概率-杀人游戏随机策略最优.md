# 杀人游戏随机策略最优

## 一句话定义

在简化版杀人游戏中，杀手每晚随机杀人、白天所有人随机投票，这一随机策略被证明是双方的最优策略。

## 详细说明

2008年，Braverman 等人从理论上证明：在杀人游戏（狼人杀的简化版，只保留狼人与平民两个身份）中，如果杀手在夜里随机选择目标，白天所有玩家随机投票，那么这就是双方的最优策略。

这意味着，在纯理性的博弈框架下，任何基于发言、逻辑推理的复杂策略都无法在期望收益上超过随机。你费尽口舌分析局势，理论上并不比闭眼随机投票更占优。

这一结论的直觉解释是：当双方都掌握完全信息且都采取最优应对时，任何可被预测的倾向都会被对方利用，于是唯一不可被利用的策略就是随机化。

需要强调的是，这个结论只适用于高度简化的模型。真实狼人杀中玩家并非完全理性，发言、情绪、心理战都会引入模型之外的变量，所以随机最优并不等于「玩狼人杀就该乱投」。它的价值在于说明：当对手足够强时，试图用固定套路取胜是徒劳的。
