# 屎壳郎靠天导航

## 一句话定义

屎壳郎走直线不依赖地标，而是依靠太阳、偏振光、月亮和星空等天体线索确定方向，遮挡上方视野后就会兜圈子。

## 详细说明

研究人员把屎壳郎脚下的土地旋转九十度，它依然能沿原来的直线前进，说明它不靠地标或环境定位；而给它戴上帽子遮挡上方视野后，它就看不了天，只能开始兜圈子。由此可知屎壳郎是靠天导航的。

具体的天体线索包括：

- 太阳：2003 年昆虫学家马库斯·伯恩等人捕捉五种屎壳郎，发现它们都会朝着太阳的方向滚粪球。
- 反射光与人造光：用镜子反射阳光并遮住太阳，屎壳郎会跟随反射光走；LED 这样的人造太阳也能驱动它的运动。
- 偏振光：野外阴天时，太阳光经大气微粒散射形成偏振光，屎壳郎能靠偏振光找到方向。
- 月亮与星空：夜行屎壳郎被带到约翰内斯堡天文馆，在圆顶天花板上四千颗恒星和银河的指引下找到正确的路。

屎壳郎推球时常站上球顶转圈，遇到障碍或球滚出去后一定会触发这个动作，推测是在重新定位。
