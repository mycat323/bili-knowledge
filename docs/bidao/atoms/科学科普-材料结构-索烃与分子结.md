# 索烃与分子结

## 一句话定义

1961年Frisch等人在JACS发表Chemical Topology，把两条分子链打成结形成机械互锁的分子，命名为索烃；此后化学家又合成出手铐烃、饼干烃、奥林匹克烷、三叶结等更复杂的分子结。

## 详细说明

1961年，Frisch等人在JACS上发表了论文Chemical Topology，将两条分子链打成了结，从而机械互锁，形成了很难写出化学式的分子，被命名为索烃。

此后化学家不断挑战更复杂的分子结，包括手铐烃、饼干烃、奥林匹克烷、三叶结等。视频中提到，分子小车也有分子打结的参与。

创造闻所未闻的分子结构，是化学家展示自己真正掌握分子规律的最好方式。他们努力打出更复杂的分子结，挑战物质合成技巧的边界，也探索微观的美学。
