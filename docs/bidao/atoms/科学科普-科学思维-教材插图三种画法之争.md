# 教材插图三种画法之争

## 一句话定义

关于水中物体虚像位置，国内外教材教辅出现原地升高、更靠近人、更远离人三种互相矛盾的画法，其中只有「更靠近人」符合折射定律。

## 详细说明

同一个初中物理问题，教材插图却分成三派：

| 画法 | 代表教材 | 是否符合折射定律 |
| --- | --- | --- |
| 原地升高，不变远也不变近 | 浙教版、人教版、沪粤版 | 否 |
| 虚像更靠近人 | 沪科版、北师大版、沪教版 | 是 |
| 虚像更远离人 | 部分外国教材、某著名教辅 | 否 |

判断依据很简单：只要严格按光的折射定律作图，两条近轴折射光线反向延长的交点一定落在物点靠近人眼的一侧，不可能相交在远离眼睛的一侧。画成远离人眼的插图，说明编者没有按折射定律准确作图，而是随手画了两条线。

这个案例说明：权威教材之间也会互相矛盾，遇到分歧时应当回到物理定律本身去验证，而不是靠教材的权威性来裁决。
