# 卡式炉气罐过热爆炸

## 一句话定义

卡式炉上放置过大的锅时，火焰加热锅、锅把热量传到边缘、边缘又加热气罐，形成循环升温，最终导致气罐爆炸。

## 详细说明

卡式炉虽然装有过压保护装置，但不恰当使用仍非常危险。当炉上的锅过大时，燃气火焰加热锅底，锅的热量会传递到锅的边缘，而边缘盖住的位置正好把下方的气罐罩住并持续加热。如此循环，气罐温度不断升高，压力随之上升，当爆炸这个小概率事件发生时，气罐会瞬间冲向不定方向，整个装置四分五裂，威力巨大。视频中做卡式炉预实验后留下的残骸就是这种后果。

另一个相关演示是：把丁烷气罐中的气体与清水、洗洁精混合产生泡沫，点燃后火能在手上燃烧而不烫伤。原因是泡沫里含有丰富的水，手也沾湿了，水的比热容较大，泡沫那点热量不足以在短时间内把手加热到烫伤温度。视频中演示者的手毛被烧焦了一点，说明仍有热量作用，因此这类实验必须在消防人员监管下进行，绝不能在家模仿。

常见误解：以为有保护装置就绝对安全。保护装置只能降低风险，不能消除错误使用带来的过热循环。
