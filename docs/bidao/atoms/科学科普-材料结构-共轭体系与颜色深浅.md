# 共轭体系与颜色深浅

## 一句话定义

深色物质往往具有更复杂的分子结构和更大的共轭体系，没几个苯环都不好意思说自己有颜色。

## 详细说明

紫色石蕊、甲基橙、花青素这类深色物质，分子结构复杂、共轭体系大。番茄红素有长有短，粪胆素有大又圆，叶绿素由四个吡咯构成卟环、中间还嵌一个镁，黑色素整个是一个超级共轭大分子，不饱和度数都数不清。

共轭体系越大，π→π* 跃迁能级差越小，吸收波长越长，颜色越深、越偏向长波端。这是「结构决定性质」在颜色上的直接体现。

这些分子人工合成难度很高——大二有机实验课合成肉桂酸做了整整一天，产率只有百分之五十；但每一片叶子都能合成叶绿素，生命体内每刻都在发生复杂、快速而精准的化学反应。
