# 听声辨水温

## 一句话定义

倒水时凭听觉判断水温，是因为冷热水在粘度、表面张力等物理性质上的差异改变了水流与容器碰撞的振动特性，从而产生可分辨的声音差别。

## 详细说明

把一杯十度的冷水和一杯九十度的热水分别倒进同一个杯子，眼睛看不出区别，但多数人能靠声音分辨出哪杯是热水。

**为什么能听出来**

倒水声来自水流冲击杯壁与水面时产生的振动。水温不同，水的粘度、表面张力、密度等性质随之变化，水流的形态、气泡的产生与破裂方式也不同，最终发出的声音在音色和频率成分上有差异。

**可动手验证**

1. 准备两杯外观相同的水，一杯约十度，一杯约九十度；
2. 背对操作者，让对方随机顺序倒入同一个杯子；
3. 记录自己的判断，再核对答案。

视频中提到，有人统计过约百分之九十六的人都能听出冷水和热水的区别。这个数字说明这种分辨能力相当普遍，并非少数人的特异功能。

**注意**

热水倒出时可能造成烫伤，实验时务必保持距离，不要用手直接接触热水杯壁。
