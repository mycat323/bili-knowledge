# 马尔可夫性质

## 一句话定义

马尔可夫性质指一个随机过程未来状态的条件概率分布仅依赖于现在的状态，人类玩石头剪刀布时往往具有很强的马尔可夫性。

## 详细说明

马尔可夫性质指一个随机过程未来状态的条件概率分布仅依赖于现在的状态，与更早的历史无关。

人类玩家在石头剪刀布中往往表现出很强的马尔可夫性：大部分人只根据目前这一轮的结果决定下一轮出什么，而不会去想过去都出过些什么，记不得那么多。

算法可以利用这一点：用马尔可夫决策过程考虑对手相邻轮次选择的条件概率，例如统计出「出完石头之后更大概率换成剪刀而不是布」，或「连出两个一样之后大概率要变一变」。这类条件概率特征很容易从对局数据中统计出来。

但计算机可以完全记住历史对局，例如记录到你的历史序列是石头、石头、剪刀，算法一匹配就能预测你下一把大概率出布。基于数据集的算法打得越多胜率越高。
