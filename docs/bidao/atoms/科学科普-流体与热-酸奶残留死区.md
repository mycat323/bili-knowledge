# 酸奶残留死区

## 一句话定义

死区是流体设备中物质一旦进入便很难流出的区域，酸奶包装的杯底坑、窄口瓶壁等结构正是死区，导致大量酸奶残留浪费。

## 详细说明

酸奶是粘性较大的流体，流动不丝滑，在包装的几何死角处容易滞留。视频中统计发现，瓶装酸奶每瓶约残留 18 克，杯装酸奶的浪费率达到 13.6%，即每喝七杯浪费的酸奶又能凑成新的一杯。

死区概念来自化工领域：物质进入该区域后很难出来。生活中类似现象包括洗澡时角落冲不掉的沫子、墙边堆积的灰坨坨。化学工程师为减少死区，会采用更大半径的弯头输送固体，或用文丘里流量计替代孔板流量计以提高精度。

包装设计上的死区主要来自两类结构：杯底与杯壁连接处的一圈坑，以及口比瓶身小的坚硬瓶子——瓶壁成为永远无法触及的盲区。这些结构让酸奶难以被吸出或倒出。
