# 胆素原循环生成黄色色素

## 一句话定义

血红蛋白经过胆素原循环，最终氧化生成黄褐色的粪胆素和尿胆素，这两种色素使排泄物呈现黄色，是人体内源性变黄的典型例子。

## 详细说明

食物饮料无论原本色泽多么诱人，在体内走一圈后都会变成黄色的液体或固体。原因是血红蛋白经过胆素原循环，被代谢为胆素原，再氧化生成黄褐色的粪胆素和尿胆素，从而给排泄物染色。

粪胆素和尿胆素的黄色同样来自氧化生成的共轭结构，与纸张、白墙变黄属于同一类化学机制。这也说明「氧化变黄」不只发生在体外材料上，人体内部的代谢过程也在持续进行。

视频中特别提醒：如果前一天吃了红心火龙果，排泄物颜色可能出现意外变化，这属于食物色素的干扰，不代表身体出了问题。
