# 发型决定第一印象

## 一句话定义

男生外貌给人的第一印象很大程度上由发型决定，换一个合适的发型带来的提升往往比五官本身更明显。

## 详细说明

毕导对比自己大一大二与现在的照片，指出五官区域没有任何变化，变化来自三方面。

第一是打光：录视频时有充分打光。第二是调色：剪辑环节会对画面进行调色，视频中甚至出现了反复要求「脸再亮一点」的对话。第三也是他认为很重要的一点，是大约两年前遇到一位懂他的理发师，告诉他男生的发型会极大决定别人对你的第一印象。

换发型之后，他的形象呈现出明显不同的效果。他给男生的建议是：努力迈出改变这一步，换一个发型对个人提升会非常明显。
