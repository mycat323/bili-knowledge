# 通讯作者充当实验对象

## 一句话定义

论文中代号 M0 的特殊实验员承担预实验与全部半裸红外影像，论文注明 M0 即通讯作者本人，构成自我实验。

## 详细说明

论文除四十二名志愿者外，还有一个被反复提及的特殊实验员，代号 M0。M0 比其他实验员更苦：二零一七年就开始预实验，先绝食三天，再独自喝五百一十二种茶，优选出最适合本次实验的十三种茶；论文中所有半裸红外影像也全部是 M0 的身体。

论文原文说明，志愿者原始影像因隐私原因不予公开，M0 是例外，因为 M0 就是通讯作者本人。也就是说，论文用来论证经络存在的关键影像，来自论文作者自己。

这带来两个问题：一是样本量为一个人，无法排除个体差异；二是作者既是实验设计者又是被观测对象，难以做到盲法，观测与解读都可能受预期影响。论文还提到 M0 喝一个月黄茶后顺便治好了自己的肾结石，这类附带结论同样只有单一案例支撑。
