# 纠错码的三份冗余

## 一句话定义

把每组数据存三份，若三份不一致就以两份相同的为准，从而实现数据自动纠错，冗余越多纠错能力越强。

## 详细说明

计算机中文件以二进制存储，数据在保存和传输过程中可能因光盘划伤或网络故障而损坏，于是需要让计算机自动纠错。

最简单的办法是把每组数据都存三份：如果三个数据不一样，就以两份一样的为准。比如约定发一一一表示接受、发零零零表示拒绝，收到幺零幺时可以大胆判断对方想发一一一，只是手抖打错一位；不太可能是想发零零零却手抖两下变成零幺。

如果约定一一一一一表示肯定、零零零零零表示否定，自动纠错能力会更强：即使收到幺零幺零幺幺，仍可判断出对方愿意，只是可以提醒他治一治手抖。
