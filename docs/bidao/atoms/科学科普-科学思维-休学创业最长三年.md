# 休学创业最长三年

## 一句话定义

清华学生手册规定休学创业最长三年，毕导2017年12月博四上学期休学，2020年12月复学，正好用满这一期限。

## 详细说明

毕导的时间线：2010年考来清华化学工程系，学高分子材料与工程专业；2014年在本系读博；2017年12月博士休学，当时是博四上学期；2020年12月复学。他明确提到，清华学生手册规定休学创业最长三年。

复学时他面对的变化包括：原来活力满满的视频团队各奔东西；他翻出尘封的学生卡去C楼激活，恢复校园网账号（用户名 bxt14，对应2014年入学）；去西办办复学手续时，西办刘老师对他说「欢迎回来，大家都很想你」。

复学后他换了导师，研究方向从超波次复合波的制备转到化工厂的故障检测与诊断，从做化学合成变成写代码。组里大师兄比他小两岁，小师弟比他小七岁，隔壁副教授只比他大三岁。
