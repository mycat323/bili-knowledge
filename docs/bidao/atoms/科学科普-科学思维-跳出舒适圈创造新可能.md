# 跳出舒适圈创造新可能

## 一句话定义

无论个人还是企业，即使在一个领域做得很好，也要尝试突破创新，否则就跟不上时代变化，跳出舒适圈可能创造新的可能。

## 详细说明

毕导在视频结尾总结：这一年世界风起云涌，自己也经历了身份的转变，一切过往皆是序章。无论做出了什么改变，未来都会成为宝贵的经历。

他把这个道理从个人推广到企业：有时候跳出舒适圈，给自己一些挑战，说不定就能创造出新的可能。人生是这样，企业的发展也是这个道理。哪怕在一个领域里面做得很好，也要尝试突破创新，不然就跟不上时代变化。

他举的例子是招行：作为传统银行之一，招行率先探索金融科技、拥抱改变，其 app 设计人性化、使用方便。这段内容带有商业推广性质，但其中「做得好也要突破」的判断本身是一条可迁移的经验。
