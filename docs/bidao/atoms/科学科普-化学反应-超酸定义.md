# 超酸定义

## 一句话定义

超酸是比百分之百纯硫酸更强的酸，按酸碱质子理论，就是给出氢离子能力超过纯硫酸的物质。

## 详细说明

超酸的定义是：比百分之百纯硫酸更强的酸。按布朗斯特和劳里的酸碱质子理论，凡是能给出氢离子的就是酸，给出氢离子能力越强酸性越强，所以超酸就是特别喜欢把氢离子送给别人的物质——纯硫酸遇到超酸，也得从它那里拿走几个氢离子。

历史上对酸的认识经历了两次扩展：1887 年阿伦尼乌斯提出水溶液中电离出的阳离子全是氢离子的叫酸，这是课本定义；1923 年布朗斯特和劳里提出酸碱质子理论，把酸的范围扩大到能给出氢离子的任何物质。

超酸酸性过强，离子活度显著变化，测量 pKa 所依赖的假设被打破，因此需要新的评价体系——哈米特函数 H0。
