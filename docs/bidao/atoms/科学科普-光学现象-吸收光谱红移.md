# 吸收光谱红移

## 一句话定义

分子共轭体系扩大后电子跃迁所需能量变小，原本只能吸收紫外光的物质开始吸收可见光，吸收峰向长波方向移动。

## 详细说明

白色物质电子跃迁需要的能量很大，只吸收紫外光、不吸收可见光，所以看着是白色。氧化过程加氧去氢，可能向分子中引入碳碳双键和羰基；若单双键交替排布，就形成共轭体系。

共轭体系越大，电子发生 π→π* 跃迁所需能量越小。原来要紫外光才能激发，氧化之后能量更小的可见光也能激发，吸收光谱曲线向长波方向移动，这就是红移。

红移一丢丢后，物质开始吸收紫光，看起来就是紫色的补色——黄色。这就是「万物变黄」的化学本质。含 O、R、S、N、P 的基团也会促进红移，有一些经验公式可以估算移动量。
