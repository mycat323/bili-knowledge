# 亚历山大带

## 一句话定义

主虹与二级彩虹之间看起来特别暗的带状区域，因两道彩虹的光锥角度差导致该区域几乎没有光进入眼睛。

## 详细说明

主虹出现在四十二度方向，二级彩虹（霓）出现在五十二度方向，两者之间有一段看起来特别暗的区域，被称为亚历山大带。

它的成因与彩虹下方更亮、上方更暗是同一套光锥几何：主虹位置的水滴光锥边缘刚好到达眼睛，主虹下方水滴的光锥中部进入眼睛所以更亮，而主虹与霓之间的水滴，其光锥既不经过眼睛、又不落在能进入眼睛的角度上，因此显得暗。
