# 主动控制鸡皮疙瘩

## 一句话定义

2018年日本东北大学James Harris团队发现，极少数人无需任何外部刺激，仅凭意念就能主动诱发鸡皮疙瘩和汗毛竖起。

## 详细说明

长鸡皮疙瘩通常由寒冷、音乐、抚摸等外部刺激触发，被认为无法主动控制。在之前整整一个世纪，学术界只找到过三位能主动起鸡皮疙瘩的人。

2018年，日本东北大学的 James Harris 教授团队通过 Facebook 等互联网渠道发布寻人启事，成功集结了 32 名「鸡皮侠」进行实验。论文发表在 PRJ 上，影响因子 2.3。

论文指出，这种有意识诱发鸡皮疙瘩的能力目前还没有合理的生理学解释。据传每一千五百个人里面只有一个人具有这项能力。

视频中现场演示时，三位自称具备该能力的人同时尝试，其中一人反应明显、一人属于慢热型，还有一人因汗毛不明显而难以可视化验证。
