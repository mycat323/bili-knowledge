# 牙膏彩条不混合

## 一句话定义

彩条牙膏在管内被反复挤压、甚至剪开搅动后，内部看似已经混成一团，但挤出来仍然保持规则的彩条，原因是牙膏属于宾汉流体。

## 详细说明

直观上想，牙膏被拼命挤压之后内部应该混起来，但实验结果是：即使把牙膏管剪开、用玻璃棒狂搅，挤出来仍然能看到彩条，只是没有原来那么明显。

原因在于牙膏是宾汉流体：没有剪切作用时它表现为固体形态，受到挤压（剪切）时才表现为流体形态，像固体一样被挤出去。因此管内各层彩条在未受足够剪切时不会互相混合。

实验可以这样复现：先正常挤出一段观察彩条，再用力捏管身，剪开管壁看内部结构，最后用玻璃棒搅拌后再挤，对比彩条的清晰程度。

这个现象说明，日常最熟悉的东西背后也可能藏着没被注意过的规律。
