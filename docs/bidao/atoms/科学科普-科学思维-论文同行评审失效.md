# 论文同行评审失效

## 一句话定义

一篇 2017 年关于子宫肌瘤的论文声称选取 80 例患者，其中 25 名女性、55 名男性，且全部签署知情同意书，发表八年后才被撤稿，暴露作者、审稿人、编辑全部失守。

## 详细说明

一篇关于子宫肌瘤的论文在实验方法中写道：研究选取了 80 例子宫肌瘤患者，其中 25 名女性，但有 55 名男性。既然子宫肌瘤是女性疾病，这 55 名男性究竟同意了什么，成为视频作者最大的疑问。

这篇文章发表于 2017 年，直到多年后才被抓出来撤稿，作者也受到处分。视频作者由此感叹：作者自己可能都没看过，审稿人也没看过，期刊编辑也没看过，发表八年来应该也没人看过。

这个案例的价值不在于疾病本身，而在于它说明：

- 同行评审并非万无一失的过滤器；
- 明显的逻辑矛盾可以一路通过作者、审稿、编辑三道关卡；
- 论文的"信任"不能替代对内容的实际阅读。

视频作者坦言，本着对论文的信任，他第一次看到时一度疑惑男性是否真能得这种病，现在看来应该是不可以的。
