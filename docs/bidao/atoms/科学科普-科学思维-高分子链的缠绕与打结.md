# 高分子链的缠绕与打结

## 一句话定义

高分子是一条长长的链，长了容易弯、弯了容易打结，链与链缠绕打结的状态赋予塑料、橡胶、纤维不同的动力学和流变学性质。

## 详细说明

高分子本质上就是一坨扭结。生活中接触的一切塑料、橡胶、纤维都属于高分子。

普通分子在微观上长得像个小球，但高分子是一条长长的链。长了就容易弯，弯了就容易打结，所以高分子链都是缠绕在一起的。恰恰是这种缠绕打结的状态，赋予了高分子独特的动力学和流变学行为。

看似毫不相干的性质，都可以归结为高分子链不同的打结方式：

| 现象 | 与打结的关系 |
| --- | --- |
| 橡胶柔软 | 链的打结方式 |
| 防弹衣坚硬 | 链的打结方式 |
| 口香糖能开椰子 | 链的打结方式 |
| 玉米糊能水上漂 | 链的打结方式 |

纽结理论看似是数学家的脑力游戏，但高分子专业的人会突然顿悟：自己研究的对象本质上就是扭结。
