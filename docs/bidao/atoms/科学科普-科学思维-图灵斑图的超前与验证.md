# 图灵斑图的超前与验证

## 一句话定义

图灵 1952 年提出斑图概念时未引起波澜，因为当时没有任何计算机能计算如此复杂的偏微分方程组，直到七十年代被复刻、二十一世纪分子生物学找到对应蛋白和基因才被证实。

## 详细说明

图灵斑图提出时命运多舛。1952 年图灵提出这个概念，竟然没有掀起一丝波澜。早年间生物学界一直对这个模型很反感，因为没有人真的找到过激活剂和抑制剂，而生成条纹的数学模型也远远不止一种，凭什么相信这个理论？

说白了，图灵实在太超前了。1952 年世界上没有任何一台计算机有能力计算如此复杂的偏微分方程组，他完全是用大脑的直觉预见了这些图案。

直到七十年代，他死后近二十年，Gierer 和 Meinhardt 才又复刻了他的结果，让普通人也能看见这些美妙的图形。到了二十一世纪，分子生物学迎来大发展，终于在很多体系中找到了图灵预言的激活剂和抑制剂，比如指纹、手指分叉和上颚条纹，一个个蛋白和基因证明了它的正确，图灵的模型终于成为学术界的宠儿。

可惜图灵没有机会看见这些。在他提出图灵斑图的当年，他被判处化学阉割，两年后死于氰化物中毒，英国官方认定为自杀，年仅四十二岁。
