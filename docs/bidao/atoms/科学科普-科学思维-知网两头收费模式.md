# 知网两头收费模式

## 一句话定义

在现有学术规则下，作者发论文没有收益甚至要交版面费，读者看论文还要交阅读费，知网作为学术中间商两头收费并年年涨价。

## 详细说明

知网本身不生产论文，只是知识的搬运工，但它在学术链条中同时向两端收费。

作者一端：全国硕士博士论文入知网库，知网会给作者稿酬，硕士论文一本 60 元，博士论文 100 元。但知网不会主动发放，作者需要把本人学位证和身份证复印件邮寄给知网，下载表格填写信息发送到邮箱，才能等待稿酬到账。

读者一端：高校每年花几十万到上百万购买知网数据库，学生和老师才能看论文。

与此同时，作者发论文可能还要交版面费，读者看论文还要交阅读费，大头利润被知网这个学术中间商收入囊中。中文论文还要在知网查重，老师工程师评职称还要看知网文章，评价体系建立在一家独大的知网之上，学校和学生就变成了任人宰割的韭菜。
