# 绿豆汤红绿之争是氧化还原之争

## 一句话定义

绿豆汤的红绿表面是颜色之争，实质是酚与醌的氧化还原平衡之争，颜色只是多酚氧化程度的可视化指标。

## 详细说明

围绕绿豆汤颜色流传着大量「配方」：水质偏碱煮出来红、偏酸煮出来绿，开盖煮红、盖盖煮绿，自来水煮红、纯净水煮绿，大铁锅煮红、玻璃壶煮绿。这些说法各自抓住了一个变量，但都停留在现象层面。

把它们统一起来的是一个化学过程：绿豆中的多酚溶出使汤呈绿色，多酚被氧化成醌及深色聚合物后汤变红褐。加热、加多酚氧化酶、碱性条件、强氧化剂、金属离子，都是通过加速或促进这一步来改变颜色；纯净水、酸性条件、盖锅盖则是通过减缓这一步来保绿。

这个案例的科普价值在于：生活中可见的化学现象并不多，一碗绿豆汤可能是普通人离化学最近的一次。它同时展示了化学思维的方法——面对一堆互相矛盾的经验说法，先找出共同的底层反应，再用控制变量实验逐个验证。
