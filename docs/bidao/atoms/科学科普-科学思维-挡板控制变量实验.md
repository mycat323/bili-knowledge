# 挡板控制变量实验

## 一句话定义

在蜡烛与音响之间插入一块挡板，声音的频率和响度不变而火焰从动到不动，用控制变量法证明灭火的不是声音而是被挡板挡住的风。

## 详细说明

熊才义论文中最关键的一步实验设计极其简单：把蜡烛放在音响前面，开六十赫兹声音，蜡烛疯狂摆动；在蜡烛和音响中间放一块板子，火焰几乎不动；拿开板子，火焰又动起来。

这个实验的精妙之处在于控制变量。板子挡不住声音——人耳听到的频率和响度都没有变化，蜡烛接收到的声学条件与之前完全相同。既然声学输入不变而火焰行为改变，那么导致火焰熄灭的原因必然是被板子挡住的另一个东西。

顺着这个逻辑继续追问，答案自然浮现：

- 板子能挡住什么？风。
- 为什么蜡烛离音响远一点就灭不掉？风吹不了那么远。
- 为什么低频效果更好？低频时振膜振幅大，风更强。
- 振膜运动和火焰运动是否同步？完全同步。

这套推理不依赖任何复杂仪器，在家就能复现。它说明科学发现的关键往往不是设备有多先进，而是能否设计出一个把混杂因素分离开的对照实验。前人研究声音灭火几十年，实验装置基本都是「摆音响、照筒子、点蜡烛、放声音」，恰恰缺少了这块挡板。
