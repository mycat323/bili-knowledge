# 彩条牙膏捏不混

## 一句话定义

彩条牙膏反复捏压后挤出来仍是彩条，剪开狂搅才会混成一坨，说明捏压属于层流剪切而狂搅破坏了条纹结构。

## 详细说明

这是一个可以自己动手复现的实验。

实验材料：三管面貌全新、口感细腻的彩条牙膏。

步骤与现象：

1. 直接挤出，得到白绿相间的条形；
2. 对整管牙膏一通狂捏，再挤出，结果仍是彩条；
3. 剪开牙膏管，用工具狂搅一通，再挤出，结果混成一坨。

结论：原视频说「剪开狂搅后挤出来还是彩条」是不对的，应该只是搅得不够透彻。捏压不混合的原因是挤牙膏处于层流，牙膏各部分互不干扰、平行向前流动；而剪开狂搅直接破坏了原本的条纹结构。

补充观察：把牙膏用超低温凝聚法处理后脱去外皮，可得到一根牙膏冰棍，轴向由四白四绿八道条纹间隔而成，锯成小块横截面非常好看。挤牙膏时彩条整体向前移动并从小口排出，所以仍是彩条。
