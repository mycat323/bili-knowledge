# CIE色度图

## 一句话定义

一九三一年国际照明委员会通过颜色匹配试验提出 CIE XY 色度坐标，X 表示红色分量、Y 表示绿色分量、大 Y 表示亮度，可在二维图上画出五彩大舌头图。

## 详细说明

CIE 一九三一色度图把各种颜色变成可以量化的坐标。读图要点：

- 舌头最外圈那条线叫单色光轨迹线，对应不同波长的光谱色，是严格意义上真正存在的颜色；其他颜色都是不同波长光混合后大脑脑补出来的。
- 中间那条线叫黑体色温轨迹线，对应黑体在不同温度下的发光颜色，A、B、C、D、E 点是常见的几种白色光定义及对应色温值。
- 任何一个颜色 S 与白光点的连线，与舌头外圈交于 O 点，O 点的波长就是 S 色的主波长。
- 越靠近白光点，颜色饱和度越低。
- 任何一条穿过白色区域的直线上，可以找到一对互补的颜色光，比如绿色和红色、紫色和黄色。

后来还改良出用于自照明的 CIE LUV 和用于非自照明的 CIE LAB 颜色空间。
