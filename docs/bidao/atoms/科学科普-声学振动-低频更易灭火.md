# 低频更易灭火

## 一句话定义

六十赫兹左右的低频声音让烛焰摆动达到巅峰，频率越低振膜振幅越大、风越强，灭火效果越好。

## 详细说明

用蓝牙音箱给蜡烛播放不同频率的声音，可以观察到清晰的规律：

| 频率 | 火焰反应 |
| --- | --- |
| 200 赫兹 | 完全不动 |
| 100 赫兹 | 几乎不动 |
| 80 赫兹 | 仍无明显反应 |
| 70 赫兹 | 开始摆动 |
| 60 赫兹 | 剧烈摆动，接近熄灭 |
| 50 赫兹 | 明显摇摆 |

六十赫兹左右是火焰摆动的巅峰。用高速摄影观察：一千五百帧下火焰像丝绸一样在烛芯前后律动；三千帧下火焰仿佛要离开蜡烛奔向远方，最终熄灭化作白烟，白烟本身也在六十赫兹下前后摆动。

原因在于音响播放低频声音时振膜运动幅度更大，推出的风更强。巧合的是，普通人能唱的最低音差不多就是六十赫兹。
