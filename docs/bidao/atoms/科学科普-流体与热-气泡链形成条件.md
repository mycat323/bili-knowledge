# 气泡链形成条件

## 一句话定义

气泡半径和表面活性剂浓度在一定范围内越大，越容易形成稳定的气泡链，因为二者会改变气泡上升的尾流结构。

## 详细说明

在汽水（如香槟）中，气泡有时会连成一条直线上升，形成气泡链。

2023 年发表在 PRF 上、影响因子 2.5 的研究发现：在一定范围内，气泡半径和表面活性剂浓度越大，越容易形成稳定的气泡链。

机理是：气泡半径和表面活性剂会改变气泡上升时产生的尾流结构，从而改变后续气泡受到的升力方向，让气泡更容易直线排列。表面活性剂的作用可以类比为水里加的洗衣液，让泡泡能够手牵手排直线。

实验人员进行了大量模拟，结论是只有虚线以上（即参数超过某一阈值）才有可能出现稳定气泡链。视频中实测发现香槟的气泡链最直。
