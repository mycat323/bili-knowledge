# 浅景深相机测虚像位置

## 一句话定义

用景深极浅的长焦镜头对水下钢球逐点对焦，通过反光点由模糊变清晰时尺子上的读数，可以分别测出两个虚像的实际位置。

## 详细说明

实验装置：长焦镜头把景深调得很浅，只能看清对焦点上的物体，稍远稍近都模糊。水缸后壁贴一个小钢球，旁边立一把尺子，以钢球上一个小反光点作为对焦判据。

操作步骤：
1. 把钢球放入水缸并贴在后壁，相机从近到远改变对焦点。
2. 当反光点由模糊变清晰时，说明对焦到了钢球在水中的一个虚像，记录此时尺子上最清晰的数字。
3. 继续往里对焦，反光点会再次由模糊变清晰，记录第二个位置。

实验现象：第一次清晰时反光点变成一条横线，尺上数字六附近清晰，说明该虚像比钢球实际位置向镜头靠近了几厘米；第二次清晰时反光点变成一条竖线，尺上数字一、二附近清晰，位置约在钢球实际位置的正上方。

这个实验把「虚像在哪」从作图争论变成了可测量的读数，也直接证明了水下物点存在两个虚像。
