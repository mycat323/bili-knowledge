# 经络与茶分类的对应质疑

## 一句话定义

论文将六种茶的分类与十二条经络建立一一对应，但茶的分类是近几十年按制备工艺划分，经络记载于黄帝内经，两者相隔两千多年且无已知关系。

## 详细说明

论文的核心主张是：喝完十二种茶后，人体不同部位温度迅速上升，上升部位恰好对应十二条经络，一种茶对应一条经络。例如喝完龙井茶，足太阳膀胱经区域温度上升。

毕导提出的质疑是时间尺度上的：六种茶的分类是近几十年里根据茶的制备工艺划分的，而十二经络在《黄帝内经》中就有记载，两者相隔两千多年，也没有已知的关联，却能建立一一对应，这本身很玄妙。

此外论文还有一些更细的发现，比如喝完黑茶中指最热、喝完白茶大拇指最热、喝完青茶食指最热，毕导调侃这可能是杯子太烫导致的。

论文声称喝茶实验揭示了靶向药物设计的新方法，但这一推论同样需要独立验证。
