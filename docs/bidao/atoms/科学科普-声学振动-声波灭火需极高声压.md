# 声波灭火需极高声压

## 一句话定义

若排除风的影响、只靠声波能量震灭蜡烛，声压级需达到一百四十五分贝以上，相当于火箭发射的噪声。

## 详细说明

实验用九十分贝的重低音才能艰难熄灭一根靠得很近的蜡烛，全公司都被吵到。而九十分贝重低音的灭火效果甚至不如用手掌扇一下。

理论预测：如果没有风，只想靠声波的能量把一根蜡烛震灭，声音要达到一百四十五分贝以上，跟火箭发射的噪声差不多——蜡烛是灭了，人也受不了。因此熊才义在论文中写道，单纯通过声波来灭火只是美好的幻想。

这也解释了为什么早期文献中十篇论文能提出十种机理：实验装置都是摆音响、照筒子、汇聚声音、点蜡烛、播放声音、熄灭蜡烛，却没有人把振膜产生的风这一变量控制住。
