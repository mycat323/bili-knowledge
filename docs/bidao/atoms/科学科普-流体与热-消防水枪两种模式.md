# 消防水枪两种模式

## 一句话定义

消防水枪按场景切换模式：直流水流集中且有穿透力，用于冲击；雾状水流细密、覆盖范围广，能快速降温并防止火势蔓延。

## 详细说明

视频中水与火的对撞实验展示了消防水枪的两种工作模式。一种是高压直流水流，集中且有穿透力，实验中能直接冲击玻璃。另一种是雾状水流，水流被分散成非常细密的雾滴，但覆盖范围非常广，能够快速降温、防止火势蔓延。

在演示中，火势已经很猛，但水枪一开，水雾完全把火包了起来，眼前全都是水，最终水战胜了火。这说明灭火效果不只取决于水量，还取决于水的形态和覆盖方式：雾状水增大与火焰和高温烟气的接触面积，吸热降温效率更高；直流水则适合需要穿透力和冲击力的场景。

消防员会根据火情类型和现场条件选择对应模式，这也是消防作业中「因火施策」的体现。

常见误解：以为水枪只有一种出水方式，或者认为水越多越好。实际上模式选择直接影响降温效率和安全性。
