# 牛顿第二定律

## 一句话定义

物体加速度的大小与所受合外力成正比、与质量成反比，方向与合外力方向相同，是牛顿力学预测运动的核心方程。

## 详细说明

牛顿第二定律说明：物体的加速度由它受到的合外力决定，力越大加速度越大，质量越大加速度越小，加速度方向与合力方向一致。

在预测运动时，它的用法是：先确定物体的初始位置和初速度，再列出它受到的全部力，代入定律求出加速度，然后通过积分得到之后任意时刻的速度和位置。视频中正是用这条定律来说明，只要知道瓶子的形状、质量、位置、出手的力、空气阻力、地转偏向力等条件，就能算出瓶子的飞行轨迹。

牛顿第二定律是决定论式预测的工具基础：受力一旦确定，运动就被唯一确定。
