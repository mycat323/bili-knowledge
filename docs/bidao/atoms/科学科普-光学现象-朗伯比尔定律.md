# 朗伯比尔定律

## 一句话定义

光在液体中传播时强度随距离指数衰减，液体越厚吸收的光越多，透出的颜色就越深越暗。

## 详细说明

1729 年，法国科学家皮埃尔·布格第一个发表论文指出，光在液体当中走，强度随距离指数衰减。为纪念他的贡献，这个规律被称作朗伯比尔定律。

它解释了为什么同一杯液体换个厚度就换个颜色：光穿过液体时被吸收的比例与穿过的距离有关，距离越长，被吸收的光越多，透出来的光越弱、颜色越深。所以香油、可乐、咖啡、水都会随厚度改变观感。

这条定律不只是解释火锅店里的怪现象，它开辟了科学分析的全新领域：以它为原理的紫外分光光度计造福了无数环化材生的研究生；大气学家利用它监测地球的二氧化碳浓度；智能手表也用它监测血氧含量。

因此，变色的香油不是科技狠活，桶也不是特制的桶，背后只是这条定律。
