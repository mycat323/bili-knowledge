# 论文乌龙与审稿失职

## 一句话定义

一篇子宫肌瘤论文声称选取了 80 例患者，其中 25 名女性、55 名男性，且所有患者都签署了知情同意书，暴露了作者、审稿人和编辑层层失职。

## 详细说明

一篇关于子宫肌瘤的论文在实验方法中写道：研究选取了 80 例子宫肌瘤患者，25 名女性，但有 55 名男性。而且论文声称所有患者都签署了知情同意书。

男性不会得子宫肌瘤，所以这 55 名男性究竟同意了什么，成为明显的逻辑漏洞。这篇文章是 2017 年的，发表八年后才被抓出来撤稿，作者也受到了处分。

这个案例说明：作者自己可能都没看过，审稿人也没看过，期刊编辑也没看过，发表八年来应该也没人看过。本着对论文这个东西的信任，第一次看到时甚至会产生疑惑——难道男性确实可以得这种病吗？现在看来应该是不可以的。
