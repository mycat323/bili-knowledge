# 响水不开开水不响

## 一句话定义

水加热时声音先随温度升高而增强，在六七十摄氏度达到顶峰，之后减弱，完全沸腾时转为低沉声音，即俗语所说的响水不开、开水不响。

## 详细说明

烧水过程中声音的变化可以分为三个阶段：

1. **初期安静**：刚开始加热时水比较安静，几乎没有明显声响。
2. **响声增强到顶峰**：随着水温上升，水开始发出声音，并且越来越响，在六七十摄氏度时达到顶峰。此时水还远没有开，这就是「响水不开」。
3. **响声减弱并转为低沉**：继续加热到八九十摄氏度，响声反而明显减弱；完全烧开后，声音变成一种低沉的声音，这就是「开水不响」。

这个现象看似违反直觉：温度越高能量越高，水里的对流越剧烈，声音理应更响。但六十摄氏度的水看着平静却「唠唠叨叨」，剧烈沸腾的开水反而「静静悄悄」。

关键线索是：响水和开水的声音并不是同一声音的强弱差别，而是两种不同的声音。开水的声音听起来像是往水里吹大泡泡的声音。因此要解释这个俗语，需要分别找出两个阶段各自的声音来源。
