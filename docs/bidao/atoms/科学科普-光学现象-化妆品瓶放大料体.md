# 化妆品瓶放大料体

## 一句话定义

化妆品瓶多为玻璃或亚克力，折射率约 1.5，料体贴紧瓶壁时被放大到实际粗细的约 1.5 倍，看着比真实用量多。

## 详细说明

把一管化妆品锯开，料体半径只有截面的一半，面积只有四分之一，即四分之三都是包装；但视线移下来，厚瓶壁让细细的料体填满针管，视觉上显得很粗。从底部看，瓶身外侧的缺口与料体缺口一一对应，说明是瓶子把料体从细放大到了粗。

化妆品瓶一般是玻璃或亚克力等高分子材料，折射率通常在 1.5 左右。料体柔软、能贴紧内壁，满足贴壁放大的条件，所以瓶子能把料体放大到实际粗细的约 1.5 倍。

泡在水里时，上方水凹透镜会把它缩小约 1.33 倍，最终约为真实粗细的 1.13 倍，所以水确实能大致还原化妆品的真实粗细。想更准确地看真实粗细，可以泡在开塞露里：甘油折射率约 1.5，能完美还原；或者直接买方管化妆品，方管没有任何放大缩小效果。

同样的放大也发生在圆柱形罐头和口服液上：黄桃看着更大，口服液看着满满一罐，其实里面没多少药。
