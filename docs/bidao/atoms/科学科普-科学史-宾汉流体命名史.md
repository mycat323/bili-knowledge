# 宾汉流体命名史

## 一句话定义

宾汉流体由宾汉 1916 年提出屈服应力解释，但「宾汉流体」这一名称由 Oldroyd 和平井一二在 1949 与 1954 年先后确立。

## 详细说明

宾汉流体的命名有一段曲折的历史。

- 1916 年，宾汉（Bingham）在开山之作中给出解释：悬浮物中的固体颗粒网络让它在静止时具有固体般的屈服应力；当外力超过临界值，颗粒网络被破坏成小结构，流体开始流动、粘度降低。
- 1949 年，英国流变学家 Oldroyd 率先使用了 Bingham solid 这个词。
- 1954 年，日本的平井一二先生在《管内塑性流体の热伝达の理论解に就いて》中首次使用了「宾汉体」和「宾汉流体」的说法。

可惜宾汉先生于 1945 年去世，所以他并不知道自己研究的这类物质后来叫宾汉流体。

这段历史也说明：科学概念的命名往往滞后于发现，一个现象被研究清楚之后，可能还要等几十年才获得统一的名字。
