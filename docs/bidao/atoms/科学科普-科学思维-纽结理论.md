# 纽结理论

## 一句话定义

纽结理论是拓扑学的一个分支，研究绳结在连续变形下是否等价，用同痕、Reidemeister移动和琼斯多项式等工具区分结的本质。

## 详细说明

1867年，开尔文勋爵提出原子可以描述为漩涡的结。这个想法虽然没多少人理会，但数学家们由此从拓扑学中开辟出一个分支——纽结理论。

纽结理论要回答的核心问题是：两个看起来不同的结，是否本质上一样？只通过拉扯、扭转、移动，一个结能否变成另一个结？有些结看起来密密麻麻，实际上能轻松拉开；有些结又小又简单，却越拉越紧。

- **平凡结**：一拉就开的结，学术上叫平凡结，看着唬人，其实相当于没打结。翻花绳、一下松开的鞋带都是平凡结。
- **同痕**：本质上一样的结，在数学上称为同痕。
- **Reidemeister moves**：扭、交叉、移动这些判断结是否同痕的最简单操作。爱翻花绳的小学生其实就是在复杂的Reidemeister移动组合中探究花绳的同痕不变量。
- **琼斯多项式**：1985年琼斯发现的一个多项式族，可以用来描述一个结的结构。
