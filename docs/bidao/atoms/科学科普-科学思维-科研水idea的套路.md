# 科研水idea的套路

## 一句话定义

科研中浅显 idea 的常见套路是替换材料、调控参数、更换预处理手段，再配全套表征包装成论文。

## 详细说明

毕导用「炒蛋」作比喻，自嘲自己只能提出浅显易懂的 idea，并总结出几种典型套路：

| 套路 | 炒蛋版例子 | 论文版对应 |
| --- | --- | --- |
| 替换材料 | 别人西红柿炒蛋，我拿哈密瓜炒蛋 | 有效解决前人炒蛋太酸不甜的问题 |
| 调控参数 | 调控菜籽油、橄榄油、花生油浓度分别炒蛋 | 标题叫《基于油品浓度动态调控法的哈密瓜炒蛋制备及性能研究》 |
| 更换预处理 | 别人用桌子磕蛋，我用大锤砸蛋 | 提升蛋碎成功率，工业应用前景广泛 |
| 全套表征 | 用电镜、红外、原子把蛋全部测一遍 | 补足数据量 |

他还模仿论文腔调补上一句「However, so far, 大锤砸蛋 has not been fully investigated」。

毕导同时承认，自己佩服 CNS、JACS、AM 上那些巧妙的 idea，但确实不知道怎么想出来的，本质原因是积累少、对科学领域洞察不足。他把这种水 idea 描述为「一聊就文思泉涌」，但清楚它只是保底手段，不是科研的目标。
