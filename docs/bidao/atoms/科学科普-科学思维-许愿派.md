# 许愿派

## 一句话定义

只宣布「传送带就是能让飞机飞不起来」，却不说它靠什么工作逻辑做到这一点，这样的立场无法被检验也无法被反驳。

## 详细说明

讨论跑步机时，定义传送带必须指明它的工作逻辑：它「与飞机速度一致」到底是指追踪机身速度，还是追踪轮子转速？不说清楚，「一致」二字就没有确定含义。

两种可分析的路径都已经走完：追踪机身速度（v带 = v机）拦不住飞机，飞机照常前进起飞；追踪轮速（v带 = v轮）对人和汽车有效，但对飞机会触发自指悖论，机器根本无法造出来。

于是只剩下一种表述：「不管怎么样，传送带就是可以让上面的飞机无法前进」。它没有给出任何机制，也就无法被公式检查、无法被实验否定。视频把这种立场称为许愿派——它不属于任何一种可以被讨论的定义，只是把结论当成了前提。
