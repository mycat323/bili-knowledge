# 声音灭火的多种错误机理

## 一句话定义

在振膜风被确认前，学界对声音灭火提出过至少三种看似合理的机理，但都未控制住风这一变量。

## 详细说明

早期文献提出的三种代表性机理：

1. 声波振动说：声音是纵波，传播路径上的空气微粒前后振动，火焰区域微粒被带着振动，响度越大振幅越大，大到一定程度使火焰整体震动失稳而熄灭。
2. 声能吸收说：火焰中的分子吸收声能转化为运动动能，火焰从蜡烛顶上离开，石蜡蒸汽跟不上，燃料供给被切断。
3. 温度切断说：热火焰被声音震到一边，原地升上来的蜡蒸气还是冷的，达不到着火点，火焰回来碰到冷蜡蒸气就熄灭了。

这些机理听起来都自洽，但共同的漏洞是没有排除音响振膜产生的风。挡板实验表明，只要挡住风，火焰就不再受声音影响，说明上述机理都不是主因。
