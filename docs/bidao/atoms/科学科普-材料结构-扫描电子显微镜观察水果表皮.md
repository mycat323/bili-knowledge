# 扫描电子显微镜观察水果表皮

## 一句话定义

扫描电子显微镜用电子束扫描样品表面，能拍到果蜡等微观结构的形貌，是研究结构色的关键观察手段。

## 详细说明

要确认蓝莓的蓝色是否来自果蜡的微观结构，光靠肉眼和砂纸实验还不够，需要看到果蜡在微观尺度上长什么样。

扫描电子显微镜用聚焦电子束逐点扫描样品表面，收集二次电子等信号成像，分辨率远高于光学显微镜，可以拍到纳米到微米级的表面形貌。

用它观察蓝莓表皮，能看到果蜡并不是一层光滑的膜，而是有特定排列的微观结构。正是这种结构对光产生作用，让无色的果蜡呈现出蓝色。

这类观察把宏观现象（蓝莓看起来是蓝色）和微观机制（果蜡的结构）连接起来，是结构色研究的标准路径。
