# 数觉的进化解释

## 一句话定义

有观点认为数觉源于早期人类打猎时快速判断野兽数量的需要，能瞬间看出敌人数量的人存活率更高。

## 详细说明

从进化论角度解释数觉起源的一种说法是：早期人类打猎时，如果遇到两三个野兽，有数觉的人能瞬间看出敌人数量，从而思考战斗策略，存活率更高。所以有数觉的人比没有数觉的人更「适者生存」。

那为什么数觉只停留在五，而不是十个以上？按同样的逻辑，能瞬间数出十个以上的人岂不是更适应环境？视频给出的解释是：遇到五个以上的野兽，数不数觉已经不重要了——要么直接跑，要么已经来不及，快速判断数量的收益大幅下降。

这个假说与心理学实验的观察相吻合：数觉在一到三个物体时最准最快，四个开始出错，五六个就必须切换到数数。进化压力只把这种能力打磨到「够用」的程度，而不是无限提升。
