# 厚缸中固体不被放大

## 一句话定义

厚壁圆柱容器对内部固体几乎没有放大效果，因为固体难以真正贴紧内壁，中间总隔着薄薄空气层，等效于折射率为 1 的介质。

## 详细说明

往大厚缸里倒沙子，从顶上看沙壁紧贴内壁，但从侧面看，内壁被放大到了远处，沙子却留在原地，中间空出一段仿佛虚空。不管往缸中间放什么东西，看上去都在原地。

原因在于：固体（沙子、小球）很难在微观上真正贴紧内壁，中间总会隔着薄薄的空气层。把液体模型套过来，沙子仿佛浸泡在折射率等于空气的液体里，所以放大率等于空气的折射率 1，也就是不放大。

这个解释留下一个未解之谜：如果把气球或手指死命怼在大厚缸内壁上，它们的像会鬼魅般浮现在缸壁里，最远能到内壁的边界。视频作者猜测，这可能是贴紧到亚波长级别后发生了受抑全内反射，倏逝波把光「碎」穿进去了，但尚未有定论。
