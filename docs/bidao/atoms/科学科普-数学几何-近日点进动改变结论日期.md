# 近日点进动改变结论日期

## 一句话定义

地球近日点的日期并非固定，受月球和太阳系其他行星引力影响，地球轨道持续进动，每年到达近日点的时间晚约二十多分钟，累积两千五百年后日期偏移约四十三天。

## 详细说明

第四层：地球公转还受月球和太阳系其他行星引力扰动，所以每年「中午更远」的具体日期会有几天偏差，不同年份结果略有不同。

第五层：地球轨道在进动。地球每年进动六十一点八角秒，换算成时间就是每年到达近日点的时间晚二十多分钟。这个变化极其微小，人根本感觉不到，但时间的长河可以累积。

孔子见到两小儿距今约两千五百年。那时地球的近日点不是现在的一月三号，而是比现在早四十三天，落在十一月二十号。据此推算，孔子围观两小儿辩日时，十二月六号到四月十六号是中午的太阳更近。

最后一层是历法问题：公历明朝才传入中国，孔子不知道「十二月六号」是什么。好在二十四节气两千五百年未变，换算成农历后，最终结论是：大雪前的一两天到谷雨前的四五天，中午的太阳更远，其余时间早上的太阳更远。
