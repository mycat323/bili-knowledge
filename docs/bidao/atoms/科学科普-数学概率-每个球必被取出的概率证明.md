# 每个球必被取出的概率证明

## 一句话定义

在花瓶悖论中，任意编号的球在无穷次操作后仍留在花瓶里的概率为零，即它百分之百会在某一次被取出。

## 详细说明

以一号球为例。第一轮放入十个球后取出一个，一号球没被取出的概率是 9/10。第二轮放入十个球，瓶中共有十九个球，取出一个而没取到一号球的概率是 18/19。第三轮瓶中有二十八个球，没取到一号球的概率是 27/28。

于是经过 n 轮操作后，一号球仍在瓶中的概率是：

(9/10) × (18/19) × (27/28) × …

把这个乘积展开并化简，可以得到一个调和级数形式的表达式。当轮数 n 趋于无穷大时，该乘积的极限等于零。

也就是说，一号球留在瓶中的概率是 0，它必然在某一次操作中被取出。对二号球、三号球乃至任意编号的球做同样的计算，结论完全相同：每个球都百分之百会被取出。既然所有球都必然被取出，无穷次操作结束后花瓶里自然一个球也不剩。
