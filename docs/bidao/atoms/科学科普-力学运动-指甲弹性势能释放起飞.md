# 指甲弹性势能释放起飞

## 一句话定义

指甲水平方向有微妙弧度而指甲刀刀口平行，剪时指甲被压扁形变储存弹性势能，断裂后势能释放转化为动能使其飞出。

## 详细说明

慢镜头揭示了指甲飞舞的完整过程。指甲整体上是扁平的，但在水平方向上有一个微妙的弧度；而指甲刀的刀口在水平方向却是平行的。

剪指甲时，指甲刀会压扁指甲，指甲像弹簧一样发生形变，储存弹性势能。当指甲刀做的功 W 超过了指甲断裂所需要的能量 W0 时，指甲就会断裂。随后指甲瞬间恢复原本的形状，弹性势能释放，转化为断裂指甲的动能，指甲就地起飞。

这一机理也提示了解决思路：如果有一个和指甲相同曲率的弧形指甲刀，让刀口贴合指甲弧度，理论上就能避免压扁形变，从而解决问题。
