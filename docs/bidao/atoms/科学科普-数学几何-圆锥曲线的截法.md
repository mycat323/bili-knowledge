# 圆锥曲线的截法

## 一句话定义

用平面去截圆锥面，随着平面倾斜程度不同，交线依次是圆、椭圆、抛物线和双曲线，这一分类由古希腊数学家阿波罗尼奥斯在《圆锥曲线论》中给出。

## 详细说明

公元前三世纪，古希腊数学家阿波罗尼奥斯在《圆锥曲线论》中指出：用平面去截圆锥，平着截得到圆，斜一点截得到椭圆，平行于母线截得到抛物线，竖着截得到双曲线。

这四类曲线在生活中出现的频率差别很大：圆、椭圆、抛物线都很常见，唯独双曲线几乎见不到。但在这期视频里，它藏在沟槽的反光中——案板上那条反射亮线正是竖直平面截圆锥面得到的交线，所以它是一条标准的双曲线。
