# 声音灭火实为振膜风

## 一句话定义

音响播放声音时振膜前后振动推动空气形成风，真正吹灭蜡烛的是这股风，而非声波本身。

## 详细说明

把蜡烛放在音响前播放六十赫兹低频声音，火焰会剧烈摆动甚至熄灭。但若在蜡烛与音响之间插入一块挡板，火焰几乎不动；拿开挡板火焰又动。挡板挡不住声音——蜡烛接收到的频率和响度都没变，说明起作用的不是声音，而是被挡板挡住的气流。

音响工作时振膜一阵一阵地向外推空气，形成一股定向的风，这股风把火焰吹灭，与声波、振动、声压都无关。可验证的判据：

- 振膜运动与火焰运动完全同步；
- 音响振膜处能明显感到有风；
- 蜡烛离音响稍远就灭不掉，因为风吹不了那么远；
- 低频比高频效果好，因为播放低频时振膜振幅更大、风更强。

声波引起的空气粒子位移约为微米量级，对火焰没有影响。
