# 弹幕同步评论

## 一句话定义

弹幕是把观众评论按视频播放时间点叠加在画面上的评论形式，同一时刻的评论会同时出现在屏幕上，形成多人同步观看的体验。

## 详细说明

弹幕的核心机制是**时间轴绑定**：每条评论在发布时记录它对应的视频播放进度，播放到该进度时这条评论才出现在画面上并横向飘过。因此不同时间观看同一视频的人，看到的弹幕内容与出现时机基本一致，形成一种「虽然不同时、却像同时」的集体观看感。

与普通评论区相比，弹幕的差异在于：

| 维度 | 弹幕 | 普通评论 |
| --- | --- | --- |
| 位置 | 叠加在画面上 | 视频下方独立区域 |
| 时机 | 绑定播放进度 | 按发布时间排序 |
| 体验 | 与画面同步、瞬时 | 事后阅读、可长文 |

这种形式让「热闹」不只来自节目本身，也来自观众之间的即时呼应。转写稿中把「有弹幕」和「热闹」直接并列，正是强调弹幕带来的共看氛围。
