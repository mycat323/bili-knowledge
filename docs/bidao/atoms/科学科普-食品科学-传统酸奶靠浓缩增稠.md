# 传统酸奶靠浓缩增稠

## 一句话定义

传统酸奶工艺先加热浓缩牛奶蒸发水分，再经均质、灭菌、接种、发酵，不加添加剂也能得到浓稠酸奶。

## 详细说明

为获得浓稠质地，食品商家常用变性淀粉、果胶等添加剂，这样还能减少真正牛奶的用量。而传统酸奶制作工艺的第一步是加热浓缩牛奶，适当蒸发掉牛奶中的水分，再经过均质、灭菌、接种、发酵，不用任何添加剂也能得到香醇好喝的酸奶。

视频中提到的简爱零蔗糖酸奶即遵循这一思路：配料表只有生牛乳和乳酸菌，采用 1.3 倍浓缩鲜奶，不靠添加剂增稠，蛋白质含量比普通酸奶高出 42%，钙含量高出 26%。

乳酸菌选择上搭配了特别的中温菌品种，能带来类似奶酪的醇厚口感。市面上很多酸奶为迎合口感加入大量糖，含糖量接近可乐。
