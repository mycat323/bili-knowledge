# 斑马是黑底白纹

## 一句话定义

斑马是黑底白纹的：斑马宝宝在妈妈肚子里刚开始就是全黑的，之后慢慢长出条纹状的黑色素缺失，没长好的小斑马就是一匹小黑马的样子。

## 详细说明

关于斑马是白马黑条纹还是黑马白条纹，答案是黑底白纹。

斑马宝宝刚开始就是全黑的，在妈妈肚子里慢慢长出了条纹状的黑色素缺失，也就是黑色素没有长上的部分呈现白色，于是形成条纹。没长好的小斑马，就是一匹小黑马的样子。

这与猫猫狗狗的染色方式形成对比：很多猫猫狗狗身上有颜色但肚子是全白的，是因为色素细胞从背上的脊柱位置开始往下长，长到哪算哪，没墨了就停，经常长到肚子就没墨了。这个过程像是拿盆墨水往背上一泼，颜色染到哪全看缘分。而斑马、豹子、老虎这类规整的斑纹，则更可能由图灵反应扩散机制产生。
