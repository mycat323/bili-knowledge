# 罗素悖论

## 一句话定义

罗素悖论由理发师悖论引出：一个只给不自己理发的人理发的理发师，若给自己理发则违反规则，若不给自己理发则又该给自己理发，两种结论同时成立而矛盾。

## 详细说明

罗素悖论是二十世纪初打破数学对错分明信念的经典悖论之一。通俗版本是理发师悖论：理发师宣布「我只给不自己理发的人理发」，那么他给不给自己理发？

- 如果他不给自己理发，按规则他就得给自己理发；
- 如果他给自己理发，按规则他就不能给自己理发。

两个相反的结论都能推出，理发师被「CPU 干烧了」。罗素悖论的原始形式更清楚，它直接指向集合论中「用自己定义自己」的套娃式说法。

这类悖论对数学是灾难，因为矛盾模糊了真与假的概念。视频中强调，一对矛盾足以用来证明一切，这就是爆炸原理。因此数学中绝不允许出现罗素悖论这样的矛盾，一个不知道给不给自己理发的理发师必须死。

解决路径包括罗素的类型论（把数学对象排出层次结构，禁止用自己定义自己）和策梅洛等人建立的 ZFC 集合论（不会出现罗素悖论）。
