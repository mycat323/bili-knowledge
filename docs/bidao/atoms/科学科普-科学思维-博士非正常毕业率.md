# 博士非正常毕业率

## 一句话定义

我国博士的非正常毕业率在百分之六十多，硕士在百分之十几，读研因此是孤独而艰难的过程。

## 详细说明

毕导在视频结尾给出了一组数据：我国现在一年的博士毕业人数大约是七万，硕士是七十万；但博士的非正常毕业率在百分之六十多，硕士在百分之十几。

这组数字说明，延期或未能按期毕业在博士阶段是多数情况而非例外。毕导自己从 2010 年进入清华到 2023 年博士毕业，前后共十三年，其中博士阶段因休学创业和复学而拉长，他自嘲「一不小心把这个博士读了九年」。

他由此得出的结论是：读研确实是孤独而艰难的，硕博毕业表明你在某一知识领域经受了若干年的学术创新训练并通过了成果考核，但考核完之后怎么过毕业后的人生，是更需要思考的选择。

这组数据也解释了为什么他把「与自己和解」看得比科研水平进步更关键——在多数人都会延毕的现实下，接受普通毕业、保持内心自洽，是可持续完成学业的心理基础。
