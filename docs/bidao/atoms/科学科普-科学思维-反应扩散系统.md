# 反应扩散系统

## 一句话定义

反应扩散系统是图灵斑图思想的升华形式，描述物质在局部反应与空间扩散共同作用下自发形成稳定图案的机制，广泛存在于化学、生物、地质乃至星系尺度。

## 详细说明

图灵斑图的存在远比想象中广泛，它升华为一种思想，成为反应扩散系统。最容易拓展的是化学，因为图灵斑图本就是生物体内的化学反应，图灵在提出斑图时顺便预言了震荡化学反应。后来 BZ 反应被发现，培养皿中涟漪般的蓝色圈圈神秘浮现，又在相撞后湮灭，这种图案也是一种图灵斑图。

反应扩散系统可以拓展到不同尺度：

| 尺度 | 例子 | 激活与抑制 |
| --- | --- | --- |
| 原子 | 铋晶体在硒化镍表面结晶 | 铋原子垂直位移为激活剂，水平位移为抑制剂 |
| 地球 | 沙丘波纹 | 风把沙子吹高是激活，高处挡风、滑落是抑制 |
| 地球 | 斯瓦尔巴群岛冻土石圈 | 冻土推动石头的复杂运动，方程仍是反应扩散方程 |
| 宇宙 | 星系螺旋结构 | Lee Smolin 1996 年论文提出类似反应扩散的方程 |

从最小的原子到最广袤的星系都能找到它的踪迹，说明图灵斑图简单、优雅又深刻。
