# 亲水粉末收缩

## 一句话定义

高表面能的亲水性粉末如亲水二氧化硅落到水面后不会铺开，反而会收缩成一团，看起来像倒放。

## 详细说明

往水上撒亲水性二氧化硅，它们不会像胡椒粉那样铺满水面，反而会缩回来。即使刻意把它撒满整个水面，它们也会收成一团，效果看起来像视频倒放。

这与疏水粉末的行为正好相反：疏水低表面能粉末会主动铺展、挤开别人；亲水高表面能粉末则倾向于收缩，不占据水面。

这一对比说明，粉末在水面上的铺展或收缩取决于其表面能相对水的高低，是表面能驱动下的自发行为。
