# 水下观察湿裤子

## 一句话定义

把湿裤子泡在玻璃缸中、眼睛也潜入水下观察，排除了水—空气界面的全反射，湿裤子依然很深，说明全反射不是变深的主要原因。

## 详细说明

全反射只发生在光由水射向空气的界面上。如果湿裤子变深真是因为水膜把光全反射回纤维，那么当观察者也在水中、不存在水—空气界面时，裤子就应该不变深。

实验做法：把裤子泡在玻璃缸里，先在水面外看干裤子的颜色，很浅；再看湿裤子的颜色，很深；然后整个人潜入水中直接观察湿裤子。结果是水下的湿裤子和水上的湿裤子颜色差不多深，若说有区别，水下可能还稍微亮一点点。既然没有全反射时湿裤子依然很深，全反射就不是变深的主要原因。

1983年，美国大气学家Boring的实验也质疑了昂斯特伦的模型：给沙子浇水会变深，浇折射率更高的甘油则变得更深，变深程度取决于液体折射率。若按昂斯特伦模型，液体折射率从1.35变到1.4时沙子应只变暗约百分之七，实际却变暗约百分之四十。
