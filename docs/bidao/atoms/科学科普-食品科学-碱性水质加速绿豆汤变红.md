# 碱性水质加速绿豆汤变红

## 一句话定义

碱性条件下多酚更易去质子化形成酚阴离子，给电子能力增强，因此碱性水煮出的绿豆汤更快变红，酸性水则偏绿。

## 详细说明

实验设计：三只三角烧杯各倒入三百毫升纯净水，第一杯加少量柠檬酸，第二杯不加，第三杯加少量小苏打，用 pH 试纸确认分别为酸性、中性、碱性。各加入十五克绿豆开煮。

二十分钟后结果：酸性和中性水煮出的绿豆汤都偏绿色，碱性水煮出的呈红褐色。

原理：碱性条件下酚羟基更容易去质子化，形成电子密度更高的酚阴离子，更容易向氧化剂给出电子，自身转化为醌，所以变色更快。

这解释了「南绿北红」的说法：北方水质偏硬、碱性可能更强，煮出的绿豆汤更容易变红。有些人煮绿豆时会加碱帮助煮烂，也会让汤变红。

注意：自来水的实际情况更复杂。实验中北京自来水（pH 8.09）和杭州自来水（pH 8.29）煮出的绿豆汤都是红色，但碱性稍弱的北京自来水反而更快变红，说明除 pH 外还有其他因素在起作用。
