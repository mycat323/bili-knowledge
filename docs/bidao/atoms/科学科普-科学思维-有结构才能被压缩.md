# 有结构才能被压缩

## 一句话定义

物理规律能以更简洁的形式写出，说明世界有内在结构；没有结构的东西无从压缩，无规律不可压缩才是常态，简洁是稀少的幸运。

## 详细说明

物理规律能以更简洁的形式写出，这正说明我们的世界是有内在结构的。

一个直观的类比是循环小数 0.142857142857……。为了表达它，你需要无限位数字；但因为这个数有完美的结构，我们可以把它写成 1/7，只要两个数字就能表达它。反过来，如果你随便挑一个无理数，它大概率是一坨混乱的数，你没有任何办法把它写得更简洁。

所以没有结构的东西其实无从压缩，而无理数远多于有理数。这暗示我们，世界上无规律、不可压缩的事物是常态，有结构、能变得简洁的东西才是稀少的。

但我们世界的物理学竟然可以被压缩得如此简洁，让我们以最少的因说明最多的果，这是多么幸运的一件事，也可见物理学的结构是多么深邃。从亚里士多德到伽利略、牛顿、爱因斯坦、薛定谔、杨振宁，每一个公式当中都蕴含着越来越美的规律和智慧。
