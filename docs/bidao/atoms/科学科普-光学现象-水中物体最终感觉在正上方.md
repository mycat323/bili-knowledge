# 水中物体最终感觉在正上方

## 一句话定义

眼睛虽然接收到子午像和弧矢像两个虚像，但大脑会把二者合成为一个像，最终让人感觉水下物体就在实际位置的正上方。

## 详细说明

眼睛能看到一前一后两个像，但大脑不会把「站在水里的人腿向自己靠过来」这种画面直接呈现给意识，否则视觉会显得混乱。大脑把子午像合成掉，只保留弧矢像的效果，于是人不会觉得水里的物体在靠近自己。

用双眼看水下物体时，理论上会出现左眼子午像、右眼子午像和双眼重合的弧矢像共三个像；如果两只眼睛竖着排列，还会出现左眼子午、右眼子午、左眼弧矢、右眼弧矢四个像。大脑同样会把它们合成为一个，否则会看到水里有好几条鱼。

所以「水中物体在哪」分三层：按折射定律作二维图，虚像更靠近人眼；考虑三维光锥，物体有两个像；再考虑大脑的合成，最终感觉物体就在实际位置正上方。真实鱼的位置始终在所见位置的正下方。
