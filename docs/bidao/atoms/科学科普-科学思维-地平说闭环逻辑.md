# 地平说闭环逻辑

## 一句话定义

地平说支持者用一套自洽的解释逐条反驳地球是球的常见证据，使辩论陷入举证循环而无法取胜。

## 详细说明

视频中，地平说支持者面对常见证据时，都能给出内部自洽的反驳：

| 常见证据 | 地平说的反驳 |
| --- | --- |
| 微信加载界面是地球 | 照片可能是 P 的，是上面的阴谋 |
| 麦哲伦环球航行 | 历史故事不一定是真的 |
| 走到大地边缘会掉下去 | 边缘的人掉下去死了，所以没人发出警告 |
| 世界各地有时差 | 太阳像有灯罩的手电筒，只发出窄窄一道光 |
| 月食缺口是圆形 | 平面圆饼一样可以挡出圆形影子 |
| 南北半球星空不同 | 星星离地面只有几十公里，越往南角度越低被楼房挡住 |

这套逻辑的特点是：只信眼见为实，不信历史事件，任何证据都能被重新解释。毕导由此意识到，网络上很多人从一开始就没打算被说服，和他们辩论只会不停举证，但永远无法取胜。
