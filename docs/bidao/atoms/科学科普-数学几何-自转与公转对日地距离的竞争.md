# 自转与公转对日地距离的竞争

## 一句话定义

从早上到中午，地球自转使人向太阳靠近约六千多千米，而公转带来的远离量在数量级上也是六千多千米，两者势均力敌，谁占上风取决于具体日期。

## 详细说明

第二层：地球自转。日出时人在晨昏线上，中午转到正面，半个白天里向太阳靠近约一个地球半径的量级，即六千多千米，具体数值随纬度和太阳直射纬度变化。

第三层：地球公转。地球轨道是椭圆，每年一月初离太阳最近（近日点，约一点四七一亿千米），七月初最远（远日点，约一点五二亿千米）。做数量级估算：半年远离约零点零五亿千米，每天约两万七千千米，每四分之一天约六千多千米——恰好与自转靠近量相当。

于是出现两种情形：七月到一月，自转靠近、公转也靠近，中午必然更近；一月到七月，自转靠近而公转远离，若公转远离抵消了自转靠近，中午反而更远。

精确计算需要日地距离公式（半长轴除以一加偏心率乘 cos 真近点角）、半个白天比例公式，以及太阳直射点纬度数据。对北京（北纬四十度、东经一百一十六度）而言，二零二五年一月二十二日到六月五日是中午太阳更远，全年一百三十五天中午远、二百三十天早上远。
