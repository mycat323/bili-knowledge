# 亚克力板热弯成型

## 一句话定义

亚克力板受热后变软，可在软化状态下被外力掰弯，冷却后固定成新的弯曲形状。

## 详细说明

亚克力（聚甲基丙烯酸甲酯）是一种热塑性材料，温度升高到玻璃化转变温度以上时会变软，此时施加外力就能改变它的形状，冷却后形状被固定下来。

视频中才浅用热风枪对亚克力板加热，然后把它掰弯，这就是最基础的热弯成型工艺。整个过程不需要模具或复杂设备，一块板加一把热风枪即可完成。

热弯成型的关键在于温度：温度不够时板材仍然偏硬，掰弯容易开裂或回弹；温度过高则可能起泡、烧焦或失去透明度。视频里才浅也提到「感觉这个热风枪不是很热」，说明加热温度是否到位直接影响成型效果。

这种工艺在广告招牌、展示架、灯箱等场景中很常见，也是把平面透明板材加工成曲面光学元件的入门手段。
