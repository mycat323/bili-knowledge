# 调和级数极限为零

## 一句话定义

花瓶悖论中球留在瓶内的概率乘积化简后呈调和级数形式，当操作次数趋于无穷时该乘积的极限为零。

## 详细说明

在计算某个球经过无穷次操作后仍留在花瓶里的概率时，会得到一长串分数的连乘，例如 (9/10) × (18/19) × (27/28) × …。把每一项的分子分母整理后，这个连乘式可以化成一个与调和级数相关的形式。

调和级数 1 + 1/2 + 1/3 + 1/4 + … 是发散的，即它的部分和随项数增加而无限增大。利用这一性质，可以判断上述连乘式的极限。当操作次数 n 趋于无穷大时，连乘的结果趋于零。

这一步是整个证明的关键：它把「球是否被取出」这个概率问题，转化成了一个关于级数收敛性的数学问题。结论是概率为零，也就是球几乎必然被取出。理解这个极限需要中学以上的级数知识，但思路本身并不复杂。
