# 侧斑蜥蜴求偶循环

## 一句话定义

加州侧斑蜥蜴的橘、黄、蓝三种雄性求偶策略互相克制，形成类似石头剪刀布的循环，已持续约一点七五亿年。

## 详细说明

加州侧斑蜥蜴在求偶中有一种奇妙现象：雄性蜥蜴喉咙有橘、黄、蓝三种颜色，雌性只有黄色。

三种雄性的策略与相克关系：

| 颜色 | 策略 | 相克关系 |
| --- | --- | --- |
| 橘 | 进攻者，很强 | 打败蓝蜥蜴和雌蜥蜴 |
| 黄 | 伪装者，很弱 | 伪装成雌性骗过橘蜥蜴 |
| 蓝 | 守护者，战斗力不强 | 守住老婆，赶走黄蜥蜴 |

橘蜥会打败蓝蜥蜴，黄蜥会骗过橘蜥，蓝蜥会赶走黄蜥，三者像石头剪刀布一样形成美妙的循环相克。这种古老的求偶策略已经持续了约 1.75 亿年，主导丛林的蜥蜴颜色在橘黄蓝间循环往复，从恐龙时代至今生生不息。

它说明石头剪刀布式的非传递性博弈并非人类发明，而是自然界长期存在的稳定策略结构。
