# 自相似迭代生成分形

## 一句话定义

大自然不需要精准控制细节，只要让简单的步骤在所有尺度上不断重复，复杂而规律的分形结构就会涌现。

## 详细说明

分形的生成机制是自相似的迭代：把简单的步骤在所有尺度上不断重复，复杂而规律的结构就涌现出来。

自然中的例子：海浪拍打岸边，总有些地方更薄弱、被优先侵蚀，海岸线就形成了从大到小的各种凹凸；一道闪电劈出，总有些路径能更快释放能量，就形成了弯弯绕绕的分叉；水在河床上汇聚，所有的水都想快点降低重力势能，所以形成复杂的支流结构，支流之上还有支流，难以穷尽。

分形在生物体上也有功能意义——长成分形能获得极大的表面积。同样体积的物体，想让表面积最小就缩成球，想让表面积最大就进化成分形。人的大脑在很小体积里折叠出沟沟回回，约 2.8 维；肺不断分叉长出几十亿个肺泡，达到约 2.97 维。

分形维度甚至能反映健康状况：健康视网膜上的血管约 1.4 维，近视会让它下降；正常人海马体神经元大致排列成 1.45 维，阿尔茨海默病人海马体中的神经元会增长到 1.75 维。
