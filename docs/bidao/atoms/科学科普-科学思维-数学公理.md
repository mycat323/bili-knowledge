# 数学公理

## 一句话定义

数学公理是通常显然成立、不证自明、大家都接受的命题，被希尔伯特纲领当作每个数学领域的出发点，从公理出发一步步证明其他命题是真是假。

## 详细说明

在希尔伯特纲领中，公理是宇宙万法那个源头。公理通常是一些显然成立、不证自明、大家都接受的命题。视频举的例子是「两点确定一条直线」，以及玩笑式的「毕导的视频都应该三连」。

公理的作用是作为证明的起点：从公理出发一步步证明其他的命题是真是假，就绝对严谨。视频以算术领域为例，给出皮亚诺公理，看着都很简单，但从它们出发只要五十多步就可以方便又严谨地证明一加一等于二。

希尔伯特纲领要求在每个数学领域都规定一些基本的公理，再把公理写成形式语言，用来证明其他一切。这样数学就褪去了模糊的面纱，将纯粹的美貌向人类展现出来。

需要注意的是，公理本身不证自明，但整个体系是否完备、一致、可判定，是希尔伯特纲领另外要证明的三条品质。
