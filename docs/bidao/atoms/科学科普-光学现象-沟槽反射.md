# 沟槽反射

## 一句话定义

光照射在布满平行凹槽的表面上时，每道沟槽都像一面 U 型小镜子把光反射向不同方向，其中总有一点把光镜面反射进观察者的眼睛，这些点连成一条始终指向观察者的连续亮线。

## 详细说明

拉丝不锈钢案板上有一条条与短边平行的沟槽。把它放在实验台上打光，案板上会照亮一条竖线；左右移动眼睛，这条线会跟着走，并始终垂直指向观察者。

对照实验能看出差别：用激光笔照镜子，镜子上是一个光点，墙面上也是一个光点；用激光笔照案板，墙面上反射出的却是整整一条竖线——激光打在案板上仍是一个光点，经沟槽反射后变成了一面光幕。

原因在于：照在镜面上发生镜面反射，反射光方向固定；而一道凹陷的沟槽相当于一面 U 型小镜子，会把光线反射到许多方向形成扇形，其中总有一条光线能进入眼睛。当沟槽很密集时，每道沟槽里都有某个点把光镜面反射进眼睛，这些点在眼中都是亮的，于是连成一条连续的、指向观察者的反射亮线。

这种反射既有镜面反射的规整，又有漫反射的混乱。平静湖面上太阳的倒影还是太阳；大海上有波浪，每道波浪就像一道沟槽，太阳倒影如同奶油般化开成一条；洗发水广告最爱拍的高光天使环，拍的也是沟槽。
