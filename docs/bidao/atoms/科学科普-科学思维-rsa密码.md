# RSA 密码

## 一句话定义

RSA 是一种现代密码，安全性建立在质因数分解的困难之上：大数相乘容易，把大数分解回质因数却极难。

## 详细说明

RSA 密码的安全性建立在质因数分解这一困难数学问题上。正着算容易、倒着算难：六等于二乘三、十五等于三乘五，这种小数的质因数分解谁都会；但给一个很大的数，想写出它的质因数分解就非常困难，计算机都要算很久很久。

只要这个数学问题悬而未决，基于它的密码就相对安全。RSA 被广泛应用于现代通信加密，换句话说，银行账号之所以安全，是因为人类对质数规律的无知。

RSA 公司为了实时掌握人类对质数的掌握程度，搞了一项悬赏计划，公布一些很大很大的数，谁能分解出质因数就能获得巨款。例如视频中提到的一个数，在二进制下有两千零四十八位，分解出来可得二十万美元奖金。该悬赏已经过了截止日期，但可以拿来练手。
