# 导师课题的落地过程

## 一句话定义

复学后导师最初提出的课题往往过于宏大或跨领域，学生需通过展示真实能力让课题收敛到可执行方向。

## 详细说明

毕导复学后一个月去找导师聊方向，导师的第一个想法是做一个能在系馆里走来走去的机器人，监督同学穿实验服、戴护目镜。毕导心想「你是不是把我认成志飞君了」，两天后决定告诉导师自己完全不懂机器，不要让他做这个课题。好在两天过去，导师好像已经忘了说过什么。

导师的第二个想法是：中国目前还没有商业化很好的化工厂故障诊断与预警软件，让毕导在组里工作基础上写出第一个这样的软件，打破美帝卡脖子。毕导形容这相当于「你去把唐僧师徒除掉」，他通过展现自己的真实实力让导师放弃了这个想法。

最终他研究的落点是化工故障检测诊断算法，方向从超分子复合膜的制备转到化工厂的故障检测与诊断，从做化学合成变成写代码。

这段经历说明，导师给的初始课题常常是愿景式的，学生需要用实际能力反馈来让课题收敛到可执行、可毕业的范围，而不是硬扛一个超出自己能力边界的任务。
