# 狼人杀是马尔可夫过程

## 一句话定义

有学术观点把狼人杀简化为马尔可夫过程中的离散时间纯死亡过程，即下一步状态只取决于当前存活人数与身份分布。

## 详细说明

狼人杀本质上是一个心理博弈游戏，但有学术观点把它简化成马尔可夫过程中的离散时间纯死亡过程。

所谓纯死亡过程，是指游戏状态的变化只体现为玩家出局，每一步的状态只取决于当前场上的存活情况和身份分布，而不依赖更早的历史发言细节。

这个简化模型是后续多条数学结论的基础：杀人游戏随机最优策略、杀手胜率公式、深水狼被压制等结论，都建立在把游戏抽象成状态转移过程的前提上。

当然，视频也强调，算法再复杂也复杂不过人心。数学模型可以解出游戏的最优策略，但永远解不透人性，程序世界里没有悍跳、归票、盲毒、自刀这些真实对局中的心理博弈。
