# 水中物体虚像更靠近人

## 一句话定义

按折射定律作图，从水下物点射入人眼的两条近轴光线反向延长交于一点，该虚像位置比物点更靠近人眼，而非原地升高或远离。

## 详细说明

初中教材讲「水中的鱼看起来更浅」时，通常只强调虚像位置比鱼的实际位置高，却回避了虚像在水平方向上是更近还是更远。

用延长线法作图：从水下物点发出两条夹角很小的光线，经水面折射后进入人眼。由于人默认光沿直线传播，会把这两条折射光线反向延长，交点即虚像位置。只要严格按斯涅尔定律画出折射光，这个交点一定落在物点靠近人眼的一侧。

- 眼睛位置改变时，虚像位置随之移动，但始终不会跑到远离人眼的一侧。
- 只有从正上方竖直向下看时，光线竖直，虚像才正好在物点正上方。

教材教辅中出现的三种画法（原地升高、更靠近人、更远离人）里，只有「更靠近人」符合折射定律。那些画成远离人眼的插图，是编者没有按折射定律准确作图、随手画线造成的。
