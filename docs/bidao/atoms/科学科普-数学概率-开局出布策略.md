# 开局出布策略

## 一句话定义

由于人在石头剪刀布中出石头的概率最高（约 36%），开局先出布有最大概率赢在起跑线上。

## 详细说明

浙大等机构的实验统计显示，玩家出石头的概率约 36%，高于剪刀的 32% 和布的 33%。石头最多，可能是因为石头最方便——还没想好就先出个石头。

由此得到最简单的开局策略：先出布。布克制石头，因此对上最可能出现的石头就能赢。

但策略存在层级博弈：如果对手也知道这个结论而改出布，你就应该出剪刀；如果对手又想到这一层改出剪刀，你就该回到石头。这种「我知道你知道我知道」的无限嵌套，正是石头剪刀布作为智力游戏的体现。

实战中不必追求无限嵌套，只需判断对手处在哪一层：对普通玩家用开局出布即可获得起跑线优势。
