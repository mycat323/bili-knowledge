# 粘滑现象

## 一句话定义

当静摩擦力最大值大于动摩擦力、且系统具有弹性时，物体被拉动会周期性卡顿前窜，这种走走停停的运动叫粘滑现象。

## 详细说明

中学课本说滑动摩擦力 F=μF_N，与支持力成正比，是个定值。但用橡皮筋或弹簧测力计拉手机、拉小木块做匀速直线运动时，实测结果却是一卡一卡地往前窜，很难丝滑。

原因藏在初中课本一句不起眼的话里：**静摩擦力的最大值大于滑动摩擦力**。

过程拆解：

1. 开始拉力打不过最大静摩擦力，物体不动，只有弹簧在伸长，积累弹性势能（粘的阶段）。
2. 拉力超过最大静摩擦力，物体开始运动，摩擦力瞬间从静摩擦切换成更小的动摩擦。
3. 此时拉力比动摩擦力大一截，物块弹射起步，弹簧顺势缩短，猛猛冲刺。
4. 冲过头后弹簧又松了，拉力小于动摩擦力，物块减速停下，动摩擦变回静摩擦。

如此循环往复，就出现「一下便秘、一下窜稀」的卡顿运动。粘滑出现的条件：静摩擦与动摩擦差距较大，且体系有一定弹性。
