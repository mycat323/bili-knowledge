# 石头剪刀布的非随机性

## 一句话定义

人无法真正随机出手，自以为随机的选择会暴露内心偏好，因此石头剪刀布存在可被利用的统计规律。

## 详细说明

理论上只要有一方绝对随机出手，胜率就是五五开。但人的一切想法源自主观思考，只能随心，无法随机。

一个直观验证：让人从 0 到 10 中随机选一个数，弹幕里出现最多的往往是 7，说明人自以为随机的行为会无意间暴露潜在偏好，而偏好就是博弈中的弱点。

2014 年浙江大学、浙江工商大学、中科院物理所发表论文，招募 360 名浙大学生分成 60 组，每组连玩约两小时石头剪刀布循环赛，按胜率发奖金，平均每人 50 元。结果表明玩家出石头、剪刀、布的概率分别约为 36%、32%、33%——石头最多，剪刀最少，出手并不平均。

这一非随机性是所有后续策略与算法预测的前提：正因为人类出手带有可统计的偏好，才存在胜率超过 50% 的可能。
