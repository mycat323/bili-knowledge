# 蜂蜜麻酱卷绳实例

## 一句话定义

蜂蜜下落绕圈、麻酱折叠堆叠、洗护用品在掌心画圈，都是卷绳效应在日常生活中的常见实例，共同点是流体粘性大。

## 详细说明

卷绳效应在生活中随处可见，可以按场景列举：

- 吃早饭时，黏黏的蜂蜜下落会绕出均匀的圈圈。
- 取麻酱时，麻酱会像叠被子一样折来折去。
- 挤洗头膏、沐浴露时，它们会在掌心画圈圈。

这些例子的共同点是流体粘性大。作为对照，洗澡时温暖的水流倾泻而下并不会发生任何绕圈，更不会产生水坨坨；家中常备的甘油、食用油也是竖直流下去，不会出现卷绳效应。

同样是流体，蜂蜜、麻酱、便便会卷起来，水和油不会，差别就在粘性。这一组生活实例可以作为理解卷绳效应成因的直观入口。
