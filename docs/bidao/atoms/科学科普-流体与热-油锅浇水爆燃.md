# 油锅浇水爆燃

## 一句话定义

向起火的油锅浇水时，水因沸点远低于热油而迅速气化膨胀，把油打散成油雾弥散到空中，遇明火形成巨大火球。

## 详细说明

油锅着火时油温约 500~700 度，远高于水的沸点。水进入油中会快速气化和膨胀，且水的密度比油大，会一边下沉一边沸腾，把周围的油变成细小的油雾弥散到空气中。扩散范围巨大的油雾一旦碰到明火，就会产生比原来猛烈得多的爆燃效应。视频中仅一瓢水浇进当时没有明火的油锅，瞬间升起了高达十米的火球，高速摄影显示整个过程发生在极短时间内。

正确做法不是用水降温，而是用锅盖盖住隔绝氧气。实验还显示，如果一定要用液体降温，冷油反而可行——它能把温度降下去，火也随之熄灭。

常见误解：以为「水能灭火」适用于所有火情。实际上油类火灾（B 类）用水会加剧火势，甚至把操作者包裹进火球中。
