# 湿裤子颜色变深

## 一句话定义

裤子打湿后颜色变深，本质是亮度降低而非色度改变，即反射进入眼睛的光变少，与物体被放在阴影中显得更深是同一类现象。

## 详细说明

我们看到的物体颜色由反射光的色度和亮度共同决定。色度是红橙黄绿青蓝紫的类别，亮度是独立于色度的明暗感。把同一个红色放在光影交界处，影子一侧光少、亮度低，看起来颜色就更深。湿裤子变深同样属于亮度问题：裤子沾水后反射到眼睛的光变少，看着就变暗。

需要区分的是，如果裤子由钠和酚酞之类遇水变色的材料做成，变色原因就另当别论。对普通织物而言，水是无色的，变深只能来自光路的改变。

这一现象在生活中普遍存在：海滩上打湿的沙子比干沙子深，打湿的头发比干头发深，马路、木板、台面湿了之后都会更深，额头上汗水流过的皮肤也看着更深。它们共享同一个待解释的问题——水究竟对光做了什么，使反射回眼睛的光减少。
