# 麻将记牌与出牌顺序

## 一句话定义

在麻将中，记住对手的出牌轮次与记住出牌花色同样重要，同样的两张牌以不同顺序打出，可以反推出完全不同的手牌组合。

## 详细说明

麻将玩家按水平可分三类：菜鸟型眼中只有自己的手牌，场上有啥完全不看；达人型会看桌面上已打过的牌，对形势有粗略判断；雀神型清楚记得场上每一张牌是第几轮谁打的，能分析每个人手里有什么牌、胡什么牌。

大神比菜鸟强的地方不只是记牌，更在于反向思维——根据你出的牌反推你手牌的概率分布，从而调整自己的策略。

**出牌顺序为什么关键**：假设上家先后打出二筒和四筒。

- 若他先打二筒后打四筒：第一轮摸到的应是四五六筒，第二轮在四六筒组合下摸到七筒，于是舍四留七，剩下六七筒。
- 若他先打四筒后打二筒：结论完全不同。先打四筒说明手里二筒相关的牌多于四筒，后打二筒说明二筒的价值可被舍弃，大概率是有一对一筒——第一轮在一一二四配置下打掉四筒，第二轮又摸到一筒或放弃一二筒组合，于是出掉二筒。

同样打了二四筒，不同的出牌顺序可以反推出完全不同的手牌组合。所以只有按照正确顺序去推演，才能算出最准确的概率。
