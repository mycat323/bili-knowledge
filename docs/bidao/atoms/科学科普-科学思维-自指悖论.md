# 自指悖论

## 一句话定义

当传送带要求 v带 = v轮，而飞机又必须满足 v轮 = v机 + v带 时，两个条件无法同时成立，速度会相互追赶直到无穷大。

## 详细说明

过程可以逐步推演：起初 v机、v带、v轮 都等于零。飞机发动机一喷，v机 大于零，带动轮子向前滚，v轮 也大于零。传送带说，我要满足 v带 = v轮，得转得和轮子一样快；轮子又说，我要满足 v轮 = v机 + v带，得比传送带转得更快。于是传送带加速、轮子加速，两者相互卷起来，最终速度都趋于无穷大，机上乘客「成功观测到了相对论的世界」。

从方程上看更直接：v轮 = v机 + v带 与 v带 = v轮 联立，只能解出 v机 = 0；但没有人能阻止 v机 大于零，方程于是无解。

结论是：不存在一条通过追踪轮子转速来把飞机控制在原地的传送带，这个想象违背数学规律。当然，如果承认无限转速的传送带和轮子可以存在，那上面的飞机也可以起飞。
