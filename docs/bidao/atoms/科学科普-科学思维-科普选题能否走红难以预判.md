# 选题能不能火预判不了

## 一句话定义

科普选题能否走红很难用理性事先预判，被广告甲方否掉的选题也可能大爆，因此团队只以研究过程是否开心来决定做不做。

## 详细说明

团队判断选题的标准里，「会不会火」几乎不起作用。

- **水中鱼**：一条水中的鱼经过折射会成几个虚像，团队曾向一个广告甲方力推在这个选题里植入，甲方问讲什么，听完笑了笑，再没有理他们。最后这期视频却非常火。
- **大厚缸**：正常人会觉得「厚缸里液体的直径会放大折射率」这种内容不会有人愿意看，结果同样出乎预料。

由此得到的结论是：科普选题很难用理性预判它会不会火。所以团队一般不放弃选题，只要想做了就会把它做出来，至少不会因为担心某个选题不火而放弃它。唯一的例外是研究不明白——原理或实验上走不通，才会放弃。

支撑这套做法的是动机本身：只要团队研究科学的过程是开心的，就会满怀着对科学的信念把它做成视频，并期待观众也感受到这份开心。团队最困难的选题之一是「如何放出一个无声的屁」，难点就在于很难做实验。
