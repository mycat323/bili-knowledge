# 杀人游戏杀手胜率公式

## 一句话定义

2013 年华沙大学 Migdal 论文给出杀人游戏数学模型：n 个玩家中 m 个杀手时，杀手胜利概率可由含双阶乘的公式计算。

## 详细说明

2013 年，华沙大学理论物理研究所的 Migdal 发表论文《杀人游戏的数学模型》。

模型设定：场上有 n 个玩家，其中有 m 个杀手。经过推导，杀手胜利的概率可以用一个包含双阶乘的公式表示。视频特别提醒，公式里的感叹号是双阶乘符号，不是用来加强语气的。

根据这个公式可以画出函数图像，并进一步算出：为了让游戏更公平、双方胜率都在百分之五十左右，杀手数量最好是玩家数开根号再除以二左右。

这条结论可以直接用来检查日常开局配置是否平衡。比如玩家数越多，按公式算出的合理杀手数增长得比直觉更慢，盲目加狼会让狼人一方优势过大。
