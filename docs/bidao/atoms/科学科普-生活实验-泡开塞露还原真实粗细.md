# 泡开塞露还原真实粗细

## 一句话定义

把化妆品泡进折射率约 1.5 的开塞露（甘油）中，可抵消瓶壁的 1.5 倍放大，从而看到料体的真实粗细。

## 详细说明

化妆品瓶的放大率约等于瓶材折射率 1.5，只要让周围介质的折射率也接近 1.5，放大效果就被抵消。开塞露的主要成分是甘油，折射率约 1.5，正好满足这一条件，因此把化妆品泡在开塞露里能完美还原真实粗细。

对比几种做法：

| 观察方式 | 介质折射率 | 最终放大率 |
| --- | --- | --- |
| 直接看 | 空气约 1 | 约 1.5 倍 |
| 泡水 | 水约 1.33 | 约 1.13 倍 |
| 泡开塞露 | 甘油约 1.5 | 约 1 倍 |
| 方管包装 | — | 无放大 |

泡水只能大致还原，泡开塞露才能准确还原。这个实验材料易得、操作简单，是验证贴壁放大理论的直观方法。
