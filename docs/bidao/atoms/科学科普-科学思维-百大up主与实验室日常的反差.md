# 百大up主与实验室日常的反差

## 一句话定义

平时在B站上被观看的百大UP主，在实验室里可能正因为看不懂化工流程图而十分痛苦，这种身份反差带来奇妙的冲击。

## 详细说明

毕导回忆百大公布那天，实验室的师弟们都来祝贺，说「百大竟在我身边」。他让大家想象那个场景：平时你在B站里看的一个百大UP主，此时正在你身边，因为看不懂化工流程图而十分痛苦，这种冲击其实还蛮奇妙的。

这个观察点出了网络身份与日常身份的分裂：观众看到的是剪辑完成、节奏可控的视频形象，而同一人在实验室里面对的是完全陌生、需要从零学起的专业内容。两种状态同时存在，构成一种认知落差。
