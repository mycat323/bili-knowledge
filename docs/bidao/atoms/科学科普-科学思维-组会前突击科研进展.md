# 组会前突击科研进展

## 一句话定义

组会前一天突击出科研进展或至少表现得仿佛有进展，是许多科研狗的被动技能。

## 详细说明

毕导在描述博士日常时提到，他相信每个科研狗都有一个被动技能：组会前一天总能突击出一些科研进展，或者至少能在组会上表现得仿佛有一些科研进展。

他把每周的节奏描述为：上午看文献、泡茶、配置环境、跑代码，临近中午实验室渐渐变嘈杂，经常一事无成就去吃午饭；下午一般效率最高，但也经常一事无成地去吃晚饭；晚饭回来有灵感就继续科研，如果科研很烦躁就回家打游戏。每周组会和工业项目会之后，兄弟们会去南门外吃一顿烧烤、打一场台球，庆祝又活过了一次组会。

这段描述反映的是科研工作的非线性：日常产出与时间投入并不成正比，而组会作为周期性节点，会倒逼出集中的产出。毕导用「庆祝又活过了一次组会」来形容这种周期性的压力释放。
