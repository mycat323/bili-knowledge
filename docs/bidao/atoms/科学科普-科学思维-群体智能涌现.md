# 群体智能涌现

## 一句话定义

大量个体按简单规则各自行动时，整体会呈现出任何单个个体都不具备的新特征，这种由数量带来的整体行为称为涌现。

## 详细说明

涌现的关键在于：**整体性质不能从单个个体的性质直接推出**。单个观众发一条弹幕只是个人表达，但当观看人数达到很大规模、每个人都在同一时间点发出自己的反应时，屏幕上会形成密集、滚动、彼此呼应的评论流，这种「热闹感」是任何一条弹幕都不具备的。

涌现现象通常需要两个条件：

1. **个体数量足够多**，规模不足时整体特征显现不出来；
2. **个体之间遵循相同或相似的简单规则**，例如都在同一时间点发表评论。

转写稿中反复强调「和三亿年轻人一起看春晚」「热闹」，指向的正是这种由规模带来的整体氛围——它不属于任何一个观众，只属于同时在场的人群。
