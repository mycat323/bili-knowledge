# 开水不响的低沉声来源

## 一句话定义

水完全沸腾后发出的低沉声音，听起来像往水里吹大泡泡的声音，与响水不开阶段的响声是两种不同的声音。

## 详细说明

水完全烧开后，声音不再是六七十摄氏度时那种较响的声音，而变成一种低沉的声音。视频中描述，开水的声音听起来像是往水里吹大泡泡的声音。

这一阶段的关键在于：开水并不是「没有声音」，而是声音的音色和来源发生了变化。响水和开水的区别不是同一声音的强弱问题，而是两种不同的声音。

因此「开水不响」这个说法是一种日常概括，指的是开水不再发出响水阶段那种明显的响声，而不是绝对无声。

把开水的声音与浴缸里放屁冒泡的声音作类比，是为了说明它带有明显的气泡特征。要真正解释这个现象，需要把响水阶段和开水阶段分开，各自找到对应的发声机制。
