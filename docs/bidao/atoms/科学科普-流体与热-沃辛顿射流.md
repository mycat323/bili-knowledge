# 沃辛顿射流

## 一句话定义

液体射流冲入液面时激起飞溅水花的物理现象，其强度受液体温度影响，温度越高飞溅越强。

## 详细说明

沃辛顿射流是液体射流撞击液面后形成向上飞溅水花的现象。毕导在视频中用实验验证：将约四十度的温水从水准瓶喷入冷水烧杯，纸板上留下大致呈二维正态分布的水点，边缘相对安全；换成持续沸腾的开水后，飞溅显著增强，纸板中间被溅湿一片，甚至烫到了脚。

其机理猜想是：开水具有更低的粘度和表面张力，更容易分裂成小水滴，因此飞溅更强劲。二零零三年 Manzano 等人的研究也发现，液体越烫，临界韦伯数越小，会产生越强力的飞溅，与实验相符。

实际含义：往开水里尿尿时，飞溅的水花会更强，容易溅到脚上烫出水泡；如果比较急，喷流速度可能达到平时的两倍，溅射伤害进一步上升。
