# 屈曲产生皱纹

## 一句话定义

细杆受压会在屈服前由直变弯并在卸压后恢复，二维薄板受压除整体变弯外还会长出皱纹，这是材料为降低弹性应变能而选择面外弯曲的结果。

## 详细说明

材料在拉伸或压缩时通常经历弹性、屈服、塑性、破坏几个阶段。达芬奇早在十五世纪就注意到一种特殊情况：胖柱受压先屈服后破坏，而细杆受压可以在屈服前由直变弯保全自己，卸掉压力后还能由弯变直，这个现象叫屈曲。1757 年欧拉计算了屈曲的临界压力，压力超过临界值弹性细杆就会屈曲。

二维薄板受压也会屈曲，但除整体变弯外往往还长出皱纹。原因可以这样理解：材料内部分子原本维持舒服的距离，挤压使分子被迫靠近并相互抵抗，分子离开平面就能重新恢复到舒服的距离，于是形成波浪形皱纹。更准确地说，外部挤压在二维材料内部引起压应力，增加弹性应变能，材料要么继续面内压缩，要么向面外弯曲；如果面外弯曲能量更低就选择变弯，并选择能量最低的波长和振幅。

因此长出皱纹是材料对抗外界压力、降低弹性应变能的方式，皱纹方向与压应力垂直。薄壁圆柱体沿轴向压缩时会出现类似施瓦茨灯笼的三角形网格屈曲图案，称为吉村屈曲（Yoshimura buckling），卷袖子时容易观察到。
