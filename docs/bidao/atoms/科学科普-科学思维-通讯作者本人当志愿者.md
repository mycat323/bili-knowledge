# 通讯作者本人当志愿者

## 一句话定义

论文中反复出现的特殊实验员 M0，其实是通讯作者李辉本人，论文所有半裸红外影像都来自他的身体。

## 详细说明

论文除四十二名实验员外，还有一个被反复提及的特殊实验员，代号 M0。M0 比其他实验员更苦：二零一七年就开始预实验，先绝食三天，再独自喝五百一十二种茶，优选出了本次实验用的十三种茶。

论文中所有半裸红外影像也全部是 M0 的身体。原文说明：志愿者的原始影像因隐私原因不予公开，M0 除外，因为 M0 就是通讯作者本人。

此外文章还提到 M0 在喝了一个月黄茶之后顺便治好了自己的肾结石。

这一细节是理解该论文可信度的关键：核心影像数据来自作者自己，样本代表性有限，读者在评估结论时需要把这一点纳入考量。
