# 教材三种画法各有对错

## 一句话定义

初中教材对水中虚像位置存在原地升高、更靠近人、更远离人三种画法，其中前两种分别对应弧矢像和子午像，第三种不符合折射定律。

## 详细说明

同一道「水中的鱼看起来更浅」的经典题，不同版本教材给出的虚像位置互相矛盾：浙教版、人教版、沪粤版画成原地升高；沪科版、北师大版、沪教版画成更靠近人；外国某教材和部分教辅画成更远离人。

用严格按斯涅尔定律作图的实验和数学模拟可以判定，两条折射光线的反向延长线交点永远落在物体与眼睛之间，不可能出现在远离眼睛的一侧。因此「更远离人」的画法是错的，编者多半没有按折射定律把图画准，而是随手画了两条线。

「原地升高」和「更靠近人」两种画法并非全错，它们分别对应三维成像中的弧矢像和子午像，只是各自只描述了其中一个像。

这个案例说明：权威教材之间也会互相矛盾，遇到分歧时应回到物理定律和可复现的实验去判断，而不是靠版本权威投票。
