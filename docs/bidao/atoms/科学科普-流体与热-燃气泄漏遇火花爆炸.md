# 燃气泄漏遇火花爆炸

## 一句话定义

液化石油气主要成分是丙烷和丁烷，泄漏后与空气混合，遇到电火花会瞬间爆燃，把整个空间填满火焰并产生冲击波。

## 详细说明

视频用亚克力箱模拟了煤气泄漏场景：箱内通入液化石油气，装上点火器，一通电产生电火花，瞬间发生爆炸。实验中仅仅通了一秒钟的气体，就把一面墙崩掉，冲击波的力量能够瞬间让火焰把整个空间全部填满。

液化石油气的主要成分是丙烷、丁烷，它们比空气重，泄漏后容易在低处积聚，与空气混合达到一定浓度后，遇到任何火源——包括开关电器产生的电火花——都可能引爆。视频中演示者只是开了一下阀门，就造成了这样的后果。

这个实验想说明的是：燃气泄漏时，任何主动点火查看的行为都极其危险。亚克力箱相对坚固尚且被炸开，如果人在里面，后果不堪设想。燃气泄漏对消防员来说也是非常危险的场景。

常见误解：以为「开灯看看哪里漏气」「点一下火试试」是小事。在燃气已经积聚的空间里，这些动作本身就是点火源。
