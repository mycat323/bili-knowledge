# 做视频的最大收获是认清自己

## 一句话定义

做视频带来的最大收获不是流量，而是逐渐认清自己喜欢什么、擅长什么，并把创作变成一种快乐的搞科研过程。

## 详细说明

毕导在回答「做视频以来有什么大的收获」时给出两层答案。

个人层面：慢慢认清了自己喜欢啥、擅长啥，他认为这是一件很可贵的事。现在的视频包含好玩的话题、高深的科学原理、详实的文献资料和沙雕实验，对他而言像一个快乐搞科研的过程，每天做喜欢的事感觉很好。

观众层面：最大的收获是陪伴他的观众，大家在弹幕里刷「二年级」「amazing」「泪目」，让他高兴的是视频能带来快乐和对科学的感悟。

关于未来规划，他希望把现在做的事发扬光大，做出更大、更有影响力的栏目，对标 Vsauce、3B1B、Smarter Every Day、Physics Girl 等国外博主，让更多人感受到科学很好玩。
