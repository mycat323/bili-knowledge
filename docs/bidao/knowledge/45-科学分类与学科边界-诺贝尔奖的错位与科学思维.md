# 第四十五章 · 科学分类与学科边界：诺贝尔奖的错位与科学思维

> 这一章讨论科学分类体系与真实科研之间的错位，以诺贝尔化学奖为例，分析为什么化学奖经常颁给生物学家。阅读顺序上，先看诺贝尔化学奖的学科分布统计，再看化学界的吐槽，最后理解诺奖分类与高中理综分类的差异。读完后，你会明白学科分类是人为的，而科学问题本身往往跨越边界，同时也能学会用统计证据看待科学奖项的归属。

## 45.1 诺贝尔化学奖为何总颁给生物领域

### 2020年诺贝尔化学奖的争议

2020年诺贝尔化学奖颁给了CRISPR基因编辑技术，两位获奖者是生物学家。[诺贝尔化学奖颁给生物领域](/bidao/atoms/科学科普-科学史-诺贝尔化学奖颁给生物领域.html)统计了近三十年化学奖的学科分布，发现越来越多奖项颁给了生物、物理等非传统化学领域。[化学家吐槽诺奖颁给非化学家](/bidao/atoms/科学科普-科学史-化学家吐槽诺奖颁给非化学家.html)引用了化学界内部的吐槽，认为化学奖变成了“理综奖”。

### 诺奖分类与高中理综分类的错位

[诺奖分类与高中理综分类错位](/bidao/atoms/科学科普-科学思维-诺奖分类与高中理综分类错位.html)指出，诺贝尔奖的分类是历史形成的，而高中理综分类是教学需要，两者并不对应。[生理学或医学奖关注人类疾病](/bidao/atoms/科学科普-科学史-生理学或医学奖关注人类疾病.html)说明生理学或医学奖更关注人类疾病，而化学奖则更关注分子层面的机制。学科壁垒认为，现代科学问题往往需要多学科交叉，诺奖分类已经跟不上科学发展的步伐。
