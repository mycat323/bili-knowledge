# 第五章 · 路口那个 X 并不存在：沟槽反射与圆锥曲线

> 杭州路口那个巨大的 X，看起来像画在圆盘上的图案，其实并不存在。这一章的推理从一块拉丝案板开始：表面有平行沟槽的物体在灯下会反出一条亮线，而这条亮线的形状可以被算出来——它是双曲线。接着引入圆锥曲线的截法，说明双曲线、椭圆、抛物线为什么在光学问题里反复出现。再回到圆盘：同心圆沟槽的反射亮线是一族复杂曲线，其中看起来比较直的那些段落拼起来，就成了我们眼中的 X。最后用铁盘做验证，并给出整条推理的落点——亮线只存在于眼中，它属于「光加眼睛」这个系统，而不属于那块板子。读完这一章，你会对「看到的东西一定存在于物体上」这个默认假设产生怀疑。

## 5.1 从拉丝案板开始：沟槽反射

### 5.1.1 现象
表面有平行细沟槽的东西——比如拉丝的案板——在灯下会反出一条亮线，这就是沟槽反射 [沟槽反射](/bidao/atoms/科学科普-光学现象-沟槽反射.html)。

### 5.1.2 原理
每条沟槽在垂直于沟槽的方向上是一个弯曲的反射面，光在这个方向上被强烈弯折，而沿沟槽方向基本不被改变，于是反射光被压成一条细线。这就是沟槽反射光锥的成因 [沟槽反射光锥](/bidao/atoms/科学科普-光学现象-沟槽反射光锥.html)。

### 5.1.3 推论
既然是沟槽造成的，那么亮线必然跟着沟槽的走向走：转动案板，亮线跟着转；把沟槽换成同心圆，亮线的形状就该整体改变。这是可以用一块铁盘直接验证的。

## 5.2 把亮线算出来：它是双曲线

### 5.2.1 结论
对平行沟槽做几何推导，得到的反射亮线不是直线，而是双曲线 [反射亮线是双曲线](/bidao/atoms/科学科普-光学现象-反射亮线是双曲线.html)。

### 5.2.2 为什么看起来像直的
在靠近某一段的位置上，双曲线可以非常接近一条直线，肉眼很容易把它当成一条笔直的亮带。

### 5.2.3 推论
那条亮线的形状由几何决定。改变灯的位置、改变观察角度，亮线的弯曲程度和位置都会跟着变——这比只看一张照片更有说服力。

## 5.3 圆锥曲线的截法

### 5.3.1 三类曲线来自同一个东西
双曲线、椭圆、抛物线都是圆锥被一个平面截出来的曲线，区别只在截取的角度 [圆锥曲线的截法](/bidao/atoms/科学科普-数学几何-圆锥曲线的截法.html)。

### 5.3.2 为什么光学问题里总是出现它们
因为反射问题本质上是几何问题：光源、反射面、观察位置三者构成一个锥形关系，截出来就是圆锥曲线。看到双曲线出现在光学结论里，并不奇怪。

### 5.3.3 推论
判断一条反射亮线属于哪一类曲线，等价于判断截面的角度条件。这给了一条从几何直接通向结论的捷径。

## 5.4 路口的 X 并不存在

### 5.4.1 现象
杭州路口的巨大圆盘上，一盏灯只照亮一条直径，所有的直径拼起来就形成了一个 X [X反射的成因](/bidao/atoms/科学科普-光学现象-x反射的成因.html)。

### 5.4.2 原理
圆盘上的同心圆沟槽，其反射亮线是一族复杂的曲线 [反射线极限为双曲线](/bidao/atoms/科学科普-光学现象-反射线极限为双曲线.html)。这些曲线中看起来比较直的那一段，被视觉连起来之后就像两条交叉的直线。

### 5.4.3 推论
X 并不是被画在圆盘上的图案，而是特定观察条件下的一族曲线给人的印象。换个位置看，X 应当会变形甚至散开——这正是「看起来存在」和「真的存在」的差别。

## 5.5 铁盘的验证与「亮线只存在于眼中」

### 5.5.1 验证
拉丝案板的沟槽反射图案，可以用铁盘做进一步验证 [铁盘反射图案验证](/bidao/atoms/科学科普-生活实验-铁盘反射图案验证.html)。

### 5.5.2 一个更狠的结论
沿着整条推理走到底，会得到一个反直觉的结论：那条亮线其实只存在于眼中 [亮线只存在于眼中](/bidao/atoms/科学科普-科学思维-亮线只存在于眼中.html)。

### 5.5.3 推论
亮线不是被刻在物体表面的东西，而是反射光进入眼睛后形成的一条亮痕。所以把眼睛移开、把观察位置换掉，亮线就跟着消失或改变——它属于「光加眼睛」这个系统，而不属于那块板子。
