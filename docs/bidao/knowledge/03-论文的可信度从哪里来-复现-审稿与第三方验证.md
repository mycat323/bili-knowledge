# 第三章 · 论文的可信度从哪里来：复现、审稿与第三方验证

> 这一章处理科学思维中最容易被忽视的环节：一篇论文发表了，我们凭什么相信它。毕导的素材里有两条对照鲜明的线索——一条是复旦团队「喝茶看经络」论文，实验设计严谨但结论玄乎，M0志愿者竟是通讯作者本人；另一条是知网采购费统计，用公开数据揭示学术中间商的收费结构。这两条线索共同指向一个问题：论文的可信度不来自期刊名头，而来自可复现性、审稿独立性和第三方验证。本章按「复现实验 → 检查作者身份与利益关联 → 审视审稿流程 → 用公开数据做独立统计」的顺序展开，读完后你会掌握一套判断论文可信度的具体检查清单。
