# 第三章 · 折射率、放大与浓度梯度：液体光学里的三种成因

> 这一章围绕液体光学里的放大与变形成因展开，顺序是「已知规律 → 追问极限 → 换介质 → 意外发现」。先是厚缸：装满液体的圆柱缸会把后面的东西放大，倍率等于液体的折射率，于是问题自然变成换更高折射率的液体会怎样。毕导用折射率 1.64 的一溴代萘做验证，得到的结果是放大确有上限——靠液体这条路会撞墙；换成气体则完全看不到放大，因为气体的折射率太接近 1。同一套装置还牵出两条边界：水银和有色气体的实验做不了，原因是法律与安全限制；而糖水在不搅拌的条件下会因为浓度梯度形成锥形液柱，静置之后还冒出一个意料之外的白色椭圆。读完这一章，你会知道「放大」这件事在什么条件下成立、在什么条件下失效，也会看到一次实验里冒出来的意外现象该怎么处理。

## 3.1 厚缸的放大倍率等于折射率

### 3.1.1 现象
装满液体的厚缸会把缸后面的东西放大，而且放大的倍率恰好等于液体的折射率 [厚缸放大倍率等于折射率](/bidao/atoms/科学科普-光学现象-厚缸放大倍率等于折射率.html)。

### 3.1.2 原理
圆柱形的液体柱等效于一个柱透镜。折射率越大，光线穿过界面时偏折得越厉害，成像的放大倍率就越高。所以「放大几倍」在这里不是一个感官描述，而是一个可以查表对应的物理量。

### 3.1.3 推论
换一种折射率更高的液体，倍率应当同步上升。网友正是抓住这一点来提问的：既然倍率等于折射率，那换高折射率的液体是不是就能一直放大下去？

## 3.2 一溴代萘与高折射率液体的放大极限

### 3.2.1 验证
面对追问，毕导用折射率 1.64 的一溴代萘做了验证 [高折射率液体的放大极限](/bidao/atoms/科学科普-光学现象-高折射率液体放大极限.html)。

### 3.2.2 结论
放大确实随折射率上升，但不会无限上升。1.64 已经是很高的数值，说明靠液体来提放大倍率这条路会很快撞到上限。

### 3.2.3 推论
把「倍率等于折射率」当成线性公式无限外推是错的：液体能提供的折射率本身有天花板，想继续提高，就得换材料体系，而不是继续加折射率。

## 3.3 气体、水银，以及做不了的那些实验

### 3.3.1 气体为什么不行
同样的装置换成气体，就看不到放大 [气体的折射率不被放大](/bidao/atoms/科学科普-光学现象-气体折射率不被放大.html)。原因在于气体的折射率非常接近 1，界面两侧的光学差异太小，光线几乎不被偏折。

### 3.3.2 有些实验不是想不想做的问题
水银和有色气体的实验做不了，原因不是技术，而是法律与安全不允许 [危险化学品实验的法律限制](/bidao/atoms/科学科普-科学思维-危险化学品实验的法律限制.html)。

### 3.3.3 推论
这条限制值得写进任何一份实验清单：在动手之前先问「这个实验允不允许做」，而不是「能不能做出效果」。科普里的边界既包括物理边界，也包括法律边界。

## 3.4 不搅拌的糖水：浓度梯度做出锥形液柱

### 3.4.1 现象
网友提出用糖水可以复现锥形液柱，毕导照做，而且关键条件是：不要搅拌 [糖水浓度梯度形成锥形液柱](/bidao/atoms/科学科普-流体与热-糖水浓度梯度锥形液柱.html)。

### 3.4.2 原理
糖在水中溶解的过程中，浓度在空间上是不均匀的，会形成浓度梯度。糖水浓度不同，折射率也不同，于是光在液体内部沿着一条连续变化的折射率曲线走，被慢慢弯折成锥形。

### 3.4.3 推论
既然起作用的是浓度梯度，那么搅拌就等于把实验条件毁掉：一旦浓度被搅匀，梯度消失，锥形也就不该再出现。这也解释了为什么同一杯糖水，静置一段时间和刚搅完的样子完全不同。

## 3.5 意外收获：糖水里的白色椭圆

### 3.5.1 现象
糖水静置之后，还出现了一个没被预期到的东西：一个白色的椭圆 [糖水静置后的白色椭圆](/bidao/atoms/科学科普-光学现象-糖水静置后的白色椭圆.html)。

### 3.5.2 它说明了什么
这个现象是在做实验的过程中冒出来的，不在原本的解释框架里。把它保留下来而不是剪掉，本身就是科普里重要的一环：现象永远比理论多。

### 3.5.3 推论
按这套方法往下走，下一步就是把这个椭圆也变成一个新问题——它是否同样依赖浓度梯度、是否随静置时间变化、换容器后还出不出得来。能被继续追问的现象，才是好现象。
