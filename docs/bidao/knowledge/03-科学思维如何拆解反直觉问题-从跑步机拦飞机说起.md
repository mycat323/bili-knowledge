# 第三章 · 科学思维如何拆解反直觉问题：从跑步机拦飞机说起

> 这一章要解决的是：当一个问题看起来荒谬、答案却众说纷纭时，科学思维从哪里下手。我们以「跑步机能不能拦住飞机起飞」为线索，先建立判断起飞条件的公式，再区分两种「同步」的含义，最后看因果链和自指悖论如何把伪问题暴露出来。读完之后，你会获得一套拆解反直觉问题的固定动作：先找判据，再理因果，最后检查问题本身是否自洽。

## 3.1 起飞判据：飞机离地到底由什么决定

### 起飞公式：把「能不能飞」变成可计算的问题

跑步机拦飞机的争论之所以吵不出结果，是因为大多数人跳过了第一步：飞机起飞的条件到底是什么。[起飞公式](/bidao/atoms/科学科普-力学运动-起飞公式.html)给出的判据是，机翼产生的升力必须大于飞机自身重力。升力来自机翼与空气的相对运动，[机翼升力](/bidao/atoms/科学科普-流体与热-机翼升力.html)随气流速度增加而增大。

由此可以推出一个可验证的推论：只要机翼与空气之间建立起足够的速度差，飞机就能离地，而机轮转多快、地面怎么动，都不直接进入这个判据。跑步机接触的是轮子，不是空气，所以它能否拦住飞机，取决于它能不能改变「机翼与空气的相对速度」，而不是取决于它转得多快。

### 把「同步」拆成两种：追踪机身速度与追踪轮速

「跑步机速度和飞机同步」这句话本身是模糊的，至少有两种理解。第一种是[追踪机身速度](/bidao/atoms/科学科普-力学运动-追踪机身速度.html)：跑步机表面速度始终等于机身相对地面的前进速度。第二种是[追踪轮速](/bidao/atoms/科学科普-力学运动-追踪轮速.html)：跑步机表面速度始终等于轮子的转速对应的线速度。

这两种理解会导向完全不同的结果。追踪机身速度时，跑步机只是跟着飞机跑，机翼与空气的相对速度不受影响，飞机照常起飞。追踪轮速时，跑步机试图让轮子不转，而轮子不转意味着飞机不能相对地面前进，可飞机一旦不前进，跑步机又该以什么速度运行？问题在这里开始打结。

## 3.2 因果链与自指：为什么「追踪轮速」会变成悖论

### 速度的因果链：谁决定谁

[速度的因果链](/bidao/atoms/科学科普-科学思维-速度的因果链.html)要求我们分清：在这个系统里，什么是原因，什么是结果。飞机的推力作用在机身上，使机身相对空气加速，这是原因；轮子的转动是机身相对地面运动的结果。跑步机试图通过控制轮速来反向决定机身速度，等于把结果当成原因来用。

顺着这条链可以推出：如果跑步机真的能通过轮子锁住机身，那它必须能对机身施加一个足以抵消推力的力，而跑步机与飞机之间只有滚动接触，这个力从何而来？转写稿没有给出这个力的来源，所以「追踪轮速」的拦截方案在因果链上就断了。

### 自指悖论：当规则要求系统参照自己的输出

[自指悖论](/bidao/atoms/科学科普-科学思维-自指悖论.html)是「追踪轮速」方案真正的死结。规则说：跑步机速度等于轮速。而轮速又取决于机身相对地面的速度。机身速度又取决于跑步机施加的影响。于是跑步机速度取决于它自己造成的结果，形成一个自我参照的循环。

这个循环不是物理上难实现，而是逻辑上无法给出一个稳定的解。可以验证的推论是：任何声称「跑步机追踪轮速就能拦住飞机」的说法，都必须先回答「在飞机被拦住的那一刻，跑步机速度是多少」，而这个问题在自指结构下没有唯一答案。

### 许愿派：用结论代替推导

[许愿派](/bidao/atoms/科学科普-科学思维-许愿派.html)指的是这样一种做法：不给出机制，只宣布结果，比如「反正就是飞不起来」。它和前面两种分析的区别在于，它没有进入起飞公式、因果链或自指结构中的任何一环，而是把愿望当成了论证。识别许愿派的方法很简单：问它「通过什么力、改变哪个速度」——如果答不上来，它就只是一个立场，不是一个解释。
