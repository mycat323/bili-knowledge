# 第十四章 · 颜色的量化：从视锥细胞到口红色号坐标

> 这一章把颜色从「主观感受」变成「可计算的坐标」。顺序上先讲可见光波长和三种视锥细胞，说明颜色为什么是主观的；再引入CIE色度图作为量化工具；最后落到口红色号的坐标化描述。读完这一章，你能理解为什么同一个颜色在不同人眼里可能不同，以及如何用坐标而不是形容词来精确描述一个颜色。

## 14.1 颜色是主观感受

### 可见光波长范围

[可见光波长范围](/bidao/atoms/科学科普-光学现象-可见光波长范围.html)是颜色物理基础的起点：不同波长对应不同的颜色感觉。

### 三种视锥细胞

[三种视锥细胞](/bidao/atoms/科学科普-光学现象-三种视锥细胞.html)说明人眼只有三种感光细胞，分别对短、中、长波敏感。所有颜色感觉都是这三种细胞信号组合的结果。

### 推论：颜色是主观感受

[颜色是主观感受](/bidao/atoms/科学科普-光学现象-颜色是主观感受.html)指出，颜色不是光的固有属性，而是大脑对三种细胞信号的解读。不同人、不同条件下，同一个光谱可能产生不同的颜色感觉。

## 14.2 CIE色度图：把颜色变成坐标

### 工具：CIE色度图

[CIE色度图](/bidao/atoms/科学科普-光学现象-cie色度图.html)把所有人眼能分辨的颜色映射到一个二维平面上，每个颜色对应一个坐标。这样颜色就可以用数字描述，而不是靠「正红」「豆沙色」这种模糊说法。

### 应用：口红色号坐标化

[口红色号坐标化](/bidao/atoms/科学科普-光学现象-口红色号坐标化.html)把口红的颜色放到CIE坐标里，直男也能用坐标精确描述一支口红的颜色。

### 延伸：色彩心理学

[色彩心理学](/bidao/atoms/科学科普-光学现象-色彩心理学.html)讨论颜色对人的心理影响，说明颜色除了物理坐标之外还有感知层面的效应。
