# 第三十二章 · 两小儿辩日的几何真相：太阳早上近还是中午近

> 这一章从两小儿辩日的经典故事出发，用相机实测、物理分析和天文计算，一步步揭示太阳在早上和中午距离地球的真相。我们将先拆解两小儿辩日中的两个错误论证，再建立日地距离的尺度对比，然后分析自转与公转对日地距离的竞争关系，最后引入近日点进动对结论日期的影响。读完之后，你会理解为什么这个问题的答案取决于具体日期，并看到戴文赛先生如何用计算给出了完整回答。

## 32.1 两小儿辩日的两个错误论证

### 第一个论证：早上太阳大所以近

一个小孩说，早上太阳看起来大，中午看起来小，所以早上近。这个论证的错误在于，[太阳视大小一天内不变](/bidao/atoms/科学科普-光学现象-太阳视大小一天内不变.html)。太阳的视角直径在一天之内基本恒定，早上看起来大是[月亮错觉](/bidao/atoms/科学科普-光学现象-月亮错觉.html)一类的视觉现象，与距离无关。

### 第二个论证：中午太阳热所以近

另一个小孩说，中午太阳热，早上凉，所以中午近。这个论证的错误在于，温度高低主要取决于太阳高度角，而不是距离。中午太阳高度角大，光线更集中地照射地面，所以更热；早上太阳高度角小，光线斜射，所以凉。这与日地距离的变化无关。

### 两个错误论证的共同根源

[两小儿辩日的两个错误论证](/bidao/atoms/科学科普-科学思维-两小儿辩日的两个错误论证.html)都犯了一个共同错误：把视觉感受或温度感受直接等同于距离。要回答这个问题，必须实际计算日地距离在一天之内的变化。

## 32.2 日地距离的尺度对比与竞争关系

### 日地距离的尺度

[日地距离的尺度对比](/bidao/atoms/科学科普-数学几何-日地距离的尺度对比.html)是理解这个问题的前提。地球到太阳的平均距离约为一亿五千万公里，而地球半径只有约六千四百公里。这意味着，地球自转带来的观测点与太阳距离的变化，相对于日地总距离来说非常小。

### 自转与公转的竞争

[自转与公转对日地距离的竞争](/bidao/atoms/科学科普-数学几何-自转与公转对日地距离的竞争.html)是问题的核心。地球自转使得地面上某一点在一天之内与太阳的距离发生周期性变化：当地球自转到该点朝向太阳时，距离最近；转到背向太阳时，距离最远。这个变化的幅度约为地球半径的两倍，即约一万三千公里。地球公转则使得日地距离在一年之内发生变化：地球轨道是椭圆，近日点距离约一亿四千七百万公里，远日点约一亿五千二百万公里，变化幅度约五百万公里。

### 谁的影响更大

在一天之内，自转带来的距离变化约一万三千公里，而公转带来的距离变化在一天之内只有约几万公里。两者量级相近，所以不能简单地说早上近还是中午近，必须具体计算。

## 32.3 近日点进动与戴文赛的计算

### 近日点进动改变结论日期

[近日点进动改变结论日期](/bidao/atoms/科学科普-数学几何-近日点进动改变结论日期.html)意味着，地球轨道本身也在缓慢旋转，近日点的位置不是固定的。这使得「早上近还是中午近」的答案不仅取决于一天中的时刻，还取决于一年中的日期。在某些日期，早上更近；在另一些日期，中午更近。

[戴文赛算日地距离变化](/bidao/atoms/科学科普-科学史-戴文赛算日地距离变化.html)是中国天文学家戴文赛先生的工作。他通过精确计算，给出了不同日期下早上和中午日地距离的对比结果。[戴文赛算两小儿辩日](/bidao/atoms/科学科普-科学史-戴文赛算两小儿辩日.html)表明，这个看似简单的问题，实际上需要相当精密的天文计算才能回答。

[好奇心比知识更重要](/bidao/atoms/科学科普-科学思维-好奇心比知识更重要.html)是这个问题给我们的最终启示。两小儿辩日的故事流传千年，重要的不是谁对谁错，而是它展示了人类对自然的好奇心。正是这种好奇心，推动我们去测量、去计算、去追问，最终得到比「早上近」或「中午近」更丰富的答案。
