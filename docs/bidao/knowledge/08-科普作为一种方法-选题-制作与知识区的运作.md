# 第八章 · 科普作为一种方法：选题、制作与知识区的运作

> 这一章处理科学思维在传播环节的应用。毕导的素材里有大量关于科普创作本身的内容：视频选题的学科壁垒、视频制作的分工与周期、AI 辅助科普工作流、科普选题的三个来源、选题能不能火预判不了、知识区作为提问入口、量变产生质变的知识积累。这些内容共同回答一个问题：把科学思维转化为可传播的内容，需要哪些具体的方法和取舍。本章按「选题从哪来 → 制作流程怎么分工 → AI 工具怎么用 → 知识区作为公共入口意味着什么」的顺序展开，读完后你会理解科普不是科研的简化版，而是一套独立的方法论。
