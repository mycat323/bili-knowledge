**摘要**：从等公交车总比预期久这一日常困惑出发，介绍等待时间悖论与友谊悖论，并用唐代诗人社交网络和Python模拟验证，最终归结到检查悖论：你看到什么取决于你在看哪。

## 一、为什么我等的那班公交车总是不来

我经常疑惑，为什么我等的那班公交车就总是不来？公交车明明是十分钟一班，那我有可能等零分钟，有可能等十分钟，照理说我应该平均等待五分钟，可我总是要等个八九分钟。

有人可能会说，这个叫幸存者偏差——你只记得运气差的时候吐槽，一分钟就上车的时候可没见你发朋友圈庆祝。但其实不是，这不是幸存者偏差，而是一个著名的问题，叫等待时间悖论，或者公交车悖论。它说：如果公交车平均十分钟来一班，那你等车的平均时间并不是五分钟，而是一定比五分钟长。

## 二、一个六班车的例子：快车慢车一混，等待时间就变长

来看个简单的情况。你计划七点多从家里出发，坐一小时六班的公交车去买菜。假设司机们都是 timing 侠，拥有无视一切路况、绝对准时抵达公交站的超能力，那理论上这班车的到站时间应该是七点十分、七点二十，直到八点整。你是一个随机侠，能绝对随机地在七点到八点之间的某一刻出现在车站。那你平均的等车时间就是五分钟。

但如果前三辆车的时间间隔变成了五分钟，后三辆的间隔变成了十五分钟，于是这六辆车的到站时间就变成了七点零五、七点十分、七点十五、七点半、七点四十五和八点整。虽然一小时还是六班车，但你要等待的平均时间变成了多少呢？

- 如果你七点到七点十五之间到车站，这个时候公交车的间隔是五分钟，你平均等待时长两分半。
- 如果你七点十六到八点之间到车站，这个时候的间隔是十五分钟，你平均要等待三个两分半。

也就是说你有四分之一的概率等两分半，有四分之三的概率等七分半。列式子算一下，你的平均等待时间变成了六分十五秒，比刚才的五分钟长了不少。

仅仅因为司机师傅有的开得快，有的开得慢，乘客的等待时间竟然一定会变长。这本质上是因为坐上快车和慢车的概率并不相等：慢车因为它慢，占据的时间就更多，所以你更有可能落入等慢车的区间里，从而拉长了你的等待时间。快车的快乐抵消不了慢车的漫长，人生也是如此。在时间的长河中，你有更大的概率在等待一辆慢的车，一件慢的事，一个慢慢出现的人。

## 三、用 Python 开十万辆公交车：平均等车时间等于发车间隔

如果司机师傅越开越自由发挥，那么从起点站均匀出发的公交车，它们之间的距离会越来越随机。有时候前后脚连着进站，有时候打死不来。

我们用 Python 开了十万辆公交车，可以看出，如果公交车非常随机地到站，那两辆车到站的时间间隔会服从我们小学二年级就学过的指数分布，而一小时到站的公交车数量会服从我们小学二年级还学过的泊松分布。在这种情况下，你的平均等车时间就等于发车的时间间隔。也就是说，十分钟一班的公交车，你平均就得等十分钟。听着很反直觉，但这就是数学。

## 四、友谊悖论：你的朋友就是比你更受欢迎

如果你说你不坐公交，感受不到公交车论，那我再介绍一个和公交车悖论非常相似的悖论，叫友谊论。你会不会经常觉得自己很社恐，不知道怎么跟别人说话，但你的朋友左右翻飞，跟谁都聊得热火朝天？数学上可以证明，你的朋友就是比你更受欢迎。

直觉上你会觉得，我的朋友数和我的某个朋友他的朋友数应该差不多嘛。但是平均来说，你的朋友大概率拥有比你更多的朋友。

请看这张图，这是一张唐代诗人社交关系网。简单起见，我们就把崇拜、不屑、服气、爷爷之类的关系统一看做朋友。李白性格豪爽又有钱，他有八个朋友；杜甫更厉害，有九个朋友；骆宾王就一个朋友，可能还有三只鹅。图里一共三十位诗人，连了五十条线。算下来每个诗人平均拥有 50×2÷30≈3.33 个朋友。

那他们的朋友平均会有多少个朋友呢？统计起来会有一点点复杂。比如王绩只有王勃一个朋友，王勃有俩朋友，那王绩的朋友的朋友数就是二。孟浩然有张九龄、王昌龄、李白、王维四个朋友，那孟浩然的朋友的朋友平均数就是 (3+6+8+6)÷4=5.75。

总结成表格，这一列是每个人有多少个朋友，这一列是每个人的朋友平均有多少个朋友。结果非常 amazing：大部分人的朋友数都小于他们朋友的朋友数。所以如果你去采访唐朝诗人，他们大部分人都会说，我有知友多如毛，我没朋友好无聊。甚至高适、孟浩然这样的大唐社交达人也会这么觉得，只有李白、杜甫、王维、王昌龄等几个人没有这种感觉。

这个道理其实也非常简单：因为朋友多的人会更有可能是你的朋友，所以你的朋友更有可能拥有比你多的朋友。不过大家也不用为自己朋友少而感到失落，因为同样的道理，你的敌人也拥有比你更多的敌人。这么一想是不是有点安慰了呢？不过同样的道理，你的前任也拥有比你更多的前任。这么一想，还是别想。

有数学家甚至提出了广义友谊悖论，说平均来看，你的朋友不仅比你朋友多，还比你更有钱、更好看、更快乐。原因也很简单：有钱、好看、快乐的人往往朋友多，也更有可能是你的朋友。

## 五、检查悖论：你看到什么取决于你在看哪

公交车和朋友看上去离得很远，但其实他们很像。数学家们推导了他们的公式：公交车的平均等待时间是左边这个，你朋友的平均朋友数是右边这个。谁能想到坐不上公交车和交不到朋友，冥冥之中有同样的本质呢？而他们背后就是我们小学二年级就学过的检查悖论。

检查悖论揭示了关于人类感知的世界和真实世界区别的深刻哲理：我们的经验会因为观察世界的方式而变化。

比如一个学校里有人多的大班、人少的小班。你想调研一下班级的平均人数，就随机问了十个同学：你班有多少人呢？再取平均。你觉得你的抽样很随机，但是因为大班人多，所以这十个人天然更可能来自大班，你的调研结果一定偏大。如果你是随机抽样测平均身高，那其实没问题。但正因为你是在人数中抽样来调研班级的平均人数，那你自以为的随机抽样在无形中就更容易抽到人数更多的大班。

公交车论也是一样，你是在用自己的时间去感受公交车的平均到站时间，那你就有更大的概率在等占据时间更长的慢车。

生活中检查悖论无处不在：

- 司机总是觉得自己走哪条道哪条道就堵。因为堵的道上车多，所以就是有更多的司机在堵着的那堆车里面抱怨自己运气不好。
- 航空公司觉得自己的航班统计下来平均的上座率并不高，但乘客都觉得飞机很挤。因为有更多的乘客挤在那些很挤的航班里。
- 你可能觉得自己人生中没见过几只鸡，但鸡觉得这个世界上挤满了鸡。因为鸡都聚在了一块儿。

平均来看，人群中听说过检查悖论的人应该非常少。但这期视频评论区肯定有人说，这不是小学二年级就学过的吗？这期视频太简单了。对呀对呀，为什么呀？因为知道检查悖论的知识丰富的观众会更有可能看这期视频。

检查悖论提醒着我们，你看到什么取决于你在看哪。甚至有时候你自以为在随机公平地采样，但其实你的采样方式就是这种偏见的来源。你对世界的接触构成了你对世界的认知，但时刻记得，世界很大，学会接纳。下次参加朋友聚会、挤在飞机里、堵在路上、看毕导视频、等公交车的时候，让我们想到现在的烦躁只不过是检查悖论罢了。
