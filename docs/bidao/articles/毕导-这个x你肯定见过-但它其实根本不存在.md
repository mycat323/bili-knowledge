# 【毕导】这个X你肯定见过，但它其实根本不存在

<BiliPlayer :bvid="'BV1VVhk6pEiR'" />


**摘要**：杭州路口的巨大圆盘上，一盏灯只照亮一条直径，所有直径拼成一个 X。从拉丝案板的沟槽反射实验出发，毕导一步步推出平行沟槽的反射亮线是双曲线，而同心圆沟槽的 X 其实只是复杂曲线看起来比较直的一段。

## 一、路口那个巨大的 X，谜面可能一开始就错了

前两天我在杭州一个路口，发现一个意义不明的大圆盘，真的相当大。神奇的是它上面的反光非常规则：上下两个扇形共同画出一个巨大的 X。对面绿灯闪烁时，圆盘上有一条绿色直径也同步闪烁，说明那盏小小的灯竟然精确地照亮了圆盘上的一条直径。车流通过时，它们仿佛也沿着一条直径陆续开过；车辆转弯时，也会有一条条直径在圆盘上同步旋转。

正常情况下，一盏灯就是照亮一坨区域。为什么在这个大圆盘上，一盏灯只照亮一条直径，而所有的直径共同构成一个 X？

这种 X 在生活中也经常见到：吃饭的盘子、喝水的杯子、黑胶的片子，甚至设计光盘 emoji 的人都无意间把 X 画了进去。仔细观察这些有 X 反射的圆盘，它们都有一个共性——都是圆的。这不废话吗。再仔细看，它们是圆里有圆：圆盘上有无数细微的同心圆划痕沟槽。做过精工实习的朋友都知道，这往往是车削加工的痕迹。用光照没有沟槽的盘子，就没有 X 反射现象，所以 X 反射肯定是沟槽结构带来的。只要破解了沟槽怎么反光，X 反射也将卸下伪装。

## 二、拉丝案板：一个光点如何变成一条亮线

世界上最沟槽的东西，当然是拉丝不锈钢案板。它上面有一条条与短边平行的沟槽。把它放在实验台上打光，光在案板上照亮了一条竖线；左右移动眼睛，这条线会跟着我走，始终垂直指向我。

光学问题想不通，激光笔要放手中。用激光笔照镜子，镜子上有一个光点，墙上也有一个光点。但用激光笔照案板，墙上竟然反射出了一整条竖线——激光打在案板上还是一个光点，被沟槽反射后直接变成了一面光幕。

原因在于：光照在镜子上发生镜面反射，反射光方向是固定的；但如果上面有一道凹陷的沟槽，它就像一面 U 型的小镜子，会把光线反射到许多方向，形成一个扇形，其中总有一条光线能进入你的眼睛。当沟槽很密集时，每道沟槽里都有某个点能把光镜面反射到你眼睛里，这些点在你眼中就都是亮的，你就会看到一条连续的、指向你的反射亮线。

这就是沟槽反射，它既有镜面反射的规整，又有漫反射的混乱。平静的湖面上，太阳的倒影还是太阳；但大海上常有波浪，每道波浪就像一道沟槽，太阳倒影就如同奶油般化开成一条。洗发水广告最爱拍的高光天使环，其实拍的也是沟槽。再去看梵高的《罗纳河上的星夜》，除了艺术之美，你还能感受到沟槽之美。

## 三、把案板转起来，墙上出现了一个半圆

前面案板竖着放时，激光笔在墙上打出一条竖线。随着案板旋转，这条线渐渐弯了下来；直到案板横着放时，它竟然变成了一个完美的半圆。激光打在这个方向的沟槽上，反射出的却是一个半圆——这些反射光线构成了什么形状呢？

把环境调暗，用滑轨缓慢向后移动光屏，三十秒长曝光后你就会看到：沟槽的反射竟然是完美的光锥。

为什么沟槽与入射光指向相同时，能把一根光线反射成半个光锥？在微观世界里，沟槽相当于一排小镜子：射到沟槽中心的光线沿着正常的方向反射，射到左半沟槽的光线会被反射到右边，射到右半沟槽的光线会被反射到左边。但这些反射光都学过光的反射定律，知道反射角得等于入射角，所以它们和沟槽的夹角都一样大，相当于绕着沟槽在空中转了半圈——那刚好就是半个圆锥面。

于是可以这样理解：平行光照射案板时，案板上每个点都在发出半个光锥。哪些点的光锥能通过我的眼睛，它们在我的视野中就是闪亮的。

## 四、光路可逆：这条亮线是一条双曲线

那么，这些亮点连成的亮线到底长什么样？到正面看一眼，是一条诱人的曲线。

如果你数学很好，会有一种暴力求解方程的冲动；但如果你和我一样数学一般般，那你可以放弃执笔，来个换位思考。如果一个点发出的光锥能通过你的眼睛，那根据光路可逆，从你眼睛发出一个同样的眼光锥，必然也通过这个点。既然这条亮线上的点发出的光锥都能通过你的眼睛，那这一整条亮线都必然位于你发出的眼光锥上。它既在眼光锥上，又在案板上，所以它就是你的眼光锥被案板截出的交线。

公元前三世纪，古希腊数学家阿波罗尼奥斯在《圆锥曲线论》中指出：用平面截圆锥，平着截是圆，斜一点是椭圆，平行于母线截是抛物线，竖着截是双曲线。而现在这条亮线，就是平面竖着截圆锥，所以它是一条标准的双曲线。

生活中，圆、椭圆、抛物线都很常见，唯独双曲线几乎没有，没想到它竟然藏在沟槽的反光中。回看激光笔在墙面打出的线，它的形状会从直线变成双曲线，变成抛物线，变成椭圆，变成圆。

## 五、同心圆沟槽：所谓直径，只是它比较直的一段

同心圆沟槽当然也遵循同样的规律，它每一点沟槽的方向就是圆的切线方向。平行沟槽产生的反射亮线是双曲线，而同心圆沟槽更神奇：不管光源怎么转、人眼怎么看，反射亮线都是一条直径。

但事情并不简单。平行沟槽的案板上，每个点发出的光锥都一样，所以反射光很规则；而激光笔照在圆盘上，反光乱七八糟。我用 vibe coding 做了一个沟槽反射模拟器，链接公开在评论区。模拟出来的同心圆沟槽上，每个点反射出的光锥大小方向全都不同，跟个雷达基地一样，完全看不出这么丑陋的模型中怎么能推导出「反射亮线永远是一条直径」。

那就变成一束光，进入槽中央。太阳发出平行光照在 O 点，镜面反射进入眼睛 E；圆盘上一点 Q 如能亮起，则它发出的光锥应过人眼 E。一通计算，得到这个沟槽的方程，画出圆盘上的反射亮线，对比计算结果和实验现象完全相同。这个函数必过圆心，所以这一段确实很像直径。但如果你让圆盘大一点点，你就能看到完整的反射亮线其实是一条复杂曲线——它根本不是直径，只是一条复杂曲线比较直的一部分而已。它们只是在你看得见的地方直一下，看不见的地方全是弯的。

那为什么平时看起来都像直径？因为你家的灯一般在房顶，照在圆盘上的入射角很小，可以证明：入射角越小，这条曲线越接近直线。如果灯很多，就会有很多条像直径的线亮起，加在一起就像一个 X。如果灯离得比较近、相对盘子比较宽，亮线也会变宽，从一条线变成一个扇形。如果你斜着看盘子，就能看出圆盘上的反光其实是弯的，只是平时没有人这么看而已。

更离谱的是，当我胡乱调节参数时，算出的圆盘上可以有各种奇形怪状的反射线：十字架、回旋镖、棒棒糖、一个勾带一个圈、两个顶在一起的角。

## 六、三百八十块的大铁饼，在江边画出 y＝1/x

这些图案真的能在盘子上出现吗？我当场联系了一个铁器卖家，要他打一个最大的铁盘。他问干嘛用的，我说备战奥运。他说那我给你打折。最终三百八十块成交，到货开箱，我们就叫它大铁饼。

黄昏时分，我们来到钱塘江畔。说实话我也不知道会观察到什么。结果太阳真的按照我离谱的计算，在铁饼上画下了反常的图案。

江边的晚霞如此璀璨，不禁让人发出感叹：哀吾生之须臾，羡长江之无穷。大哥这是钱塘江啊。等等，这路人在提醒我什么吗？「羡长江之无穷」——他是要我令 h 趋向于无穷。

回想沟槽方程，它看似丑陋无法化简，但将其展开，h 的平方项会恰好抵消；令 h 趋向于无穷，则一次项系数必趋向于零。一波激烈的坐标变换，这方程竟然就是 y 等于 x 分之一。也就是说，只要你站得足够高、足够远，这条复杂的四次曲线就会变成标准的两支双曲线。

动动视角，它还会变换形状紧跟着你。y＝1/x 是我们每个人在初中学到的第一条双曲线，那时候它只是一道要背的题；而现在，一张三百八十块的大铁饼、一轮一亿五千万公里外的夕阳，共同在江边画出了它的图像。

回到最初那个路口，X 反射之谜其实一开始谜面就错了。X 反射当然不是第三种反射，它从头到尾都是镜面反射；周围灯光照亮的也并不是直径，只是复杂曲线在圆盘上比较直的一段。这条亮线从来就不客观存在于圆盘之上，它只主观存在于你的眼睛里——你走开，它就会变成另一条线。想看到反常的形状，就需要你去认真地找它。光其实什么都没画，是你的眼睛画下的它。
