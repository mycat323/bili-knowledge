# 【毕导】计算机科学之父的业余爱好是什么？

<BiliPlayer :bvid="'BV1QMmZYzET2'" />


**摘要**：从斑马条纹的成因出发，介绍图灵提出的反应扩散模型如何用两种物质解释动物斑纹，并展示该模型从原子到星系尺度的广泛存在，最后回顾图灵本人超前而遗憾的命运。

## 一、斑马是白底黑纹还是黑底白纹？

你看那个斑马，是白马黑条纹还是黑马白条纹？结尾公布答案。但不管斑马是哪种，你一定会觉得这些条纹好工整。身上有漂亮斑纹的动物非常多：猎豹长满点点，老虎头上长王，壁虎的条纹周期排列，松鼠有平行线一行行，苏眉鱼身上宛如迷宫。大千世界因动物的斑斓而五彩斑斓，可这些复杂的图案都是怎么形成的呢？

也许是造物主觉得太无聊了，反正闲着也是闲着，不如就在动物身上一笔一笔画着玩。这个说法有点道理。确实有些动物的颜色就是大自然随便画上去的，比如很多猫猫狗狗身上有颜色，但肚子是全白的。这是因为色素细胞从它们背上的脊柱位置开始往下长，长到哪算哪，没墨了就停，经常长到肚子就没墨了。这个过程真的就像是拿着盆墨水往背上一泼，颜色染到哪全看缘分。

猫猫狗狗的颜色可以轻松染上，但看这条苏梅鱼，你真的相信大自然会精准控制每个细胞应该合成什么颜色的色素，然后恰好让这些色素在皮肤表面连成线，最后形成一套复杂而规整的迷宫吗？事实上，即便简单如豹子的斑点和老虎的条纹，大自然也懒得一笔一笔画上去。也就是说，它们的基因并不会精准控制哪里应该长出一个斑点。相反，在设计所有复杂斑点条纹时，大自然可能全用到了同一个神秘的规则。而发现这个规则的，是一个你不可能想到的人——计算机科学与人工智能之父图灵。

## 二、图灵和他的斑图：两种物质、两条规则

如果你在学 AI，肯定做过图灵测试。如果你懂一些历史，你会尊敬图灵在二战中破译了纳粹德国的密码。而如果你学计算机，开学第一课更是必讲图灵机。但很少有人知道，图灵还有当生物学家的业余爱好。他的成果就是我们小学二年级就学过的图灵斑图。

图灵的想法其实很简单：这些条纹看似复杂，其实只要两种物质和两条规则就够了。一种物质是激活剂，它负责提供颜色。另一种是抑制剂。激活剂能促进产生更多激活剂，激活剂也能产生更多抑制剂。抑制剂会抑制激活剂的产生，抑制剂的扩散又比激活剂快。两种物质阴阳调和，相生相克，此间的奥秘就能含在两个简洁的方程之中。结果就是抑制剂能稳定地把有颜色的激活剂限制在一个小区域里。最简单的情况是激活剂产生的抑制剂向外扩散后把激活剂包在中心，形成了一个小斑点。

你觉得这好像和条纹也没关系？那现在我会让你看见，两个简单的方程，调几个数字，简单的规则能造就多么绚丽的绽放。真是非常 amazing 啊！各种生物身上千变万化的斑纹竟然是同一个东西，来自同一种规则。大自然唯一需要做的就是对不同的生物调一波参数。这里有图灵斑图变化之术，一种是三十六般参数，一种是七十二般参数，你要学哪一种啊？师傅师傅，弟子愿学多的。

不过图灵斑图其实是个很笼统的概念。它可能是很多种方程，比如 Great Scott 方程、Ermakov–Pinney 方程、FitzHugh–Nagumo 方程，甚至可能激活抑制剂还不止一种，得重新推导方程。所以生物学家们想要完全理解某种具体生物的条纹还是很困难的。而且每种动物往往还有自己的想法，比如花栗鼠的条纹很平行，这需要稳定的浓度梯度。江豚实际的条纹边缘很清晰，这要加上扩散电泳。在图灵最基础的规则上，加上每种动物特殊的部分，这才是大自然塑造动物的全貌。

## 三、你身上也有图灵斑图：手指、指纹和上颚褶皱

当然你也许会觉得，那我身上又没有条纹，这和我有什么关系呢？那就暂停一下，仔细看看你的手。你的手指竟然是一根一根的，这是不是很像条纹呢？对，小老鼠就是用图灵机制产生条纹，再靠 Hox 基因控制缩放长出小爪子，人类也差不多。再仔细看看你的手指，你的指纹就更有那味了。没错，它靠 EDAR、WNT 两种激活剂和拮抗 BMP 作为抑制剂，三种基因形成图灵斑图。最后你还可以卷起你的舌头，舔一舔你的上颚。不出意外的话，你会感受到整齐的褶皱，这是纤维细胞生长因子和 SHH 基因的功劳。

所以大家不必烦恼，哎呀，身上没有好看的条纹，你只是对它们的存在太习以为常了。事实上，图灵斑图的存在远比你能想象的更加广泛，它甚至升华为了一种思想，成为了我们小学二年级就学过的反应扩散系统。

## 四、从原子到星系：图灵斑图的尺度拓展

最容易拓展的自然是化学，毕竟图灵斑图就是生物体内的化学反应，凭啥不能在体外复刻呢？图灵就是这么想的，所以提出斑图时，他顺便预言了振荡化学反应。果然，BZ 反应没过多久就被发现了。培养皿中涟漪般的蓝色圈圈神秘浮现，又在相撞后湮灭不见，华丽的图案让我迷恋。这个图案也是一种图灵斑图。

它可以被拓展到原子大小的尺度。世界上最小的图灵斑图是铋晶体，大块的它已经看着很科幻了，而小小的它更是神奇，居然在硒化镍的表面结晶时会长出条纹。这是因为在巧妙地控制原子间作用力后，铋原子的垂直位移成了激活剂，水平位移成了抑制剂。这两个量竟然无意间满足了图灵设定的条件，产生了图灵斑图。

它也可以拓展到地球大小的尺度。例如对一堆沙子吹风，风会把沙子吹起来让它变高，这就是激活。但变高的沙子又会挡住风，阻碍后面的沙子一起变高。如果吹得太高，沙子还会滑下来，这就是抑制。所以沙子会形成一道道波纹。这个是我去我们甘肃民勤录下的像。若是时间积累得久一些，沙子们堆成了沙丘，俯瞰它时，仿佛大地的一道道涟漪随风扑向远方。又比如在人类文明的极北之地斯瓦尔巴群岛上，有许多天然的石圈。这种出现在冻土区的分选地貌，因冻土推动石头的复杂运动形成，而石头运动的方程其实还是反应扩散方程。如果哪位观众有机会去那儿，请一定帮我看看。

再大一点，它甚至可以拓展到宇宙的尺度。在一九九六年的这篇论文里，Lee Smolin 教授还提出只需要一个类似反应扩散的方程，就可以在星系中形成螺旋结构。所以图灵斑图真是上知天文下知地理，从最小的原子到最广袤的星系都能找到它的踪迹。

## 五、图灵的超前与遗憾

如今的我们再也不会怀疑图灵斑图是多么简单、优雅又深刻。然而它就和它的主人图灵一样命运多舛。在一九五二年，图灵提出这个概念时，竟然没有掀起一丝波澜。早年间生物学界也一直对这个模型很反感，因为没有人真的找到过激活剂和抑制剂，能生成条纹的数学模型也远远不止一种，凭什么相信你这个理论呢？说白了，图灵实在太超前了。在一九五二年，世界上没有任何一台计算机有能力计算如此复杂的偏微分方程组。他完全是用大脑的直觉预见了这些图案。大概只有这样的天才的头脑才能造出计算机吧。

直到七十年代，他死后近二十年，Gierer 和 Meinhardt 才又复刻了他的结果，才能让我们这些普通人看见如此美妙的图形。而到了二十一世纪，分子生物学迎来了大发展。终于在很多体系中，图灵预言的激活剂和抑制剂找到了。比如前面提到的指纹、手指分叉和上颚条纹等等，一个个蛋白和基因证明了它的正确。图灵的模型终于成为了学术界的宠儿。

可惜图灵没有机会看见这些了。在他提出图灵斑图的当年，他被判处化学阉割，两年后便死于氰化物中毒。英国官方认定为自杀，年仅四十二岁。虽然天才的结局充满了遗憾，我们也很难想象他如果没有英年早逝，还能取得多么辉煌的成就。不过我想看到这里，每一个人都会认同，图灵先生对大自然的深刻洞察是如此跨越时代的伟大。至于他的成果是否被世界熟知，他本人是否获得了尊敬，还有英国政府和女王迟来五十多年的道歉与赦免，实在是微不足道的，有点可笑了吧。
