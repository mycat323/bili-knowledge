# 【毕导】这是科学史上最难理解的悖论

**摘要**：玻璃的透明源于其宽能带隙，但能带理论只适用于晶体，而玻璃是非晶体，因此玻璃态的本质至今仍是科学未解之谜。

## 一、透明是个辩证的概念

我刚才撞到的，是人类科学史上最难以理解的悖论之一：玻璃，它竟然是透明的。你可能没有意识到这有多反常。看看周围，你还能看到什么透明的东西吗？在塑料被发明之前，玻璃几乎是唯一常见的透明固体。它不像钻石水晶那样稀有，也不像冰一样会轻易融化。它有恰到好处的硬度，还能加工成各种形状。这些完美的性质甚至让它成为了人类文明进步和科学革命的基础。

但你每天看向窗外的时候有没有想过，玻璃为什么是透明的呢？还是说并不是？

这是一块玻璃，它看着是透明的对吧？但我们打开某手机的防晒检测模式，它可以用紫外线拍摄这个世界。用它对准我的帅脸——这玻璃怎么变黑了？对准这张纸，玻璃后面的字竟然也看不见了。奇怪啊，难道说透明的玻璃也可以不透明吗？

再看一个更诡异的：这是个黑色垃圾袋，它是不透明的吧？当我们掏出家中常备的红外成像仪，竟然就能轻松看透垃圾袋里都装了些什么垃圾。在红外线下，这层垃圾袋就像不存在一样。这么看来，不透明的黑色垃圾袋也可以是透明的。

所以说，透明是个辩证的概念，关键是看对什么光透明。垃圾袋在可见光下不透明，但对红外光就很透明。玻璃在可见光下透明，但对紫外光就不透明。如果有一个只能看见紫外线的外星生物，它近视了可千万不能配玻璃眼镜。

所以玻璃真正特殊的地方在于，为什么在我们人类眼中，几乎只有玻璃是透明的呢？

## 二、大部分物体为什么不透明

一束光打在物体上，有反射、吸收、透过三种结局。物体反射吸收的光越多，透过的光就越少，看着就不透明。

大部分物体都会反射光，这才让世界丰富多彩。金属表面都闪耀着光泽，就是因为太能反射了。镜子就是靠表面镀的那层银的反射，让你欣赏自己的美貌。即使光突破了表面进入了物体中，也大概率被吸收掉。因为世界上大部分看着很均匀的东西，都由一个个小微粒堆成，在微观上并不均匀，很难对齐颗粒。光进入物体内部就会被散射来散射去，最后就被吸收了。所以世界上大部分物体都不透明。

但玻璃和大家都不一样，它既不太反射光，也不太吸收光。可见光遇到玻璃就像没看见一样，直接从它原子中间穿过去了。

## 三、用电子跃迁解释玻璃为什么不吸收可见光

为什么玻璃不会吸收可见光呢？这就要用到我们小学二年级就学过的电子跃迁。物质里面有分子，分子里有原子，原子里有电子，电子有自己的能级。电子平时很无聊，在低能级躺平。如果一束光提供的能量刚好能让电子从低能级跃迁到高能级，电子就会吸收光并且兴奋起来，跳到高能级上。而且电子的性格很傲娇，能量太高的光和能量太低的光它都不要，只有能量恰好等于这个能级的光，它才愿意吸收。

这就像是一场特殊的英语考试，老师宣布只有正好考到四百二十五分的同学才给过，比四二五高的低的都挂掉。气体和液体基本都是这样，它们大致吸收特定波长的光。比如氧气吸收紫外线，而会透过可见光，看着就是无色透明的。氯气喜欢吸收蓝光，透出了黄绿色。

但固体有些不一样，我们小学二年级就学过的能带理论告诉我们：一个晶体里的电子的能量不再是一个个精确的能级，而是一条条宽泛的能带。只要光的能量大于两条能带的间隔，电子就愿意把这只光吸收了。这才像是正常的四级考试啊，超过四百二十五分我就给过。

在金属里，电子能随便乱动，它就像一些固定的阳离子飘在电子的海洋里，电子可以随意流淌。所以金属的带隙直接就是零。也就是说金属里的电子它不挑食，只要是光我都要吸收，所以金属都是不透明的。

而钻石、水晶、宝石、冰、盐之类的固体，它们的电子都处在共价键、离子键中的稳定状态，需要很高的能量才能让它们动起来。比如钻石的带隙是五点五 eV，也就是至少五点五 eV 能量的光才能让钻石兴奋地吸收掉。冰的带隙是八点八 eV，盐的带隙是八点五 eV，但可见光的能量只有一点六到三点二 eV，所以这些物质看到可见光根本懒得理啊，它们看着就是透明的。

玻璃的主要成分是二氧化硅，带隙也很宽，差不多九亿米，远远高于可见光的能量。可见光照到玻璃上，它只会觉得，你什么菜鸡也想让我吸收？只有能量够高的紫外线，玻璃才会非常尊重地把它们吸收掉。这就是玻璃能透过可见光却吸收紫外线最根本的原因。

## 四、光学和电学的惊人联系

这个解释的背后还藏着一个大自然留给我们的惊喜。金属里的电子能随意运动，所以它吸收所有的光是不透明的。而金属的电子能随意运动，也恰好说明它导电性强。钻石啊、玻璃啊，它电子比较懒，它们不吸收光，所以是透明的。而电子比较懒，也恰好说明它们是绝缘的。

所以我们甚至有一个非常惊人的结论：导电的固体大多是不透明的，透明的固体大多是绝缘的。真是非常 amazing 啊！光学和电学中两个看似无关的性质，竟然有深邃的内在联系。

有了能带理论，一切物质的颜色和透明度都有了完美的解释。现在啊，玻璃也不是啥特别的东西。它跟钻石、宝石、冰糖一样，只是因为带隙很宽，所以看着透明。只是因为呢，钻石买不起，宝石没多少，冰容易化，糖还要留着吃，玻璃才成为了最好用的透明固体。

## 五、能带理论解释不了玻璃

你可能要说呀，玻璃没啥神秘的，我已经看透它了。然而上面这一切解释其实是有问题的。因为我们根本不知道玻璃哪来的能带，晶体才有能带，玻璃这玩意它根本就不是个晶体啊。

翻开大学物理书，它告诉我们能带理论是从晶体推出来的。翻开初中化学书，它说固体分为两种，晶体和非晶体。晶体又分分子晶体、原子晶体、离子晶体和金属，而玻璃是最标准的非晶体。

为什么是不是晶体的区别如此重要呢？因为秩序。晶体是非常有秩序的，只要给我一个晶格，再加上 Ctrl C Ctrl V，我就能造出一坨无穷大的晶体。晶体的有序赋予了我们推导它性质的资格。然而玻璃内部是不规则的二氧化硅长链组成的连续随机的四面体网络中镶嵌着钠钾钙离子的短程有序长程无序的混乱结构。理论上讲，我们不应该用能带理论来解释结构无序的玻璃。所以呢，对玻璃透明的解释也只能暂且打个补丁，说玻璃其实是有很多微小的晶体构成，也能用能带理论。

## 六、玻璃态究竟是个啥

一九三二年扎卡里亚森提出了玻璃的第一个结构模型。直到今天，仍然没有人敢拍着胸脯说我懂什么是玻璃。有人说它是固态，有人说它是液态，科学家们单独为它定义了一个玻璃态。二零零五年 Science 杂志创刊一百二十五周年之际，提出了一百二十五个最重要的科学问题，其中就有玻璃态究竟是个啥？看看和它并列的问题都是什么？我们的宇宙唯一吗？时间和其他的维度有什么不一样？不是，哥们，你不是装在窗户上的吗？怎么这么猛啊？

五千年前，古埃及人把纯碱和沙子混合，烧出了第一块人造玻璃。两千年前，汉代人烧出仿玉的玻璃，为贵族下葬时披上铜缕琉璃衣。一千年前，中世纪的欧洲教堂用彩绘玻璃作画与装饰，一时间蔚然成风。四百年前，科学先贤们利用玻璃的透明和化学惰性，为人类打开了启蒙之窗。如果没有玻璃，就没有望远镜探索宇宙，没有显微镜揭示微观，没有我正在拍视频的相机和你正在看视频的手机，甚至会没有生化环材专业。

玻璃的意外发明推动了科学的进步，科学的进步又让人们好奇地研究玻璃。而在科学已经如此发达的今天，回看这个陪伴了我们几千年的老朋友，我们竟只能问出一句：你是谁？我们现在还看不透它，但这不妨碍我们透过它看到世界。
