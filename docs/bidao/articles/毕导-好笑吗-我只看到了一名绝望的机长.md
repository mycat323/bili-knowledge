# 【毕导】好笑吗，我只看到了一名绝望的机长

<BiliPlayer :bvid="'BV1MYgE6fE7v'" />


**摘要**：一条与飞机反向、速度始终同步的跑步机，能不能拦住飞机起飞？用“起飞公式”拆开两种“同步”理解后会发现：追踪机身速度拦不住飞机，追踪轮速对汽车有效，对飞机却会触发自指悖论；而只宣布“就是飞不起来”的，是许愿派。

## 一、直觉说飞不起来，但题目真正问的是能否相对地面前进

女士们先生们，航班准备起飞，即将在跑步机上滑行。问题来了：飞机在一条无限长的跑步机上，跑步机运行方向与飞机方向相反，速度大小与飞机随时保持一致，飞机能否起飞？

第一直觉是飞不起来。飞机要起飞，得在跑道上快速向前冲，气流掠过机翼，机翼上下表面产生压差，才能获得升力。如果机身停留在原地，光发动机喷得再猛也没有升力，那就不能起飞；能原地起飞的那叫直升机。所以题目问飞机能否起飞，本质上是在问：飞机能在这台跑步机上前进吗？如果能相对地面往前进，就认为它能起飞。

这就像人在跑步机上：跑步机向后转，我以相同速度往前跑，就会停在原地。换成飞机也一样，飞机以相同速度往前跑，只会轮子哗哗转，机身留在原地，转得再快也飞不起来。但这个说法是错的，错就错在稀里糊涂把人在跑步机上的场景直接脑补到了飞机身上。

## 二、一条传送带推出本期唯一需要的“起飞公式”

做实验。一条家中常备的传送带，表面向右运动，速度大小为 v带。上面放一架家中常备的飞机，机身相对于地面的速度是 v机。飞机轮子在传送带上不打滑地旋转，旋转线速度为 v轮。

在一定时间内，轮子总共向前滚过 v轮 的距离，传送带向后跑了 v带 的距离，飞机机身就前进了 v轮 减 v带 的距离。所以：

**v机 = v轮 - v带**

**v轮 = v机 + v带**

这就是本期视频唯一需要的公式，叫它“起飞公式”。比如 v机 等于 1，v带 等于 2，v轮 等于 3，就是飞机以 1 米每秒前进，传送带以 2 米每秒后退，轮子以 3 米每秒旋转。把传送带上的飞机换成汽车、人，甚至汽车人，这个公式永远成立。

## 三、第一种理解：传送带速度等于机身速度，拦不住飞机

题目说传送带运行速度大小和客机随时保持一致。这句话有几种理解？最直观的第一种：传送带后退的速度等于机身相对于地面前进的速度，也就是 v机 等于 v带。

如果这样，飞机能起飞吗？完全可以，人肉都能演示。机场传送带以 v带 等于 1 米每秒向后运动。如果脚不动，人就会以 1 米每秒向后运动；如果脚以 1 米每秒往前走，人就会与地面相对静止，此时 v脚 等于 1，但 v人 等于 0。拍摄时甚至来了个哥们合影，形成诡异平衡。如果脚以 2 米每秒努力往前走，人整体就会以 v人 等于 1 米每秒往前。这就是传送带速度方向与人相反、大小与人的脚一致的状态。

换成传送带上的汽车，汽车轮子转速相当于平地上的两倍，最终 v车 等于 v带。换成飞机呢？其实更容易实现。车前进靠轮子在地上往前转，传送带向后转，汽车就得比平地更努力地轰油门；但飞机前进是靠发动机直接推动机身，轮子只是个摩擦力很小的轮滑鞋。飞机发动机一开，它就会往前进。传送带再怎么反转，只是让轮子加速旋转，拦不住飞机前进。代入起飞公式也能看出，这只是让轮子转速变成两倍快而已，飞机还是能顺利前进起飞。留言终结者做过实验，在反向运行的传送带上开飞机，飞行员表示没有感觉，就正常飞。

总之，如果传送带速度等于物体相对于地面的速度，那传送带拦不住任何东西。

## 四、第二种理解：传送带速度等于轮子转速，人和汽车会被定住

另一种理解是：传送带速度和飞机的轮子转速实时保持一致。轮子转得快，传送带就转得快；轮子转得慢，传送带就转得慢。这样就能保证轮子永远无法前进，机身也就被定在原地。在起飞公式里，就是 v轮 等于 v带。

这种装置现实中也有。影视飓风健身房里有一种无动力跑步机，跑多快，传送带就同步转多快。慢跑、冲刺，传送带会实时调整转速，与脚永远保持一致，身体被控在原地，无法前进。汽车测噪音时，也会开上类似的转鼓台，就算油门焊死，传送带都会和轮子同速反转，车身不会前进。

代入公式：v轮 = v车 + v带。如果限定 v带 等于 v轮，那么 v车 就会等于 0。看到这里，是不是觉得传送带上的飞机肯定会原地空转，飞不起来？

## 五、飞机和汽车的因果相反，追踪轮速会触发自指悖论

问题出在飞机和汽车原理不一样。起飞公式只表明这三个速度之间的等式关系，但更重要的是它们三个谁是因、谁是果。

车是踩油门让轮子旋转，轮子速度决定车身速度，所以是 v车 = v轮 - v带。传送带追踪轮子，就能把车身速度控制为零。

飞机是发动机喷气直接推动机身，机身速度决定轮子速度，所以是 v轮 = v机 + v带。传送带就算能追踪轮子的速度，也管不到发动机怎么喷，所以影响不到 v机。

在这样的传送带上开飞机会发生什么？开始 v机、v带、v轮 都等于 0。飞机发动机一喷，v机 大于 0，这会带动轮子向前滚，v轮 大于 0。传送带说，我要满足 v带 等于 v轮，我得转得和轮子一样快；但轮子又说，我要满足 v轮 等于 v机 加 v带，我要比传送带转得快。传送带说，轮你又变快了，我得追上你；轮子说，带你别追了，我得比你快。v带 又加速，v轮 又加速，传送带和轮子相互卷起来，最终速度都达到无穷大。机上乘客成功观测到了相对论的世界。

飞机一往前走，系统就崩坏。因为 v轮 = v机 + v带 必须成立，但又要求 v带 = v轮，那只能解出 v机 等于 0。可是没有人能阻止 v机 大于 0，方程就只能无解。所以，v轮 等于 v带 派：传送带上的人和汽车确实无法前进，但飞机会触发自指悖论。这说明你根本无法造出一条通过追踪轮子转速来把飞机控制在原地的传送带，脑海中那个场景违背数学规律。当然，如果承认无限转速的传送带和轮子可以存在，那这种传送带上的飞机也可以起飞。

## 六、最后一种“许愿派”：不说明工作逻辑，只要求飞机飞不起来

这么看来，飞机永远可以起飞了？视频结尾又来了反转。有乘客说：我心中的传送带设定不是这样的，传送带速度和飞机保持一致的意思应该是，不管怎么样，传送带就是可以让上面的飞机无法前进。机长问，这什么派呀？许愿派吗？

定义传送带的时候一定要指明它的工作逻辑，至少得说清楚它是怎么让飞机无法起飞的。乘客却坚持：在我的传送带上，飞机就是飞不起来。视频最后放歌，唱起隐形的翅膀，说要守护梦想，今天你一定能起飞。这段是段子式收尾，但物理讨论的落点仍然清楚：不能只宣布结果，得给出传送带影响飞机的机制。
