# 【毕导】告别尴尬！酸奶如何优雅地喝到一滴不剩？

**摘要**：毕导从办公室喝酸奶被同事吐槽切入，先量化了各种包装的酸奶残留浪费，分析死区等流体力学原因，再讨论舔盖的科学原理与酸奶浓稠质地的来源，最后引出简爱零蔗糖酸奶的推荐。

## 一、办公室喝酸奶引发的科学问题

天气越来越热，可乐雪糕都太罪恶，最近我爱上了酸甜清凉的酸奶。但办公室里的姐妹们好像对我有点意见——「毕导走去拍视频啊」「哟，您还亲自舔盖呀？」「为什么所有人都在安静工作的时候，作为老板你却在喝酸奶呀？还咕噜咕噜的。」

这些现象是因为贫穷吗？不，是我对美味的尊重和对科学的探索。如何才能优雅地把酸奶喝到一滴不剩？今天我们就来聊聊酸奶的正确喝法。

喝酸奶的困境主要有两个。第一，酸奶是粘性比较大的流体，喝不干净，明明还有很多，扔的时候心有不甘。你要拼命吸吧，这份不甘还会让全世界都听到，为天下所耻笑。

## 二、实测：各种包装到底浪费了多少酸奶

我买了市场上一些常见的酸奶，统计喝完后究竟剩下了多少，结果非常 amazing：

- 瓶装浪费得最多，每瓶有十八克都被你扔了。
- 杯装酸奶的浪费率竟然达到百分之十三点六，也就是说每喝七杯，浪费的酸奶又能组成新的一杯。怪不得这种酸奶经常是买 N 送一，商家差不多就是把你浪费的送给你了。

仔细拆开端详，我发现浪费主要是包装的问题。这种杯底和杯壁连接处有一圈坑的，就是专门坑酸奶的；这种口比瓶身小的坚硬瓶子，就注定了瓶壁是你永远无法触及的盲区，打死也喝不到，狗都无可奈何。这种包装让酸奶的流动很不丝滑。

在化工里有着类似的概念叫做死区，指的就是物质进入了这个区域之后就很难出来了。洗澡的时候角落里的沫子冲不掉，家里的墙边总是会堆积特别多的灰坨坨，都是一样的道理。为了减少死区的困扰，化学工程师们会采用更大半径的弯头输送固体，用文丘里流量计会比孔板流量计精度更高，这些都是让流动更加丝滑。果然生活中处处都是化工，推荐大家学习化工原理，欢迎报考清华大学化学工程系。

## 三、学术界和专利界的「防浪费」脑洞

其实酸奶浪费的问题早就引起了学术界的关注。去年有人设计了一款大瓶盖酸奶，喝完后可以倒置再接一瓶盖，得到了设计大奖。这方面的专利也是层出不穷：

- 有从瓶体本身出发，让内部残留能聚集在一处的设计；
- 有暗藏机关、附带刮棒的设计；
- 还有底部能上推，或者底部干脆能分离的设计。

这个内壁清理装置号称适用于各种瓶装粘稠饮料，还能让你体会到全新的旋转乐趣。可惜这份乐趣没有得到产业界的扶持，两年后连一千多的专利年费也交不起了。

看了这些发明，我突然有了一个灵感。大家应该都涂过脚气膏吧？你抹完一看，哎，居然自己又冒出来了一截，恨不得多长一只脚。这是因为管壁是刚性的，能够保持形态，持续给管内加压。如果酸奶也用这种设计，这不正好就解决了酸奶的浪费问题？就是可能喝酸奶感觉像是在治脚气，这个心理障碍需要自己克服一下。明天我就去申请专利。

## 四、舔盖的优雅方案与背后的科学

喝酸奶的另一个困境就是舔盖，不舔舍不得，舔了不够优雅。我在网上看到了一种巧妙的方法，只要用吸管一转，amazing 啊！盖子比你舔的还干净。有的酸奶厂家还借鉴了荷叶表面的乳突结构，研发了超疏水材料，号称绝对不会粘酸奶的盖子，获得了「酸奶会咕噜噜流淌到盒子里真的好开心」的好评，很符合日本研发的一贯的中二气质。

实践中我发现浓稠一点的酸奶也不容易沾盖。但是有的人就要说了，盖子上那一口才是我喝酸奶的乐趣啊。喝酸奶不舔盖，就好比吃辣条不嗦手指，吃雪糕不舔冰棍，擦屁股不对折纸巾，潇洒但是没有灵魂。

盖子上的酸奶为啥比瓶子里感觉要好吃呢？这其实是有科学道理的。在运输过程当中，酸奶会浸润在盖子上面，但酸奶并不是均相，一段时间后乳清会分离析出，由于重力而下落回去。如此反复，久而久之，盖子上留下的酸奶会比瓶子里更浓稠一些，蛋白质含量也更高。喜欢舔盖，本质上就是你喜欢舌头被粘稠液体包裹的那种感觉。了解了快乐的本质，我们可以换一个思路：与其并不优雅地舔盖，不如直接喝浓稠口感的酸奶。

## 五、酸奶为什么浓稠：从乳酸菌到传统工艺

yogurt 这个词来自于土耳其语，本来的意思就是浓稠。酸奶的粘稠质地来源于牛奶中酪蛋白形成的三维网络结构。酸奶制作的时候，乳酸菌把乳糖分解成乳酸，体系内酸度达到酪蛋白的等电点，酪蛋白胶束解离形成酪蛋白胶粒，胶粒聚合形成了三维网络结构。酸奶看似平常，却是利用微生物的天才发明。只要给乳酸菌合适的温度和时间，它们不但能帮你解决无法消化的乳糖，还可以带来一番独特的风味。人们经过研究发现，这种独特的香味来源于发酵产生的微量乙醛。

很早以前，世界各地的美食家就已经各自习得了这个技巧。法式酸奶油、中亚的马奶酒、北欧的增稠乳都是酸奶的近亲。酸奶如此，泡菜、火腿、酸菜、腊肠都是细菌发酵的杰作。微生物可以将糖和氨基酸变成更具风味的小分子，而人类通过千百年的实践，学会了让它们为我所用。这一回合，如果说微生物在第五层，那么人类应该在平流层了。

为了得到浓稠质地的酸奶，食品商家有一大法宝，那就是使用变性淀粉、果胶之类的添加剂，还可以减少真正牛奶的用量。传统的酸奶制作工艺，第一步就是要加热浓缩牛奶，适当蒸发掉牛奶中的水分，再经过均质、灭菌、接种、发酵，不用任何添加剂也能得到一杯香醇好喝的酸奶，这才是大自然最本真的馈赠。

此刻我突然悟了，把酸奶喝到一滴不剩的真正方法就是买到好喝的酸奶啊，好喝到你一滴都不忍浪费。那么这样的酸奶在哪里呢？刚才我手上这杯质地浓稠的酸奶就是了。

## 六、简爱零蔗糖酸奶：用最简单的配料做浓稠

简爱零蔗糖酸奶，保证你喝完之后就会爱上它。真正做到零添加，配料表只有生牛乳、乳酸菌，其他没了。没了不代表不好喝。为了获得香醇浓郁的口感，简爱遵循传统工艺，采用了一点三倍浓缩鲜奶，不靠添加剂，简爱就是要用最简单的配料给你最纯粹的爱。所以蛋白质含量也比普通酸奶高出百分之四十二，钙含量也高出了百分之二十六。乳酸菌的选择上搭配了一些特别的中温菌品种，能带来类似于奶酪的醇厚口感。

市面上很多酸奶为了迎合口感，暗戳戳地加了很多糖。但你看这含糖量快赶上长胖界的可乐大哥了。简爱酸奶就像是天生丽质的素颜美女，喝一口就真的回不去有糖酸奶了。舀一勺丝滑醇厚，这美味不折不扣，想要一直喝到正月初六。简爱还推出了独特的椰子口味，实打实添加椰浆，赶快去尝尝吧。

高端的食材往往采取最简单的工艺。感谢简爱对本期视频的大力支持，感谢他们给我寄了整整两箱的酸奶。我这辈子都没有这么爽地喝过酸奶，但我很快发现享受美味的路上有一个巨大的障碍。
