# 二 年 级 赘 婿 之 歪 嘴 学 神

**摘要**：本文以「二年级赘婿」的荒诞剧情为引，讲述毕导被误认为普通小学生后反转身份、重掌B站知识区的故事，并穿插「过柱子」等科学实验梗。

## 一、三年之约与逐出张家

「三年，三年不准再用神通。」

阴人。妈，我拒绝让你小的人挺好，只想过平静的生活。

混账！B站顶级大人物都过不好柱子，你连个板都不爬，是要让整个B站都耻笑我吗？

贵婿，你这该不是哪个茅坑捡来的色辅助吧？有眼无珠，这可是我用神头换的。

敢跟瑞总抬杠，这一巴掌打你有眼无珠。瑞总可是我花两百万美金请来的，区区一个小学二年级学生，懂个屁过柱子。

可是，谁是张千人？

这一巴掌打你目无尊长，赘婿也敢跟张千人相提并论，得罪陈张两家，我看你怎么活。

可是。

啊！这一巴掌打断你我夫妻情分。我护你张氏三年，三年间你张氏一再辱我，今日我要同你张家恩断义绝。

离了张家，B站再无你立足之地。即日起立刻逐出张家。

别后悔，这张家不待也罢。

反了反了，张家赘婿该是主了。

## 二、张前人登场与身份反转

张前人，谁反了？你们张家有毕导坐镇，谁敢造次呢？

秦老家门不幸啊，秦老啊，我们家哪请得起毕导大人啊？我们这儿只有一个会拉屎压水花的废物，只是恰好姓毕名啸天罢了，已经反了张家了。

啊，拜见毕岛大人。

一亿美元已到，B站知识区战事紧急，请您回去重掌知识区，履行三年之约。

啊？什么？你你是病病狗？
