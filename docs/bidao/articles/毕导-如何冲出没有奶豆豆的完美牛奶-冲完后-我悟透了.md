# 【毕导】如何冲出没有奶豆豆的完美牛奶？冲完后，我悟透了……

**摘要**：毕导从给娃冲奶粉被嫌弃有奶豆豆说起，通过实验和文献拆解奶粉冲泡的润湿与渗透过程，解释奶豆豆为何形成，并探讨奶粉疏水性带来的冲奶难题。

## 一、娃说我的奶里有痘痘

最近我去我姐家玩，姐让我帮她带会儿娃。玩嗨了，娃说要喝奶，我就给冲奶粉。结果冲完之后，娃不讲武德，说我当奶妈不专业，冲的奶里有痘痘。看着娃的表情和这杯牛奶，我不禁陷入沉思。

我想起我小时候我爸给我冲的奶就是有很多奶豆豆。我爸告诉我，有奶豆豆才是好奶，那是嚼着吃提味的。但是娃告诉我，技术不好冲出来才有奶豆豆，你被你爸骗了。回家的路上雨很大，我脑子里一直回想着娃的话，我的眼泪伴随着雨水流下，我发誓一定要把清白还给我爸。

今天就让我们研究奶动力学。奶豆豆，换言之就是奶里的豆豆，是冲奶粉时很容易形成的一种团簇结构，非常影响一杯奶的口感和颜值。

先做个小调查：觉得奶豆豆很烦人的请扣一，觉得只是毕导冲奶技术太菜的请扣二，觉得嚼奶豆豆吃才是精髓的请扣三。啊，可能扣三那个是我爸。

我们先捞起一个奶豆豆看一下，它的外面是一层湿的奶糊糊，内部是没有被水接触到的干奶粉。这么看来，奶豆豆本质上就是因为水包住了一小坨奶粉，却无法渗透到它内部，就变成了冲不开的痘痘。

但这个解释还不够本质。换个思路想想，为什么我往水里加入其他粉末，比如盐、糖、咖啡、孜然、芋泥、波波都不会出现痘痘，唯独奶粉就这么讨厌呢？

## 二、科学地冲一次奶

下面让我们科学地冲一次奶，屏幕前的大家有条件也可以跟着我做一下。首先取一包豆奶，一台磁力搅拌器，一个烧杯。

其实到今天，很多奶粉已经没有那么容易起痘了，只有这种我最爱喝的豆奶，从我小时候到现在，不忘初心坚持起痘，它现在里面都在起痘。不过话说回来，不起痘的奶还叫什么豆奶呢？

向烧杯中倒入奶粉，加入七十度的热水，旋转的水流泛起优雅的波浪，淡黄的粉末漂浮着十分倔强，粉末内部的气泡不断释放，有多少奶豆豆在水下自由地跌宕。一杯豆奶冲完，让我不禁想唱一首月亮之上。

## 三、奶粉冲泡的四个阶段

二零一一年，Forny 等人在粉末技术上发表论文，把奶粉的冲泡过程分为四个阶段：

1. 水润湿奶粉的表面；
2. 水向奶粉之间的空隙内渗透；
3. 水溶解了奶粉团内颗粒之间的固体桥，使大团奶粉分散成小颗粒；
4. 小颗粒溶解在水中形成一杯牛奶。

其中最关键的是前两步：润湿和渗透。这两步搞不好，奶粉就无法被润湿和渗透，就会变成奶豆豆。

## 四、润湿：奶粉其实不喜欢水

我们来拆解一下这两个过程。润湿是液体在固体表面的倾覆和铺展。把水滴在玻璃上，它会铺展成一层液膜，说明玻璃喜欢跟水在一起，它想充分和水贴贴，那我们就说水能润湿玻璃，或者说玻璃具有亲水性。

但是把水滴在毕导纤细的玉手上，它并不会铺展开，只能形成一个个水滴，这就叫疏水。材料表面的水滴越圆，就说明这个材料越疏水。这可以用我们小学二年级就学过的杨方程来描述。
