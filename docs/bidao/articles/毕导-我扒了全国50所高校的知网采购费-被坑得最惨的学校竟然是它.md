# 【毕导】我扒了全国50所高校的知网采购费，被坑得最惨的学校竟然是它……

<BiliPlayer :bvid="'BV1CA4y1D7wc'" />


**摘要**：毕导通过政府采购网等渠道，统计了全国50所高校近四年的知网采购费用，揭示了知网年年涨价、毛利率高达53.93%的现状，并对比了各校砍价能力，最后探讨了知网作为学术中间商两头收费的问题。

## 一、中科院停用知网，高校苦知网久矣

前几天，中科院和知网轮流上了热搜。起因是中科院觉得知网数据库订购费用涨价太多，达到了千万级，决定停用知网。中科院的邮件通篇就是在说一个字：知网贵。神奇的是，记者采访双方时，知网辟谣说不属实，中科院回应说属实。但总之可以确认的是，中科院已经开始教同学们万方使用小技巧了。之后知网又回应了一波，大概意思是中科院确实嫌贵，想整团购，双方还在谈，没有崩。

这已经不是知网伤害过的第一个学校了。2016年1月，武汉理工大学就由于续订价格涨价离谱，停用知网。2016年3月，北京大学因为不向商家过分的涨价行为轻易妥协而停用。还有2018年太原理工大学，2021年集美大学。

看着这些新闻，我不禁陷入沉思：每年各大高校为了看知网上的文献要花多少钱呢？

## 二、50所高校知网采购费大起底

我们打开政府采购网，在搜索栏里输入学校名，加上知网或者数据库或者期刊，就能找到部分高校的知网数据库采购价格。当然，有的直接百度也能搜到。

以清华大学为例，2021年的采购金额是188万元。清华在校生大约五万人，等于每个人要看37块钱的文献才能回本，够我吃92.5个庆丰包子。做个对比，清华给新建的双清公寓装上空调要了100万元。

我统计了我国50所高校近四年来的知网采购价格，大家可以感受一下知网恐怖的吸金能力。声明一下，每个学校人数、专业不同，订阅的数据库内容和范围也不同，所以不是说你价格高就一定是被坑了。但是一想到你的母校一百万干点啥不好，结果就买了个知网，还是有点那个，对吧？

光这50所高校，知网一年就能收五千万，本来加上中科院就是六千万了。不过这也不算啥，根据同方集团年报，知网2020年主营业务收入达到11.68亿元，毛利率高达53.93%。

可能有的观众要问了：为啥我的母校花了这么多钱？为啥北理工这么贵？为啥只有清华没有北大？毕导你是不是夹带私货呀？其实没有。北理工写的是2021年度，但是没有写购买的年限。我怀疑294万可能是两年的总价，要是一年的话那就太能买了。或者就是北理工同学特别能看文献，得交钱。北大和上交我纯粹是没查到，所以就没写，没有内定top1 top3的意思。

从这张表中，你还能看出高校采购意向的变化。比如浙大，2020年只买了84万，到了2021年狂买112万。北航2020年是72万，2021年直接梭哈110万。估计是学校落后的数据库水平跟不上学子们日益旺盛的科研需求了。北体也很有意思，2019年是85万，2020年是90万，2021年变50万了。让人不禁好奇，二一年北体人都不科研去备战奥运了吗？以及，北电还是买过知网数据库的，翟博士走的不冤。

大家感兴趣的话也可以去搜一下你们学校给知网花了多少钱，欢迎在弹幕里面分享。

从这些数据你甚至能看出一些地域共性，北京的学校都比较豪气，北师大198万，清华188万，人大165万，地大117万。武汉也不差，华科179万，武汉理工128万。而上海就很精打细算，它就没有上百万的。同济就只有98万，复旦也才83万，上海理工更是只有区区42万。同样是理工大学，你上海理工同学看一篇论文，武汉理工同学得看三篇，你不然怎么对得起你学校多掏那大几十万？

## 三、知网年年涨价，砍价各显神通

有的同学要问了，知网不仅贵，是不是涨幅还挺大的呢？的确。相信大家看表也感受到了，知网的确年年都在涨价，这里挑部分高校的数据再给大家感受一下，我敢说比你的工资涨得都快。

比如北邮，从2019年的71万涨到了2021年的87万，涨幅高达23%。中南财经政法大学涨幅高达24%。这两个学校同学想想，你三年GPA要是不涨个25%，你对不对得起你们学校的良苦用心？中南大学三年涨幅19%，电子科大15%。但复旦和同济不知道为啥，涨幅始终维持在极低的6%，甚至在1%。有力打击了知网的嚣张气焰，可以说是大快人心。这上海还是会做生意。

有的同学又要问了，难道这些高校就不会砍价吗？实不相瞒，这其实还是砍完后的结果。在网上可以查到公示的订购知网的预算价和合同价。预算价是我想花多少钱，合同价是我实际花了多少钱。我们姑且以他们的差值作为砍价的金额。我呢其实不专业，这只是我朴素的理解。如果有错大家批评指正，但是我觉得这个数据还是很有意思的。

有的学校就比较会砍，像浙大砍了三万，人大砍了五万，有零有整。但是有的学校在知网面前就纯纯老实人了，比如川大，搞了半天只砍了一千块钱。北师大更是斯文了，2020年8月25日，北师大发布了采购预算198.36万，9月9日项目198.35万成交，历时半个月狂砍一百块钱，让我妈去砍都比这个多。不知道北师大同学现在作何感想。

总之统计完数据，我真的泪如雨下。为什么我们能坐在实验室里安心地看论文、学论文？那都是学校在为我们负重前行。知网的一粒沙，扔到每个学校头上，那就是一座山。所以大家多看一点论文吧，你看的论文多一篇，你的母校就少亏一点。你反思一下，你过去一周看了几篇论文呢？

## 四、知网的钱都花到哪里去了？

那知网赚了这么多钱，大家一定很好奇，那他都花到哪里去了呢？

一是给作者发钱。知网不生产论文，只是知识的搬运工。比如全国硕士博士的论文入知网的库，知网是要给作者稿酬的，多少呢？硕士论文一本是60块钱，博士论文更是高达惊人的100块钱。但知网不会主动发给你，你得把本人的学位证加身份证复印件邮寄给知网，然后下载表格填写信息发送到邮箱，然后就可以等待丰厚的稿酬到账了。屏幕前的硕博们赶紧去领吧。

二是给员工发钱。作为一家经营状况良好、盈利颇为可观的公司，知网对员工也是非常慷慨。我上招聘网站上查了一下知网招聘的薪资，不错。我年纪轻轻工资就达到了三千二一个月。

三是用于自身的建设。在知网母公司同方控股的年报里面有关于知网的描述，这段话写得挺高大上的，我斗胆为大家解读一下。

- 知网持续致力于大数据的人工智能挖掘工作。这个就是把搜索说得酷炫一点，我还遇到过bug，你搜某些词语的时候会出现阿拉伯语。
- 努力建设知识资源互联网传播扩散与增值服务平台。这个就是你想传播扩散你的论文是吧？那我要先增值。
- 知识资源深度开发利用平台，我能用你的知识赚很多钱。
- 以其为各行各业提供具有决策支持功能的大数据知识服务。这个就是给高校、工业界写论文评职称的时候下文献嘛。
- 同方知网在疫情最严重的时期为高校职教用户提供免费校外漫游服务，支持师生在校外免费使用该校订购的中国知网全文数据库。这说白了就是让程序员加了个校外学号登录功能。
- 免费提供中国知网OKMS点绘制（云服务版）产品，满足政府及机构用户在线协同研讨、协同编撰以及跨部门跨区域协同办公等需求。这个像是一个给实验室用的企业微信，你可以在上面看文献、和师兄发消息、多人协作写paper，堪称异地办公神器。我不说谁能想到这是个只有六个人评分的APP。
- 免费开放知网研学平台，为学习者和科研工作者提供自主学习、培养创新思维和能力的学习资源和工具。这个就是一个文献阅读和管理平台，号称免费开放，但是免费版功能极其有限。平台自己都整出一个对比图，给大家看看免费的有多拉胯，权益乍一看都是无一无湖。不过再往上呢有高校版、初级版、高级版、畅享版、尊享版。啊，你懂的。

这么一看，知网虽然年年涨价，处处收费，但也算是硕果累累，成就斐然。谁看了不说一句钱都花到了刀刃上？

## 五、天下苦知网久矣，但破局不易

这期视频给大家展示了全国部分高校的知网采购费用和砍价明细，为大家揭开了知网的神秘面纱。想必各位学子也感受到了学校的不易，不知有多少人觉得自己的母校是个大怨种呢？

我也不禁在思考，从什么时候开始，天下苦知网久矣变成了高校圈的共识？明明最开始世界学术圈建立一个论文、期刊、数据库这样一套游戏规则，是为了便于知识的传播。早在99年，CNKI主体工程还被列为国家级火炬计划项目。但现在，知网这个火炬传着传着俨然变成了个烫手山芋。

我在想本质上大家不爽的是什么？是在我国的学术游戏规则里面，作者发论文不仅没有收益，可能还要交版面费。读者看论文还要给知网交阅读费，读者和作者两头被掐，大头的利润都被知网这个学术中间商收入囊中了。他还要年年涨价，他还要涨到百万千万，你还拿他没办法。确实没有办法。中文论文还要在知网查重，对吧？老师工程师评职称还要看知网的文章，对吧？那这怎么破呢？没法破。

虽然理工科的同学平时可能不太看知网，但是也对这个规则咽不下这口气呀。当学生老师们的评价体系都建立于一家独大的知网之上，前者就变成了任人宰割的韭菜，而后者手中原本传播知识的柳枝也就变成了镰刀。天下苦知网久矣，年年都说苦，年年还在苦。大家调侃天灵四年春，中科院跳出知网坑。可又有多少学校眼看是坑还不得不跳？

所以在此我呼吁大家多多珍惜校园的数据库吧，都是你们学校花了几十万上百万买的，多看几篇论文吧。也祝我自己早日毕业。感谢大家收看本期视频，记得三连支持一下，我们下期再见。
