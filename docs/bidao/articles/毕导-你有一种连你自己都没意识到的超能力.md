# 【毕导】你有一种连你自己都没意识到的超能力

**摘要**：毕导从自家孩子数数现象切入，揭示人类拥有一种不用数就能瞬间判断五个以下物体数量的「数觉」超能力，并通过测试、文化案例和心理学研究，探讨数觉的机制、进化意义以及大脑的预判能力。

## 一、从孩子数数说起：大人一眼看出的数量，孩子却要一个个数

别划走，做个小测试。请问刚才画面上闪过了几个苹果？你看一眼就知道是三个，对吧？但请你仔细回想一下，你刚才是怎么知道这里有三个苹果的？是在脑子里飞速数出一二三，所以这里有三个苹果？还是说你看一眼就知道是三个，根本就不用数？我觉得大部分人呢应该没有在脑子里面数一二三这个过程，但你看我家娃他就不一样。

这里有几个青蛙呀？有几个直升机啊？不是儿子，一共就两个青蛙，四个直升机，旁边还有答案，竟然也要一个一个数过来才知道有几个吗？类似的案例我还录过很多。桌子上有多少个人呀？有几张纸呀？看到了吧，即使只有几个东西，他也必须要数一遍。但这三包纸我们大人肯定不用数吧？

大家可能觉得这不算什么奇怪现象吧，小朋友脑子没有大人快呗。但这其实不只是快不快的问题。你自己可能都没意识到，你其实拥有一种不用数就知道东西有几个的超能力。这个超能力就叫做数觉。数学的大致定义是人能对小于五个的物体数量进行瞬间准确自信的判断。

## 二、数觉测试：五个以下瞬间判断，五个以上必须数数

下面我测试一下大家，请你说出屏幕上有几个物体啊？都答对了吧？就这一瞬间，你根本来不及数数，但你已经知道有几个了。我们再做个测试啊。几个？说不出来了吧？啊，我知道弹幕上肯定有人嘴硬啊，说自己一瞬间就看出来了。再来，当屏幕上有十二个点的时候，如果不让你一个一个数，你根本就不可能知道有几个了。就像刚才其实有十三个点，你发现了吗？

数觉就是人类大脑的这么一种神奇的机制，五个以下你就是能瞬间看出来，五个以上你就得切换到慢慢数数。甚至当物体超过五个时，你也经常会先把它分割成五个以下，再用数觉计数。比如这张图，你脑子里是怎么数的呢？再比如这个七筒，我觉得很多人并不是数出了一二三四五六七七个筒，而是在脑子里面瞬间把它聚类成上三下四，然后算出三加四等于七。这么看来，打麻将最好的四川人和湖南人应该是我国数学最好的人。哎，快快给钱给钱给钱给钱。请问这是几桶？哇，你是怎么数出来的？

## 三、从汉字到算盘：文化里藏着数觉的痕迹

我国文化当中蕴含了丰富的数学现象，比如咱们博大精深的汉字，一二三，几就是画几道，非常直观。你看到这个三字，从来不用数三下才知道这是三。但四和五就不是画道道了，说明古人造字的时候可能也发现从四往上画道道他数不清楚了，还是单独造个字吧。罗马数字的设计也异曲同工，一二三是竖着的杠，但五就是个 V，四还得靠五减一做个减法。说明罗马人觉得我宁肯算一下五减一等于四，也不愿意数四道杠。

不过呢，我咨询了一位懂甲骨文的朋友啊，李尤西老师。他说在甲骨文里，四就是四横，五有种写法就是五横。说明中国老祖宗们数四横和五横应该也挺快的。中国的数学堪称世界一流啊。顺便说一句，我小时候一直数不清线、距、直、针这几个字里究竟有几横。以前我觉得是我语文不好，现在看来是我数学不行。嗯嗯嗯嗯。

算盘的设计也是一样，咱们中国的算盘下半部在古代是四颗珠子，现代是五颗珠子。如果要表示比五大的数，就得靠上半部的进位了，这样你数珠子就很快。要是上下连在一起用十进制，要多用好多珠子不说，就问你六七八九颗珠子，你一眼数得清吗？

哎，等等。俄罗斯那边还真有十进制算盘，叫做 shorty 我以为他们数数快呢，结果定睛一看，原来最中间的两颗是专门涂黑用来方便数数的。看来他们虽然号称数学厉害，数学也就是世界平均水平嘛。麻将里就更不用说了，条子筒子数字比较大的时候都得靠颜色分几组，不然你要是数错了。不好意思，刚数错了，这七套。

## 四、心理学实验：数觉从两岁开始，四个物体是分水岭

有心理学家做过实验，数觉广泛的存在于世界各地的人身上，两岁的宝宝就开始显示出这种能力。当物体只有一二三个的时候，人判断的速度和准确率都相当高，而且都差不多。不是，为啥一个都还有人数错呀？但从四个物体开始就会反应迟钝，判断出错。到五个六个，大脑 CPU 就要干烧了，得开始慢慢数数了。

那么数觉和数数到底有什么不同呢？在数数的时候，我们会把注意力先放在第一个物体上，在脑海里数一，再把注意力转移到下一个物体上数二，一直重复这个过程。如果用程序员的语言来说，我们用了一个循环遍历所有元素，程序运行的复杂度是 O n 但数觉的特殊之处正在于我们在脑子里完全不会有注意力从一个物体转移到另一个物体的过程，而是用直觉给出结果，程序的复杂度顿时降为了 O一，真是码农梦想中的算法呀！

有研究提出，在启动数据的时候，我们很可能是靠图形记忆，把物体很少时的形状在脑海里存储成了一张图。比如两个苹果会觉得它形成了一条线，三个葡萄觉得是一个三角形。你用图形记住了两个、三个东西都长什么样，下次见到类似的形状就瞬间唤醒。而四边形的形状就有点复杂了，它有可能是凸的，有可能是凹的，它俩看着也不太像，大脑就开始宕机了。到了五个、六个甚至更多的物体，能组合出来的几何形状更是千变万化。除非欧拉在世，不然根本没法把所有的形状记在脑子里呀。于是数学的范围就停留在了五以下。

也有人呢从进化论的角度解释了数学的起源，说早期人类打猎的时候，如果遇到两三个野兽，有数学的人就能瞬间看出敌人数量，思考战斗策略，存活率更高。所以有数学的人比没数学的人更加适者生存。那为什么数学只停留在五呢？如果有的人能瞬间数出十个以上，他岂不是更加适者生存？遇到五个以上的野兽，数不数觉得已经不重要了。

## 五、大脑的预判：从接球到橡胶手，练习让边界拓展

我常常好奇，数学在后台运行的时候，我的脑子里究竟在干什么呢？哼，谁敢暗算我？飞来的这个球我可以轻松把它接住，你觉不觉得这很诡异？难道刚才的一瞬间我大脑里面计算完成了微积分平抛运动和马格努斯效应？肯定没有，毕竟福南也可以轻松接住球。他应该是不懂微积分的。呃，你懂吗？

其实就跟数数多了，你的数觉就会越来越强一样。我们的大脑在无穷次锻炼之下，获得了越来越强的预判能力。心理学中认为，大脑并不只是简单从外界获取信息，它更是不停寻找外界环境的最佳模拟。因为我们曾经看见过千百个飞行的球，所以我们能够脑补出半秒后的球在哪。因为我们见过阴影带来的黑暗，所以这一堆视错觉的图片才能够成立。因为我们平时都能看见自己的手，所以才会把被插的橡胶手错当做是自己的手。

科学家作为人类最强的大脑，经过几百年的研究也研究不出来人类的大脑为什么这么厉害。但我们很确定的知道，我们多练习一次，我们的大脑就会进步一点点。我们多探索一些未知，人类常识的边界就会向外拓展一点点。

我家娃两岁半，最近他已经拥有了数据。现在两位数加法是他全新的。你给爸爸算一个，五十七加三十九等于几啊？对于屏幕前的你来说，瞬间算出五十七加三十九不算什么难事。但你们也面临着自己的挑战。人类就这样缓慢的传承进步。或许对于千百年后的人们来说，现在那些高不可攀的知识，会和一眼看出一二三一样简单吧？那他们看我们时，会不会就跟我现在看植树一样，看到过去、现在和将来呢？哎呀！哈哈哈。
