# 【毕导】如何成为麻将高手，包你一学就会，一打就废！

**摘要**：从麻将基础规则出发，用贝叶斯概率解释记牌与出牌顺序如何反推对手手牌，并分析自己胡牌概率为何总等不来，最后指出麻将作为不完全信息博弈比围棋更接近真实世界。

## 一、从一炮三响说起：麻将到底怎么打

小小一局麻将，居然被我打出了一炮三响的好成绩，比二营长的意大利炮还厉害。麻将是我国的传统异能，十亿人民九亿麻，还有一亿在观察。

考虑到观众当中麻将水平参差不齐，有的一岁抓周就抓了麻将，有的大学毕业还只会吃火锅蘸麻酱。先介绍一下最基础的规则，不区分各地流派。麻将就是通过每轮摸一张牌、打一张牌，努力把自己的手牌凑成 m 个 AAA 加 n 个 BCD 加一对 EE 的形式：

- AAA 是三张相同的牌，称为刻子；
- BCD 是三张连续的牌，称为顺子；
- EE 是两张相同的牌，称为将。

如果上家打出一张牌，你有两张牌能和他组成顺子，你就能吃他。如果有人打出一张牌，你手里有两张一样的，你就能碰它。如果别人打的牌你手里有三张一样的，你就能杠它。凑成这个公式就胡了。

麻将玩家按水平可以分为三类：

- 菜鸟型：眼中只有自己的手牌，看了半天打掉最没用的一张，场上有啥完全不转。
- 达人型：不仅看手牌，还看桌子上已经打过的牌，对场上的形势有粗略的判断。
- 雀神型：清楚记得场上的每一张牌是第几轮谁打的，能分析每个人手里有啥牌、胡啥牌，就连对家的眼神、表情，甚至弹鼻屎的落点都能精准定位。

所以大神比菜鸟胜在记牌能力？不，这还不本质。从数学角度考虑，麻将其实是一个概率游戏，就是用高中的排列组合算出当前局面下打哪张牌胡的概率最大。而大神比菜鸟还强在对于概率的理解和运用的深度。大神有反向思维，他会根据你出的牌来反推你手里的牌型的概率分布，从而调整自己的打牌策略。这种概率流派就是贝叶斯概率学派。

## 二、先验与后验：三张六筒如何改变你的选择

来个实战演练。已知下家没有打过筒，你想打四筒或七筒，问打哪张你更不容易放炮呢？其实两张概率差不多，没有什么信息表明它们俩有区别。

但我突然告诉你，桌面上打了三张六筒了，这个时候打四筒还是打七筒？

原本胡四筒和七筒分别是这么几种情况，概率是相等的。但是当桌子上打出过三个六筒之后，上述分布就发生了变化。对手拿有五六筒、六八筒的概率被这个新增条件降低了。打四筒点炮的概率变成了七筒的一点五倍。

一开始胡四筒和七筒的概率相等，这种符合我们直观感觉的概率称为先验概率。引入新信息进行修正后的概率称为后验概率。贝叶斯学派的主要观点就是，概率代表的是你对一件事是否会发生的信念和判断。新增的信息会修正你对局面的判断，收集的信息、证据越多，你的判断就越准。

从这个角度讲，那些专业打牌三十年的大爷大妈，那都是贝叶斯学派的十级学者。我们耳熟能详的一些口诀，幺鸡不能打，一打就是俩，二五先打八，拆边不拆卡，其实也是麻将名家们总结出来的定式，每一条背后都有它在概率层面的原理。建议大家以后概率论考试之前，先找你妈的麻友们答疑。

所以把概率论用在麻将上主要是两大理念：

1. 每一次出牌要算出一个局部最优解，不断打掉最没用的牌。
2. 根据别人的出牌反推他的手牌。

## 三、出牌顺序比花色更重要：反推上家的筒子

再来看一道题。在一局麻将当中，你发现上家摸进两张牌，先后打出了二筒和四筒，那你觉得此时他手里可能还有些啥筒子呢？

为了简化，我们只考虑他摸到的牌是二四筒相关的一二三四五六筒。如果他摸到的是一二三筒，那牌型就会变成这样。这个时候显然不会先打二筒，所以第一轮摸到的肯定是四五六筒。那我们再想一想，他第二轮摸到了什么牌，他才会选择打四筒呢？对于这两种情况，他肯定不会打四筒，只能是在四六筒的组合下摸到了七筒，于是舍四留七，剩下了六七筒。

那如果当时他是先打了四筒后打了二筒呢？你会发现结论完全不同。先打四筒证明手里二筒相关的牌要多于四筒，而后打二筒证明二筒的价值又是可以被舍弃的，所以大概率是有一对一筒。第一轮在一一二四的配置下打掉了四筒，第二轮又摸到了一筒，或者是放弃了一二筒的组合，于是出掉了二筒。

你看，同样他打了个二四筒，但不同的出牌顺序，你可以反推出完全不同的手牌组合。所以记住对手的出牌轮次和记住出牌花色同样重要。只有按照正确顺序去推演，才能算出最准确的概率。

## 四、为什么你等的那张牌永远不来

除了反推手牌之外，我们还可以用贝叶斯公式去分析自己胡牌的概率。大家打牌的时候总会遇到这种情况，自己要胡的牌明明一张都还没有出来，但等死也等不来。这本质上还是你的概率算得有问题。

来看一道例题。假设你的手牌长这样，胡一万。目前桌上一张一万都没有打，但有人碰了二万。你觉得你还有几张一万能胡呢？

二万被碰了，那意味着一万成为了一张孤零零的单牌。如果有人拿到了单张一万，那大概率会打出来。可即使这样，桌面上依旧没有人打一万，证明目前有人手里有单张一万的概率是很低的。具体多低呢？我们可以求出来。

不妨设牌堆还剩六十五张牌，四张一万随机分布在三位玩家和牌堆当中。玩家出牌有出或不出两种情况，记为 X 等于一或 X 等于零。令西塔表示单人玩家手中一万的最大张数，则问题转化为求西塔的后验分布。先给出先验分布，然后列出不同西塔值的打出概率，求出边缘分布：

- 百分之三十七的概率一万全在牌堆里；
- 只有百分之十六的概率别人手中有单张一万；
- 百分之四十七的概率别人手里有两张以上的一万。

也就是说，你在等的四个单张一万可能都被别人捏死在手里。同理可得，当牌堆剩下三十九张的时候，别人拿有两张以上一万的概率为百分之六十七，二十六张的时候概率将近百分之八十。随着牌堆数目的减少，一万更有可能被别人捏死在手里。你在那傻乎乎地等着，怎么四张一万一张都不出来？其实他们永远不会打出来。所以该拆牌时就得拆，不然输钱就是活该。

## 五、麻将比围棋更接近真实世界

有的观众可能会说，麻将比围棋简单多了，围棋都被阿尔法狗攻破了，麻将算个啥？但其实麻将和围棋哪个难还真不好说。围棋是变化繁多的完全信息博弈，局面是公开的，拼的就是算力。但麻将是不完全信息动态博弈，隐藏的不确定信息太多，拼的是人心，而人心是世界上最难以捉摸的事情。

大家往往会发现，新手总是手气很臭，你打也打不过他们，就是因为他们打牌放飞自我，不按概率走。正所谓无招胜有招，老手也挨刀。当然你打不过新手可能单纯是你手臭，建议用脚打。

现实世界往往不是明朗而单纯的，就像你我的人生有太多不确定信息。从这个意义上讲，麻将比任何棋牌都更加接近真实世界。人生就是一盘麻将，每个人都是自己的庄家。你随手摸了张没用的一筒没打，可能几轮之后直接凑齐三张胡牌了。念念不忘，必有回响。现在做出的每次努力都会让你在未来闪闪发光。

打牌一下午赢了二十块钱，结果请全员吃饭花了两百块钱，你以为自己赚了，其实亏得不行。命运里所有的馈赠，其实早已在暗中标好了价。他说自己听了三万和三条，结果捡了你三筒的炮，赢得沾沾自喜。人生如戏，每个人都在伪装，展示着想给别人展示的那一面，将真实的喜怒哀乐藏在面具之下，等到漫漫长夜再独自消化。所以那些整天搓麻将的人，搓出的都是人间的酸甜苦辣呀。

最后给大家留一道思考题，请问面对下面这局牌，此时你应该打哪张呢？欢迎各位把自己的答案打在弹幕上。不会打牌的可以分享给你妈的麻友求助。我们下期再见。
