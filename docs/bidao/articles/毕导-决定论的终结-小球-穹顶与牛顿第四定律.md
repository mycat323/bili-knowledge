# 【毕导】决定论的终结：小球、穹顶与牛顿第四定律

**摘要**：毕导从牛顿力学决定论出发，通过小球在穹顶上的运动实验，展示了一个违反直觉的物理现象：小球会在没有任何外力干扰的情况下，在某个时刻自发地离开穹顶，从而挑战了决定论的确定性。

## 一、牛顿力学能预测一切吗？

我同佢最接近嘅时间，我哋之间嘅距离只有一百公分。佢饮咗最后一啖奶，将手抬高，等出咗一个樽。我知道零点一四秒之后，我嘅发丝将亲吻呢个樽。你要问我点解知道？那当然是因为我们小学二年级就学过的牛顿第二定律啊。只要我确定了瓶子的初值和受力，比如形状、质量、位置、出手的力、空气阻力、地转偏向力和我正在吃的板栗，我就能精确计算出它怎么飞行，砸不砸头。也就是说，在你出手的那一刻，瓶子未来的运动已经被牛顿力学狠狠拿捏了。抛出手的瓶子、掉地的薯片、下落的水滴、红。

## 二、决定论与牛顿第四定律

牛顿力学告诉我们，只要知道初始条件，就能预测未来。这就是决定论。但牛顿第四定律是什么？其实牛顿第四定律并不存在，它是我编的。我想说的是，在牛顿力学中，存在一些情况，使得未来无法被预测，甚至会出现违反直觉的现象。

## 三、小球与穹顶的实验

考虑一个理想实验：一个小球放在一个光滑的穹顶顶端。按照牛顿力学，小球应该静止在顶端，因为重力被支持力平衡。但如果我们给小球一个微小的扰动，它就会滑下来。然而，有一个特殊的解：小球可以在顶端静止任意长时间，然后突然在某个时刻开始下滑。这个解是牛顿方程的一个解，但它意味着小球在未来某个时刻自发地离开穹顶，没有任何原因。

## 四、诺顿穹顶与决定论的终结

这个实验被称为诺顿穹顶。它表明，即使在一个完全决定论的系统中，未来也可能是不确定的。因为小球可以在任何时刻开始运动，而初始条件完全相同。这挑战了决定论的核心：给定初始状态，未来是唯一的。

## 五、结论

所以，牛顿力学并不能保证决定论。小球、穹顶与牛顿第四定律（我编的）告诉我们，世界可能比我们想象的更加不确定。
