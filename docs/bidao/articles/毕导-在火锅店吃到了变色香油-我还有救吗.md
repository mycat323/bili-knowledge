# 【毕导】在火锅店吃到了变色香油？！我还有救吗……

<BiliPlayer :bvid="'BV1EE421V7B5'" />


**摘要**：毕导在火锅店发现黑色香油接出来就变黄，由此展开一系列实验，发现可乐、咖啡、水等液体的颜色都随厚度变化，最终揭示背后的朗伯比尔定律。

## 一、火锅店里的黑色香油

吃火锅时，我注意到小料台上有一桶黑黑的香油。你们见过黑色的香油吗？但这也不可能是一桶醋，这是重庆火锅，又不是山西火锅。去接一碗看看。不管从顶上看还是侧面看都乌漆嘛黑，难道加了什么科技狠活吗？战战兢兢接到碗里，黑色的香油一接出来就变成正常的浅黄色了，这什么魔术桶吗？

刚开始我的猜想是店家在小料台上打了一个绿光灯，黄色的香油在绿色的光下看着就是黑色的。但是我把一碗香油怼到那个绿光灯边，它并没有变黑，所以这个猜想好像也不成立。对这个现象的好奇让我魂不守舍，我吃饭都不香了，我决定搞点香油回去探索一下。

## 二、香油、可乐、咖啡的颜色之谜

看这瓶香油，从侧面看是清澈的橙黄色，但转到下面看，突然变成了深深的红褐色。把香油倒进杯子里面是越倒颜色越深，还怪好看的。难道说液体的厚度越大，颜色就越深？

我突然看向手边的可乐，它和那桶香油一样是黑色。那如果可乐只有浅浅一层是什么颜色？把可乐倒进家中常备的培养皿，哇，可乐原来是淡淡的棕色。把可乐倒进容量瓶里，细脖子这的可乐厚度很小，颜色就很淡；胖肚子这的可乐厚度很大，颜色就很黑。我喝了三十年可乐，竟然从来不知道可乐原本是这个颜色的。

等等，难道黑色咖啡其实也不是黑色的？把咖啡倒出来一看，咖啡竟然不是黑色，而是咖啡色的。原来我们的眼睛一直在欺骗我们吗？我当场把香油倒进家中常备的比色皿中，随着厚度增加，香油的颜色呈现出清晰而美丽的渐变。所以，可乐、香油、咖啡，它们到底是什么颜色的呢？哪个颜色才是它真正的颜色？

## 三、浴缸里的水也不是无色的

都是瞎研究，累了，回家泡个澡吧。但当我给浴缸里放满水的时候，我不禁发出了和阿基米德当年一样的呐喊。一杯水似乎是无色的，但放了一缸水，水竟然就变成浅蓝色了。从缸里舀出一杯水还是无色的。这说明了什么？这说明水其实根本就不是无色的，而是它本来就有一丢丢蓝色，只是一杯水太少了，你根本就看不出来。水越多就越蓝，在这管水里你就能看出水忧郁的蓝调。大海就更蓝，深海甚至蓝的有点黑，就像那桶香油一样。

我们从小就学过水是无色透明的，但今天这个常识被我家的浴缸推翻了。不信你就去打个水的可见光吸收光谱，你会发现水吸收红黄光，所以它本来就是蓝色的。总之一个液体越厚它就会越黑，这就是厚黑学嘛。

## 四、背后的科学规律：朗伯比尔定律

我试图找到它背后的科学规律。一通乱搜之后终于发现，原来早在1729年，一个法国科学家叫皮埃尔·布格，他就已经发现了这个现象，而且第一个发表论文指出，光在液体当中走，它是随着距离而指数衰减。为了纪念布格对科学的贡献，这个定律就被称作朗伯比尔定律。

他开辟了科学分析的全新领域，以它为原理的紫外分光光度计造福了无数环化材生的研究生。大气学家利用朗伯比尔定律监测地球的二氧化碳浓度，你的智能手表都在使用朗伯比尔定律监测血氧含量，守护你的健康。布格泉下有灵一定倍感欣慰吧。

所以，变色的香油不是啥科技狠活，那个桶也不是特制的桶，它的背后就只是我们小学二年级就学过的朗伯比尔定律而已。只要用心观察生活，小小的火锅店也能引导我们探索科学的奥秘啊。
