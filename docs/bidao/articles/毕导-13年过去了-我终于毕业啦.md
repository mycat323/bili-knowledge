# 【毕导】13年过去了，我终于毕业啦！

<BiliPlayer :bvid="'BV19c411o7os'" />


**摘要**：毕导分享了自己从2010年进入清华到2023年博士毕业的13年经历，重点讲述了2017年休学创业后2020年复学读博的两年半里，从迷茫、焦虑到与自己和解、最终完成科研并毕业的过程，以及毕业时的喜悦与离愁。

## 一、从延毕侠到毕业：我的清华十三年

虽然我已经在很多地方都说过这件事了，但我还是要在这里庄严地宣告一句：我终于博士毕业啦！最近两年我每天都会收到私信，毕导你怎么消失了呀？百大UP怎么变百慕大UP了呀？答案特别简单，因为回去读博了，搞科研确实没时间更视频。我姓毕，我一直觉得这个毕是毕业的毕，但后来我才意识到它其实是延毕的毕。

打开我的视频列表，从2020年12月博士复学开始，我就更得越来越少，合作视频越来越多。今天和罗老师唱rap，明天和彩浅逗乐子，后天找team白嫖装修。从2020年12月到2023年7月，这科研时长两年半里面，我基本就是大家对我视频催更厉害了，我就憋一期；导师对我SCI催更厉害了，我就发一篇。哎，开玩笑，这个催更了也发不出来。

我从2010年来到清华，没想到2023年才离开。清华校史112年，我竟然陪伴了其中的11.6%。我见证了清华的百年校庆和110年校庆，熟悉所有的食堂装修、操场变色、新楼修建、道路命名。我送走了我的每一位同班同学，也经历了四位校长的先后换届。新来的领导都得找我打听学校的内幕。我连毕业歌都唱了两首，学生卡都换了四张。在我临近毕业的时候，我们系有教授建议我毕业后留校工作。我说我科研成果哪够留校的？教授说我没说让你留校搞科研，我是说你可以去校史馆。反正这些年真是在清华活成了一个梗。

毕导毕不了业这件事给无数同学、老师和网友都提供了快乐。我不知道是不是很多人把看我读博当成一个养成类游戏在玩。我甚至在想，你们得知我真的毕业了的那一瞬间，会不会第一反应不是恭喜，而是怅然若失。但可能只有我自己、我实验室的兄弟们和广大在科研的海洋中挣扎、纠结甚至延毕的硕博们才能理解我的感受。今天就和大家聊一聊我消失的这两年半里的感悟与得失，迷茫与和解。

## 二、复学：从博主变回博士生

这个楼就是我的宿舍啊。好看。这现在怎么变女生宿舍了？我2010年考来清华化学工程系，学的高分子材料与工程专业。2014年在本系读博，2017年12月博士休学，当时是博四上学期。清华学生手册规定，休学创业最长三年。2020年12月呢，我就复学了。原来活力满满的视频团队也各奔东西了。我翻出了尘封的学生卡去C楼激活，这是一张来自上古时代的学生卡，拥有让卡的主人卡着不能毕业的神力。我恢复了校园网账号，用户名bxt14，彰显着一四年入学的尊贵身份。我去西办办了复学手续，办完正要走，西办刘老师跟我说了一句，欢迎回来，大家都很想你。这甚至让我想到了这个场景：It's been a long time。走在系馆里，每位老师见到我都说一句，呵，回来啦，还是相当温暖的。

我复学的时候呢换了一位导师，研究方向也从超波次复合波的制备到了化工厂的故障检测与诊断，从做化学合成变成了菜鸡码农。刚开始我很担心难以融入新课题组，因为确实有点年龄差距。组里大师兄比我小两岁，小师弟比我小七岁，连我们隔壁的副教授都只比我大三岁。但好在我有两个优势，第一这位大师兄吴博，我当年是他的辅导员，现在他可以辅导我科研。第二，我好歹也是一个知名UP主对吧？所以当组里同学知道毕导要来我们组读博的时候呢，都很激动。我们很快成为了狐朋狗友。唯一的问题是大家不知道应该管我叫师兄还是师弟。

虽然很顺利地融入了课题组，但是作为一个大龄博士生，还是难免会遇到问题。有次实验室的兄弟们摸鱼的时候在聊这个打新冠加强针的感受，听得我十分的迷惑。我说为啥你们都打过了，就我没打，你们哪收的通知啊？兄弟们说年级群里通知的呀，你们年级群里没有人通知吗？哎，他们没有意识到我们年级只剩下我一个人了，我的年级群已经变成校友群了。系里对此高度重视，当即批示必须把毕导拉到某个年级的群里，但问题来了，应该拉到哪个年级的群里呢？有人建议，如今毕导复学面临着全新的开始，应该拉到2020级研究生新生群里，大家一起成长。我说不妥不妥，有代沟。又有人建议可以拉到博五毕业年级的群里，毕导当年是他们的辅导员，比较熟。研工助理沉思之后说，不妥不妥，博五年级明年就毕业了，毕业了这个群又变校友群了，毕导哪有那么快毕业呀？大家纷纷表示还是研工助理考虑周全，兄弟们纷纷唱起不会吧不会吧，毕导不会明年就毕业吧。屋里充满了快活的空气。题外话，大家可能注意到了，为什么我上面管实验室的人都叫兄弟而没有叫姐妹呢？没错，这就是我组科研现状。

总之生活就慢慢转变啦，我从一个博主变回了一个博士生，每天早起背着小书包去上学，有时也会被导师查岗抓住。看上文献泡杯热茶，我是快乐的调包侠。配置环境pip conda，无聊就看看周志华。求助兄弟debug炼丹确实很复杂。跑跑代码临近中午实验室渐渐变嘈杂。总之上午的时间很短暂，经常一事无成就去吃午饭。吃完午饭回来水水老戴冲点零八，实验室里笑哈哈。鱼都摸完专心学术，科研状态很爆发。忙一下午仔细一看实验数据很奇葩。总之呢下午一般效率最高，但也经常是一事无成的去吃晚饭。晚饭回来有灵感呢就继续科研，万一导师晚上查岗来看到我我就赚大了。如果科研很烦躁呢就回家砍一下萎靡一心，让Arthur Morgan露个营，在马拉卡拔两个寨子被女武神踩上两脚，解锁一个底特律的分支再去神石厅行侠仗义。我相信每一个科研狗都有一个被动技能，那就是组会前一天总能突击出一些科研进展，或者至少能在组会上表现得仿佛有一些科研进展。每周组会和工业项目会之后，兄弟们就会去南门外吃一顿烧烤，再打一场台球庆祝又活过了一次组会。已经很厉害了。

大家可能也能感受到，我刚复学的时候感觉挺兴奋的。我甚至在公众号上开了个栏目叫岩壁记录搞笑日常。无数人工作后都会怀念起校园回不去的单纯美好，而我在工作了三年之后竟然回去了。而且科研入门阶段，你学知识啊看教程，你每天都会觉得自己进步了一点点。今天写个CNN，明天写个SVM，后天配环境配了一天，你都挺有成就感的。周围还有一帮和你一样没心没肺的兄弟，非常快乐。但快乐是不能帮助你毕业的，科研大部分时候的本质是孤独而苦闷的。能沉浸在快乐中的，要么是天才，要么是还在学教程的新手。当你品尝到持续的焦虑、挫败、无助的时候，恭喜你，你才算是开始科研了。

## 三、科研的迷茫与和解：从哈密瓜炒蛋到第一篇论文

这是我读博的二周目了，所以我有一个优点，那就是心态好。作为一个28岁刚换的方向，一篇文章没有肯定要延毕的博士生，已经身在学术的低谷，怎么走都是向上。但是我也有一个缺点，那就是只有心态好，科研水平还是和一周目差不多的菜。我相信很多科研人都跟我有一样的感觉，就是我们只有能力提出一些浅显易懂的idea，别人西红柿炒蛋，我就拿哈密瓜炒蛋，有效解决了前人炒蛋太酸不甜的问题。别人提出炒蛋要放油，那我就调控菜籽油、橄榄油、花生油的浓度分别炒蛋，再用电镜红外原子力把你蛋全部测一遍，标题就叫基于油品浓度动态调控法的哈密瓜炒蛋制备及性能研究。别人炒蛋是用桌子把蛋磕碎，那我就提出用大锤把蛋砸碎。这个预处理提升了蛋碎的成功率，在工业中有广泛的应用前景。However so far 大锤砸蛋 has not been fully investigated。你看，一聊这种水idea我就文思泉涌。我当然也佩服那CNS呀、JACS呀、AM上那些巧妙idea，但我确实不知道怎么想出来。本质上呢就是积累少，对这个科学领域洞察不足。那洞察不足也得干呐，得发文章毕业啊。

复学后一个月，我斗胆去找导师聊方向，导师说咱们系同学对实验安全不够重视，比较天然。你去做一个能在系馆里走来走去的机器人，监督同学穿实验服、戴护目镜。听完我心想，你是不是把我认成智慧君了？两天后我决定告诉导师我完全不懂机器，你不要让我做这个课题了。好在两天过去，导师好像已经忘了跟我说过什么。但这次导师有了全新的想法，他说中国目前还没有商业化很好的化工厂故障诊断与预警软件。毕啸天，你在咱们组工作基础上写出第一个这样的软件，打破美帝对我们的卡脖子。你去把唐僧师徒除掉。我嗯不过我只是展现了自己的真实实力，就让导师放弃了这个想法。最后呢我去研究了化工故障检测诊断算法，但我依然很迷茫。尽管科研大方向放在这了，我还是定不下来。那我具体研究个啥创新点呢？我今天应该做啥呢？看篇文献好像有点用，做几个实验也挺充实的。但每天这么看几篇文献，做几个实验，半年后成果就会冒出来吗？我不知道。不积跬步无以至千里，但积了跬步一定至千里吗？读博就像是在没有攻略的情况下要你五天通关艾尔登法环，最多延你两天，你怎么玩？你是先刷级，还是先找装备，还是无用之人出门硬刚大树守卫？复学前两个月，我每天就这样在迷茫中睡去，又在困惑中醒来，并陷入不能毕业的恐慌。甚至又开始和一周目一样，深夜搜索读研抑郁怎么办。

也不怕大家笑话，让我科研走上正轨的因素，我觉得不是水平进步了，而是与自己和解了。我的一位学术大神师兄跟我说了一段话，你可以志存高远的科研，也可以心平气和的科研。你擅长科研就追求优秀的毕业，不擅长科研就接受普通的毕业。只要你能堂堂正正地达到毕业要求，那两种选择都成立，关键是内心要自洽，别拧巴。选前一条路，别看不起选后一条路的。选后一条路，别看不起自己。我当时以为自己听到了读博的真谛啊，后来明白在科研大佬心中这就叫躺平。师兄跟我说，你就先做出点东西来保个底，你哈密瓜炒蛋都行，只要你发过了一篇paper你就有信心了。读博这种苦行是要靠着信心才能撑下去的。当然不同的人有不同走出科研困境的方式，但这种心态转变至少让我轻松了一些。我平时呢会用笔记软件记录代码和数据，并用一个表情来描述今天的成果。现在回头来看，每一天的情绪就像过山车一样跳跃，但也不时地会做出一点小成果。导师对我的课题悉心指导，我的兄弟朋友们也和我热烈地讨论，他们说科研上不懂的尽管问我们啊，你有空了赶紧去更新视频。兄弟情谊真是好笑又感动。

不知不觉搞了一个学期，我通过了新方向的开题答辩，也颤颤巍巍地写完了第一篇paper。原来这就是科研的感觉。兄弟们跟我说啊，导师对论文要求很高，会很细致地跟你讨论修改。在我忐忑地把初稿给导师发过去之后，我收到了他的回复。那是我科研生涯比较幸福的一个瞬间。虽然我博四下学期才写第一篇paper属于是老来得子，但那一刻我就像一个孩子得到了认可一样。文章投出去，审稿人给了小修，修完就accept发表了。回想起自己一学期的工作，甚至有一点小小的自我感动，甚至还发了期视频庆祝了一下。然后第二天就被导师叫到办公室里去了。科研就像蹲坑呐，手里有paper就有底气，我整个人的腰不酸背不疼了。

## 四、从工业项目到综述：科研渐入佳境

在导师发现，哎呀，毕啸天这小子居然真能搞出点东西之后，我也开始承担更多的工业项目。这些年呢，导师带着我和兄弟们去了好多化工厂，从最开始说不出几个炼油工艺，到后来做梦都在想连续重整。有一次呢，B站邀请我去参加上市的敲钟，前一天刚刚跟一众UP们聊完他们的自由生活，第二天就赶紧飞去泉州石化，讨论炼厂R201反应器的压降与瓦斯流量的关系。泉州这个城市啊很有意思，楼下的小店叫做文献生活，隔壁卖酒的地方叫做摘要，看得我们兄弟阵阵头疼。离开上海的凉风，来到泉州的凉风。在高塔铁斧的轰鸣声中，我忽然觉得读博也有点意思。

我们组呢每学期结束会发一个问卷啊，调研组会效果。问卷里有个题目是问你最想和谁一起科研，你最想和谁一起玩。综合得分高的人有奖金拿。那大家都想一起科研的人，那当然是大神了。但是大家都想和你玩的话，你不就是组里带头摸鱼的鱼王？结果一出，好家伙呀，合着全组就三个人想和我搞科研，只有一个人想和我做企业课题，那一票还是我自己投的。但几乎所有的人都想和我一起旅游娱乐，我前四项总分倒数第一，硬是靠这后两项勇夺正数第三。这两千奖金我宁肯不要啊，没办法，谁让你又菜又搞笑呢？

然后我的博五开始了，我竟然在科研中有一种跃跃欲试的感觉。啊，我竟然博五才有一种跃跃欲试的感觉吗？有天导师跟我说，你做科普视频的时候感觉读文献挺快的，要不你写篇综述吧。其实我个人觉得，科研中迷茫的心累是最累的，写综述这种肉体的累对我就还好。我白天科研，晚上码字，加上导师指点，兄弟齐心，投出去一波大修，终于accept。发了两篇paper，自己也作为审稿人审了一堆paper之后，科研有点感觉了。我对能毕业的信心强了很多，也开始搞一些比哈密瓜炒蛋更有意思的工作。我还合作了一篇paper，承担了一个新的横向项目，甚至还发挥特长在公众号上帮导师招来一位博士后。然后我顺利通过了中期答辩，申请了一个延毕，还发了个视频庆祝了一下。然后又被导师叫到办公室里去了。哎，不是，导师你是特别关注了我吗？

博六开始了，我也度过了我的三十岁生日。兄弟们开始忙着找工作、投简历，但因为有屏幕前的大家的支持和催更，我可以继续做一名UP主。因此呢，在当时的秋招季，我还是继续埋头科研，追赶毕业。然后我又投了一篇专利和一篇paper。每学期的组会调研问卷啊，想和我科研的人越来越多了。博六上学期的问卷里面，我终于在最想科研和最想玩的人两项都排到了前几名了。我就像唐僧，走了二十五集，终于看到了西天的佛光。我其实没怎么和导师商量过我能不能博六毕业，毕竟作为一个复学的人心虚嘛，你只能好好表现，期待导师大发慈悲。但是呢有一天我和导师聊天，他突然说了一句，你要把你的方法传授给师弟们，毕竟你下学期就要毕业了。我嘴上说着好的，我这就回去整理一下，但我心里已经爽翻天了。原来导师他记着我毕业这回事，他的心里有我。

今年一月除夕夜，我看了会儿春晚，呃，觉得还是去写博士论文吧。我新建了个word，瞎扯了几千字，然后忽然意识到，我竟然真的要毕业了。以后观众们再也不能调侃我岩壁侠了。那些之前挡住我的九九八十一难都没了，好虚无啊。然后我就接到了系院的电话，说毕啸天，你培养方案里有个一学分的必修课还没有修，没有修完下学期是不能申请毕业答辩的。啊，我当时感觉天都塌了，我就要取得真经回来路过通天河的唐僧突然被告知你还差一难，延毕吧你。快，快到，还少一难。我研究了一下那个一学分的课，只要听八次讲座就得过。我也不知道为什么我八年了连八次讲座都没听够。但即使我下学期把它听完也没用了，因为那个课是期末给分，博士毕业答辩在学期中间，所以赶不上了，我又要延毕了。系办老师说你现在还剩最后一条路，退了这门课，选一门下学期前八周结课的一学分替代课，然后在第九周抱着老师大腿求他赶紧给分，只要老师给分时间早于你的毕业答辩时间，你就还能正常毕业，这是你毕业的唯一希望。我跟导师说这件事的时候，他以关爱智障的眼神看着我，因为他上学期刚开了一门这样的课。最后呢，我选上了环境学院的环境工程伦理。当兄弟们都在冲刺毕业论文的时候，只有我还在每周背着小书包去上课。当兄弟们都在紧张地准备预答辩的时候，只有我还在课上和小组同学演小品。博士的课呢确实很有意思，我也顺利地结课，赶上了毕业答辩。感谢老师。

如果以一到十打分的话，写博士论文的痛苦程度是快，不算特别大，但无穷无尽。改到后来我打开那个word我就想吐。唯一值得高兴的是送审在烂之前呢，我投那篇paper刚好发表了。当时我的精神状态是这样。三月三十号终于论文送审，四月二十七号评审通过。五月十七号是我的毕业答辩。我将头发梳成大人模样，穿上一身帅气西装。刚入场呢，看到台下的外校专家有点紧张。其中一位石油大学的王老师说，哎呀，我们课题组同学都是你的粉丝啊。他们说如果今天答辩不给你过的话，就不读我的博士了。答辩教室瞬间充满了快活的空气。感谢石油大学同学们的暗中相助啊！我答辩了整整一个半小时，在台上都给我站麻了，直接听结果。答辩委员会经无记名投票表决，一致同意通过博士论文，并建议授予毕啸天工学博士学位。祝贺啸天。

## 五、毕业：喜悦与退场

后面就放飞自我了，我报仇雪恨一般的吃喝玩乐了两周。我要戴上我的帽子，我的袍子，带上我的兄弟们在镜头面前摆造型。我要比你看到过的、听到过的那些所有严厉故事加在一起还要顶。我要走遍清华大学的每个犄角旮旯，我要变成一个展示馆的展示品。从此进开的二校门，从此进开的二校门。六月二十三号是我们系的毕业典礼，我负责开场唱歌搞气氛，真是快乐到要飞起来了。那几天不管你和我聊什么，我都能扯回到毕业的话题上。六月二十五号是全校的毕业典礼，校长给我拨完穗，工作人员说，同学请从这边退场。退场这个词突然击中了我。从2010年来到清华，十三年过去了，我终于等到了博士毕业这一天。然而这一天既是我庆祝毕业喜悦的一天，也是我退场离开的一天。行至城门残酒醒，万重离恨一时来。当天下午我就收拾东西离开了我做了两年半的实验室工位，也离开了陪伴我十三年的学校。这两天有什么感受？我的学生生涯结束了。

我视频断更这段时间的故事呢就是这样了，占用了大家这么久，听了一段流水账。主要是之前被催更的太多了，现在终于毕业了，所以给大家一个交代。我国现在一年的博士毕业人数大约是七万，硕士是七十万。但博士的非正常毕业率在百分之六十多，硕士在百分之十几。所以读研确实是孤独而艰难的。所以最后我想跟大家分享的是，读研最重要的能力可能是自我规划和剖析的能力，找到适合自己的科研和生活节奏。硕博毕业表明你在某一知识领域经受了若干年的学术创新训练，并通过了成果考核。但考核完了，怎么过毕业后的人生，是更要思考的选择。我因为各种机缘巧合，一不小心把这个博士读了九年，这确实很漫长。但幸运的是，我也找到了自己喜欢做的事。每当我们用视频与大家交流科学中的快乐和美的时候，是我自己最满足的时刻。能有这么多人聚在我们视频的评论区聊物理、聊化学、聊水花和subn时期，这已经是个奇迹了。不知你最喜欢的是哪一期呢？你的大学生涯可能会比我短，嘿嘿，肯定比我短。我衷心希望大家在二十多岁最珍贵的时光里找到自己喜欢做的事，获得内心的自洽。衷心祝福大家生活顺利。未来呢我们也会努力更新啊，哎呀，这个毕业了也没有脸再拖更了，只是需要一点时间来进入创作的状态。最后呢，感谢我的导师的指导，感谢兄弟们的帮助，感谢亚青、植树、福南，感谢亚青工作室全体同仁，感谢各位观众的陪伴、支持和鼓励。我们下期再见。下期是什么时候呢？
