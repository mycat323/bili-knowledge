# 【毕导】这可能是世界上唯一科普这种皱纹的视频……？

<BiliPlayer :bvid="'BV1Fj411H7Xi'" />


**摘要**：毕导从汤和牛奶表面的皱纹出发，通过复刻双皮奶、分析材料力学中的屈曲现象，并结合2017年关于奶皮皱纹的论文，揭示了皱纹是由蒸发导致的压应力产生的，并延伸到生活中的各种皱纹现象。

## 一、汤和牛奶表面的皱纹：从日常观察到科学问题

前几天我们工作室的小伙伴在群里发了个视频，说他在家里吃乌鸡甲鱼大补汤的时候发现，汤的表面浮着一层膜，膜上有一条条皱纹，皱纹还在动来动去，姿态怪风骚的。我仔细一看，大为震撼。因为我此时正在吃的泡面的汤上也浮着这样一层有皱纹的膜。我给植树热过的头的牛奶上竟然也浮着这样一层膜。它轻盈自由，它快乐摇摆，它的皱纹是如此规律，每个人看一眼都会涌起一种想用微分方程把它给狠狠描述的冲动。

看着这些膜，我不禁陷入沉思。为什么汤和牛奶表面会有一层膜呢？为什么膜上会有像水波被冻结了一样的规则皱纹呢？难道这就是魔法？在我查了一堆文献之后，我发现这个话题竟然实现了科研界的 SNP 大一统。今天我们一起来探索一下魔力学。

其实这层膜呢，大家喝肉汤的时候应该都注意到过。特别是广东爱煲汤的靓仔靓女肯定经常见到。有的人觉得它有点恶心，会把它撇掉。也有人对它欲罢不能，就喜欢单独捞出来嗦着吃。不知你是哪一种？它的形成原因其实很简单，热的肉汤当中的动物油脂和变性蛋白质冷却时在汤表面聚集凝固，就变成了一层膜。所以这层膜呢看着恶心，其实它和汤的营养成分基本一样，撇不撇你也都会长胖，你就安心吃吧。

喜欢甜品的朋友应该知道，双皮奶的皮也是这么一层有皱纹的膜。相传清朝广东顺德的董奶奶把牛奶煮沸后冷却，发现表面形成的皱巴巴的皮意外的好吃，由此发明了双皮奶。

## 二、复刻双皮奶：观察成膜动力学

我给大家复刻一下董奶奶当年做奶皮的工艺，观察一下成膜动力学。取出家中常备的烧杯，倒入普通的牛奶，再取出家中常用的磁力搅拌器，加热牛奶到八十度保持五分钟，此时乳清蛋白会发生变性。取下烧杯让牛奶自然冷却，我们凑近仔细观察可以发现，半胱氨酸残基的硫醇基团之间通过氢键或者二硫桥键相结合。蛋白质之间的疏水相互作用以及未折叠氨基酸链的构象自由度增加而产生的熵增等多种因素共同促进蛋白质在液体表面聚集成膜。

这张薄膜比我的脸皮还薄，我目测厚度大约在五十八点四微米。膜上皱纹像是正弦函数，波长大约五毫米。皱纹似乎在随着蒸发而产生的白气而扭动。轻轻戳一戳，膜上出现了星形放射状的折叠。捞起来嚼一嚼，您别说，这味道还真别说，董奶奶当年就掌握了如此复杂的化学过程，董奶奶真懂奶啊。

现在我们知道这张膜是怎么来的了，但是好好的一张膜也没有人动它，怎么就自己会皱起来呢？

## 三、生活中的皱纹：压缩与拉伸的启示

皱纹这个现象我们并不陌生，先来看看生活中常见的皱纹都是怎么产生的，也许能找到一点启发。现在捏一捏你对象的胳膊，胳膊上会挤出皱纹。压缩一个面包，面包表面会出现皱纹。如果你家里碰巧有液压机的话，压一个金属圆柱薄壳就可以看到整齐漂亮的皱纹。捏我朋友家的无毛猫，猫猫背上会产生皱纹。大象卷起鼻子，鼻子弯曲的部分会产生皱纹。某些飞机的表皮在大载荷下能观察到奇怪的皱纹，某些歌手的表皮在大风力下也能观察到可爱的皱纹。如果你看毕导看的太认真了，你的眉间就会挤出皱纹。如果你看毕导笑的太开心了，你的眼角就会长出皱纹。

观察上面这些案例我们会发现，挤压平面材料时可以产生与挤压方向垂直的皱纹。当你拉一张餐巾纸时，纸会产生皱纹。当你拽对象的衣服时，衣服上会有皱纹。吃完饭蒙保鲜膜用力大一点也会有皱纹。拉一坨口香糖虽然很恶心，但恶心的表面也有皱纹。一张软软的椅子戳一戳，表面出现了皱纹。一张平整的床单盖在鬼的头上也产生了皱纹。这个东西大家认识吗？是竹笛上贴的笛膜，轻轻一拉也会出现平行的皱纹。如果没拉出皱纹，声音就会紧绷发闷。如果皱纹拉的细密均匀，笛子音色就会清脆水灵。

观察上面这些案例，我们会发现拉伸平面材料时会产生与拉伸方向平行的皱纹。为什么挤压和拉伸物体都会产生皱纹呢？

## 四、材料力学与屈曲：皱纹的本质

让我们复习一下小学二年级就学过的材料力学，也许能窥探到皱纹的本质。材料力学研究的内容概括起来就三句话，力产生形变，小力产生小变，大力产生大变。以材料力学当中最经典的拉伸实验为例，当外力在一定范围内时，物体能在外力消除后恢复原有的形状和尺寸，很有骨气，这就叫弹性。当外力大到一定程度，材料就会屈服，投降了。屈服后物体继续被拉长并发生永久变形，这就叫塑性。随后材料会由于内部的排列规整而出现回光返照的强化和颈缩，最后咔嚓断了。这个实验工科生几乎都做过，每台万能机的缝里都插了无数工科生的头发。总之，很多材料在拉伸或压缩时都会经历弹性、屈服、塑性、破坏这几个阶段。

但早在十五世纪，意大利的全才达芬奇研究了一种特殊的情况。一根胖柱受到压力时会先屈服后破坏，但一根细杆受到压力时却可以在屈服前由直变弯保全自己，卸掉压力后还能由弯变直完好如初。这个现象叫做屈曲。比如这是一个屈曲的铁轨，铁轨材料本身没有破坏，但结构已经失稳，火车开在上面就有一点点危险了。再比如撑杆跳也是细杆的屈曲带来的体育魅力。如果杆子屈曲后发生了屈服断裂，就会有点疼。

一七五七年，瑞士数学家欧拉计算了屈曲的临界压力，并提出了我们小学二年级学过的欧拉公式中的一个。弹性细杆受到的压力超过这个临界值就会发生屈曲。你可能觉得屈曲屈曲不足为奇，这哪用达芬奇和欧拉研究呀，我大舅也能独立发现这个现象啊。但接下来的研究就不是你大舅轻易能想到的了。

随着材料力学的发展，人们认识到二维材料受到的挤压力超过临界值也会屈曲。一维的细杆屈曲表现为变弯，而二维的薄板屈曲除了整体变弯，还往往会长出皱纹。那这是为啥呢？我们给大家人肉演示一下。材料内部的分子本来维持在一个比较舒服的距离，你一挤压材料，分子就被迫相互靠近，相互抵抗。这个时候聪明的分子就会离开平面，大家就能重新恢复到舒服的距离啦，这就会形成波浪形的皱纹。简单来说就是外部挤压会在二维材料内部引起压应力，将材料分子推得更近，增加了弹性应变能。这时材料有两种选择，要么继续面内压缩，要么向面外弯曲。如果面外弯曲能量更低，那它就选择变弯。弯的时候又会选择能量最低的波长和振幅，最后就形成了皱纹。所以长出皱纹是材料为了对抗外界压力，降低弹性应变能的一种方式。一个很直观的计算我放在这里，应该能帮助大家理解。

现在大家都明白了，压应力会导致二维材料屈曲并产生与压应力垂直的皱纹。总结起来就一句话，外界太 push 了，你就会长出皱纹。从二十世纪初开始，人们提出了一些理论来定量描述皱纹的发生条件和图案规律，比如我哥们张力场理论等等。从此皱纹有了方程。在这个世上，一件事物拥有了自己的方程，就开始褪下神秘，走进科学。

科学家们计算解释了各种各样的皱纹，比如蒙娜丽莎的袖子上有美丽而规则的皱纹图案，神秘吧？一九五一年，日本科学家 Yoshimaru Yoshimura 给出了解释。薄壁圆柱体沿轴向压缩时会出现类似于施瓦茨灯笼形状的三角形网格屈曲图案，这种现象被命名为吉村屈曲，Yoshimura buckling。在你起袖子的时候很容易观察到。

有的同学要问了，那为什么拉伸也能产生皱纹呢？拉伸和压缩不是反义词吗？没错，但是一张薄膜在水平方向上拉伸时，水平方向变长了一点点，那竖直方向就得变短一点点。这就是我们小学二年级就学过的泊松效应。两个方向的应变比值加个负号就是泊松比。所以水平方向的拉伸就会带来竖直方向的压缩，这个我们肉眼都能观察到。二零零零年，Friedl 等人发表论文《拉条条的屈曲》。二零零二年，Cerda 等人发表了 Nature《张力下的弹性膜起皱》，他们均指出，薄膜拉伸时会由于泊松效应在中心产生与拉伸垂直的压应力，这导致薄膜发生屈曲产生皱纹。所以这个皱纹垂直于压应力，平行于拉应力。总结一下，不管是拉伸的皱纹还是压缩的皱纹，都是由于压应力而产生皱纹。

## 五、奶皮皱纹的成因：蒸发导致的压应力

有的同学要问了，毕导你讲的我倒是全听懂了，但你搁这扯了半天，奶皮和汤膜上的压应力从哪来呢？是呀，奶皮在奶上安安静静，汤膜在汤上本本分分，没有外力拉伸挤压，哪来的应力呢？是膜的重力吗？是水的浮力吗？是我哥们张力吗？都不是。

二零一七年终于有人发现了奶皮起皱这颗学术界的沧海遗珠。Alice 等四位爱喝奶的科研人员把一堆牛奶在不同条件下加热冷却制备奶皮，再用共聚焦显微镜轮廓曲线仪一通观察，发了一篇 Soft Matter，标题就叫《奶皮的皱纹是蒸发导致的》。他们提出奶皮可以看作一层多孔弹性膜，内部充满了牛奶，牛奶通过奶皮蒸发就会在膜的孔里形成好多孔瘤。这个孔瘤意味着孔内有压力，这个压力产生了奶皮平面内的应力，这个应力产生了奶皮上的皱纹。

有的同学要问了，为什么孔流就说明奶皮孔里有压力呢？压差是流动的推动力，奶能通过奶皮蒸发就是因为上面压力小。牛奶的蒸发通量勾和压力梯度成线性关系，这就是我们小学二年级还学过的达西定律。这样呢我们还可以算出奶皮孔里的奶压。

有的同学要问了，那为什么孔里有压力就会有奶皮面内的应力呢？我请教了我的土木哥们，通俗的讲就是，牛奶蒸发向上运动，奶皮会给奶一个阻力，奶就会给奶皮一个向上的渗透力。根据我们小学二年级课外班还学过的太沙基有效应力原理，奶皮在竖直方向上的有效应力就会降低，再根据广义胡克定律，奶皮会在水平方向上收缩。但奶皮不同部位蒸发不均匀，所以有的地方收缩多一点，有的地方收缩少一点，相互拉扯，在奶皮内部形成了复杂的应力。这些应力最终形成的皱纹。具体的计算大家可以参考流体饱和多孔介质的本构关系，算的非常清楚。这呢是土木工程和材料工程的一个交叉学科，叫孔隙弹性力学。感兴趣的同学可以报考土木和材料的双学位，开展深入的学习。

作者还在不同湿度下做了一堆奶皮，发现湿度越大，蒸发越慢，皱纹越少，证明了皱纹的确来源于蒸发。所以如果你想吃皱纹多的双皮奶，你就去干燥的大西北。你要是不爱喝有皱纹的汤，呃，你就在洗澡的时候喝。

## 六、皱纹的方程与广泛存在

说到现在，你是不是也想狠狠的用方程描述它了？我懂你。二零零二年起，Cherdah 和马哈德文对着膜一通狂拉，还在膜上滴水产生皱纹并计算其规律，发表了 Science、Nature 和 PRL，实现了科研顶刊的 S N P 大一统。他们发现膜上的皱纹遵循 Föppl von Kármán 方程。Föppl 大家不一定认识，他就是我国导弹之父钱学森的导师，超音速飞行之父冯卡门的导师，现代流体力学之父普朗特的老师。我们跟着一通计算猛如虎，不难发现，奶皮上皱纹的波长正比于奶皮的弯曲刚度除刚度的四分之一次方。弯曲刚度等于杨氏模量乘以厚度的三次方除以十二倍的一减泊松比的平方。皱纹的振幅正比于压缩应力的二分之一次方乘以波长。到这里，我们终于把这个皱纹给狠狠描述了，好爽啊！

我认为汤膜的皱纹也是一样的原理，不过目前我还没有查到任何的论文。欢迎爱喝汤的科研人员对汤膜开展详细的研究。稍微 P 一下啊，发个 Nature 封面应该不成问题。

朋友们，你喜欢吃豆皮吗？李时珍本草纲目豆腐篇有云，豆腐之法，始于汉淮南王刘安。其面上凝结者，揭取晾干，名豆腐皮，入甚佳也。清代李调元有豆腐皮诗云，石膏化后浓如酪，水沫挑成皱成衣。老祖宗早就知道做豆腐表面那一张皱巴巴的膜晾干之后变成豆腐皮很好吃。谁能想到这个现象如此常见，但竟然到二零一七年人类才弄清这层膜皱纹背后的奥秘。

你可能不喜欢皱纹，有皱纹的衣服意味着邋遢，有皱纹的皮肤意味着衰老。但不管你喜不喜欢，皱纹都是我们生活当中常见、重要而神奇的结构。在微观的世界里，细胞内膜结构的起皱反映着细胞的生命健康状态。在日常的生活中，大脑皮层皱纹丰富是人类智慧发达的象征。在深邃的大海里，海蝓巧妙的通过皱纹增大自身面积，盗取更多藻类中的叶绿体来进行光合作用。在广阔的陆地上，大陆板块在漫长的岁月里相互推动，压应力主导的造山运动形成了褶皱山脉。喜马拉雅山就是印度板块和欧亚板块挤压形成的褶皱。它下面的地壳至今仍然在被压缩的过程当中，所以喜马拉雅山每年还能长高一厘米。你觉得喜马拉雅山是世界第一高山，但在地球母亲眼里，孩子还在长身体的时候。

在天体的视角下，宇宙里也布满了皱纹结构。火星和月球上的皱脊都是滚烫的熔岩冷却时产生压应力而形成的几百公里长的皱纹。这么看来，月球不过是碗双皮奶。甚至还有研究表明中子星的表面也会形成皱纹。中子星的密度和引力奇大无比，理论上应该坚硬、圆润、完美。但当中子星的星壳应力变化时，也会产生皱纹一样的山脉，大概零点几毫米高的山脉。正是这零点几毫米的起伏造成的不对称性，才让中子星旋转时能放出引力波，这也让人类能观测到这种仅次于黑洞的强者的存在。

随着人类对皱纹规律理解越来越深刻，皱纹不再是一件纯粹烦人的事。人们开始反过来思考，如果能可控的让皱纹随我心意产生，岂不妙哉？这个想法一听就让科研人员两眼放光，这能创新出多少 idea 啊？近二十年来，关于皱纹的研究直线上升。如果让你大胆想象，你想研究什么的皱纹？在学术界，有人制造柔性机器人，皱纹结构让它更加灵活。有人控制了石墨烯表面的皱纹，实现了特殊的力学、电学、催化性能。有人用激光控制材料定向起皱，成功让薄膜长出了 T J U 形状的皱纹。有人研究了泡泡破裂时的表面皱纹，发了篇 Science。他们还把那个帮忙吹泡泡的哥们放在了致谢的第一位。所以如果你想发顶刊，但科研水平不行，可以考虑学门手艺。别的不说，就说咱们大家最关心的豆皮，皱纹控制的更多，做出来的辣条也更加入味。

从我们工作室小伙伴喝那碗汤到今天，我研究了这么久的皱纹，到最后自己头上也多长了几条皱纹。但我理解了皱纹的规律，学习了皱纹的方程，还吃了很多双皮奶。嗯，好吃。这件事的畅爽和快乐让我的眼角也笑出了几条皱纹，负负得正，等于皱纹抵消了。
